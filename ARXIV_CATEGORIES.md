## Tips for choosing categories

1. **Start broad, narrow over time.** Set 3~5 categories with weight 3 each, watch the briefing for a couple weeks, then tighten.
2. **Mix sizes.** A high-volume category (`cs.LG`, `cs.CV` — 1000+/wk) plus a low-volume one (`cs.HC`, `eess.IV` — ~100/wk) gives both depth and diversity.
3. **Weight = bandwidth.** Categories you genuinely read every day get higher weight (5~7); categories you skim get lower (2~3).
4. **Check overlap.** `cs.AI` and `cs.LG` overlap heavily. Same with `stat.ML` and `cs.LG`. Pick one or accept duplicates.

## Common workflow presets

```bash
# AI/ML researcher
TRENDS_ARXIV_CATEGORIES="cs.LG:5,cs.CV:3,cs.CL:3,cs.AI:2"

# Medical imaging / clinical AI
TRENDS_ARXIV_CATEGORIES="eess.IV:5,cs.CV:3,cs.HC:2,q-bio.QM:2"

# Robotics
TRENDS_ARXIV_CATEGORIES="cs.RO:5,cs.AI:3,cs.LG:2,cs.CV:2"

# HCI / UX research
TRENDS_ARXIV_CATEGORIES="cs.HC:5,cs.CY:3,cs.AI:2,cs.SI:2"

# Security
TRENDS_ARXIV_CATEGORIES="cs.CR:5,cs.LG:2,cs.NI:2"

# Computational biology
TRENDS_ARXIV_CATEGORIES="q-bio.QM:4,q-bio.GN:3,q-bio.BM:3,stat.AP:2"
```
