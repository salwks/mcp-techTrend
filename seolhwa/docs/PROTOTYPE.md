# 설화록 — 1단계 비주얼 프로토타입

개발계획서 27장 1단계. **3D 환경 + 2D 캐릭터 조합이 성립하는지**와 **스타일**을 검증한다.
게임성(조사·전투·사건)은 이 단계의 범위가 아니다.

## 확정된 방향
- 카메라: 옥토패스 트래블러식 **고정 시점**. 카메라는 회전하지 않고 비스듬히 내려다보며 따라간다. 구역마다 각도와 거리만 연출로 바뀐다.
- 이야기 중심 RPG. 3D의 역할은 "이야기의 무대"다. 조명, 구도, 안개, 밤과 낮이 핵심이다.
- 아트: **민화·옛 이야기책 삽화풍**. 먹선 윤곽, 한지 질감, 채도를 낮춘 오방색(적·청·황·백·흑). 사실주의가 아닌 "살아 움직이는 이야기책".
- 캐릭터는 **컷아웃(부위 조합) 애니메이션** 방식으로 만든다. 본 제작에서 Spine 같은 뼈대 애니메이션으로 옮길 수 있는 구조다.

## 무대 (작은 조선 산골 마을)
- 남쪽(카메라 쪽)이 마을, 북쪽이 산. 플레이어는 마을에서 개울 다리를 건너 굽은 산길을 올라 고갯마루의 서낭당까지 갈 수 있다.
- 마을: 초가집 여러 채, 기와집 1채, 돌담, 싸리 울타리, 우물, 장독대, 정자와 느티나무, 논, 개울과 돌다리.
- 산길: 소나무 숲, 경사와 높낮이, 바위, 안개.
- 숲 가장자리의 외딴 초가집(오누이의 집 예정지) — **안으로 들어갈 수 있는** 실내 검증용.
- 고갯마루: 서낭당(돌무더기와 오색 천을 단 나무), 호랑이 한 마리(크기감 검증용, 대기 동작만).

## 검증 체크리스트 (계획서 25장 + 고정 시점 반영)
1. 3D 공간 안에서 2D 캐릭터가 자연스럽게 보이는가
2. 캐릭터 방향 전환(4방향)이 고정 시점에서 충분한가 — 정면 1장 방식(A)과 비교
3. 2D 캐릭터와 3D 환경의 크기감(사람·아이·호랑이·집·나무)
4. 깊이 방향(화면 위아래) 거리 판단이 가능한가 — 발밑 그림자
5. 건물·나무에 가려졌을 때 읽기 쉬운가 — 실루엣, 가리는 물체 반투명
6. 실내에서도 자연스러운가 — 지붕과 앞벽 걷어내기, 카메라 근접
7. 3D 조명·그림자가 2D 캐릭터와 어울리는가 — 낮, 해질녘, 밤(초롱불)
8. 높낮이(산길)가 고정 시점에서 읽히는가
9. 틸트시프트·블룸·한지 질감이 "이야기책" 분위기를 만드는가
