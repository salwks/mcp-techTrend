# 설화록 — 스토리보드 작성용 브리프 (2026-10-04)

이 문서 하나만 읽고 스토리보드를 쓸 수 있게 정리했다. 개발 현황(이미 만든 무대)과 예정 사항, 이야기 작성 규칙, 스토리보드에 바라는 결과물을 담았다.

---

## 1. 게임 한 줄 소개
**1870년 무렵의 가상 조선을 나그네로 떠돌며, 전래설화가 실제 '사건'으로 벌어지는 고을들을 조사하고 해결하는 이야기 중심 RPG.**
- 장르: 탐험 → 사건 발견 → 조사(단서·규칙 파악) → 대응(전투 또는 지혜) → 해결 → 지역 변화.
- 플레이어: 이름 없는 나그네(환도와 활을 쓰고, 사건 기록 책자를 들고 다님).
- 핵심 재미: 설화 속 존재(호랑이·도깨비·여우·구렁이·원귀…)에게는 **규칙**이 있다. 조사로 규칙을 알아내면 싸우지 않거나 더 쉽게 이기는 길이 열린다.

## 2. 보는 방식 (화면 연출 전제)
- **3D 지형 + 2D 캐릭터.** 옥토패스 트래블러처럼 카메라는 회전하지 않고 비스듬히 내려다보며 따라간다. 장소마다 각도·거리만 연출로 바뀐다.
- 아트: **민화·옛 이야기책 삽화풍** — 먹선 윤곽, 한지 질감, 채도를 낮춘 오방색, 틸트시프트(미니어처 느낌), 안개.
- 낮/해질녘/밤(초롱불), 날씨(맑음·흐림·비·안개·눈·강풍)가 있다. 날씨는 **지역(기후대)별 차이**다: 남부·중부는 해와 비, 북부는 추위와 눈, 고산은 늘 눈, 제주·해안은 바람과 비.
- 고을에 들어서면 화면 위쪽 가운데에 지명이 흰 글씨(검은 테두리)로 떴다 사라진다. 건물에 들어가면 같은 자리에 건물 이름이 뜬다. 그 밖의 한글 표기는 화면에 두지 않는다.
- 지도: M = 도시 지도, Tab = 권역 지도 → 전국 지도(확대·축소).

## 3. 이야기 작성 규칙 (반드시 지킬 것)
1. **원작 제목을 게임 안에서 쓰지 않는다.** 플레이어가 보는 것은 '사건'뿐이다. 예: 「해와 달이 된 오누이」 → 사건 기록 제목 「산길의 실종」.
2. **설화 지역 등급**(원본 명세서 §22)을 따른다.
   - A+ 지역·지형 자체가 설화(설문대할망 ↔ 제주)
   - A 전승지가 명확(아랑 ↔ 밀양, 장화홍련 ↔ 철산, 은혜 갚은 꿩 ↔ 치악산, 춘향 ↔ 남원)
   - B 작품 배경·강한 지역전승(심청 ↔ 황주·장산곶, 우투리 ↔ 지리산)
   - C 연고지 주장 여러 곳 — 게임에서 "여기가 진짜"라고 선언하지 않는다
   - D 전국형 민담(호랑이와 곶감, 혹부리 영감, 도깨비방망이 등) — 특정 고을에 고정하지 않고 **환경이 맞는 곳**에 둔다
3. **D급 배치 규칙**(§23): 호랑이 = 산지·고개·깊은 숲 / 도깨비 = 오래된 나루·폐가·주막·산길·장터 외곽 / 귀신 = 읍성·폐가·무덤·나루·객사·버려진 관아 / 용왕·수중 = 큰 강·깊은 소·바다·큰 나루.
4. **한양에는 특정 전래동화를 고정하지 않는다.** 한양은 소문·야담·도시괴담·정보의 허브(오성과 한음, 강감찬, 바리데기 같은 야담·무가는 '떠도는 이야기'로).
5. **시대 충돌로 쓰지 않는 것**: 금도끼 은도끼·토끼와 거북(근대 이솝 유입), 박달재(1948 가요 이후 각색). 혹부리 영감은 1915년 교과서 문장을 피한다.
6. 고증은 참고용이다. 정확한 재현보다 "그럴듯한 조선"이 우선이다.
7. 대사는 짧게 끊고, 장면마다 플레이어가 직접 움직이는 구간을 둔다. 사건 하나 30~45분.
8. 결말은 2~3갈래로, 차이를 분명히(처치 / 함정 / 물러나게 함 등). 결말에 따라 **지역이 바뀐다**(잔치, 장꾼 귀환, 서낭당 공양, 밤의 울음소리 등).

## 4. 이미 만든 사건 견본: 「산길의 실종」 (원작: 해와 달이 된 오누이)
웹 프로토타입에서 끝까지 동작했다(Godot 이식은 아직). 스토리보드 양식의 기준으로 삼는다.
- 겉 사건: 떡 팔러 고개를 넘은 어미가 사흘째 안 돌아옴. 외딴집에 오누이만 남음.
- 실제: 고개의 호랑이가 어미를 해치고 그 옷과 목소리를 흉내 내 아이들을 노림.
- 호랑이의 규칙(조사로 얻는 지식): 먹이 집착 / 목소리 흉내 / 앞발을 밀가루로 희게 칠함 / 나무를 탐(미끄러운 나무는 못 탐) / 고갯마루 너머가 영역.
- 흐름: 도착 → 소문(주모·이웃·포수·오누이 중 아무나) → 오누이 → 산길 조사(떡 3곳, 치맛자락, 핏자국, 발자국, 서낭당 앞 빈 광주리) → 첫 조우(호랑이가 물러남) → 마을 추가 조사(방앗간·포수·기름집·헛간·큰 나무) → 밤, 호랑이가 어미 옷을 걸치고 문을 두드림.
- 해결 3갈래: A 마당에서 처치 / B 참기름 바른 나무 함정 → 기절한 호랑이와 전투 / C 경고 + 떡으로 유인 + 횃불로 영역 밖으로 몰아냄(싸우지 않음).
- 결과: 잔치·장꾼 귀환 / "나무 위 오누이" 이야깃거리 / 밤이면 먼 울음, 서낭당에 떡 공양. 공통으로 오누이에게 어미 소식을 전하고 마을이 아이들을 거둠. 보상: 새 해결 수단 "짐승의 흔적 읽기".

## 5. 전투 (웹 프로토타입 완료, Godot 이식은 아직)
- 단순하고 읽기 쉬운 전투: 2D 자세만 보고 공격을 예측(몸을 낮춘다 → 멈춘다 → 돌진).
- 플레이어: 환도 3연타, 모아 베기, 구르기, 방어, 활(12발), 떡 던지기.
- 적의 규칙을 이용하면 쉬워짐(떡을 먹는 동안 뒤에서 기습 2배, 영역 밖으로 나가면 쫓지 않음, 체력이 낮으면 물러남).
- 결말: 처치 / 물러나게 함 / 도망 / 패배.

## 6. 무대 — 지금까지 만든 것 (Godot, 실측 지형 기반)

### 6.1 세계 구조
- **대표 도시 8곳**(문화권마다 하나, 설화가 몰린 곳)은 완전히 지었다. 둘레 **위성 마을**은 같은 지형 안에서 걸어서 간다.
- 도시와 도시 사이는 **노정**(이동 스테이지) 10개로 잇는다. 노정에는 고개·나루·주막·성황당이 있는 **길목 쉼터**가 순서대로 있다.
- 원본 명세서의 **거점 88곳은 모두 전국 지도에 있다.** 지은 곳 31곳, 나머지 57곳은 지도·이정표·소문으로만 존재(나중에 필요하면 짓는다).
- 정체성 층: 시대(조선 1870) → 기후대(남부·중부·북부·고산·해안섬) + 문화권(호남·영남·기호·관동·해서·관서·관북·탐라: 집 모양·지붕·담·풍습·말씨) → 권역(수계·분지) → 고을(입지 유형: 읍치·평야·강가·산악·고개·사찰 아래·해양·섬·도읍) → 장소(건물).

### 6.4 사람과 짐승 (돌아다니는 NPC, 대화 없음)
- 사람 14종: 선비, 상인, 보부상, 관리, 승려, 보살, 뱃사공, 해녀, 농부, 아낙, 목동, 도롱이 입은 사내(비 올 때), 나그네, 무당 (+ 기존 마을 사람 9종).
- 짐승 6종: 소, 말, 개, 암탉, 수탉, 갈매기.
- 고을 성격표에 따라 배치: 종로·장터는 붐비고, 상점엔 상인, 나루엔 뱃사공, 우물엔 아낙(제주는 해녀), 향교엔 선비, 절엔 승려, 들엔 농부와 소. 비 오면 줄고, 밤엔 주막 말고는 들어감.
- 아직 없음: 앉는 동작, 소 끄는 사람·말 탄 사람, 짐승 앞뒤 모습.

## 8. 스토리보드에 바라는 것

1. **큰 줄기(메인 아크)**: 나그네가 왜 팔도를 떠도는가, 8개 대표 도시를 어떤 순서·동기로 지나는가(시작은 남원 권역), 마지막은 어디서 어떻게 맺는가. 한양은 소문·정보 허브로서 역할.
2. **대표 도시별 주 사건 1~2개** — 「산길의 실종」과 같은 양식으로:
   - 사건 기록 제목(원작 제목 금지) / 원작과 등급
   - 겉 사건 / 실제 벌어진 일
   - 존재의 규칙 3~5개(조사로 얻는 지식, 단서와 출처)
   - 장면 순서(장소는 6.2 표의 실제 장소를 쓸 것), 첫 조우
   - 해결 2~3갈래와 필요한 준비·지식
   - 결말별 지역 변화, 보상(새 해결 수단)
3. **장소 유형 사건 틀 20~30개(D급)**: 틀 이름, 붙는 자리 유형, 등장 존재, 규칙 1~2개, 짧은 흐름, 결말 2갈래. 노정 쉼터 사이에 재사용한다.
4. **길 위 만남 틀 15~20개**: 보부상 흥정, 길 잃은 아이, 비 피하는 나그네, 산적, 주막 소문, 장날 등 — 짧고 반복 가능하게, 지역·날씨·밤낮에 따라 변주.
5. **소문 목록**: 각 도시 주막·장터에서 들을 수 있는 다른 고을 소문(지도에만 있는 거점 57곳으로 이어지는 떡밥 포함).
6. 표기: 장면마다 [장소 / 시간대 / 날씨 / 등장인물 / 플레이어 행동 / 대사(짧게) / 연출 메모(카메라·컷신·소리)].
