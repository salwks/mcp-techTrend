## 추가 지시

1. **시험 저장 경로 버그와 실제 저장 덮어쓰기 위험을 가장 먼저 고친다.** 고치기 전에 실제 저장을 백업하고, 고친 뒤 시험이 실제 저장에 더는 쓰지 않음을 확인한다. (2단계 앞 — 이번에 수행)
2. 오누이 **진행 중인 옛 저장은 그 사건을 이어** 하고, 끝난 뒤에는 새 메인 구조에 자연스럽게 합류한다. (3·5단계)
3. 춘향 진입에서 **오누이 완료 의존을 없애고**, 옛 저장 호환을 확인한다. (3단계)
4. ~~v3.2의 참기름 디딤돌 갈래는 지우지 않는다. v3.4와 대조해 검토한 뒤 남길지 정한다.~~ → **아래 '참기름 기준(사용자 확정, 2026-10-16)'을 따른다.** (5단계)
5. **9m 끈 순간이동을 없애고**, 플레이어 조작과 카메라가 자연스러운 방식으로 바꾼다. (5단계)

## 참기름 기준(사용자 확정, 2026-10-16 — 추가 지시 4를 대신한다)

> 이력: 같은 날 먼저 적은 '결정 정정 — 참기름'(플레이어 참기름 갈래는 지운다 · 참기름은 어떤 식으로도 강조하지 않는다, 커밋 8de4eea)은 전달 과정에서 지나치게 강하게 옮긴 것이어서 아래 기준으로 바뀌었다.

1. 오누이 시나리오의 기준은 **Onui v3.4**(`Seolhwarok_Onui_Playable_Script_v3_4.md`)다.
2. 누이가 **참기름을 발랐다고 말해 범을 속이는 원작 장면은 유지**한다(v3.4 F3411, 대화 카메라 v1.1 '나무 장면').
3. 참기름을 **필수 준비물·최우선 아이템·특별한 정답**으로 다루는 설계는 버린다.
4. 기존 참기름 사용 갈래는 v3.4와 대조해 갈래마다 **유지 / 수정 / 제거**로 분류한다. **한꺼번에 임의로 지우지 않는다.**
5. STORY.md·아이템 목록·소품 목록·v2.4·v3.2는 **과거 설계 이력으로 보존**하고, 참기름 중심 설계가 현행 기준이 아니라는 **주석**을 단다.
6. 남원 코드의 참기름 자리(약 24곳)를 **기능별로 나누어**, 실제 수정 대상과 원작 장면 유지 대상을 구분한다.
7. 갈래나 아이템을 없애려면 **기존 저장과 사건 진행**(플래그·기록 항목·소지품·결말)에 주는 영향을 먼저 검토한다.

- 원작 장면과 게임 안 아이템 활용 가능성은 **구분해서** 다룬다.
- 분류·영향·제안: `seolhwa_godot/docs/reports/chamgireum-audit.md`. 시나리오 갈래 변경은 **따로 승인**을 받은 뒤에만 구현한다.
