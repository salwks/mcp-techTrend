# 1. 게임 정체성과 핵심 플레이 원칙

한 문장: 조선의 3D 마을·산길을 2D 설화 인물들과 돌아다니며, 탐험→발견→조사·대화→직접 개입→그 결과를 『설화록』에 기록하는 오픈월드 RPG.

- 주 시점은 고정 사선 카메라. 영화적 연출은 현재 카메라와 공간의 연속성을 깨지 않는 짧은 보조 쇼트만.
- 시나리오의 핵심 정보는 행동·소리·물건·인물 위치로 전달. 작은 얼굴 표정에 의미를 의존하지 않는다.
- 대화를 완료하면 이동·시점·E 상호작용이 즉시 복원되고, 같은 NPC를 다시 말 걸어도 사건이 중복되지 않는다.
- 메인 시작은 이겸의 편지 단 하나. 오누이는 자유 발견 가능한 남원 북쪽 독립 설화; 메인을 막지 않는다.
- ‘계획대로 자동 재생’보다 플레이어가 목표·위험·결과를 이해하고 움직이도록 한다.

# 3. 공통 카메라 시스템 — 대화·조사·컷신

| 카메라 상태 | 구도 | 전환/유지 | 복귀 |
|---|---|---|---|
| EXPLORE | 현재 쿼터뷰 중심, 주인공과 길 읽히게 | 기존 이동 카메라 유지 | 해당 없음 |
| TALK_TWO | 화면 왼쪽 40%·오른쪽 60%에 주인공/NPC; 앞뒤 겹침 금지 | 0.45~0.75초 ease; 대화 동안 유지 | 0.5초 플레이 시점 복귀 |
| TALK_FOCUS | 상대만 한 번 강조; 얼굴 클로즈업 아닌 동작·손·소품 중심 | 중요 문장 전환 0.3초, 2~3초 유지 | TALK_TWO로 복귀 |
| INSPECT | 월드의 대상 소품이 프레임 중앙 1/3에 보이는 고정 구도 | 0.35초 진입, 통상 1.5~3초 | 0.35초 복귀 |
| VISTA | 기존 고정 시점에서 거리·높이만 천천히 확장 | 2.5~4초, 입력 차단 시 스킵 허용 | 0.6초 원위치 |
| THREAT | 문틈·그림자·발소리 위치 중심; 직접적인 정체 스포일러 금지 | 1~2.5초 + 짧은 정적 | 플레이 조작권 회복 |

카메라 선택 로직: ① 상호작용 대상 화면 좌표 획득 → ② 머리/몸통 가림 비율 검사 → ③ 좌/우 오프셋 후보 3개(기본·좌·우) 평가 → ④ 배경 가림 최소 후보 채택 → ⑤ 화면 가장자리·충돌 등 실패 시 EXPLORE 확대 없는 안전 구도로 폴백. 실제 엔진 구현은 카메라 충돌/투영방식에 맞춰 조정.

# 4. 대화 시스템 재설계 — 보이는 품질 기준

- E 접근: 2.2m 이내 NPC 이름+“대화” 표시; 별도 사건 진행 가능 때만 작은 말풍선 표시.
- 첫 입력: 다른 이동 입력 정지, NPC 진행 동작/시선 정리, 카메라 정렬 후 첫 대사 출력. 카메라 정렬 대기 상한 0.8초.
- 화면: 말하는 사람 이름, 본문 최대 2~3줄, ‘E 다음’; 선택 시 선택지와 ‘↑↓/확인’ 분리. UI가 캐릭터 발/소품을 가리지 않도록 상단 여백 확보.
- 대화 진행: 텍스트 출력 중 확인은 즉시 문장 완성, 완성 후 다시 확인은 다음 문장. 과도한 입력으로 대사 건너뛰지 않음.
- 닫기: 스크립트 이벤트·UI modal·카메라 override·입력 잠금 해제 순서 명시; 게임 재개 첫 프레임에 중복 E 발동 금지.
- 실패 폴백: NPC가 가려지거나 2인 구도가 불가능하면 캐릭터를 강제로 이동시키지 말고 카메라 중심만 보정.
- 최소 재진입 테스트: 대화 10회 반복, 도중 저장·로드, 선택지 닫기, NPC와 물체가 겹친 위치, 연속 E 입력.

|---|---|---|
| 지도 열기 | M | 현재 플레이어 위치를 화면 중간에 표시, 지역 지도의 마지막 확대율 복원 |
| 줌 | 마우스 휠 또는 +/- | 커서 아래 월드 좌표를 고정한 채 연속 줌. 0.18초 보간, 최소/최대 영역 한계 명확 |
| 지도 이동 | 좌클릭 드래그 | 마우스 드래그 시 화면 이동. 클릭과 드래그는 5px 임계값으로 구분 |
| 행선지 선택 | 알려진 장소 표식 클릭 | 장소명·거리/경로 추정·이동 방법 작은 팝업 |
| 웨이포인트 | [목적지 표시] | 월드에서 방향 안내 표지(원거리 표식) 표시; 언제든 변경/해제 |
| 역마 자동 이동 | [역마 이동] | 현재 위치에서 승마 가능한 큰길 접근점을 계산. 접근 전에는 [여기서 탈 수 없음]+가장 가까운 탈 수 있는 지점 안내 |
| 빠른 이동 | 조건 충족한 거점의 [빠른 이동] | 미방문 구간 잠금 이유를 명확히 표기. 웨이포인트 지정과 빠른 이동 구분 |
| 이동 중 | 중지 / 건너뛰기 | 필수 사건 전·도착 전에는 안전 하차; 진행 세이브를 망치지 않음 |

필수 결정: “지도상 아무 점”은 기본적으로 핀/길찾기이며, 자동 역마는 ‘길 그래프에서 도달 가능하고 이미 알려진 거점’ 또는 검증 가능한 길목만 제공. 오프로드 임의 좌표까지 말이 질주한다고 보장하지 않는다.

# 8. 오누이 설화의 지위와 재작성 규칙

오누이 사건은 메인 1부의 조작 튜토리얼로 시작하지 않는다. 북쪽 전주길 고개를 탐험한 플레이어가 선택적으로 발견하는 독립 사건이다. 이겸 도입·편지 조사·기록책과 지도를 메인 1부에서 배운 플레이어라면 동일한 튜토리얼을 중복 표시하지 않는다.

| 구간 | 문제 / 개편 기준 |
|---|---|
| 주막 소문 | 주모가 오누이 사건과 이겸 메인 모두 강제 연결하는 구조는 분리. 독립 사건 루머로만 등장 가능 |
| 첫 방문 | 아이들과 최소 1회 공동 행동; 대화·표정만으로 호감 형성 금지 |
| 피신 | 아이들을 마을로 데려가려는 플레이어의 합리적 선택을 반드시 제공. 안전한 낮 피신 성공을 금지할 이유가 없다면 대체 결말을 승인해야 함 |
| 위험 발견 | 플레이어가 직접 확인한 단서/불확실한 전언을 기록책에서 구분. 관객에게만 보이는 과거 컷신의 정보가 추리 정답이 되지 않도록 |
| 밤 사건 | 이미지에 맞는 실루엣/문 그림자/오누이 위치 중심. 누이의 핵심 지혜는 빼앗지 않음 |
| 전투 | 시간 벌기의 성과가 아이들의 이동·포수 개입·주인공 부담에 반영. 체력만 높은 무적 호랑이처럼 느껴지면 실패 |
| 결말 | 원작 결말 보존 루트와 실제 피신 성공 시 대체 루트는 ‘승인 대기’ 두 개로 관리; 무리한 철로식 강제 실패 금지 |

# 10. 시나리오·데이터 연결 표준

각 장면의 제작 카드에는 SCENE_ID / region_id / world_anchor / required_state / input_enabled / camera_profile / on_enter / dialog_ref / interactables / exit_condition / checkpoint / failure_fallback / skip_policy를 기입한다.

상태 예시: OPENING_LETTER_SEEN, OPENING_WRITING_COMPARED, OPENING_FIRST_TALK_DONE, MAP_WAYPOINT_SET, RIDE_FIRST_ARRIVAL, FOLK_ONUI_OFFERED, FOLK_ONUI_ACCEPTED. 저장은 컷신 재생 플래그와 실제 사건 완료 플래그를 별개로 보관한다.

# 12. 제작 승인 전 결정해야 할 질문

- 오누이 사건의 ‘피신 성공’ 대체 결말을 허용할지: 원작 결말 유지 원칙과 플레이어 합리적 행동의 충돌 해결 필요.
