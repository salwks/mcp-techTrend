# 01. 이 문서에서 확정하는 것

메인 시작을 이겸의 거처로 통일한다. 서장 첫 15분은 편지를 받고 의심한 후 남원 주막에서 행적을 추적하여 지도에 여원재 방면 목적지를 직접 지정하는 시점까지다. 운봉 이동과 백운 대면은 후속 구간. 오누이 사건은 남원 북쪽 전주길 고개에서 선택적으로 발견하며 튜토리얼 필수 경로가 아니다.

주요 원칙: 이동·조사·대화·지도는 설명 창이 아니라 사건의 맥락으로 배운다. 프레임 안에서 말하는 인물의 얼굴/실루엣을 가리지 않는다. 컷신마다 카메라 목표·재생 시간·입력 반환 조건을 분명히 정한다.

# 04. 공간·동선: 구현 지시

신규 공간 A=이겸의 숙소: 남원 읍내 보행 가능 구획에 붙인 1층 소형 사랑방+마당, 책상·장부·수선 신발·마른 붓·문을 조사. 주요 상호작용이 화면에 한꺼번에 보이지 않게 자연스럽게 2~6m 분산 배치. NPC가 문을 막지 않도록 문 앞 2.5m 여유.

신규 공간 B=솔잎 주막: A에서 큰길 기준 도보 60~110초 거리(초기 후보; 플레이 실행 후 확정). 기존 주막 키트 활용. 좁은 NPC 군집·큰 초가지붕이 2D 캐릭터를 가리지 않게 전면 3~4m 비움; 손님 2명과 장부 사이 2~5m.

A→B 동선: 지붕/담장을 뚫고 단축하는 경로가 아닌 골목→대로→주막 간판. 시야가 막히면 소문 소리와 골목 끝 조명으로 길을 유도. 전주길 고개(오누이)와 여원재(메인)는 도시 밖 갈림길에서 별도 표기.

좌표 정책: 새 A/B의 수치는 placement JSON과 도로 충돌을 검증한 뒤에만 확정. 기존 [-2952,184]는 현행 새 게임 출발 좌표이지 거처라는 의미가 아님. 개발 도중 씬만 그럴듯하게 두고 nav/interaction/collision 연결을 생략하지 말 것.

| 대사·정보 | 기록: “확인된 것은 이겸의 마지막 숙박. 고갯길 소문은 아직 전해 들은 말.” / 시스템 문구: “목적지를 표시했다. 직접 가거나 역마를 이용할 수 있다.” |
| 완료·저장 | WAYPOINT_SET + M_OPEN_SEEN; 15분 시점 이후 역마 사용 온보딩 준비. |
| 구현 ID/유의 | MAP_FIRST_OPEN / WAYPOINT_SELECTED / 우연히 잘못 클릭시 재지정 허용 |

# 06. 지도·웨이포인트·역마의 인터페이스 계약

| 단계 | 조작 | 반드시 구별할 상태 |
|---|---|---|
| 1 지도 열기 | M; 지도가 현재 위치를 중심으로 열림 | 월드 일시 중지 / 이벤트 진행 중 입력 막음 |
| 2 확대·축소 | 휠=커서 중심 연속 배율; 드래그 이동 | 도시/권역/전국 계층은 범위 경계에서 자연스럽게 안내 |
| 3 장소 선택 | 알려진 여원재 방면 마커 클릭 | KNOWN=위치 정보만; VISITED=방문 완료 |
| 4 웨이포인트 | 「목적지 설정」 클릭, 단일 활성 마커 | 설정 자체로 자동 텔레포트 금지 |
| 5 역마 이동 | 이동 가능한 지점에서 「역마 타기」 혹은 단축 상호작용 | 장거리 경로와 하차 규칙은 ride_net 재사용 |
| 6 빠른 이동 | 지도에서 방문 거점 선택 시 가능 조건 표시 | 미방문 거점은 불가 사유 명시 |

# 07. 공통 튜토리얼 트리거 / 충돌 예방

| 안내 | 최초 등장 | 완료 조건 |

| WASD 이동 | OP00 조작 반환 | 3m 이상 실제 이동 |

| E 대화 | 심부름꾼 또는 주모 접근 | 대화 시작 후 1줄 재생 |
| R 기록책 | 첫 확인 정보 등록 | 실제 열고 닫음 |

| 웨이포인트 클릭 | 지도에 목적지 표기 후 | 목적지 활성화 |
| 역마 / 빠른 이동 | 후속 구간의 이동 가능한 지점 | 실제 승차/조건 충족한 빠른 이동 |

처음부터 전투 키·역참 목록을 모두 띄우지 않는다. 가려진 프롬프트, 동시에 뜨는 힌트, 대화 뒤 잔류한 입력 잠금은 우선 버그로 취급. 모든 핵심 안내는 행동 완료 시 SEEN, 건너뛰기나 시간 경과만으로 완료 처리하지 않는다.

# 08. 개발 산출물 / QA 승인 기준

필요 구현: (1) NEW_GAME 새 시작점 거처 배치 (2) 방 상호작용 3종+편지 비교 UI (3) 신규 심부름꾼·주모 데이터 및 대화 (4) 타이틀 인게임 오버레이 (5) 지도 직접 장소 선택+웨이포인트 (6) 거처↔주막 출입구·길 검사 (7) 저장/복구 체크포인트.

| 테스트 | 통과 기준 |
|---|---|
| 첫 15분 진행 | 새 저장 3회: 시작 → 편지 → 주막 → 목적지 지정 진행 중단 없이 성공 |
| 대화 가림 | 고정 화면 크기 1920×1080, 1280×720: NPC가 주인공/지붕에 주요 발화 중 가리지 않음 |
| 키 입력 | 대화 종료 후 WASD 즉시 복귀; E 중복으로 2개 UI 안 열림 |
| 저장 재개 | 편지 읽기 직후, 비교 중, 주막 대화 후, 지도 지정 후 각 재개 |
| 지도 | 최소/중간/최대 배율에서 커서 중심 유지, 클릭 정확도, 마커 갱신 |
| 미방문 이동 제한 | 웨이포인트는 설정 가능하지만 미방문 지점으로 무료 순간이동 안 됨 |
| 기존 설화 보호 | 오누이 지역/플래그/이벤트 경로 기존 유지, 독립 진입 확인 |
| 성능·장면 | 카메라 전환 중 지형 스트리밍/캐릭터 팝인/충돌 없음 |
