# 『설화록』 지도·웨이포인트·역마 통합 UX 상세 명세

v1.3 | 2026-10-15 | 최초 15분 플레이 시나리오 v1.2 후속 | 개발 지시·검증 기준

적용 범위: Godot 4.7 / 3D 지형·2D 인물 / PC 키보드·마우스 우선. 기존 맵·이동 자산은 보존하며, 코드 변경과 콘텐츠 변경을 분리한다.

# 00. 설계 결정 및 비결정

- 결정 1 — 지도(M)는 탐험 중 어디서나 열고 지도에서 목적지를 바로 선택한다. 마부·깃발 접근은 선택의 필수 선행조건이 아니다.
- 결정 2 — 웨이포인트(길 안내), 말 자동 이동(현실 이동), 역참 빠른 이동(조건부 장면 생략)은 세 개의 서로 다른 행동이다.
- 결정 3 — 처음 방문하는 여원재는 지도에서 표적 지정·말 이동은 허용하되 빠른 이동은 잠근다. 미발견 장소는 정보에 따라 목적지 선택 가능 범위를 구별한다.
- 결정 4 — 지도 조작을 게임 시스템 학습의 연장으로 설계한다. 카메라 복귀·입력 충돌·오버레이 중첩도 합격 기준에 포함한다.
- 비결정 — 실제 Godot 실행 검증은 수행하지 않았다. 좌표·도로 연결의 런타임 안정성, 최종 거리·소요시간은 코드 실행 및 플레이테스트에서 측정한다.

# 01. 실제 저장소 기준 현황과 차이

| 대상 | 현재 코드에서 확인한 상태 | 변경 방향 |
|---|---|---|
| region_map.gd | M: 지도 / Tab: city·all·nation / 휠 1.15배 확대·축소, 커서 중심 보정과 드래그 코드 존재 | 줌 기능을 새로 만든다고 단정하지 않음. 실제 불편의 원인 진단: 확대 한계·레벨 전환·관성·표지 충돌 |
| station_keeper.gd | 마부·길목 깃발 E → region_map.open_pick() → 지도에서 갈 곳 선택 | 일반 지도에서 목적지 선택 기능 분리·상시 노출 |
| region_map.gd open_pick | 선택 전용 pick 모드, warp/ride 전환 R, 같은 항목 두 번 클릭하면 확정 | 지도 일반 모드에서 waypoint 선택 → 방법별 행동 버튼 고정 |
| horse_ride.gd | 도로망 자동 기승, 성문·마을·사건 전 자동 하차, 수동 정지 기능 | 웨이포인트 목적지에 ride_net 경로를 연결하고 경로 갱신·중단 처리 |
| fast_travel.gd | 이미 방문한 거점과 완료된 노정에 따라 빠른 이동 제한 | 현재 조건 유지, 잠금 사유를 지도 상세 패널에 명시 |
| waymarks.gd | 도로 거점 기반 길목 깃발 배치·발견 상태 공유 | 깃발은 세계 속 안내 및 이동 보조로 유지, 지도 강제 진입 절차 제거 |

저장소 기준: salwks/mcp-techTrend, branch claude/youthful-gauss-d0fxzv, seolhwa_godot/. 신규 기능은 현행 코드와 차이 검토 후 추가한다.

# 02. 사용자가 느끼는 지도 조작 규칙

| 입력 | 행동 | 예외 / 피드백 |
|---|---|---|
| M | 지도 열기 / 닫기 | 첫 지도 열기 시 1회 안내만 표시; 장면 전환 중 열림 차단 |
| 마우스 휠 | 커서 지점을 고정한 연속 확대·축소 | 축척 경계에서 중심이 튀지 않아야 함; 자연스러운 보간 0.12~0.20초 목표 |
| 좌클릭(지점) | 표지 선택 → 상세 카드 | 선택만으로 역마 출발하지 않음 |
| 좌클릭(빈 곳) | 임시 핀 제안 / 미지원 지형이면 근처 길목으로 보정 | 임시 위치와 보정된 실제 길 도착점을 서로 다른 심벌로 |
| 좌드래그 | 지도 화면 이동 | 최소 6px 이후 드래그 인식; 클릭 오인 방지 |
| 우클릭 | 현재 선택 해제 / 목적지 취소 메뉴 | 실수로 즉시 이동하지 않음 |
| Esc | 상세 카드→지도→게임 순서로 닫기 | 웨이포인트는 지도 닫아도 유지 |
| Tab | 지도 범위 도시↔권역↔전국 | 현재 중심·선택 목적지 최대한 유지; 강제 점프 최소화 |
| WASD / 화살표 | 지도 키보드 패닝·선택 이동 | 지도 열린 동안 캐릭터 걷기 금지 |
| Enter | 선택된 지도 카드의 기본 행동 수행 | 이동 실행은 별도 확인 후 확정 |

# 03. 지도 화면 레이아웃 (1920×1080 기준)

| 영역 | 위치 및 크기 목표 | 내용 |
|---|---|---|
| 메인 지도 | 좌측 0~1440px / 상단~전체 | 지형·지명·탐험 표지·웨이포인트·도로·경로 |
| 장소 상세 패널 | 우측 1440~1920px / 폭 480px | 지명·방문 여부·거리·이동 수단 3종·잠금 사유 |
| 상단 범위 컨트롤 | 상단 36px 안전 영역 이내 피함 | 현재 지역 / 도시·권역·전국 / 확대축소 안내 |
| 하단 컨트롤 힌트 | 하단 72~106px | M 닫기, 휠 축척, 드래그 이동, 선택·목적지 제거 |
| 현재 캐릭터 | 지도 위 독립 아이콘 | 항상 현재 위치/방향, 다른 마커보다 높은 우선순위 |
| 목적지 핀 | 현재 타깃 위치 고정 | 보이는 지도마다 재투영; 꺼진 범위에선 화면 가장자리 방향 힌트 |

화면 비율이 작은 경우 480px 패널을 축소·슬라이드 방식으로 전환한다. 텍스트 크기는 실제 게임 스크린샷과 함께 1080p/768p 모두 점검한다. 색만으로 발견 상태를 구분하지 않는다.

# 04. 줌·패닝 상세 UX와 교정 기준

- 4.1 확대는 마우스 커서 아래 지도 지점을 기준으로 수행한다. 확대 전후 대상 월드 좌표 오차 8px 이하(1080p 목표).
- 4.2 연속 휠 5틱, 10틱, 20틱 테스트에서 맵 중심이 갑자기 다른 마을로 이동하지 않아야 한다.
- 4.3 도시/권역 사이의 지도 레이어 전환은 화면 전체가 번쩍이거나 이전 중심이 초기화되지 않도록 한다. 가능하면 동일 중심 유지·0.15~0.25초 크로스페이드.
- 4.4 고도·가시성 때문에 지명이 너무 많으면 LOD 우선순위로 솎되 목적지 및 현재 위치는 절대로 솎지 않는다.
- 4.5 지도의 최소·최대 확대 한계를 실제 월드 크기와 화면 해상도에 따라 정의하고, 확대 불가 시 자연스럽게 멈춘다.
- 4.6 멀티 상태 충돌: 지도 위 말 이동 확인 창, 튜토리얼 창, 대화창이 동시에 입력을 받지 않도록 단일 모달 소유권 적용.

# 05. 웨이포인트 상태 모델

| 상태 | 의미 | 표시 / 다음 단계 |
|---|---|---|
| NONE | 현재 지정 없음 | 지도 클릭 대기 |
| PREVIEW | 지도 지점 임시 선택 | 목적지로 지정 / 다른 장소 선택 |
| ACTIVE | 게임 세계에 목적지 적용 | 미니 안내·지도 핀·거리 추적 |
| ROUTING | 큰길 이동 경로 계산 | 가능/불가능 사유 표시 |
| ON_RIDE | 말 자동 이동 중 | 목적지 거리·예상 도착·정지 가능 |
| ARRIVED | 목표 주변 안전 하차점 도착 | 웨이포인트 유지 또는 자동 해제 설정 |
| BLOCKED | 길 폐쇄·전투·노정 조건 미달 | 원인·대체 경로·도보 안내 |
| CANCELLED | 사용자가 목적지 제거 | 기존 표시·경로 정리 |

상태 분리 핵심: waypoint를 설정했다고 곧바로 역마나 빠른 이동이 시작되면 안 된다. 달성 상태는 save data에 저장해 재접속 시 보존한다.

# 06. 장소 선택 상세 카드 · 버튼 정책

| 유형 | 지도에서 목적지 지정 | 말 자동 이동 | 빠른 이동 |
|---|---|---|---|
| 알지만 미방문 고을/고개 | 허용 | 연결된 큰길·승마 가능 구역이면 허용 | 불가 — 미방문 |
| 방문한 역참/깃발 | 허용 | 허용 조건 충족 시 | 연결 노정·방문 조건 확인 후 허용 |
| 장·주막·산길의 이름난 곳 | 허용 | 가까운 진입 가능한 큰길까지 | 해당 지점 직접 빠른 이동은 기본 불가 |
| 전혀 모르는 지점 | 임의 핀 허용 여부를 기획 옵션으로 설정 | 도로 접근 경로가 확인된 경우만 | 불가 |
| 전투/대화/필수 컷신 중 | 지도 접근·핀 편집 제한 | 불가 | 불가 |

버튼 언어: [목적지 지정] [말로 이동] [빠른 이동] [취소]. 잠긴 버튼은 회색만 처리하지 말고 “이 역참을 아직 방문하지 않았습니다”처럼 이유를 표시한다.

# 07. 지도→역마 자동 이동 플로우

| 순서 | 플레이어 경험 | 내부 처리 / 실패 시 |
|---|---|---|
| 1 | M 지도 열기 | 플레이어 이동 및 전투 입력 일시 중단 |
| 2 | 여원재 주막 또는 고개 선택 | KNOWN/VISITED 및 도로 연결성 확인 |
| 3 | [목적지 지정] 선택 | ACTIVE 핀 표시, 지도 닫기 후 방향 표시 |
| 4 | [말로 이동] 선택 | 말 탑승 가능 위치 여부 및 ride_net 경로 확인 |
| 5 | 자동 이동 확인 | 현재 위치→가까운 유효 탑승 지점→목적지 전 안전 하차점 |
| 6 | 말 타는 연출 0.8~1.5초 목표 | 말이 없거나 진입 불가면 실시간 도보 안내; 자동 순간이동 금지 |
| 7 | 큰길 따라 자동 주행 | 경로와 사건 70~200m 전 감속 정책 재사용 |
| 8 | 여원재 어귀 정차·하차 | 거리 조건 + 안전성 검증, 목적지 갱신 |
| 9 | 도보로 사건 진입 | 이겸·백운 시나리오 진입 이벤트 확인 |

중요: 마부와 깃발은 보조 입구로 유지한다. 하지만 일반 지도에서 지정한 목적지로 가는 기능과 `station_keeper.open_pick()` 진입 조건은 분리해야 한다.

# 08. 역마 세 종류의 사용처 구분

- ① 웨이포인트 길 안내: 어디서든 설정 가능, 캐릭터는 직접 조작, 탐험·설화 자유도를 최대로 보존.
- ② 역마 자동 이동: 말에 올라 실제 도로를 주행하며 세계를 보여 줌. 지점 진입 전 하차, 사건·전투·지형상 장애물에 반응.
- ③ 역참 빠른 이동: 방문·노정 조건을 만족할 때만 화면 연출 후 도착. 시간과 플레이 비용을 줄이되 초행 모험은 건너뛸 수 없음.

# 09. 빠른 이동·말 이동·카메라 연출

| 이벤트 | 구도·워크 | 시간 목표 |
|---|---|---|
| 지도 열림 | 현재 플레이 카메라 정지 → 지도 한지 오버레이 페이드 | 0.20~0.30초 |
| 핀 지정 | 경로 미리보기 선이 순차적으로 나타남 | 0.25~0.40초 |
| 말 탑승 | 기본 사선 카메라에서 인물과 말이 겹치지 않는 와이드, 전방을 보여줌 | 0.8~1.5초 |
| 자동 주행 | 이동 방향 따라 완만한 yaw, 지붕 등 가림 방지 | 상시; 급회전 완화 |
| 사건 근접 | 카메라를 원래 시점에 수렴·감속·하차 | 1.0~2.0초 |
| 빠른 이동 | 지도 닫음→한지/먹 전환→거점 도착 카메라 | 2.0~3.0초 |
| 지도 닫기 | 열기 전 탐험 시점 복구 | 0.20~0.30초 |

컷신 연출 타이밍은 우선 목표값이며, 실제 입력 지연·멀미·가림에 대한 플레이테스트 후 재조정한다.

# 10. 최초 15분에 적용할 튜토리얼

| 조건 | 1회 안내 문구 | 완료 조건 |
|---|---|---|
| 주막에서 여원재 행선지 습득 | M — 지도에서 들은 장소를 확인한다 | 지도 열기 |
| 지도 첫 열기 | 휠 — 확대·축소  \|  드래그 — 지도 이동 | 실제 줌 1회 + 패닝 1회 (필수 진행 잠금은 아님) |
| 여원재 지도 표시 | 여원재를 선택하고 목적지로 지정한다 | ACTIVE waypoint == 여원재 |
| 지도 종료 | 목적지를 따라 길을 나선다 | 거리 안내 확인 |
| 말을 이용할 수 있는 큰길 | [말로 이동] — 큰길을 따라 자동 이동한다 | 말 이동 첫 성공; 원하지 않으면 도보 가능 |

튜토리얼 안내 자체가 목적지를 가리거나 지도 클릭을 방해하지 않도록 가장자리 배치. 한 번 수행한 조작은 저장 후 반복 안내하지 않는다.

# 11. 실패·예외 및 데이터 저장 계약

| 상황 | 기대 행동 |
|---|---|
| 목적지로 가는 길이 없음 | 핀은 남기고 “연결된 큰길 없음” 안내, 순간이동·경로 날조 금지 |
| 사건 발생으로 길이 막힘 | 자동 감속·안전 하차→현재 사건 상태 반영해 재탐색 |
| 주인공이 이미 목적지 옆 | “현재 위치와 같습니다” 알림, 무의미한 탑승 금지 |
| 전투 중 M 입력 | 보호 상태에서는 지도 열리지 않음 또는 명확히 일시 정지 정책 선택 |
| 자동 이동 중 저장 후 불러오기 | 안전한 인근 도로 노드로 복구, 이동 목표와 발견 상태 유지 |
| 다른 지도 축척으로 전환 | 핀·현위치·목적지 이름 유지 |
| 지도 닫는 동시에 E 입력 | 해제 직후 대화/말 상호작용 중복 실행 금지 |
