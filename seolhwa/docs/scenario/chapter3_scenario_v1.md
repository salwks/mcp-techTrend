| 장의 질문 | 이겸이 견주려던 압수본은 어디 있나 — 그리고 오늘 밤, 누가 그 기록을 없애려 하나 |

**사건의 진실(v5.8 §2).** 서리 조필성이 구휼미를 빼돌림 → 연옥이 알림 → 조필성이 장부를 고쳐 연옥에게 누명 → 연옥 병사 → 원본 반출 기록 한 장이 옛 창고 출입자 명부 뒤에 끼워져 봉인 → 연옥의 혼이 밤마다 창고 문 앞 → 조필성은 귀신 소문을 핑계로 기록을 없애려 함.

**메인 쪽 진실(v5.8 ⑦ + 사건 순서 C6·C7).** 떠돌이 퇴마 장사꾼이 도술책 '귀신 쫓는 장'을 읊다 신고돼 관아가 견본·납품표를 압수했다. 압수품 접수 기록은 **같은 옛 창고 명부 묶음**에 철해져 있다. 앞선 나들이의 이겸이 그 견본을 보고 갔다.

**이 밤에 걸린 기록 셋.**

| 기록 | 무엇을 증명하나 | 어디 |
|---|---|---|
| ㄱ 원본 반출 기록 | 서리의 횡령 · 연옥의 누명(원귀 사건) | 출입자 명부 묶음 **뒤쪽**에 끼워짐 |
| ㄴ 압수품 접수 기록 + 납품표 | 책을 판 상인 · 다음 장(인월) — **메인 단서** | 같은 묶음 **아래쪽 반**에 철해짐 |
| ㄷ 출입자 명부 본체 | 연옥이 알린 날 서리가 혼자 창고에 남았다는 정황 | 묶음 위쪽 |

## 3. 메인 필수 — 들어가는 길과 지키는 길

### 3-1. 창고에 들어가는 길(어느 것이든 된다)

| 길 | 행동 | 남는 것 |
|---|---|---|
| 말로 | 창고지기 방 문 앞에서 E → '퇴마 마무리' 핑계, 또는 원귀 증언 조사 경험이 있으면 '그 혼은 사람을 해치지 않소'로 설득 | 창고지기가 깨어 있다 → **갈래 ②에서 목격자** |
| 우치 | 우치에게 E → 문틈으로 손짓 하나, 열쇠 꾸러미가 벽에서 떠올라 문틈으로 빠져나온다(작은 도술) | 창고지기가 깊이 잠듦(목격자 없음). 우치가 창고 둘레에 남는다 → 갈래 ③에서 불 끄는 손이 하나 더 |
| 백운 | 문간에서 조는 백운을 깨워 E → 백운이 '도사가 퇴마 마무리를 하겠다' 허세로 창고지기에게 열쇠를 받아 옴 | 백운이 문간에 있다 → **갈래 ②에서 백운이 목격자** |

- 실패하는 길은 없다. 고른 길은 아침의 **목격자 구성**만 바꾼다.

### 3-2. 증거를 지키는 길(대체 경로)

| 기록이 상하면 | 대신 쓰는 것 |
|---|---|
| ㄱ 반출 기록이 반쯤 탐 | 창고지기·운반인의 장날·비 온 날 증언(v5.8 §4) + 쌀 포대 표식과 구휼미 장부 수량 대조 |
| ㄱ 반출 기록이 찢김 | 반쪽 둘 맞추기(하나는 문간, 하나는 마당 — 원귀가 섰던 자리 가까이) |
| ㄴ 접수 기록·납품표가 탐 | 압수를 맡은 **아전의 기억**('다음 장은 인월이라 적었소') + 견본 책 판권 장의 상인 인장 |
| 서리가 '귀신에 놀라 떨어뜨렸을 뿐'이라 버팀 | 플레이어의 목격 / 창고지기의 목격 / 백운의 목격 / (목격이 없으면) 서리 품의 부싯돌·기름병과 마당 종이가 던져진 모양 |

- **메인 단서(인월장)는 어느 갈래에서도 손에 들어온다.** 달라지는 것은 증명의 단단함과 아침에 더 해야 할 일이다.

## 4. 원귀 — 소리 설계와 출현 단계

### 4-1. 문고리 긁기 ↔ 프롤로그 두드림

| | 프롤로그 두드림(E1·E6 — 제자, N14면 5장 응답) | 3장 원귀 — 문고리 긁기 |
|---|---|---|
| 재료 | 나무 문짝을 손마디로 | **무쇠 문고리**가 고리쇠·나무 문짝을 긁음 |
| 꼴 | 끊어지는 타격음 '똑' | 이어지는 마찰음 '끼이—익', 1.5~3초 |
| 박자 | **셈이 있다**: 느린 두 번(간격 약 0.6초), 그다음 침묵 | **셈이 없다**: 길이·세기가 매번 다름, 멈췄다 다시 |
| 높이·결 | 낮고 마른 소리, 가까이 | 높고 쇳소리, 창고 안 울림 약간 |
| 끝 | 깨끗하게 끝남 | 끝이 갈라지며 잦아듦 |
| 뜻 | 사람이 사람을 부름(대답을 기다림) | 닫힌 문을 열려는 손(대답을 바라지 않음) |

- 3장에서는 **어떤 두드림 소리도 쓰지 않는다**(의식의 방울·북은 쓰되 문을 두드리지 않음). 임시 소리는 `knock.wav`와 섞이지 않게 새 임시 `latch_scrape` 하나.

### 4-2. 출현의 단계 — 절정이 첫 출현보다 세게

## 8. 해원 후일담 — 따로 떼 낸 선택 이야기

- **메인에 남는 것:** 원귀 사건의 진실(서리의 횡령과 누명), 관아의 판결, 원귀의 마지막 출현.
- **선택 후일담 「연옥의 이름」 [신규 제안 — 짧은 선택 사건, 5~10분]:** 메인 장 사이(쉬는 자리)에 운봉에 들르면 열린다. 창고지기에게서 연옥의 무덤 자리와 연옥을 기억하는 이웃 아낙(이름 없는 역할)을 듣고, 무덤에 판결 소식을 알리고, 아낙에게 반출 기록의 사본을 전한다. ③ 갈래(약한 판결)였으면 관아 조사가 끝나 '누명을 벗었다'는 방이 붙은 뒤에야 끝까지 간다.
- 메인 진행과 깃발을 주고받지 않는다. 설화록에 한 쪽이 더해질 뿐이다.
