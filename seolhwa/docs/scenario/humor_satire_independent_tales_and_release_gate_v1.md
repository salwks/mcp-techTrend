# 독립 설화와 생활 해학: 적용안·검증 기준 v1

2026-10-19. **새로운 시나리오 제안 문서이며 승인·구현은 아직 아님.** 코드·확정 원본·사용자 저장 변경 없음. 모든 검토는 해학·풍자와 **사건이 굴러가는 방식**만 대상으로 하며 그래픽/텍스처는 제외한다.

근거: 남원 춘향 상세 v1.1, 해와 달이 된 오누이 v3.4, 마스터 스토리보드 v2.4.1 F01~F50 전승 소스 목록. F 목록은 현행 50개 완성 대본이 아니다. 갤러리의 풍속화 등 146점은 배포 소스 등록값이며 개별 원본 이미지를 전부 검증한 숫자가 아니다.

## 1. 독립 설화별 사건 개편

| 전승 | 현재 핵심 | 해학·풍자가 실제 사건을 움직이는 방식 | 주인공 행동 보존 |
|---|---|---|---|
| F01 도깨비방망이 | 도깨비가 개암 소리를 주문으로 오인 | 탐욕스런 모방자가 소리를 그럴듯하게 재현하려다 실패, 플레이어가 오인의 원인을 관찰 | 원작 인물의 보은·방망이 취득을 가로채지 않음 |
| F02 혹부리 영감 | 혹과 노랫소리 혼동 | 도깨비의 잘못된 추론이 기대와 거래를 뒤집음 | 노인이 직접 노래; 혹 자체를 조롱하지 않음 |
| F04 호랑이와 곶감 | 곶감이 호랑이보다 무섭다는 오인 | 울음·곶감·도둑·호랑이의 정보 차이가 연쇄 사건을 만듦 | 플레이어는 위치와 증언만 검증, 오해의 중심 행위를 탈취하지 않음 |
| F24 봉이 김선달 | 대동강 물 판매 | 문서상 소유 주장 vs 물을 쓰는 백성의 실제 이해관계. 플레이어는 사기 거래의 근거 확인 | 김선달의 속임수 설계는 원래 인물 |
| F25 옹고집 | 진짜/가짜 논쟁 | 재산 장부·신분증명보다 관계의 기억이 인물을 가름. 플레이어는 서로 다른 증언 수집 | 원작의 신원 판정과 결말 유지 |
| F27 흥부전 | 선행과 탐욕의 모방 | 놀부가 이익을 모방하면서도 수고를 거부해 일이 꼬임 | 흥부·놀부의 주요 행동을 플레이어가 수행하지 않음 |
| F29 수궁가 | 토끼의 간을 요구 | 권력자의 무리한 요구를 약자의 말재주가 무력화 | 토끼가 자신의 계책으로 탈출 |

## 2. 춘향 v1.1: 이미 있는 풍자를 행동 결과로 회수

- ACT 3 월매가 몽룡을 경계하는 장면은 몽룡의 서투름을 활용하되 월매를 탐욕스런 희화화 대상으로 만들지 않는다.
- ACT 13 술/쌀/상소: 선택이 기록 문구만이 아니라 **ACT 17 잔치상에 실제 놓인 술독·쌀가마의 양**과 상인·농민의 반응, ACT 19의 반환/보상 대사로 보이게 한다. 사건 구조는 새로 늘리지 않는다.
- 잡역을 거절해도 사건에 진입하는 기존 장면은 선택 무력감 위험이 있다. 거절 사실을 아전이나 주민 한 명이 기억해 나중의 반응에 영향을 주되, 춘향의 수청 거절·몽룡의 시·어사출두·변학도 처분은 그대로.
- ACT 17 잔치상에서 백성이 댄 술·쌀이 관료들에게 돌아가는 모습을 보고, ACT 18에서 같은 관료들이 권위가 바뀌자 자세를 바꾸는 순간이 풍자적 절정. 이를 익살스런 과장 대사보다 **행동의 대비**로.
- 춘향은 스스로 굳게 버틴 인물이며 조롱의 대상이 아니다.

## 3. 오누이 v3.4: 낮에만 작은 웃음, 밤은 절제

- 낮 F3403 나무 장난감을 찾는 선택형 생활 행동: 아우가 장난감을 감춘 어설픈 이유를 댐 → 누이가 단호하게 혼냄 → 본인도 걱정했음을 드러냄. 주인공은 찾기만 돕는다. 낮의 친밀감이 밤의 위기를 더 크게 함.
- F3404 피신 시도와 F3405 고갯길 증거, F3406 준비는 농담을 만들기 위해 긴장감을 삭제하지 않는다.
- F3407~F3412 밤 사건과 동아줄, 참기름/도끼 대목에 코미디 효과를 추가하지 않는다. 아우의 실수는 **위험한 원작 행동**이며 웃음 유도 이벤트가 아니다.
- 플레이어는 누이의 기지·아우의 발언·오누이의 기도·해와 달 결말을 대신하지 않는다.

## 4. 자유 탐험: 짧은 해학 사건 우선 10개 (신규 후보)

| 우선 | 사건 | 형태 | 개입 |
|---|---|---|---|
| 1 | 나룻배에서 신분 먼저라고 다툴수록 배가 기움 | 짧은 개입 | 사람과 짐의 순서를 재배치 |
| 2 | 주막에서 외상값 부인, 주모와 손님이 각각 장부 주장 | 짧은 개입 | 실제 본 장부와 들은 말 대조 |
| 3 | 서당의 아이들 웃음 참기와 훈장의 오해 | 배경 | 지나가며 목격 |
| 4 | 씨름판 구경꾼 두 무리의 판정 시비 | 배경 | 관찰 |
| 5 | 행상 두 사람이 좁은 길을 양보하지 않음 | 짧은 개입 | 짐수레를 빼거나 증언 |
| 6 | 술 마신 양반이 빚을 부인하다 자신의 표식에 걸림 | 작은 이야기 | 장부와 물건 확인 |
| 7 | 신행 길에서 예법 타령 때문에 행렬이 정지 | 배경 | 지나감 |
| 8 | 역참 말에 편자 박는 장인을 손님이 훈수하다 망신 | 짧은 개입 | 말을 진정시킴 |
| 9 | 장기판 패자가 규칙을 자꾸 다르게 기억 | 배경 | 관찰 |
| 10 | 고양이가 병아리를 훔쳐 집안이 소란 | 배경 | 지나가며 목격 |

이 사건들은 원작 회화가 실제 묘사한 사건이 아니라 **회화의 주제와 사람 관계에 영감 받은 창작 후보**다. 대부분 퀘스트로 등록하지 않고 NPC 행동/잠깐 참여로 운영한다. 별도 경제 시스템/레벨/신규 맵 금지.

### 승인 전에 남은 다섯 결정

1. 1장 작은 제물을 옮겨주는 선택을 직접 플레이로 허용할지.
2. 3장 출입 금지 명령 기록을 기존 출입자 명부에 남길지, 별도 표지로 할지.
3. 4장 폭로 시 일시 판매 중단과 군중 재배치를 어떤 분기로 표현할지.
4. Q9 우치 강제 진입 위기 원본 미결 사항을 먼저 승인할지.
5. 독립 설화 50개 소스 목록 중 실제 구현된 대본을 더 조사할지.

**작업 적용 순서(승인 이후):** 원본/개편 1·3·4장 회색 상자 비교 → 2장 대사/판정 조정 → 5·최종장 인물 회수 → 춘향의 술·쌀 결과 연결 → 오누이 낮 친밀감 최소 보강 → 생활 소동 1~3개 시험. 다른 작업자의 커밋이나 사용자 저장을 덮어쓰지 않는다.
