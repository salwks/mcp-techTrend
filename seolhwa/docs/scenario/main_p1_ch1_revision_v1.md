## 3. 위기와 절정 — M103-C · M104 자세히

**왜 위기인가.** 1장에서 플레이어가 잃을 수 있는 것이 처음으로 화면에 선다: 이겸을 본 **유일한 목격자**. 사자가 몸을 돌리는 순간, 낮에 들은 노인의 '어디까지 갔는지는 내 눈으로 보질 못했소'와, 제단 끝 사내의 '며칠째 안 내려왔소'가 한꺼번에 무거워진다. **다만 이 위기는 플레이어를 시험하는 실패 판정이 아니다.** 상황을 다 알아본 뒤에 움직일 수 있어야 한다(4차 결정 ①).

### 3-1. 시간 창 — 연출 목표값과 늘어나는 규칙

| 항목 | 값 · 규칙 |
|---|---|
| 목표 길이 | 첫 예고부터 둘째 예고까지 **약 12~15초**, 둘째 예고 뒤 기다림 **약 8초**. 합쳐 약 20초 남짓. 이 값은 **연출 목표**이고 플레이테스트로 맞춘다 |
| 멈추는 것 | 플레이어가 **걷고 있거나**, 대화·증거 창·선택이 열려 있거나, 사자·백운·노인 쪽으로 다가가는 동안에는 **창의 시간이 흐르지 않는다**(사자도 그 자리에 멈칫 서 있다) |
| 늘어나는 것 | 사자 쪽으로 3m 다가갈 때마다 사자의 걸음이 한 박자 더 느려진다. 증거 창을 연 동안에는 사자가 돌아서 기다린다 |
| 하드 컷 없음 | 사자는 숲 가장자리에서 사라지지 않는다. 화면이 끊기거나 장면이 저절로 넘어가지 않는다 |
| 조작 | 박자 3부터 끝까지 플레이어가 조작을 쥔다. 컷신으로 넘어가는 것은 플레이어가 고른 뒤뿐이다 |
| 끝내 아무것도 안 할 때 | 둘째 예고 뒤 **아무 입력이 없는 시간**이 약 8초 쌓이면 노인이 일어나 백운의 등을 떠민다(갈래 d) |
| 자리를 떠날 때 | 제단에서 40m 넘게 멀어지면 창은 멈추고, 사자는 숲 가장자리에서 돌아본 채 기다린다(이야기 시계 v1.1 '기다리는 사건'). 돌아오면 둘째 예고부터 다시 |

## 4. 제단 끝의 사람 — 가족 장면 규칙

사건 순서 §5의 네 갈래를 이 장에 옮긴 것이다.

| 갈래 | 이 장에서 |
|---|---|
| 최종장과의 인과 | 이 사람은 최종장 M606에서 아이를 받는 사람이다. 이 장은 얼굴만 세운다. 5장 밤에 담요와 주먹밥을 들고 다시 온다 |
| 언제 사라졌나 | 0일. 오늘(3일)이 사흘째 — '며칠째'와 맞음 |
| 가족이 아는 것 | 아이가 고개로 올라가 안 내려왔다 · 같은 소나무로 돌아왔다(도깨비 탓으로 믿음) · 옛 움막 자리. **이겸은 모른다** |
| 플레이어에게 알리는 것 | 아래 한 줄과 몸짓 둘(일어섬 · 고개를 듦). 그 밖은 없다 |

| 순간 | 보이는 것 | 들리는 것 |
|---|---|---|
| 제물 놓는 동안 | 제단 끝, 홑옷 차림 사내가 작은 짚신 한 켤레와 주먹밥 하나를 놓고 두 손을 모은다. 다른 구경꾼과 떨어져 있다 | 없음 |
| E로 말 걸면(선택) | 사내가 짚신을 고쳐 놓는다 | '우리 아이 길도 좀 지켜 주십사 하고. …며칠째 안 내려왔소.'(구조 검토 B4) |
| 다시 E | 사내가 고개를 젓는다 | 없음(더 말하지 않는다) |
| 사자가 돌아설 때 | 사내가 일어선다 | 없음 |
| 사자의 '작은 사람 하나가…' | 사내가 고개를 든다. 1초 | 없음 |
| 1장 끝 | 사내는 제단에 남아 있다. 플레이어가 고갯길로 갈 때 뒤를 돌아보면 그가 아직 앉아 있다(선택 시선) | 없음 |

- 하지 않는 것: 플레이어에게 부탁 · 이겸 이야기 · '도깨비에 홀렸다' · 울음 · 백운이 그의 두려움으로 돈을 버는 그림(백운은 이 사람을 알아보지 못한 채 제사 준비에 바쁘다).
- 주먹밥은 5장·최종장 생존 흔적('아이가 싸 갔던 주먹밥')과 같은 꼴이다(시간표 §6-4).

## 7. 2장으로 넘기는 갈고리

- 주모의 '해 지기 전엔 내려오시오'를 어기고, 해 질 녘 고갯길로 오른다(2장 M201에서 해가 넘어감).
- 화살표가 바뀌고, 백운이 같은 나무를 두 번 지나고, 멀리 웃음 — 암전(S1.0).
- 백운의 '내 책의 한 구절을 확인해보려는 것'이 2장 내기의 판돈(책)이 되고, M101-A의 '하룻밤 빌려 갔다니까'가 2장 M206 책 속 이겸 표시의 근거가 된다(v5.12 C04 해소).
- 제단 끝의 사내 — 그가 기다리는 '작은 사람'이 4장에서 소문으로, 5장에서 신호로 돌아온다.
