# 메인 1부 페이싱 검토 v1 — 서장 ~ 산신의 사자

- 대상: `seolhwa/docs/opening/Main_Story_Script_Part01_v1_0.md`(S1.0) P00~M105-C
- 구현 기준: `seolhwa_godot/story/main_p1/`(OP00 ~ P02-C [목적지 설정]까지 구현. **P03 이후는 아직 구현되지 않음**)
- 성격: 설계 검토안. 코드와 데이터는 바꾸지 않았다. 2026-10-17

**문제 제기(사용자).** 비교작(Wandering Sword)보다 도입부에 조사와 대화가 길다. 위험이나 기이한 일을 너무 늦게 겪는다.

**결론.**
- 현재 흐름에서 처음 초자연을 보는 시점은 **약 42분**(M103-A)이다. **몸으로 겪는 위험은 1부에 한 번도 없다.**
- 서장은 그대로 둔다. 대신 그 뒤의 **여원재 길(15~30분)**을 사건이 일어나는 구간으로 바꾼다.
- 그렇게 하면 첫 30분 안에 다음을 모두 겪는다: 기이한 일 3번, 위험 1번(회피·막기), 웃음 3번, 결과가 남는 선택 2번, 설화록 기록 2번.
- 전체 시간은 늘지 않는다(58분 → 54.5분). P03 이후는 아직 구현 전이라 지금 바꾸는 비용이 가장 싸다.

## D. 개선안

**태그**
- 기존 장면 유지: 장면을 그대로 둔다.
- 연출 강화: 대사와 결과는 같고, 보여 주는 방식만 바꾼다.
- 게임플레이 변경: 플레이어의 입력이나 판단을 바꾼다.
- 신규 장면 제안: 새 장면을 넣는다.

### D0 · 기존 장면 유지 — 서장 전체(OP00 ~ P02-C)

- 프롤로그, 편지 견주기, 주막 대화는 한 줄도 바꾸지 않는다(조건).
- 오누이 들머리(북문 행상)도 그대로다. 오누이는 선택 사건으로 남는다.
- 아래 D1과 D2는 장면 사이에 붙는 덧줄이다. 기존 대사를 바꾸지 않는다.

### D1 · 연출 강화 — 남원 길에서 엿듣는 소문 두 줄(약 8.5분)

| 항목 | 내용 |
|---|---|

| 대사(신규, 짧게) | 행인 '여원재 넘던 소금장수가 같은 서낭당을 세 번 지났다더군.' / 다른 행인 '그 양반, 주막을 세 번 지났겠지.' |

| 누설 점검 | 소문뿐이다. 원인·술법·책을 말하지 않는다 ✓ |

### D3 · 게임플레이 변경 — 말이 멈춘 자리(약 20분)

| 항목 | 내용 |
|---|---|
| 입력·판단 | 여원재 오르막 들머리(아랫주막 약 600m 전)에서 말이 놀라 선다. 이 이야기 지점은 반드시 서는 곳이라 Space로 건너뛰어도 여기서 멈춘다. 카메라가 능선 바위를 1.5초 비춘다. 작고 낮은 그림자 하나가 이쪽을 보다가 사라진다. 플레이어가 고른다: ① 내려서 바위 쪽을 살핀다 → 바위 앞에서 끊긴 젖은 짐승 발자국(◆) ② E로 다시 올라 간다. 어느 쪽이든 진행한다 |
