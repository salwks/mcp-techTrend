# 설화록 CHARACTER_MASTER v1.3

> 기준: `STORYBOARD_BRIEF.md`, `seolhwarok_master_scenario_storyboard_v2.3.1_consistency_lock.md`
>
> 목적: 현재 확정된 메인 시나리오와 설화 F01~F48을 실제 캐릭터 제작 자산으로 환산한다. 이 문서는 등장인물 이름 목록이 아니라 **스프라이트·애니메이션·의복 변형·재사용 구조 관리표**다.

## 1. 제작 원칙

1. 고유 서사 인물만 고유 스프라이트를 만든다.
2. 대부분의 설화 인물은 `Human Base + 얼굴 + 의상 + 소품` 조합으로 제작한다.
3. 동일한 귀신·동물 모티프는 기본 베이스를 공유하고 상태 변형으로 처리한다.
4. 지역 차이는 전신 새 제작보다 의복·머리·모자·소품 변형을 우선한다.
5. 군중은 고유 캐릭터가 아니라 얼굴·옷 변형 풀로 만든다.
6. 초자연 존재도 원전에서 외형이 핵심이 아닌 경우 과도한 고유 디자인을 추가하지 않는다.
7. 향후 163편 설화 전체를 대입할 수 있도록 ID 체계를 유지한다.

### 제작 우선순위

- **P0:** Vertical Slice 즉시 필요
- **P1:** 메인 진행 또는 다수 설화에서 반복
- **P2:** 특정 지역/중반 이후
- **P3:** 고비용 특수 자산, 사건 가치 검토 후 제작

## 11. v2.3.1 전투 숙련 반영

메인 시나리오 v2.3.1에서 확정된 숙련은 **새 캐릭터 자산이 아니라 플레이어 동작/상태 로직 확장**으로 처리한다.

| 숙련 | 캐릭터 제작 영향 | 권장 방식 | 우선 |
|---|---|---|---|
| 받아밀기 | 방어 후 짧은 밀치기 | 기존 방어 자세 후 4~6프레임 추가 | P0 |
| 회피베기 | 구르기 후 짧은 1타 | 기존 베기 초반 프레임 재사용 | P1 |
| 빠른 투척 | 공통 던지기 1종 | 떡·돌·소형 도구 공용 | P0 |
| 빠른 사격 | 활 짧은 발사 | 기존 활 모션 축약 | P1 |
| 큰 짐승 흘리기 | 신규 풀 애니 불필요 | 회피 로직 + 방향 보정 | P1 |
| 보조도구 전환 | 애니 영향 거의 없음 | UI/상태 전환 | P1 |

### 제작 제한

- 이 6종 때문에 새 무기 모델을 만들지 않는다.
- 전용 이펙트는 최소화한다.
- Vertical Slice에서는 `받아밀기`, `빠른 투척`만 먼저 구현해도 된다.
- 전투 숙련 6종은 설계상 확정한다. Vertical Slice에서는 `받아밀기`, `빠른 투척` 2종만 먼저 구현하고, 나머지 4종은 해당 사건 도달 시점에 순차 구현한다.

### 박규상 복선 자산 영향

박규상 조기 복선은 캐릭터 신규 제작이 아니다.

- ACT 1~3에서 박규상 본인을 직접 보여 주지 않는다.
- 기존 상인·짐꾼·수레·문서 자산에 `朴` 인장 텍스처만 추가한다.
- 박규상 고유 캐릭터 `CHR_MAIN_005`는 기존 계획대로 최종장용 P1을 유지한다.

## 12. 성장 해금 규칙

전투 숙련은 캐릭터 레벨에 연결하지 않는다. 모든 해금은 메인 사건 완료 플래그로 처리한다.

| 숙련 | 해금 | 캐릭터 자산 영향 |
|---|---|---|
| 받아밀기 | 남원 주 사건 완료 | P0, 방어 후 짧은 동작 |
| 빠른 투척 | 한양 `비어 있는 책방` 완료 | P0, 공통 던지기 |
| 회피베기 | 강릉 주 사건 완료 | P1, 기존 베기 재사용 |
| 빠른 사격 | 경주 주 사건 완료 | P1, 활 모션 축약 |
| 큰 짐승 흘리기 | 평양 주 사건 완료 + 짐승 흔적 읽기 | P1, 회피 로직 중심 |
| 보조도구 전환 | 함흥 주 사건 완료 | P1, 애니 영향 거의 없음 |

일반 `Lv` 값, 경험치 게이지, 레벨업 전용 애니메이션은 제작 대상이 아니다.
