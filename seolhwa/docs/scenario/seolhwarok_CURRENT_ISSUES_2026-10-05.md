# 1. 핵심 문제 — 설화를 쓰는 방식이 처음 목표와 어긋남

## 1.1 현상

v2.1~v2.4 시나리오는 설화를 **배경으로 끌어오는** 구조로 굳어졌다.

- 시대는 1870년 한 해로 고정했다. 사건은 모두 "그해 그 고을에서 벌어진, 설화를 닮은 별개의 사건"이다.
- 원작 제목과 인물 이름은 화면에 쓰지 않는다(§1.3).
- 설화 속 초자연은 실제로 일어나지 않는다. 진위는 판정하지 않는다.
- 이야기의 중심은 이겸·우치·강복·박규상의 메인 줄기다. 설화는 무대(SETTING), 소문(RUMOR), 연상(ECHO)으로만 깔린다.
- 대표 고을의 설화는 "그 고을에 실제 전해지는 전승"으로 골랐다. 그래서 신라 설화(박제상·망부석, 수로부인, 대관령 성황)가 섞였다.

예: 황주 「빈 배의 값」에는 심청이 나오지 않는다. "눈먼 노인의 딸이 제물로 팔려 가는 1870년 사건"을 막는 이야기이고, 심청 이야기는 주민 소문으로만 깔린다. '인당수'라는 이름도 쓰지 않는다.

결과적으로 지금의 게임은 **"설화를 겪는 게임"이 아니라 "설화를 닮은 사건을 조사하는 추리물"**에 가깝다. 8개 대표 사건 가운데 설화를 실제로 재현하는 것은 남원(오누이) 하나뿐이다.

## 1.2 처음 목표

설화 내용을 **이벤트로 직접 겪게 하는 것**이다.

- 심청 편 예: 도화동에 가니 심봉사가 울고 있다 → 왜 그런지 물으면 이야기가 시작된다 → 심청전 인물들과 대화하고 보조 이벤트를 겪는다 → 남경 선인 배의 뱃사람으로 채용된다 → 인당수에 빠지는 것을 뱃전에서 본다 → 이후 이야기에 계속 개입한다.
- 플레이어는 **주인공도 관찰자도 아닌 3자 개입자**다. 이야기 안의 일자리나 부탁으로 들어가, 원작 장면 한가운데에서 손을 쓴다.

## 1.3 원인

시나리오가 판본을 거듭하며 **고증과 지역성**을 우선했다. 1870년 고정, 지역 고유 전승만 사용, 원작명 비공개, 초자연 판정 금지가 그 결과다. 그러면서 "아는 이야기를 직접 겪는다"는 처음 의도가 밀려났다.

# 2. 결정된 것

| 항목 | 결정 |
|---|---|
| 플레이어 위치 | 3자 개입자. 원작 인물이 아닌 곁의 누군가 |
| 형식 | **모든 설화에 같은 틀을 씌우지 않는다.** 들어가는 계기, 플레이어의 편, 놀이 방식, 길이, 정서, 개입의 무게, 결말이 편마다 다르다(방향 전환안 §3). 공통은 ① 원작 인물이 아닌 자리 ② 원작다운 장면은 화면에서 일어남 ③ 본 판본이 설화록에 남음, 셋뿐 |
| 원작 인물 | 이름 그대로 등장한다(심청, 심봉사, 뺑덕어미…). v2.x §1.3 원작명 비공개는 폐지 |
| 초자연 | 설화 안에서는 진짜로 일어난다(연꽃, 용궁, 구렁이) |
| 시대 | **조선시대로만 한정**한다. 연도, 왕조, 임금 이름은 내세우지 않는다. 설화는 '이 조선'에서 지금 벌어지는 일이다 |
| 설화 선택 | 플레이어가 아는 **조선 배경의 설화와 고전소설**을 우선한다. 신라·고려 인물 설화는 대표 편에 쓰지 않는다 |
| 메인 스토리 | **바꾸지 않는다.** 이겸 추적, 서강 창고 사건, 우치·강복·박규상, 함흥 S6009, 최종장 「세 번 두드리는 밤」을 유지한다 |
| 메인과 설화의 연결 | 고을마다 메인 단서가 설화 안에서 나온다. 이겸이 앞서 그 이야기를 기록하러 다녀간 자취, 남긴 메모, 그를 기억하는 원작 인물이다. 예: 심봉사 "몇 해 전 웬 선비가 우리 청이 이야기를 적어 갔소" |
| 개입의 무게 | 편마다 다르다 — 결말까지 흔드는 편, 과정만 바뀌는 편, 아무것도 못 바꾸고 지켜보는 편. 숨은 결말도 편에 따라 있거나 없다 |
| 고을당 밀도 | 한 고을에 하나는 적다. 권역마다 대표 설화 1~2편(30~90분), 짧은 설화 4~6편(5~20분), 생활 장면 상시 |

## 2.1 대표 설화 배정안 (확정 대기)

편마다 들어가는 계기·편·놀이 방식이 다른 배정표는 방향 전환안 §5에 있다. 대표: 남원 오누이·춘향·흥부, 강릉 선녀와 나무꾼, 경주 별주부, 황주 심청, 평양 봉이 김선달·장화홍련, 함흥 함흥차사(임금은 이름 없이), 제주 배비장·김녕굴, 한양 메인 거점 + 전우치 소문.

분량 목표: 대표 12편, 짧은 설화 약 50편, 메인 장. 합쳐 약 30시간.

- EVENT_CLASS 3분류와 출처 검사기(MAIN_FRAME / FOLKLORE_EVENT / AMBIENT, F49 등록 완료)

**다시 짜는 것**
- 강릉, 경주, 황주, 평양, 제주의 사건 내용. 이 사건들의 메인 단서는 새 설화 편 안으로 옮긴다
- 남원 춘향·흥부, 평양 장화홍련, 제주 배비장 신규 편
- 짧은 설화 약 50편(88개 거점 배치표 재선정)
- 원작 인물 캐릭터·소품 자산(심청, 심봉사, 춘향, 흥부·놀부, 별주부…)
- 시나리오 문서의 §1.3(원작명 비공개), 1870년 고정 서술, 지역 전승 앵커 규칙 정리

**보류**
- 9차 최종장 「세 번 두드리는 밤」은 메인 줄기가 그대로이므로 진행할 수 있다. 다만 고을별 메인 단서를 옮기는 내용이 확정된 뒤 함께 맞추는 편이 안전하다.
