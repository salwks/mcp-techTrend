# 설화록 — 방향 전환안 v3.0
## 설화 개입형: 플레이어는 설화 속으로 들어가 그 이야기를 직접 겪고 손을 쓰는 3자 개입자다

> 상태: r5 — 시간축 확정(한 해 남짓 + 설화 시간 압축), 남원 오누이 재작업 확정(§8)
> 이전 기준: v2.4.1 (설화를 1870년 사건의 배경·소문으로만 쓰는 구조)
> 바뀌는 것: 설화를 **배경으로 끌어오는 것**에서 **설화 내용을 이벤트로 직접 겪는 것**으로

---

# 1. 한 문장

> 나그네는 설화가 벌어지는 고을에 닿아, 그 이야기의 사람들 사이에 끼어들어, 원작의 장면을 눈앞에서 겪으며 손을 쓴다.

# 2. 플레이어의 자리 — 3자 개입자

| 아닌 것 | 이유 |
|---|---|
| 주인공(심청이 되기) | 원작 인물을 대신하면 다른 이야기가 된다 |
| 관찰자(멀리서 보기) | 손을 쓸 수 없으면 게임이 아니다 |
| **개입자** | 원작 장면 한가운데 있으면서, 원작 인물이 아닌 자리에서 선택한다 |

- 원작 인물은 **이름 그대로** 나온다. v2.x의 §1.3 '원작 제목·인물명 비공개'는 폐지한다.
- 원작의 초자연은 설화 안에서 **진짜로 일어난다.**

# 3. 공통 규칙 5개 — 이것만 규칙이다

1. **플레이어는 원작 인물이 아니라 그 곁의 누군가다.**
2. **원작을 원작답게 만드는 핵심 장면은 실제 게임 화면에서 일어난다.**
3. **그 핵심 선택과 행동은 원작 인물이 직접 한다. 플레이어가 대신하지 않는다.** [최우선]
   - 흥부 대신 제비 다리를 고치지 않는다(발견해서 알리는 것까지). 춘향 대신 변학도에게 맞서지 않는다. 토끼를 대신 속이지 않는다. 부사 대신 원한을 판결하지 않는다.
4. **플레이어는 한 장면만 구경하고 빠지지 않는다.** 자연스러운 이유를 갖고 이야기의 주요 흐름을 처음부터 결말까지 따라간다.
5. **그 과정에서 플레이어가 실제로 보고 관여한 것이 자신의 『설화록』 판본으로 남는다.**

## 3.1 설화마다 먼저 적을 두 줄

```text
ENTRY:      왜 이 이야기에 들어가는가?
CONTINUITY: 왜 마지막까지 이 사람들 곁에 있게 되는가?
```

CONTINUITY가 비면 그 배정은 미완성이다.

## 3.2 제작자용 판본 기준 (플레이어에게 보이지 않음)

에이전트·작가가 서로 다른 판본을 섞지 않도록, 각 편의 시나리오를 쓰기 전에 아래를 먼저 고정한다.

```text
BASE_VERSION:      기준 판본 (예: 완판 「심청전」)
FIXED_BEATS:       반드시 화면에서 일어나는 원작 장면, 순서대로
OPTIONAL_VARIANTS: 쓸 수도 있는 이본 요소 (쓰면 어느 것을 썼는지 적는다)
GAME_ADAPTATION:   게임을 위해 바꾸거나 더한 것 (원작에 없는 인물·장면, 시간 압축 등)
```

- FIXED_BEATS는 플레이어가 무엇을 하든 일어난다. 원작 중심축을 깨는 결말(예: 심청을 건져 내 연꽃·왕비·개안이 사라짐)은 두지 않는다.
- 플레이어의 개입이 바꾸는 것은 FIXED_BEATS 사이의 주변 결과뿐이다.

- 플레이어의 위치는 한 설화 안에서도 바뀔 수 있다(구경꾼 → 머무는 손님 → 관아에 동원된 사령). 처음부터 끝까지 한 직업일 필요는 없다.
- 설계 순서: 그 설화에서 가장 재미있는 장면을 먼저 고르고, 그 장면을 가장 가까이서 겪을 수 있는 자리를 찾는다. 결과가 다른 편과 비슷해도 억지로 바꾸지 않는다.

## 3.3 아이디어 체크리스트 (규칙 아님)

| 축 | 떠올려 볼 갈래 |
|---|---|
| 들어가는 계기 | 채용 · 부탁 · 휘말림 · 누명 · 속아서 · 귀신이 찾아옴 · 내기 · 묵어 감 |
| 플레이어의 편 | 주인공 쪽 · 악역 조직 안 · 구경꾼 · 피해자 쪽 · 이용당하는 쪽 · 공모자 |
| 놀이 방식 | 조사 · 잠입 · 흥정 · 추격 · 뱃일 · 설득 · 증언 · 노래·장단 · 시간 맞추기 · 심부름 |
| 길이 · 정서 | 하룻밤~몇 해 · 비극 · 해학 · 공포 · 풍자 · 동화 |
| 개입의 무게 | 원작 중심축은 그대로 두고, 주변 결과만 달라진다 — 전해진 말, 주변 인물의 운명, 악인의 처벌, 원작 밖 희생자, 플레이어가 그 자리에 어떻게 있었는가 |

# 4. 예시 — 황주 「심청」 편 (전체 비트)

> 이 흐름은 심청 편 하나의 것이다. 다른 편의 틀이 아니다.

```text
BASE_VERSION:      완판 「심청전」
FIXED_BEATS:       심봉사 개울에 빠짐 → 화주승과 공양미 삼백 석 약속 → 심청이 남경 선인에게 몸을 팖 →
                   인당수 투신 → (용궁 — 화면 밖) → 연꽃으로 떠오름 → 왕비가 됨 → 맹인잔치 → 부녀 재회·개안
OPTIONAL_VARIANTS: 뺑덕어미(재산을 털고 달아남), 장승상 댁 부인의 수양딸 제안, 황봉사
GAME_ADAPTATION:   용궁은 보여 주지 않는다(플레이어는 배 위에 있다). 함께 실려 온 다른 아이, 몸값을 빼돌리는 선주는 원작 밖 인물.
                   투신 → 맹인잔치 사이는 재방문으로 나눈다(§6.3).
```

**① 도착 — 도화동**
- 마을 어귀 개울가에서 앞 못 보는 사내(심봉사)가 젖은 옷으로 주저앉아 울고 있다. 지나는 사람들은 혀만 찬다.

**② 사연**
- 말을 걸면 심봉사가 털어놓는다. 개울에 빠진 자신을 몽은사 화주승이 건져 주었고, 눈을 뜨게 해 준다는 말에 **공양미 삼백 석**을 시주하겠다고 적어 버렸다는 것.
- "딸년 볼 낯이 없소."

**③ 사람들 (보조 이벤트)**
- **심청:** 삯바느질하며 아버지를 돌본다. 삼백 석 이야기를 들으면 말이 없어진다.
- **뺑덕어미:** 아직 오지 않았다. 이웃 아낙들이 "저 집에 들러붙을 여자가 하나 있다"고 수군댄다(뒷날 복선).
- **장승상 댁 부인:** 심청을 수양딸로 삼고 싶어 한다. 플레이어에게 "그 아이를 말려 달라"는 부탁.
- **몽은사 화주승:** 시주 장부를 들고 온다. 장부를 살펴볼 수 있다.
- **포구의 소문:** 남경 장사꾼들이 "인당수에 바칠 처녀를 산다"며 값을 부르고 다닌다.
- 보조 이벤트 예: 심청 대신 동냥 다녀오기, 화주승 장부의 삼백 석 글씨 확인, 장승상 댁 심부름.

**④ 채용**
- 포구에서 남경 선인들이 뱃사람을 구한다. 품삯을 받고 배에 오른다.
- (심청은 이미 몸값을 받기로 했다. 플레이어가 이를 막을 수는 없다 — 고정 장면.)

**⑤ 한가운데 — 뱃길과 인당수**
- 배 위의 일: 노 젓기, 물 긷기, 밤 당번. 뱃사람들의 말로 제사의 내막을 듣는다.
- 개입 지점:
  - 심청과 갑판에서 이야기하기 → 아버지에게 전할 말을 맡는다.
  - 선주가 몸값의 일부를 빼돌린 것을 알아내기 → 뒷날 선주 처벌 여부가 바뀐다.
  - 함께 실려 온 다른 아이(원작 외 인물)를 찾아내기 → 다음 포구에서 내려 줄 수 있다.
  - 술 취한 선원이 심청을 함부로 대하는 것을 막기 → 그 선원이 뒷날 어떻게 되는지가 바뀐다.
- **인당수(고정 장면):** 폭풍. 제사. 심청이 치마를 뒤집어쓰고 뛰어든다. 플레이어는 뱃전에 있다.
- 며칠 뒤 같은 바다에서 **큰 연꽃**이 떠오른다(고정 장면). 뱃사람들이 그것을 건져 올린다.

**⑥ 뒷날 — 맹인잔치**
- 몇 달 뒤, 황성에서 맹인잔치가 열린다는 소문을 듣는다.
- 그 사이 심봉사는 뺑덕어미에게 재산을 털리고 홀로 길을 떠났다(④⑤에서 심청의 말을 전했다면 장면이 달라진다).
- 잔치에서 왕비가 된 심청이 아버지를 알아보고, 심봉사가 눈을 뜬다(고정 장면).

**⑦ 기록**
- 설화록에 플레이어가 본 판본이 적힌다. "뱃전에서 보았다", "연꽃은 사흘 뒤 같은 물에서", "아비에게 전한 말: …"

**달라지는 결과(원작 중심축은 그대로):**
- 심청의 마지막 말이 심봉사에게 전해졌는가
- 몸값을 빼돌린 선주, 심청을 함부로 대한 선원이 벌을 받았는가
- 함께 실려 온 다른 아이를 구했는가
- 맹인잔치에 플레이어가 어떻게 함께했는가(심봉사의 길잡이였는가, 뒤늦게 소문으로만 들었는가)

**이겸의 흔적:** 심봉사가 "며칠 전에도 책 든 선비 하나가 왔다 갔소. 몽은사 이야기를 묻더군." 이겸은 플레이어보다 조금 앞서 같은 일의 앞머리를 지나갔다.

# 5. 대표 설화 배정 — ENTRY / CONTINUITY

원칙: 플레이어가 이미 아는 조선 배경의 설화·고전소설을 고른다. 고을과 원작 배경이 겹치면 그 고을에, 아니면 어울리는 풍경의 고을에 둔다.

### 남원(입문) — 해와 달이 된 오누이 (F49, 구현됨)
- 판본: BASE `구전 일반형(전국)` · FIXED 떡 하나 주면 안 잡아먹지 → 어머니를 해침 → 어머니 행세(목소리·손) → 오누이 집 → 오누이의 탈출, 나무 위 → 참기름·도끼 → 동아줄 → 호랑이도 줄을 청함 → 썩은 동아줄과 추락 → 해와 달 · OPTIONAL 해와 달을 서로 바꾸는 대목, 수수 줄기가 붉은 내력 · ADAPT 기존 조사·전투 도입부를 살린다(§8)
- ENTRY: 고갯길에서 떡장수 어머니의 실종에 휘말린다.
- CONTINUITY: 어머니를 찾는 길이 곧 오누이 집으로 이어진다. 하룻밤 안에 끝난다.

### 남원(본편) — 춘향
- 판본: BASE `완판 84장본 「열녀춘향수절가」` · FIXED 단오 광한루 그네 → 백년가약 → 이별(몽룡 한양행) → 변학도 부임·기생점고 → 수청 거절·곤장·옥 → 몽룡 급제·암행어사 → 거지 차림 월매 집 → 옥중 상봉 → 생일잔치 시 → 어사출두 → 재회 · OPTIONAL 경판본의 짧은 흐름, 춘향의 신분 차이 · ADAPT 이별 → 어사출두 사이는 재방문으로 나눈다(§6.3)
- ENTRY: 단오날 광한루 그네 구경꾼 속에서 이몽룡·방자 일행과 마주친다. 남원에 묵으며 방자의 심부름(편지 전달)을 거든다.
- CONTINUITY: 남원에 머무는 동안 변학도가 부임하고, 관아 일손으로 끌려가 사령이 된다. 춘향을 옥으로 끌고 가는 일, 생일잔치 준비를 악역 조직 안에서 겪는다. 어사출두 날 관아 마당에 있다.
- 지킬 것: 수청 거절, 옥중 버팀, 어사출두는 춘향과 몽룡이 한다.

### 남원 운봉·인월 — 흥부
- 판본: BASE `경판 「흥부전」 + 신재효 「박타령」 보충` · FIXED 쫓겨난 흥부 → 가난(매품팔이 등) → 제비 다리를 고침 → 박씨 → 흥부 박(재물) → 놀부가 제비 다리를 부러뜨림 → 놀부 박(재앙) → 형제의 결말 · OPTIONAL 놀부 박에서 나오는 것들의 목록, 흥부가 형을 거두는 결말 · ADAPT 제비가 강남에 다녀오는 한 해는 재방문으로 나눈다(§6.3)
- ENTRY: 놀부 집에 머슴으로 든다.
- CONTINUITY: 놀부의 심부름으로 흥부 집을 계속 오간다. 제비를 발견해 흥부에게 알리면 흥부가 고친다. 흥부의 박 소문이 나자 놀부가 다시 플레이어를 보내고, 놀부 박 타는 날 그 집 마당에 있다.

### 강릉 — 선녀와 나무꾼
- 판본: BASE `승천형 — 두레박으로 하늘에 올라가는 판본` · FIXED 사냥꾼에 쫓기는 사슴을 숨겨 줌 → 사슴의 귀띔 → 연못에서 날개옷을 숨김 → 혼인 → 아이 → 날개옷을 돌려줌 → 선녀가 아이와 승천 → 두레박 · OPTIONAL 지상 회귀형(노모를 보러 내려왔다 수탉이 됨) · ADAPT 아이 수와 몇 해의 흐름은 시간축 결정 뒤 정한다(§6.4)
- ENTRY: 사냥꾼 일행의 몰이꾼으로 사슴을 쫓는다. 나무꾼이 사슴을 숨기는 것을 본다(입을 다물지는 플레이어의 선택).
- CONTINUITY: 몰이 중 다쳐 일행에게서 떨어지고, 나무꾼의 노모 집에서 몸을 추스르며 머문다. 첫 방문에서 사슴 · 연못과 날개옷 · 혼인을 겪는다. 여행을 계속하다 강릉에 다시 들르면 후반부(아이 · 날개옷을 돌려준 밤 · 승천 · 두레박)를 겪는다(§6.3).
- 지킬 것: 옷을 숨기고, 돌려주고, 두레박을 타는 것은 나무꾼과 선녀가 한다.

### 경주(동해) — 별주부
- 판본: BASE `완판 「토별가」(토끼전)` · FIXED 용왕의 병과 토끼 간 처방 → 자라가 뭍으로 → 벼슬 약속으로 토끼를 꾐 → 용궁 → 간 요구 → "간을 빼 두고 왔다" → 다시 뭍으로 → 토끼의 조롱과 도망 · OPTIONAL 자라의 결말(자결 / 신선이 약을 줌), 뭍에서 토끼가 겪는 다른 위기 · ADAPT 그물에 걸린 자라·어부 길잡이는 원작 밖. 용궁은 실제 공간으로 만든다 — ASSET_COST 최상위

## 5.1 고을당 밀도

한 권역에 대표 설화 하나만 두지 않는다. 권역은 세 겹으로 채운다.

| 겹 | 수량(권역당) | 길이 | 형태 |
|---|---|---|---|
| 대표 설화 | 1(남원·평양·제주는 2) | 30~90분 | 편마다 다른 흐름 — ENTRY·CONTINUITY로 처음부터 결말까지(§3) |
| 짧은 설화 | 4~6 (권역의 마을·거점과 노정에) | 5~20분 | 장면 하나를 겪는 것부터 짧은 사건까지 제각각 |
| 생활 장면 | 상시 | 1~3분 | 장터 흥정, 주막 허풍, 소문 — 사건으로 세지 않음 |

- 짧은 설화는 88개 거점 배치표(v2.4 §39)를 이 기준으로 다시 고른다. 대표 설화와 겹치지 않는 이야기로 고른다.
- 대표 설화의 주변 인물이 짧은 설화로 이어지기도 한다(예: 흥부 편의 놀부 박 → 별도 짧은 편).
- 전체 분량 목표: 대표 12편 × 75분 + 짧은 설화 약 50편 × 15분 + 메인 장 → 약 30시간.

# 6. 시대 · 메인 줄기 · 시간축

## 6.1 시대
- 조선시대로 한정한다. 연도·왕조(임금 이름, 실록 사건)는 화면에 내세우지 않는다. 설화는 '이 조선'에서 지금 벌어지는 일로 겪는다.
- 대표 편은 조선 배경의 잘 알려진 설화·고전소설로 고른다(§5). 신라·고려 인물 설화는 쓰지 않는다.
- 함흥차사의 임금은 '물러나 함흥에 머무는 늙은 임금'으로 이름 없이 다룬다.

## 6.2 메인 줄기 — 바꾸지 않는다
- 이겸·우치·강복·박규상, 사라진 스승을 쫓는 여정, 서강 창고 사건, 한양 책방, 함흥 메인 장 「돌아오지 않는 전갈」(S6009 「서강의 두 필체」 포함), 최종장 「세 번 두드리는 밤」은 그대로 둔다.
- 바뀌는 것은 고을마다 메인 단서가 전해지는 그릇뿐이다.
- **이겸은 완성된 설화를 먼저 기록한 사람이 아니다.** 이야기는 지금 벌어지고 있으므로, 이겸은 **플레이어보다 조금 앞서 같은 일의 앞머리를 지나간 사람**이다. 원작 인물이 "며칠 전 책 든 선비가 왔다 갔소"라고 기억하고, 그가 남긴 메모가 있고, 그가 묻고 간 질문이 있다. 플레이어는 그 흔적을 따라와 이야기의 나머지를 끝까지 본다.
  - 예: 심봉사 "며칠 전에도 책 든 선비 하나가 왔다 갔소. 몽은사 이야기를 묻더군." / 심청 "전에 어떤 선비가 아버지 일로 몇 가지 묻고 갔어요."

## 6.3 시간축 [확정]
- **설화록 본편은 한 해 남짓의 사계절 여행이다.** 설화 때문에 메인 스토리가 몇 해씩 흐르지 않는다.
- 원전에서 몇 해가 걸리는 시간은 게임용 판본(GAME_ADAPTATION)에서 몇 달로 압축한다.
  - 춘향: 이별 → 급제·어사 귀환을 몇 달로
  - 흥부: 제비 치료 → 박을 이듬해 봄까지 기다리지 않고 계절 하나로
  - 선녀와 나무꾼: 아이 셋을 고집하지 않고 아이 하나 또는 둘로 기준을 바꾼다
  - 심청: 인당수 → 맹인잔치를 몇 달 뒤로
- 원작 시간이 긴 편은 첫 방문과 재방문으로 나눈다(춘향, 흥부, 선녀와 나무꾼, 심청).
- 화면에 "3개월 후"를 박지 않는다. 다시 들렀을 때 옷차림, 계절, 농작물, 아이의 자람, 마을 사람들의 말로 시간이 흐른 것을 보여 준다.
- 하룻밤~며칠에 끝나는 편(오누이, 김선달, 장화홍련, 함흥차사, 배비장, 김녕굴)은 한 번에 겪는다.

# 8. 남원 오누이 재작업 [확정] — v3 기준 샘플

남원은 기존 시스템을 살리면서 "설화를 조사하는 게임"을 "설화를 직접 겪는 게임"으로 바꾸는 첫 사례다.

- **살리는 것:** 실종 조사 → 산길 흔적 → 호랑이 발견 → 마을 조사 → 밤에 오누이 집. 원작에 플레이어를 들여보내는 도입부로 쓴다.
- **바꾸는 것:** 세 해결(A 마당에서 사살 / B 기름 나무 함정과 전투 / C 떡과 횃불로 영역 밖 유인)은 원작을 중간에 끝내 버린다. 세 갈래는 이제 **호랑이를 어떻게 죽이느냐가 아니라, 오누이가 원작의 다음 장면으로 갈 시간을 어떻게 벌어 주느냐**다.
  - A 전투: 싸우지만 죽이지 못하고, 아이들이 달아날 틈을 번다.
  - B 함정: 기름칠한 나무와 함정으로 호랑이를 늦춘다.
  - C 유인: 떡으로 잠시 다른 데로 꾀지만 호랑이는 다시 쫓아온다.
- **화면에서 일어나야 하는 장면:** 호랑이가 어머니를 해침 → 어머니 행세 → 오누이 집에 다가옴 → 손·목소리 속임수 → 오누이의 탈출 → 나무 위(참기름·도끼는 아이들의 말) → 동아줄 → 호랑이가 뒤쫓아 줄을 청함 → 썩은 동아줄 → 추락 → 아이들이 하늘로 올라감 → 하늘에 두 빛이 자리 잡음.
- **플레이어가 하지 않는 것:** 동아줄을 부르는 것은 아이들이다("하늘님, 저희를 살리시려거든 새 동아줄을 내려 주시고…"). 플레이어는 바로 옆에서 호랑이를 막거나 시간을 벌고, 호랑이가 줄을 청하는 것과 떨어지는 것을 본다.
- **해와 달:** 인격체로 그리지 않는다. 하늘에 두 빛이 자리 잡는 변화를 민화풍 연출이나 실루엣으로 보여 준다.
- **결말:** "마을이 오누이를 거둔다"는 기존 결말은 삭제한다. 마을로 돌아와 "아이들은 어디 갔소?" 하고 물어도 아무도 모른다. 본 사람은 플레이어뿐이다. 밤하늘을 올려다보는 짧은 연출로 끝난다.
- **설화록 기록:** "아이 둘이 하늘로 올라가는 것을 보았다."
