# 설화록 ITEM_MASTER v1.0

> 기준: 현재 메인 시나리오와 설화 F01~F48.
>
> 목표는 아이템 수집 게임을 만드는 것이 아니라 **조사·준비·사건 해결에 실제로 쓰이는 최소 아이템 체계**를 확정하는 것이다.

## 1. 불변 원칙

1. 일반 장비 파밍을 중심 재미로 만들지 않는다.
2. 설화 신물은 대부분 사건 물품이며 플레이어 영구 장비가 아니다.
3. 주술 물품은 공격 마법이 아니라 `감지/접근/보호/의식`에 사용한다.
4. 소금·술·부적 등에 임의의 범용 귀신 약점을 부여하지 않는다.
5. 증거는 가능한 한 가방 아이템이 아니라 사건 기록에 등록한다.
6. 아이템이 해결 조건이면 사용법은 반드시 사전에 관찰·증언·원형 서사로 제시한다.
7. 같은 기능의 물건을 이름만 바꿔 여러 개 만들지 않는다.

도깨비방망이, 깃옷, 여우구슬, 감응 매듭, 서천 꽃, 강복 증거물 등 고유 신물/증거.

## 11. 신규 설화 아이템 비용식

```text
NEW_ITEM_COST =
  new_system_item * 5
+ unique_relic * 3
+ new_evidence_visual * 1
+ reuse_item * 0
```

새 설화 하나 때문에 새로운 시스템 아이템이 필요한 경우 우선 재검토한다. 가능하면 기존 생활품·조사도구·주술도구의 새 사용법으로 해결한다.
