# 설화록 PROP_MASTER v1.3

> 목적: 대사를 줄이고 **환경 자체가 사건을 설명하도록 만드는 프롭 제작 마스터**.
>
> - `ITEM`: 플레이어가 소지·사용하거나 사건 시스템이 직접 참조한다.
> - `PROP`: 월드에 배치되어 생활감·단서·상태 변화를 보여 준다.
> - 같은 물건이 둘 다 필요하면 ITEM과 PROP이 그래픽 자산을 공유한다.

## 1. 제작 원칙

1. 대사로 설명할 정보를 가능하면 프롭 상태로 보여 준다.
2. `정상/파손/넘어짐/젖음/그을림/비어 있음/이동됨` 상태를 적극 재사용한다.
3. 설화 전용 프롭은 원형의 핵심 사물일 때만 만든다.
4. 한 사건만 사용하는 대형 프롭은 P3로 두고 사건 우선순위를 재검토한다.
5. 문화권 차이는 재질·배치·생활도구 조합으로 표현하고 완전 중복 제작을 피한다.

```text
NEW_PROP_COST =
  large_unique_environment * 5
+ unique_interactive_prop * 3
+ unique_static_prop * 1
+ state_variant_of_existing * 0.5
```

새 설화 하나 때문에 대형 고유 환경 프롭이 2개 이상 필요하면 사건 우선순위를 재검토한다.

## 14. v2.3.1 연결부 보강 자산 영향

### 박규상 복선

신규 3D/2D 프롭을 만들지 않는다.

기존 아래 자산에 같은 상단 표식만 변형으로 얹는다.

- `PRP_OFF_002` 장부/문서 더미
- `PRP_OFF_004` 도장
- `PRP_MKT_*` 곡물가마니·짐짝·수레 계열
- `PRP_OFF_008` 박규상 객주 표식 세트

필요 텍스처:

1. 작은 `朴` 인장
2. `박규상 객주` 납품표
3. 곡물 포장 표식
4. 운송장 거래처 표기

이 네 가지는 동일 그래픽 언어를 공유한다.

### 이겸 조사 원칙

추가 대형 프롭 없음.

- 기록 조각
- 탁본 가장자리 필기
- 운송장 뒷면 메모
- 평양 문서 메모

모두 기존 종이/장부/탁본 텍스처 변형으로 처리한다.

즉 v2.3.1로 인해 **대형 환경 자산 추가는 0**이다.
