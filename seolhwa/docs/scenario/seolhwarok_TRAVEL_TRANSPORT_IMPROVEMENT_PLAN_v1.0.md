# 설화록 — 이동수단 개선안 v1.0

> 기준 프로젝트: 설화록  
> 연계 문서: `seolhwarok_master_scenario_storyboard_v2.3.1_consistency_lock.md`, `seolhwarok_ONBOARDING_UX_DESIGN_SUPPLEMENT_v1.0.md`  
> 적용 대상: 도시 간 노정, 위성마을 접근, 사건권역 진입, 재방문 이동  
> 핵심 목표: **세계의 거리감은 유지하고, 플레이어의 반복 이동 피로는 줄인다.**

---

# 0. 결론

설화록의 이동은 다음 네 단계로 분리한다.

```text
도보
→ 탐색·마을·사건

자동 기승
→ 장거리 노정 이동

자동 하차
→ 사건권역·마을·고개·나루 진입

역마/지도 이동
→ 이미 경험한 노정의 재이동
```

핵심 원칙:

> **거리는 세계관으로 느끼게 하고, 이동시간은 게임에 필요한 만큼만 플레이하게 한다.**

> **처음 가는 길은 여행이어야 하고, 이미 아는 길은 교통이어야 한다.**

> **말은 탈것 시스템이 아니라 장거리 여행 모드다.**

---

# 1. 현재 문제

현재 설화록의 장점 중 하나는 도시와 도시 사이를 실제로 이동한다는 점이다.

플레이어는 남원에서 한양으로 이동하면서 오수, 전주, 공주, 차령, 천안 같은 길목을 직접 지나갈 수 있다.

이 구조는 다음 장점을 가진다.

- 조선 팔도를 실제로 여행하는 느낌
- 지역 사이 거리감
- 풍경과 기후 변화 체감
- 노정 자체가 세계관의 일부가 됨
- 도시가 서로 분리된 장소처럼 느껴짐

그러나 노정이 반복되면 다음 문제가 생긴다.

```text
“다음 도시까지 또 저만큼 가야 하나?”
```

이 감정은 모험 기대가 아니라 이동 부담이다.

게임에서 플레이어가 느껴야 할 것은:

```text
“다음 길에는 뭐가 있을까?”
```

이지,

```text
“또 몇 분 동안 달려야 하지?”
```

가 아니다.

---

# 2. 이동 설계의 목표

## 유지할 것

- 전국을 여행하는 느낌
- 도시 사이 거리감
- 노정의 지형·기후·생활 풍경
- 고개·나루·주막·장터 같은 중간 거점
- 여행 중 사건 발견 가능성
- 처음 방문하는 지역의 긴장감

## 줄일 것

- W/Shift를 오래 누르는 반복 이동
- 같은 길의 재주행
- 의미 없는 장거리 달리기
- 이미 아는 구간의 왕복
- 이동 자체 때문에 다음 도시가 부담스러운 느낌

---

# 3. 이동 수단 역할 구분

## 3.1 도보

도보는 도시 내부, 마을, 시장, 관아, 사찰, 주막 주변, 나루, 산길, 숲, 동굴, 폐가, 무덤, 사건권역, 조사구간에서 사용한다.

### 도보의 역할

```text
탐색
조사
관찰
상호작용
전투
사건 접근
```

즉, 도보는 **플레이어가 공간을 읽는 이동 방식**이다.

## 3.2 자동 기승

말은 장거리 노정의 이동 피로를 줄이기 위한 수단이다.

플레이어가 직접 세밀하게 조종하는 자유 승마 시스템으로 만들지 않는다.

큰길 또는 기승 가능 도로에서:

```text
길을 따라 이동
```

을 선택하면 자동 기승이 시작된다.

말은 도로 중심선을 따라 자동 이동한다.

플레이어는 카메라 회전, 주변 감상, 정지, 하차, 갈림길 선택 정도만 한다.

### 권장 속도

보행/달리기 기준 노정이 6~7분이라면:

```text
자동 기승 전체 이동 시간:
약 2분 30초 ~ 3분 30초
```

를 1차 기준으로 삼는다.

실제 값은 플레이테스트로 조정한다.

---

# 4. 자동 기승의 핵심 원칙

자동 기승 중에도 세계는 살아 있어야 한다.

다만 모든 구간을 사건으로 채우지 않는다.

### 보여줄 수 있는 것

- 농부
- 소
- 보부상
- 장사꾼
- 관리
- 나그네
- 비 피하는 사람
- 수레
- 장터 접근
- 강
- 나루
- 성문
- 산이 가까워지는 변화
- 날씨 변화
- 낮/해질녘 변화
- 멀리 들리는 종소리
- 새 떼
- 강풍
- 눈
- 바다 첫 노출

### 원칙

> **빈 길은 있어도 되지만, 변하지 않는 길은 길어서는 안 된다.**

---

# 5. 자동 하차

말은 사건의 중심까지 들어가지 않는다.

### 자동 하차 지점

다음과 같은 장소를 `TRAVEL_GATE`로 지정한다.

- 도시 성문 앞
- 마을 입구
- 고개 초입
- 숲 진입점
- 동굴 앞
- 절 입구
- 나루
- 장터 입구
- 폐가로 들어가는 갈림길
- 해안 절벽 접근로
- 사건권역 시작점
- 눈길/폭우 등으로 말 이동이 어려워지는 지점

### 기본 규칙

말이 `TRAVEL_GATE`에 접근하면:

```text
자동 감속
→ 정지
→ 자동 하차
→ 도보 전환
```

플레이어가 다시 기승 가능한 지점까지는 도보로 이동한다.

---

# 6. 사건 접근 거리

자동 하차는 사건 바로 앞에서 일어나지 않는다.

### 권장 도보 접근 거리

일반 사건:

```text
30초 ~ 90초
```

주요 사건:

```text
1분 ~ 2분
```

### 목적

하차 이후 다음 감각을 만든다.

```text
여행
→ 분위기 변화
→ 이상 징후
→ 조사
→ 사건
```

즉 말은 사건권역까지 데려다주는 수단이며, 사건 자체는 도보 플레이로 경험한다.

---

# 7. 이동의 3구역 구조

각 노정 또는 사건 접근은 다음 세 구역으로 설계한다.

## A. 여행 구간

```text
자동 기승
```

역할:
- 거리감
- 풍경
- 기후 변화
- 생활 장면
- 지역 변화

## B. 접근 구간

```text
하차 후 도보
```

역할:
- 음악 변화
- 카메라 변화
- 조사 가능 프롭 등장
- 첫 이상 징후
- 긴장 상승

## C. 사건 구간

```text
완전 수동 플레이
```

역할:
- 조사
- 대화
- 선택
- 전투
- 의식
- 구조
- 해결

---

# 8. 자동 기승 중 이벤트 처리

이동 중 발생하는 장면은 세 등급으로 나눈다.

## 8.1 PASS

그냥 지나가는 장면.

예:
- 농부와 소
- 장사꾼
- 비 피하는 사람
- 아이들
- 장날 이동
- 수레 행렬

기승 상태 유지.

## 8.2 OPTIONAL_STOP

선택적으로 멈출 수 있는 짧은 사건.

예:
- 쓰러진 수레
- 길가 다툼
- 부상자
- 이상한 물건
- 서낭당 앞 사람들
- 길을 묻는 나그네

자동 기승이 약간 감속한다.

플레이어가 정지 입력:

```text
하차
→ 짧은 사건
```

아무 입력 없음:

```text
그대로 통과
```

## 8.3 FORCED_STOP

메인 사건 또는 진행상 반드시 경험해야 하는 장면.

자동 감속.

```text
정지
→ 하차
→ 사건 시작
```

예:
- 길이 막힘
- 다리 파손
- 눈보라
- 메인 인물 등장
- 필수 단서
- 산길 입구
- 메인 사건권역

---

# 9. 자동 기승 중 갈림길

자동 기승은 플레이어 선택을 완전히 제거하지 않는다.

갈림길 도착 전 말이 감속한다.

예:

```text
왼쪽 — 공주
오른쪽 — 청주
```

또는 지도 기준 방향 표시.

플레이어가 입력하면 해당 노정으로 진행한다.

입력이 없으면 기본 스토리 목적지 방향으로 이동할 수 있다.

---

# 10. 처음 가는 길과 이미 간 길

## 처음 방문

직접 여행을 경험한다.

```text
자동 기승
+ 주요 쉼터
+ 풍경
+ 접근 도보
```

핵심 노정은 일부 구간을 직접 걷게 할 수 있다.

## 재방문

노정 전체를 반복하지 않는다.

지도 또는 역마:

```text
도착한 적 있는 주요 거점 선택
→ 짧은 이동 연출
→ 도착
```

### 재방문 가능 지점

- 대표 도시
- 주요 위성 마을
- 큰 주막
- 역참
- 나루
- 중요 고개
- 스토리상 반복 방문 가능한 사건 허브

---

# 11. 역마/빠른 이동

역마는 순간이동처럼 보이지 않도록 한다.

### 표현

지도 위:

```text
현재 위치
→ 이동선
→ 목적지
```

짧은 시간 변화 연출.

예:

```text
아침
→ 해질녘
```

또는:

```text
비
→ 흐림
```

로딩이 끝나면 목적지 도착.

### 원칙

> 이동 시간을 생략하되, 이동했다는 사실은 보여준다.

---

# 12. 자유 승마 시스템은 만들지 않는다

이번 개선안에서 제외한다.

### 제외 항목

- 말 체력
- 말 성장
- 말 장비
- 말 먹이
- 말 소유권
- 말 호출
- 승마 전투
- 말 전용 공격
- 자유 오프로드 질주
- 말 AI 전투 반응
- 좁은 지형 자유 승마
- 말 수집

### 이유

이동 피로 개선을 위해 새로운 대형 시스템을 만들지 않는다.

말은:

```text
장거리 이동 편의 + 여행 연출
```

만 담당한다.

---

# 13. 기승 시작 조건

기승은 아무 장소에서나 시작하지 않는다.

### 가능

- 도시 외곽 마방
- 주막 앞
- 역참
- 큰길 진입부
- 주요 노정 시작점

### 불가

- 도시 골목
- 시장 내부
- 산길
- 숲
- 사찰 내부
- 동굴
- 사건 전투구간
- 실내

---

# 14. 자동 하차 후 말 처리

하차 후 말은 게임플레이 오브젝트로 계속 남겨둘 필요가 없다.

권장 방식:

```text
하차
→ 말이 뒤쪽으로 이동
→ 화면 밖으로 나가면 비활성화
```

또는 마방/주막에 묶여 있는 상태로 유지.

플레이어가 사건 해결 후 다시 큰길로 나오면:

```text
기승 가능
```

상태로 복귀.

---

# 15. 장거리 이동 중 카메라

자동 기승에서는 도보보다 카메라를 약간 멀리 둔다.

### 목적

- 풍경 감상
- 속도감
- 지역 규모 표현
- 지형 변화 인식

### 사건 접근

`TRAVEL_GATE` 접근 시:

```text
카메라 서서히 가까워짐
→ 말 감속
→ 하차
```

이 연출만으로도 사건권역 진입을 전달할 수 있다.

---

# 16. 오디오 설계

## 자동 기승

- 말발굽
- 바람
- 지역 환경음
- 멀리 들리는 사람 소리
- 강/파도/숲 소리
- 낮은 여행 음악

## 하차

말발굽 소리 종료.

환경음 강조.

사건권역에서는 음악을 줄이거나 교체한다.

### 목적

UI 없이도:

```text
여행 모드
→ 탐색 모드
```

전환을 체감하게 한다.

---

# 17. 날씨와 이동

날씨는 기승 속도와 연출에 영향을 줄 수 있다.

## 맑음
기본 속도.

## 비
약간 감속 가능. 도롱이 NPC 증가.

## 폭우
특정 구간 자동 하차 가능.

## 눈
북부 노정 감속.

## 눈보라
강제 하차 또는 사건 전환 가능.

## 강풍
제주·해안에서 카메라/환경 효과 강화.

---

# 18. 특별 노정 변주

모든 노정에서 같은 패턴을 반복하지 않는다.

## 남원 → 한양

첫 장거리 여행.
기승 비중 중간.
중간 쉼터 체험 강조.

## 한양 → 강릉

평야 → 산 → 고개 → 동해.
풍경 변화 강조.
치악산 또는 대관령에서 하차 비중 높음.

## 평양 → 함흥

생존 노정.
눈/추위.
말 자동 감속 또는 강제 하차 구간 포함 가능.

## 남해 → 제주

말 대신 배.

```text
육로 기승
→ 포구 하차
→ 배 이동
→ 제주 포구 도착
→ 도보
```

---

# 19. 노정 장면화

노정 전체를 단순 거리로 보지 않는다.

각 노정은 3~5개의 기억할 장면으로 구성한다.

예:

## 한양 → 강릉

```text
1. 한양 출발
2. 원주 평야
3. 치악산 접근
4. 대관령
5. 동해 첫 노출
6. 강릉 도착
```

장면 사이 긴 구간은 자동 기승으로 압축한다.

---

# 20. 여행 비트

자동 기승 구간에서는 30~45초 이상 화면 변화가 없는 상황을 피한다.

변화는 사건일 필요가 없다.

### 변화 예시

- 지형
- 수계
- 날씨
- 시간대
- NPC
- 동물
- 건축 양식
- 길 폭
- 배경 산
- 강
- 바다
- 소리
- 생활 풍경

---

# 21. 사건 밀도 과잉 방지

장거리 이동을 지루하지 않게 만들기 위해 사건을 과도하게 넣지 않는다.

### 금지

```text
300m마다 괴이
500m마다 전투
매 쉼터마다 퀘스트
```

### 권장

```text
생활 풍경
→ 조용한 이동
→ 지형 변화
→ 가끔 사건
→ 다시 이동
```

괴이가 없는 길도 필요하다.

그래야 괴이가 등장했을 때 이상하게 느껴진다.

# 29. 이동 비용

이동 시스템을 경제 압박으로 만들 필요는 없다.

### 권장

- 최초 장거리 기승: 무료 또는 매우 낮은 비용
- 역마 재이동: 소액
- 메인스토리 필수 이동은 비용 때문에 막히지 않음

### 금지

말 이용을 위해 반복 파밍 요구.

# 30. 기승 튜토리얼

# 32. 실패 방지

자동 기승이 다음 상황에서 멈춰야 한다.

- 전투 진입
- NPC/동물로 길이 막힘
- 이벤트 강제 정지
- 갈림길
- 하차 게이트
- 씬 전환
- 물리 충돌 이상

자동 이동이 길을 벗어나지 않도록 도로 중심선 또는 경로 노드를 사용한다.

# 35. 플레이테스트 기준

각 노정에서 다음을 측정한다.

1. 자동 기승 전 이동 시간
2. 자동 기승 후 이동 시간
3. 45초 이상 화면 변화 없는 구간 수
4. 플레이어가 중간에 수동으로 끊은 횟수
5. 자동 하차 위치가 너무 먼지
6. 자동 하차 위치가 사건에 너무 가까운지
7. “다음 도시까지 가기 부담스럽다”는 반응 여부
8. “여행하는 느낌이 사라졌다”는 반응 여부
9. 풍경을 볼 시간이 충분한지
10. 재방문 시 빠른 이동 사용률

# 36. 성공 기준

플레이어가 처음 노정에서는:

> “멀리 여행했다.”

라고 느껴야 한다.

하지만 다음 도시를 볼 때는:

> “또 몇 분을 뛰어야 하나.”

가 아니라:

> “이번 길에는 어떤 풍경과 사건이 있을까.”

라고 느끼는 것이 목표다.

재방문에서는:

> “이미 아는 길인데 왜 또 걸어야 하지?”

라는 불만이 없어야 한다.

---

# 37. 최종 이동 원칙

설화록의 이동은 현실의 거리를 그대로 재현하는 것이 목적이 아니다.

목표는 **여행 경험을 재현하는 것**이다.

따라서:

> **장거리 구간은 말이 맡는다.**

> **사건으로 들어가는 마지막 길은 플레이어가 걷는다.**

> **처음 가는 길은 보여준다.**

> **이미 본 길은 줄인다.**

> **도시 안에서는 다시 사람의 속도로 걷는다.**

이 다섯 문장을 이동 시스템의 최종 기준으로 사용한다.
