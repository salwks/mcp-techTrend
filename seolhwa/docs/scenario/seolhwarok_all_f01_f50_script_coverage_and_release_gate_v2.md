- **ALT:** F24는 봉이 김선달 원전 중심 5~10분안과 기존 평양 '우치 이름을 빌린 사기꾼 둘' S5001~S5006 개편안이 **서로 다른 설계**여서 하나를 정해야 함. **1편**.

### 공통 판단

1. **원작 인물의 핵심 행위 보존**: F03 방이, F05 아우, F06 새/길손, F07 선녀, F08 신부, F09 며느리, F10 형제, F17 박문수, F27 흥부, F29 토끼, F41 바리공주 등 주체성 유지. 그러나 시안의 일부 원전 이본 해석은 자료 추가 검증이 필요.
2. **풍자는 실제 대가를 만들어야**: 관리의 호통 뒤 증거가 나와 권위가 무너지는지, 상인의 사기 뒤 돈·사람 관계가 바뀌는지, 탐욕스러운 모방 뒤 원전 인물이 치른 값과 다른지 검증. '빈정거리는 대사 1줄 추가'만으로 통과 금지.
3. **신화의 시간 구분**: 고대·신라·고려 실존 인물을 조선 현재의 마을 사람처럼 상주시킬 수 없다. 꿈/혼/연희/장소의 잔향인지 명확히 구분하고 진입/복귀 시각을 검증.
4. **원귀·아동·고난**: 피해자의 죽음, 미성년 학동, 아이들의 위기, 빈곤/장애를 희화화하는 풍자 금지. F07 원전의 비동의 문제는 매력적인 로맨스 공략 기믹으로 바꾸지 말 것.
5. **전승의 이본과 고증**: 각 문서에 있는 대사는 모두 **창작 대사**. 원전 인용으로 쓰거나 한국민족문화대백과 원문을 정밀 검증했다고 말하지 않는다. 제주 본풀이 실제 의례 절차는 제주 전문가/자료 검증 필요.
6. **◆ ◇ △**: 플레이어가 화면에서 본 것/남에게 들은 것/여전히 추정인 것을 끝까지 분리한다. 관아의 정식 판결이나 원귀 소멸을 플레이어의 한 동작으로 대체 금지.
