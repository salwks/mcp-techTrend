# M204-N 「두 백운의 목소리」 회색상자 시험 제작 명세 v1

## 목표와 정답

**목표:** 도깨비가 백운 목소리를 흉내 낸다. 플레이어는 **음색이 동일해도 인물의 말 내용이 어떻게 달라지는지** 들어 보고 진짜를 찾는다. '같은 문장을 기계적으로 반복하는 가짜'와 '실패에 따라 변명 내용이 바뀌는 진짜'라는 인물의 성격 차이를 게임의 추리 규칙으로 쓴다.

**원안의 불변 요소:**
- 어두워지면서 낮에 쓰던 팻말·바퀴 자국을 눈으로 읽는 길 찾기가 먹히지 않는다.
- 백운이 스스로 '책을 되찾겠다'며 숲속으로 들어가 일행과 떨어진다.
- 도깨비는 **같은 허풍 문장을 반복**한다. 진짜 백운의 변명은 **호흡·상황·단어가 매번 달라진다**. 이는 높은/낮은 목소리 정답 문제가 아니다.
- **우치는 관솔 횃불에 불씨만 붙여 준다. 백운의 방향을 직접 알려주는 정답 힌트가 아니다.**
- 잘못된 갈래에 가도 갇혀서 게임오버가 되는 장면이 아니다. 밤 내기의 개시 전 백운을 찾아야 한다.
- 도깨비의 가짜 목소리가 이겸·실종 아이·진짜 길돌림에 대한 정확한 정보를 누설해서는 안 된다.

**코미디 작동 근거:** 매번 변명을 달리 만드는 진짜 백운의 **자기 책임 회피**가 소리 구분의 원인이 된다. 도깨비는 인물의 억양은 복제해도 **상황마다 변하는 변명까지 복제하지 못한다**. 웃음의 이유와 플레이의 규칙이 같은 사건이다.

실제 음성 녹음 대신 임시 한국어 자막·단일 음색의 소리/위치 표시로 먼저 구현해도 된다. 특정 성우의 억양 연기력이 퍼즐의 필수 정답 단서가 되어서는 안 된다.

## 실험 조건 — 순서를 모른 채 풀게 한다

1. **L/R 위치 변경**: 진짜 좌/가짜 우, 진짜 우/가짜 좌 **두 배치**를 반드시 자동 테스트. 처음 위치를 외워 정답 맞히지 않도록 테스트 참가자는 위치 무작위.
2. **첫 소리만 듣기**: 두 방향 첫 발화만 들으면 **아직 정답을 확정할 수 없어야 한다**. 단순 음량·색깔·음색으로 맞히는 트릭 금지.
3. **반복 듣기**: 같은 방향에서 두 차례 들었을 때 가짜 반복/진짜 변화가 드러나야 한다. 음성과 자막에 **타임스탬프**를 둬 어떤 말을 들었는지 기록책에서 확인 가능.
4. **잘못된 방향 시도**: 1회 이상 실패해도 길목으로 복귀하고 짧은 흔적이나 힌트가 **누적될 뿐 영구 막힘/시간 사망 없음**.
5. **우치 횃불**: 어두운 시야에서 조명 범위만 바뀌고, NPC 위치를 정답 마커로 찍지 않는다. 발자국과 주변물 단서가 더 잘 보이도록 함.
6. **접근성**: 소리를 꺼도 구분 가능한 **방향별 발화 자막·반복 기록**을 제공하되 '가짜 백운/진짜 백운' 라벨이나 정답 강조색은 표시하지 않는다. 자막 자체가 게임플레이 단서로서 의미를 갖는다.
7. **볼륨 조절**: 음악을 꺼도 대사 신호가 남고, 소리 방향을 분간하지 못하면 **반복 발화 내용으로 풀 수 있음**을 검증.
8. **재회 성공**: 찾아낸 방식(반복 말 확인 / 우치의 횃불로 보조 확인)을 **서술 기록 한 줄에서 구분**할 수 있으나 자동적으로 다른 도술 보상 지급 금지.

## 자동 시험에 필요한 반례

- 진짜와 가짜를 **같은 위치/같은 발화 순서**로 고정해도 정답이 나오면: 스크립트에서 위치가 이미 누설된 것인지 확인.
- 자막 OFF/ON, 소리 OFF/ON 모두에서 최소 두 번 들은 **패턴의 차이**로 해결 가능한가?
- 가짜 방향을 연속 세 번 들어가면 게임이 막히는가? 막히면 실패.
- 우치에게 E를 누르면 직접 "왼쪽이 진짜요"라고 말하는가? 말하면 실패.
- 첫 발화 두 개의 의미가 너무 달라 **반복 확인 없이 정답이 바로 보이는가**? 초기 난도 테스트 후 조정.
- 성공 뒤 밤 내기 연결 플래그 BAEKUN_FOUND가 설정되고, 가짜를 먼저 골랐다고 사건 내기를 영원히 놓치지 않는가?

## 사람 시험(3~5명) 관찰

**과제:** "밤이 되자 백운이 사라졌습니다. 찾아 주세요."라는 한 문장만 제시한다.
- 처음에 움직이는지/제자리에 서서 듣는지, 실제로 **두 발화를 비교하는지**.
- 한 방향만 듣고 선택하는지, 가짜 쪽을 택한 뒤 기록을 읽는지.
- **정답을 말로 설명**할 수 있는지: "똑같이 반복하는 쪽이 가짜"와 "상황마다 핑계가 달라짐".
- 자막이 필요했는지, 자막 때문에 너무 쉽게 즉시 정답이 보이는지.
- 우치 횃불을 실제로 쓰는지, 불씨가 도움이 되는지.
- 청각 환경 영향과 좌/우 소리 분리 문제가 있는지.

## 구현 범위 및 보류

- 기존 Godot 걷기/E 상호작용/대화 UI/기록책 R/효과음 재생기를 재사용하는 것을 **우선 검토**. 별도 공간·입체 음향 시스템이 이미 있다는 근거 없이 새 기능 구현 완료라고 주장하지 않는다.
- 숲 전체를 만들지 말고 **갈림길 2개, 시작점, 실패 시 돌아오는 짧은 루프, 우치와 백운 임시 모델**만.
- 화면·음향·자막 측정 로그: 첫 소리까지 시간 / 방향 재청취 / 우치 횃불 사용 / 오답 횟수 / 성공 시간 / 재시도 여부.
- **회색상자 구현·자동 시험·사람 시험은 아직 없음**. M605 사람 시험을 진행하는 동안 이 M204-N 명세로 **다음 분리된 그레이박스**를 만드는 것이 권장된다.
