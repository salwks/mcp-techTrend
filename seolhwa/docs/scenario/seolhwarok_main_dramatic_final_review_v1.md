# 『설화록: 천하제일 신선 소동』 메인 극적 완성도 검토 v1

**2026-10-19 / 기준:** `seolhwarok_main_full_playable_script_v2_draft.md` v2.1 수정본. **독립 설화 재집필 작업은 이 검토 범위에서 제외.** 본 문서는 '게임에 들어갈 수 있다'는 보증이 아닌 **작가 관점의 극적 검토**다. 기존 Godot 코드·승인 정본 변경 없음.

## 한 편으로 읽었을 때의 판단

**핵심 매력은 '큰 마법을 배워 영웅이 되는 이야기'가 아니라, 구별해서 보고 기록할 줄 아는 제자가 어른들과 협력해 스승과 아이를 구해 오는 사건**이다. 1장 산신·2장 도깨비·3장 원귀·4장 장사꾼을 서로 다른 장르로 유지하면서도 매번 **'본 것과 들은 것의 차이'**가 위기에 개입하게 만들면 게임의 제목 『설화록』 자체가 메인에서 유효해진다.

**아직 실측하지 못한 위험**은 이동과 반복 조사에 의한 박자 단절이다. 2장 우물 반복→밤 소리 반복과 5장 소나무 반복→경계석 탁본이 **시각적으로 비슷해 보이면** 중반에는 '또 길을 잃는 이야기'라는 피로가 생길 수 있다. 2장은 누가 웃고 규칙이 있는 **장난**, 5장은 팻말이 멀쩡한데 발자국이 먼저 있고 **아무도 웃지 않는 고립**으로 반드시 차이를 보여 줘야 한다.

## 장별 극적 기능과 수정 결과

| 장 | 들어올 때 인물의 결핍 | 절정에서 실제 해야 할 것 | 다음 장에 남는 감정/물건 | 판단 |
|---|---|---|---|---|
| 서장 | 스승이 사라졌으나 평소처럼 기록하던 사람인지조차 의심 | 필체보다 **문장의 태도와 책임 부정**을 비교 | 위조가 아닌 **의심** + 여원재 길 | '책임 묻지 말라'는 위조자 고백으로 회수하도록 v2.1 수정 |
| 1장 | 큰소리치는 백운은 진짜 사자 앞에서까지 변명 | 제자 행동 뒤 **백운 스스로 제물 사실 자백** | 아이 아버지의 얼굴·이겸의 '작은 사람' 질문 | 유일한 목격자 사자에게 강제 실패 타이머 넣지 않음 |
| 2장 | 팻말만 믿은 백운이 자기 책을 건다 | 발소리/물소리로 도깨비 규칙을 이용 | 책·이겸 필적·관아 단서 | **패배 B에서도 백운이 진 걸 인정하고 책을 허락받아 돌려받음**으로 수정 |
| 3장 | 귀신을 쫓는 의식이 사실 관아의 증거 은폐 도구가 됨 | 서류/실물 증거 보존 선택 후 관아에서 입증 | 연옥의 명예 상태(분기)·납품표 | **③ 불충분 증거 = 누명 정정 보류+원귀 잔존**으로 수정 |
| 4장 | 허세와 사기 장사꾼의 똑같은 오자에 백운이 망신 | 제자가 사기 증거를 제시, 백운이 폭발해 추격 발생 | 진짜 낱장 출처·위조자 고백·백운의 침묵 | 같은 오자 인정→수치→실언, '책 판 사람이 없는 셈'으로 책임 회수 |
| 5장 | 도술 앞에서도 이겸과 아이는 보이지 않음 | 원본/탁본/신호, Q9 우치에게 맡긴 역할에 따라 다른 침묵 원인 해결 | 이겸의 두드림·아이 생존 정황·움막 방향 | Q9 세 갈래로 실제 복구 조작 다르게 구성; **사용자 승인 전** |
| 최종장 | 밖은 자리만, 안은 방문 차례만 안다 | A/B 정렬 후 우치가 기록 운반, 제자가 C 덧획을 지움 | 이겸과 아이 구조·손/도포 역전 | Q10 해결 절차는 논리화, 하지만 **UI/동선 실제 시험 전** |
| 에필로그 | 기록하던 스승에 기대던 제자 | 제자가 자기 설화록을 **스스로 덮음** | 자유 탐험 | Q11 새 날짜 한 줄은 조건부 |

## 인물 감정선 검토

- **백운:** 1장 자백(처음엔 변명) → 2장 자기 책을 잃고 내기 B에서도 패배 인정 → 3장 귀신 앞 침묵 → 4장 자기 책의 오자 인정 후 실언/분노 → 5장 줄·물 준비 → 최종장 가장 뒤에서 안전 자리 확보. 마지막 허풍 자체는 남아 인물이 다른 사람으로 바뀌지 않는다. **실패해야 할 위험:** 4장의 실언이 단순 실수로만 소비되면 3장 침묵·2장 자백이 후퇴로 느껴진다. 수치 때문에 분노가 튄다는 행동 맥락이 장면 표정·호흡으로 보여야 한다.
- **우치:** 2장의 웃기는 참견→3장 잠깐의 협조→4장 보조 도술→5장 해서는 안 될 일을 알고도 참을 수 있는가(Q9 ③), 또는 실수 뒤 인정→최종장 결코 정답을 대신 말하지 않고 **문서를 옮기는 조력자**. 우치의 정체와 이겸과의 과거는 끝까지 열어 둔다.
- **이겸:** 앞선 기록/숯표시를 고쳐 그은 선/날마다 두드린 신호/아이에게 도포를 내준 행동/안쪽 기록의 방문 차례로 부재중에도 행동한다. 7일에 구조하므로 시간표상 허용되지만 피로·떨림·기록지 얼룩은 **구조의 물리적 대가**로 남겨야 한다.
- **제자:** 일관된 성장 방식은 레벨·능력치가 아니라 **어떤 자료를 믿고 어떤 행동으로 확인하느냐**. 1장 제물/사자, 2장 물소리, 3장 증거, 4장 연습지/장부, 5장 탁본과 응답, 최종장 덧획. 이 모든 선택이 UI만 열었다 닫는 절차라면 성장처럼 느껴지지 않을 위험.

## 제작 이전의 위험 순위

1. **P0 — 승인되지 않은 편집 결정:** Q9 우치가 강제 도술을 써 신호가 끊기는 권장안, Q10 안팎 견주기, 프롤로그 소나기 A 회색상자(시험 승인이 최종 채택은 아님). 본문에 상세하게 썼다고 사용자 확정으로 오인 금지.
2. **P0 — 사료/전승의 시간:** 인월장 실제 조선 장날은 근거 미확인. 극중 5일 장날은 이야기 규칙이지만 실제 특정 오일장 날짜처럼 화면에 단정 표기 금지.
3. **P0 — 3장 정정 상태:** 메인 4장으로 진행 가능한 **'연옥 미해원'** 상태를 유지할 수 있어야 한다. M306-E/F에선 연옥이 무조건 사라진다는 종전 표현을 삭제했다. 독립 후일담으로 추가 증거를 모을 수 있는 조건 필요.
4. **P1 — 2장 실패의 대가:** 책은 도깨비의 **허락으로 회수**되지만 도깨비가 패배를 인정하는 M205-E는 승리 A만. 이를 코딩에서 같은 엔딩/기록으로 합치면 캐릭터 성장선이 깨진다.
5. **P1 — 최종장 퍼즐 공정성:** 바깥 탁본만으로 C-2 답이 눈에 보이면 이겸 기록과 신호는 장식으로 전락한다. 안의 반복 차례/바깥의 실제 위치를 **둘 다 써야만** 특정할 수 있도록 설계해야 한다.
6. **P1 — 프롤로그 충격:** 출시 기준은 현재+E1~E7이고 소나기 A는 graybox 시험만 승인. 이 중 하나를 자의로 바꾸는 건 금지.
7. **P2 — 동선 피로:** 관아 창고 3그룹 문서, 인월 판본 네 권, 여원재 경계석 셋, 마지막 C 세 후보를 **매번 똑같은 서류 맞추기 창**으로 만들지 않는다. 2장은 소리/돌다리, 3장은 증인/서류, 4장은 추격/실랑이, 5장은 걷고 듣기, 최종장은 손으로 지우는 행동으로 다양화.
8. **P2 — 해학 수위:** 아버지·아이·연옥을 조롱하는 농담 없음. 1·4장의 관리/판매 장사치와 2장의 도깨비·백운, 최종장 백운 허풍을 **인물 목적과 실제 불이익**에서 웃기게 한다.

## 단계 판정

- **완료:** 메인 전체 연속 대본·대사 흐름의 재독, 강한 충돌과 맥락 없는 분기 수정(문서), 서장→4장 위조 편지 책임 회수, 2장 패배/3장 약한 판결 후유증, 5장·최종장 절정 설명.
- **미완:** 사용자 승인/확정, 실제 게임 구현, 엔진 저장 회귀, 퍼즐 시간 측정, 프롤로그 회색상자 비교, 역사/원전 사료 고증.
- **실행 우선순위:** 편집 결정 승인 → 메인 대본 확정 기준선 → 프롤로그 A 시험(별도) → 1~최종장 단계별 그레이박스 테스트 → 감정·음향·군중 보강 → 독립 설화로 복귀.

**권고:** 기존 v2.1을 **최종 확정본이 아니라 '1차 편집 통과한 메인 정본 후보'**로 관리한다. 추가 대사와 설정을 무한히 늘리지 말고 Q9/Q10과 퍼즐 공정성만 확정한 뒤 게임에서 테스트한다.
