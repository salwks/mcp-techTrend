## 1. 총평의 객관성

외부 보고서의 가장 설득력 있는 지적은 **M206에서 산을 떠나는 이유 부족**, **아이의 부적 사용과 실제 길돌림의 원인 설명 부족**, **최종 C 숯 획이 바깥만 보고 식별될 위험**, **4장의 연속된 대조 입력**, **아버지 짚신의 미회수**다. 실제 텍스트와 맞는다.

반대로 보고서의 **'아이의 부적을 엿 포장지로 얻었다'**는 방안은 기존 시간표의 **산마을 아이가 자기 엽전으로 낱장 부적을 구입했다**는 설계와 충돌한다. 보고서는 이것을 세계 설정의 미확정처럼 취급하지만, 이미 문서에 아이의 직접 구매 경위가 있었다. **문제는 아이가 부적을 어떻게 획득했는지가 세계에 전혀 없는 것이 아니라, 그 사실과 도술의 작동을 플레이어가 적절한 시점에 확인하지 못한다는 정보 전달 부족이다.**

2장 끝에 미리 **진짜 길돌림을 체험하게 하는** 제안 역시 M502의 **'표지가 안 움직이는데 실제 길이 접힌다'**는 첫 충격을 소진하고 2장 도깨비의 눈속임과 원인을 혼동시킬 위험이 있다. **원래 2→3장 사이의 연결은 보완하되 제안된 첫 체험은 채택하지 않았다.**

69/100은 해당 작성자의 **해석·가중치에 따른 주관적 평점**이다. 지금의 문서 기반 대조로 **새 객관적인 총점을 계산했다고 주장하지 않는다**. 서사와 게임플레이의 실제 성능은 플레이테스트가 필요하다.

## 3. 새로 만든 규칙의 경계(정본으로 오인 금지)

기존 자료에는 **아이의 부적 구매/0일 길돌림/2일 이겸 실종/3일 위조 편지**가 이미 있다. 이와 달리 다음은 **이번 외부 평가에 답하면서 문서에 새로 쓴 구체화**다.

1. 복제 부적의 인쇄 테두리 조각이 5장 바위에 남아 있음.
2. '돌아오는 길'은 원래 길 잃은 사람을 표시한 자리로 돌려 보내는 술법이고, 중단 절차가 빠지면 되돌림을 멈출 수 없다는 작동 설명.
3. C 주변의 세 홈 모두 아이가 비슷한 숯 표시를 남김. 최종 활성 획은 **마지막에 덧그어 주문을 읽은 홈**.
4. 이겸은 들어가기 전에 세 위치에 분필 점검선을 남기고, 안에 갇힌 뒤 **아이 본인의 당시 행동 진술**을 듣고 반복 순서와 함께 기록.
5. 관아 연옥의 됫박, 아버지 짚신 귀환, 우치 멀리서 빛을 보는 컷.

**이 설정은 내부 논리를 강화하기 위한 편집 초안이다. 사용자 승인 전 기존 설정을 소급해 확정했다는 뜻이 아니다.** 고증·전승 이본·문서 UI 플레이 반응·시간 실측은 별도.

## 5. 본 검토 뒤의 우선순위

**메인 스토리 구조 전면 재설계 불필요**라는 외부 보고서 의견에는 동의한다. 그러나 "다섯 곳 고치면 곧 최종 정본"이라는 결론은 **아직 증명되지 않았다**. 시나리오를 문서에서 고쳤다는 사실은 플레이어의 재미나 UI의 공정성이 검증됐다는 사실과 다르다.

1. **우선 P0:** 이번 수정이 2→3→4→5장 동기를 실제 플레이에서 자연스럽게 만들었는지 *장면간 클릭/걷기* 검증.
2. **P0:** M605의 C 3 홈 퍼즐을 A/B 기록 없이 / 안 기록 없이 각각 풀게 해 보는 **정보 비대칭 반례 테스트**. 둘 중 하나만으로 풀리면 실패.
3. **P1:** 4장 압축 후 **3장 압수 견본→장터 인장→진짜 낱장→판매자 분노→위조 고백**의 공개 순서가 억지 없이 연결되는지.
4. **P1:** 프롤로그 현재판 첫 조작 시각 직접 계측하고 소나기 A 그레이박스와 비교. 현행 E1~E7 자동 폐기 금지.
