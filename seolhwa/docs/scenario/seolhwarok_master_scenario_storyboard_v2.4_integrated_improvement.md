## v2.4 수정 범위

v2.3.1의 8개 대표 권역, 메인 진행 순서, 이겸·우치·강복·박규상 프레임, F01~F48 설화 배치, 레벨 없는 성장 체계는 유지한다.

이번 버전에서 추가·수정하는 것은 다음 일곱 가지다.

1. **도입부 S0000 추가**
   - 이겸의 세 문장 → 즉시 조작 → 첫 조사 → 상반된 소문 → 남원 전경 → 타이틀 순서로 게임 문법과 메인 동기를 함께 제시한다.
   - 정답은 숨기되 조작·현재 목표·기록책 사용법은 숨기지 않는다.

2. **남원 실제 구현 위치 반영**
   - 오누이 외딴집은 여원재 방향이 아니라 현재 구현된 **남원 북쪽 전주길 고개권**을 기준으로 한다.
   - 설화 원형이나 사건 인과는 바꾸지 않는다.

3. **0~8차 실제 구현 결말 역반영**
   - 경주: 밀수꾼 체포 A / 놓침 B.
   - 평양: 사기꾼 체포 A / 놓침 B.
   - 함흥: 돌아온 전갈꾼 3/2/1명에 따라 A/B/C.
   - 함흥 S6009는 장문 대사 대신 조사 카드로 반전을 제시한다.

4. **장거리 이동 방식 시나리오 반영**
   - 도보 = 탐색·사건.
   - 자동 기승 = 노정 장거리.
   - 사건권역 30~90초 전 자동 하차.
   - 이미 경험한 길 = 역마/지도 빠른 이동.
   - 자유 승마·말 육성·승마 전투는 추가하지 않는다.

5. **평양 부벽루 구현 정합**
   - 실제 씬 구조에 맞춰 핵심 대면 위치를 `부벽루 인근 공터`로 고정한다.
   - 누각 바닥 모델이 보강되면 연출 위치만 되돌릴 수 있다.

6. **최종장 명칭·출처 정책 정리**
   - `칠패의 밤`은 내부 제작명으로만 유지한다.
   - 플레이어 사건 기록명은 **「세 번 두드리는 밤」**으로 변경한다.
   - 이 최종장은 특정 전래설화를 원작으로 삼은 사건이 아니라 `MAIN_FRAME` 창작 메인 프레임임을 문서에 명시한다.
   - 존재하지 않는 설화 출처를 붙이지 않는다.
   - 대신 이전 설화 사건에서 배운 조사 문법과 선택적 ECHO가 최종장 해석에 재사용된다.

7. **강복 해결 방식 보강**
   - 갑자기 등장하는 일반 주술·새 의식으로 해결하지 않는다.
   - 강복의 유해·이름·곡물 수량패·변조 기록을 복원해 **신원과 기록을 되돌리는 행동**으로 해결한다.
   - 감응 매듭·호신물은 진짜/가짜 구별과 보호에만 쓰며 퇴마 마법이 아니다.

**변경하지 않는 것:** 남원 시작, 한양 정보 허브, 이겸 약 70% 재회, 제주 후 한양 최종장, 박규상 조기 복선, 이겸 조사 원칙, 전투 숙련 6종, 완료 플래그 8종, 원작 제목 비공개, 조사→규칙→대응의 핵심 루프.

## 0. 이 문서의 사용법

이 문서는 소설 대본이 아니라 **게임 구현용 시나리오 계약서**다.

각 장면은 가능한 한 다음 형식을 사용한다.

- `SCENE_ID`
- 장소 / 시간 / 날씨
- 진입 조건
- 장면 목적
- 플레이어 행동
- 자동 연출
- 핵심 대사
- 조사 단서
- 상태 변수
- 실패·대체 흐름
- 카메라 / 사운드
- 종료 트리거

에이전트나 개발자가 임의로 긴 대사를 추가하거나, 사건 해결을 컷신으로 대신하거나, 본문에 없는 새로운 초자연 능력을 플레이어에게 부여해서는 안 된다.

### 구현 임시 대체 원칙

사운드 시스템이 아직 없는 현재 빌드에서는 다음을 자막·화면효과로 임시 대체할 수 있다.

- 방울
- 문 두드림
- 숨소리
- 먼 군중 소리

그러나 시나리오의 **최종 연출 의도는 소리 포함**으로 유지한다.

임시 대체 때문에 기준 시나리오의 소리 연출 자체를 삭제하지 않는다.

# 1. 프로젝트 핵심 불변 규칙

## 1.1 게임 한 줄 정의

**1870년 무렵의 가상 조선을 이름 없는 나그네로 떠돌며, 실제 사건처럼 벌어지는 전래설화·괴이·인간 사건을 조사하고 해결하는 이야기 중심 싱글플레이 RPG.**

## 1.2 기본 플레이 루프

탐험  
→ 사건 발견  
→ 조사  
→ 규칙 파악  
→ 준비  
→ 대응  
→ 해결  
→ 지역 변화  
→ 다시 여행

## 1.3 원작 제목 비공개

게임 안에서 다음을 하지 않는다.

- 「해와 달이 된 오누이 시작」
- 「심청전 퀘스트」
- 「아랑전설 완료」
- 원작 줄거리 요약
- 원작을 직접 설명하는 도감

플레이어가 보는 것은 언제나 **현재 벌어진 사건**이다.

예:

- 원작 내부명: 해와 달이 된 오누이
- 플레이어 기록명: `산길의 실종`

## 1.4 초자연의 원칙

이 세계에서 괴이는 실제로 존재할 수 있다.

그러나 다음도 동시에 가능하다.

- 괴이로 보였지만 인간의 사기다.
- 실제 괴이를 인간이 이용한다.
- 인간이 거짓말하고 있지만 괴이도 실제다.
- 괴이는 존재하지만 인간을 해치려는 것이 아니다.
- 끝까지 원인을 확정할 수 없다.

따라서 플레이어는 "귀신이 있다 / 없다"를 판정하는 직업이 아니다.

## 1.5 데우스 엑스 마키나 금지

최종 해결에 쓰는 수단은 반드시 이전에 다음 중 하나로 제시되어야 한다.

1. 플레이어가 직접 관찰한 규칙
2. 조사로 확인한 정보
3. 이미 획득한 물건
4. 미리 맺은 인간관계
5. 미리 확인한 환경 특성

금지:

- 처음 보는 신령이 등장해 해결
- 갑자기 새로운 부적을 받음
- 플레이어가 갑자기 도술을 사용
- 우연한 천재지변으로 문제 해결
- 최종 컷신에서 NPC가 대신 해결

## 1.6 대사 최소화

일반 NPC 1회 대화: 1~3문장.

중요 NPC 일반 장면: 3~6문장.

핵심 대면 장면: 원칙적으로 60초 이내.

그 이상이면 반드시 중간에 플레이어 이동·조사·선택·전투를 삽입한다.

### 정보 전달 목표 비율

- 환경·행동: 65%
- 짧은 대사: 25%
- 기록·문서: 10%

직접 볼 수 있는 사실을 NPC가 설명하지 않는다.

## 1.7 사건 구조 반복 금지

대표 도시 주 사건의 체감 장르는 서로 달라야 한다.

| 지역 | 주요 체감 |
|---|---|
| 남원 | 추적·규칙 학습 |
| 한양 1차 | 추격·정보 |
| 강릉 | 의식·시간 압박 |
| 경주 | 관찰·복수 흔적 분리 |
| 황주 | 구조·선택 |
| 평양 | 사기·문서 추리 |
| 함흥 | 생존·이동 |
| 제주 | 신앙·감응 |
| 한양 최종 | 복합 대형 사건 |

## 1.8 모든 사건 마지막 보스전 금지

전투는 해결 수단 중 하나다.

사건별로 다음을 섞는다.

- 전투 없음
- 초반 전투
- 중반 짧은 전투
- 최종 전투
- 전투 시 오히려 나쁜 결과
- 괴이와는 싸우지 않고 인간과 전투
- 전투 없이 구조·의식·증거 확보로 종료

## 1.9 친절도 원칙

설화록은 정답을 숨기되 조작법과 현재 상태까지 숨기지 않는다.

> **플레이어가 무엇을 할 수 있는지는 숨기지 않는다. 무엇이 진실인지는 숨긴다.**

친절하게 알려 줄 것:

- 이동·조사·대화·기록책·지도 조작
- 현재 확인한 사실
- 현재 알고 있는 장소
- 배운 전투 행동
- 사용할 수 있는 도구

숨길 것:

- 범인
- 미발견 단서 위치
- 증언의 진위
- 괴이의 전체 규칙
- 최적 해결법
- 엔딩 판정 점수

퀘스트 숫자 체크리스트와 미발견 단서 마커는 사용하지 않는다.

## 1.10 이동 원칙

> **장거리 구간은 말이 맡고, 사건으로 들어가는 마지막 길은 플레이어가 걷는다.**

- 도보: 도시·마을·탐색·조사·사건.
- 자동 기승: 노정의 장거리 구간.
- 자동 하차: 사건권역·고개·나루·도시 입구.
- 재방문: 이미 경험한 거점까지 역마/지도 이동.
- 말은 장거리 여행 모드이며 자유 승마 RPG 시스템으로 확장하지 않는다.

## 1.11 메인 프레임과 설화 사건의 출처 구분

콘텐츠는 내부적으로 세 종류로 나눈다.

```text
EVENT_CLASS = MAIN_FRAME / FOLKLORE_EVENT / AMBIENT
```

### MAIN_FRAME

이겸·우치·강복·박규상과 연결된 메인 서사.

- 창작 가능.
- `Fxx/Axx`를 억지로 붙이지 않는다.
- 실제 전승인 것처럼 표시하지 않는다.
- 설화 사건에서 배운 플레이 문법과 주제는 재사용 가능하다.

### FOLKLORE_EVENT

이름 있는 설화 기반 서브·지역 사건.

- 반드시 `Fxx` 또는 `Axx`.
- `SOURCE_VERIFIED=true` 필수.
- 원형과 지역성을 내부 데이터에 기록한다.

### AMBIENT

생활·풍경·비서사 장면.

- 사건 수에 포함하지 않는다.
- 억지 설화 출처를 붙이지 않는다.

이 구분으로 **메인 창작 프레임과 실제 전승 사건을 혼동하지 않는다.**


# 2. 메인 시나리오의 주제

게임의 표면적 목적은 **사라진 스승 이겸의 행방을 찾는 것**이다.

그러나 여행이 진행되며 질문이 바뀐다.

초반:
> 무엇이 실제로 있었는가?

중반:
> 같은 일을 왜 사람마다 다르게 이야기하는가?

후반:
> 사실을 알아냈다고 해서 어떻게 세상에 전해야 하는지도 알 수 있는가?

최종:
> 나는 사실을 기록하는 사람인가, 사람을 움직이는 이야기를 만드는 사람인가, 아니면 사건 속 사람을 먼저 살리는 사람인가?

플레이어는 스승 이겸 또는 우치 중 한 명의 사상을 선택하는 것이 아니다.

**두 사람의 실패를 보고 자기 방식을 만든다.**

# 3. 핵심 인물

## 3.1 플레이어 — 이름 없는 나그네

### 기본

- 이름 표시 없음.
- 환도와 활 사용.
- 읽고 쓰기 가능.
- 사건 기록책 소지.
- 과거 이겸에게 기록법과 여행 생존법을 배움.
- 거대한 혈통이나 선택받은 존재 설정 없음.

### 시작 목표

이겸의 마지막 흔적이 남원에서 끊겼다.

그가 어디로 갔는지 찾는다.

### 성격 표현

성격 수치나 선악 게이지를 전면에 표시하지 않는다.

다음 행동이 플레이어의 성향을 드러낸다.

- 누구를 먼저 구했는가
- 증거를 얼마나 확인했는가
- 거짓 연출을 이용했는가
- 사건을 공개했는가
- 괴이를 죽였는가
- 지역 관습을 존중했는가

---

## 3.2 이겸 — 스승

### 과거

전직 말단 서리.

관청 문서와 장부를 다루다 관직을 떠나 팔도를 떠도는 기록자가 됐다.

### 원칙

> “본 것은 본 대로.”

> “들은 것은 누가 말했는지.”

> “모르는 것은 모른다고.”

### 장점

- 증언 비교
- 문서 검증
- 신중함
- 억울한 사람을 쉽게 범인으로 만들지 않음

### 결함

과거 실패 이후 완벽한 증거에 집착한다.

행동해야 할 때도 조사만 계속할 수 있다.

### 현재

게임 약 70% 지점까지 행방불명.

함흥 권역에서 재회한다.

재회는 엔딩이 아니라 **후반부 시작점**이다.

---

## 3.3 우치 — 라이벌

### 정체

본명 불명.

사람들이 옛 전우치의 이름을 빌려 "우치"라고 부른다.

본인은 정체를 설명하지 않는다.

### 능력

- 변장
- 손재주
- 잠입
- 문서 위조
- 사람 심리
- 민간 주술 지식
- 기이한 도구

가끔 인간 기술로 설명하기 어려운 행동도 하지만 실제 도술 여부는 끝까지 확정하지 않는다.

### 철학

> “사람은 사실보다 이야기를 기억하오.”

### 장점

행동이 빠르다.

권력자를 두려워하지 않는다.

사람이 괴이 이야기를 어떻게 악용하는지 잘 본다.

### 결함

진실을 위해 거짓을 만드는 것도 허용한다.

자신이 만든 이야기가 통제 밖으로 퍼질 위험을 얕본다.

---

## 3.4 곽칠성 — 과거 사건의 생존 증인

## 3.6 박규상 — 최종 인간 가해자

과거 대형 객주를 운영했고 현재도 상당한 상권 영향력을 가진다.

곡물 횡령을 숨기기 위해 강복 사건을 덮는 데 가담했다.

최종장에서 초자연 현상을 이용해 오래된 증거를 제거하려 한다.

과장된 악역 연설을 하지 않는다.

### 조기 복선 운용

박규상은 최종장 직전에 처음 등장하는 인물이 아니다.

ACT 1부터 다음 형태로 배경에 반복해서 존재한다.

- `박규상 객주` 상단 표식
- 곡물·종이·운송 거래 문서
- 지방 나루와 객주의 납품 흔적
- “큰 상단이라 겨울에 곡식을 풀었다” 같은 평범하거나 긍정적인 평판
- 우치가 유독 해당 상단 문서를 따로 보는 행동

초반에는 이 흔적을 조사해도 사건이 열리지 않는다.

플레이어가 알아야 하는 것은 단지:

> “이 이름을 전에 본 적이 있다.”

정도다.

# 4. 과거 사건: 서강 창고 화재

게임 시작 약 12년 전.

그는 나무패와 장부 일부를 숨겼다.

박규상 측은 이를 알아챘다.

창고 화재 발생.

강복 사망.

사건 직후 강복 가족이 "저주를 불렀다"는 소문이 돌았다.

가족은 지역에서 쫓겨났다.

이겸은 인간 범죄를 의심했다.

### 진실의 핵심

- 인간 범죄가 있었다.
- 가짜 귀신 소동도 있었다.
- 그러나 강복 사후 실제로 설명되지 않는 현상도 발생했다.

따라서 세 사람 모두 단순한 결론을 내릴 수 없다.

첫 방문 노정은 여행 경험을 남기되 모든 거리를 도보로 강제하지 않는다.


# 6. 성장·장비·주술 시스템과 시나리오 연결

## 6.1 성장 구조 — 일반 레벨 없음

설화록은 숫자로 표시되는 일반적인 캐릭터 레벨 체계를 사용하지 않는다.

플레이어의 성장은 세 축으로 관리한다.

1. **전투 숙련** — 사건을 겪으며 새로운 행동이 해금된다.
2. **조사 숙련** — 흔적 읽기·탁본·문서 감정처럼 세상을 읽는 방법이 늘어난다.
3. **도구·신앙 지식** — 호신부·감응 매듭 등 특정 상황에 접근하거나 구분하는 수단이 늘어난다.

체력·기력·공격력은 레벨에 따라 자동 상승하지 않는다. 필요하면 게임 전체에서 2~3회 정도의 소폭 성장만 별도 사건·훈련 보상으로 허용한다.

### 금지

- 적과 플레이어의 레벨 차이 판정
- 후반 적 HP가 초반의 수십 배로 증가하는 스케일링
- 레벨 조건 때문에 사건 해결 수단을 사용할 수 없는 구조
- 조사를 무시하고 장비 수치로 모든 사건 해결
- 경험치 노가다를 숙련 해금 조건으로 사용

## 6.3.1 전투 숙련 6종

전투 숙련은 공격력 배율을 크게 올리는 기술이 아니다.

**같은 환도·활·도구를 더 노련하게 쓰게 만드는 행동 확장**이다.

| 숙련 | 해금 조건 | 기능 | 제작 영향 |
|---|---|---|---|
| `SKILL_GUARD_SHOVE` 받아밀기 | `CASE_NAMWON_COMPLETE` | 타이밍 방어 성공 직후 짧게 밀쳐 거리 확보 | 환도 방어 후 1동작 추가 |
| `SKILL_QUICK_THROW` 빠른 투척 | `CASE_HANYANG_BOOKSHOP_COMPLETE` | 떡·돌·소형 도구를 이동 흐름을 크게 끊지 않고 사용 | 손 던지기 공통 애니 1종 |
| `SKILL_EVADE_SLASH` 회피베기 | `CASE_GANGNEUNG_COMPLETE` | 구르기 종료 직후 짧은 1타 연결 | 기존 베기 프레임 재사용 가능 |
| `SKILL_SNAP_SHOT` 빠른 사격 | `CASE_GYEONGJU_COMPLETE` | 완전 조준 이전 근거리 1발 사격. 정확도는 낮음 | 활 애니 일부 재사용 |
| `SKILL_BEAST_SIDESTEP` 큰 짐승 흘리기 | `CASE_PYONGYANG_COMPLETE` + `SKILL_BEAST_TRACE` | 돌진 예고를 정확히 읽었을 때 옆으로 흘려 위치 우위 | 전용 이펙트 없이 회피 로직 확장 |
| `SKILL_TOOL_SLOT_PLUS` 보조도구 전환 | `CASE_HAMHUNG_COMPLETE` | 전투 중 보조도구 2개를 빠르게 교대 | UI·상태 로직 중심 |

### 제한

- 숙련 하나로 특정 설화의 규칙을 무시할 수 없다.
- `빠른 사격`이 활의 정식 조준보다 강해서는 안 된다.
- `큰 짐승 흘리기`는 모든 적에게 통하는 패링이 아니다.
- 기술 해금 연출을 위한 별도 스승 NPC를 추가하지 않는다.
- Vertical Slice에서는 `받아밀기`, `빠른 투척`까지만 우선 검증해도 된다.

### 해금 구현 계약

숙련은 경험치나 레벨을 읽지 않는다. 사건 완료 플래그만 본다.

```text
SKILL_GUARD_SHOVE      <- CASE_NAMWON_COMPLETE
SKILL_QUICK_THROW      <- CASE_HANYANG_BOOKSHOP_COMPLETE
SKILL_EVADE_SLASH      <- CASE_GANGNEUNG_COMPLETE
SKILL_SNAP_SHOT        <- CASE_GYEONGJU_COMPLETE
SKILL_BEAST_SIDESTEP   <- CASE_PYONGYANG_COMPLETE && SKILL_BEAST_TRACE
SKILL_TOOL_SLOT_PLUS   <- CASE_HAMHUNG_COMPLETE
```

UI에는 숫자 레벨을 표시하지 않는다. 해금 시 필요하면 `새 행동을 익혔다 — 받아밀기`처럼 짧게만 알린다.

## 20.1 최종장 출처 정책

```text
EVENT_CLASS = MAIN_FRAME
SOURCE_ID = MAIN_FRAME_FINAL
SOURCE_TITLE_INTERNAL = 이겸-우치-강복-박규상 최종 연결극
```

이 최종장은 **특정 전래설화의 직접 각색이 아니다.**

따라서:

- `Fxx/Axx`를 붙이지 않는다.
- 칠패에 실제 전승이 있었다고 주장하지 않는다.
- 강복을 실제 민속 원귀 사례로 위장하지 않는다.
- 한양을 특정 전래동화의 고정 발생지로 만들지 않는다.

설화록의 정체성은 다음 방식으로 최종장에 회수한다.

1. 이전 설화 사건에서 익힌 **“괴이는 곧 적이 아니다”**라는 문법.
2. 우치·원귀·인간 범죄를 동시에 구별하는 조사 구조.
3. 선택적으로 완료한 설화 사건이 최종장 해석에 작은 ECHO를 제공.
4. 실제 해결은 지금까지 얻은 단서·도구·기록 능력으로만 수행.

즉 **출처를 꾸며 붙이는 것이 아니라, 여행하며 배운 설화적 사고방식을 최종장에 합성한다.**

- 평양: **문서의 내용보다 수정 흔적을 본다.**
- 함흥·제주: **기록보다 구조가 먼저인 순간을 판단한다.**

# 25. 설화 기반 단기 사건 템플릿 48종

이 장은 v2.0의 창작 D01~D48을 **전부 폐기**하고 대체한다.

모든 사건은 실제로 전승·기록된 설화, 전설, 서사무가, 설화계 고전소설의 핵심 장면에서만 가져온다. 게임 편의를 위해 인물 수와 동선을 축약할 수는 있지만, 원전에 없는 초자연 능력·금기·약점·결말 원인을 새로 만들지 않는다.

### 사용 등급
- `DIRECT`: 특정 지역과 전승 근거가 명확한 직접 각색.
- `VARIANT`: 전국 또는 광역으로 전승되는 설화를 어울리는 환경에 배치. 특정 고을의 고유 전승이라고 주장하지 않는다.
- `ECHO`: 원전의 한 장면이나 물건을 짧게 체험하는 환경 서사. 새로운 사건 줄거리를 만들지 않는다.

### 원작명 노출
내부 데이터에는 원형 제목을 기록하되 게임 UI에는 `사건기록명`만 표시한다.

## F01 — 밤의 개암

- **원형:** 도깨비방망이 설화
- **종류:** 설화·민담
- **지역성:** D 전국형
- **각색 핵심:** 산중에서 도깨비들이 개암 깨지는 소리를 보물 나오는 주문으로 오해하고 방망이를 남긴다는 모방담 구조를 5~10분 사건으로 축약한다.
- **플레이:** 밤 숲 잠복 → 도깨비의 행동 관찰 → 개암 소리의 오해 파악 → 욕심내 따라 하는 인물의 개입
- **결말 운용:** 도깨비 물건을 돌려놓고 사건 종료 / 인간의 모방 욕심 때문에 일이 커진 뒤 수습
- **검증 근거:** 한국민족문화대백과사전 「도깨비방망이 설화」

## F02 — 노랫소리를 산 혹

- **원형:** 혹부리 영감 설화
- **종류:** 설화·민담
- **지역성:** D 전국형·사용주의
- **각색 핵심:** 도깨비가 노래의 근원을 혹으로 오해해 떼어 가는 전승의 핵심만 사용한다. 1915년 조선어독본의 문구나 현대 동화 정형은 직접 재현하지 않는다.
- **플레이:** 밤 산길 → 노랫소리 → 도깨비 무리 관찰 → 혹을 둘러싼 오해와 흥정
- **결말 운용:** 혹을 떼는 원형 결말 / 모방자가 실패하는 후속 소문
- **검증 근거:** 한국민족문화대백과사전 「혹부리 영감 설화」

## F03 — 돌틈의 금방망이

- **원형:** 방이 설화
- **종류:** 설화·민담
- **지역성:** D 전국형
- **각색 핵심:** 새를 따라간 방이가 밤에 붉은 옷 아이들이 금방망이로 음식을 내는 것을 보고 방망이를 얻는 전승을 짧은 탐색 사건으로 만든다.
- **플레이:** 새 추적 → 돌틈 잠복 → 밤 장면 관찰 → 물건을 가져갈지 말지 판단
- **결말 운용:** 원형처럼 보물을 얻음 / 욕심 많은 모방자가 뒤따라와 실패
- **검증 근거:** 한국민족문화대백과사전 「방이 설화」

## F04 — 곶감을 무서워한 범

- **플레이:** 민가 주변 호랑이 관찰 → 아이 울음과 곶감 대화 청취 → 도둑·호랑이의 오인 발생

- **플레이:** 밤 나무 위 은신 → 호랑이 대화 청취 → 세 단서 중 현장과 맞는 것을 검증
- **결말 운용:** 단서를 실제로 검증해 도움 / 모방한 욕심쟁이가 위험을 자초

- **플레이:** 새 구조 → 산중 숙박 → 위험 징후 → 밤 종소리 → 원인 확인
- **결말 운용:** 새의 보은을 알아차리고 생존 / 원형의 희생을 목격하고 기록
- **검증 근거:** 한국민족문화대백과사전 「까치의 보은」

## F07 — 연못의 깃옷

## F08 — 벗어둔 허물

# 36. v2.1 서브이벤트 소스 잠금 규칙

## 36.1 순수 창작 서브이벤트 0개

v2.0에 있었던 다음 유형은 폐기한다.

- 출처 없는 귀신 사건
- 출처 없는 ‘이상한 장부’ 사건
- 출처 없는 밀수·사기 사건을 고유 LOCAL 퀘스트로 만든 것
- 출처 없는 희귀 괴이
- 설화처럼 보이도록 새로 만든 금기나 주술 규칙

이후 `LOCAL`, `ANCHOR`, `HIDDEN`으로 등록되는 모든 서사 콘텐츠는 반드시 `Fxx` 또는 `Axx` 소스 ID를 가진다.

## 36.2 허용되는 각색

원전 내용을 게임으로 옮기기 위해 다음은 허용한다.

- 등장인물 수 축소
- 이동거리 축소
- 원전의 여러 이본 중 하나 선택
- 사건 시작 시점을 원전 중간으로 옮기기
- 플레이어가 목격자·조력자로 들어가기
- 원형 결말을 막을 수 있는 게임적 분기 추가

단, 분기 때문에 **새로운 괴이 능력이나 새 금기**를 만들 수 없다. 해결 논리는 원형 서사에 이미 있는 물건·행동·관계 안에서만 만든다.

## 36.3 지역성 표기

- 지역이 명확한 전승: 해당 지역에 고정.
- 여러 후보지가 있는 전승: `C`로 표기하고 진짜 장소라고 단정하지 않음.
- 전국형 설화: `D 전국형`으로 표기하고 환경만 맞춰 배치.
- 제주·함경 무가: 실제 전승권을 벗어나 전국 랜덤으로 뿌리지 않음.

# 42. v2.4 설화·메인 프레임 QA

사건 하나를 구현할 때 먼저 `EVENT_CLASS`를 확인한다.

- `FOLKLORE_EVENT`: `Fxx/Axx`와 검증 출처 필수.
- `MAIN_FRAME`: 창작 메인 프레임임을 명시하고 가짜 설화 출처를 붙이지 않는다.
- `AMBIENT`: 비서사 생활 장면이며 사건 수에 포함하지 않는다.

`FOLKLORE_EVENT`는 아래 항목을 전부 통과해야 한다.

1. `Fxx` 또는 `Axx` 소스 ID가 있는가?
2. 원형 제목과 검증 출처가 내부 데이터에 적혀 있는가?
3. 게임 UI에서 원작 제목을 직접 노출하지 않는가?
4. 해당 지역의 고유 전승이 아닌데 고유 전승처럼 서술하지 않았는가?
5. 원전에 없는 귀신 능력·금기·주술 효과를 새로 만들지 않았는가?
6. 플레이어 개입 때문에 결말을 바꾸더라도 원형 인과관계는 유지되는가?
7. 설화와 무관한 사기·밀수·범죄를 새 LOCAL 퀘스트로 추가하지 않았는가?
8. 인간 사건이 필요하면 박문수·왕미행·김선달·옹고집·송사설화 등 실제 전승군에서 가져왔는가?
9. 길 위 빈 공간은 억지 사건 대신 생활 앰비언트로 둘 수 있는가?

11. 제주 본풀이와 함경 무가를 전승권 밖에 무작위 배치하지 않았는가?
12. C급 후보지는 ‘진짜 발생 장소’라고 단정하지 않았는가?

# 44. 구현 데이터 필수 필드

모든 콘텐츠:

```text
EVENT_ID
EVENT_CLASS             # MAIN_FRAME / FOLKLORE_EVENT / AMBIENT
RECORD_TITLE            # 플레이어에게 보이는 사건명
TRIGGER
LOCATION_TYPE
TIME_WEATHER
PLAYER_ACTIONS
RESOLUTION_BRANCHES
WORLD_STATE_CHANGE
```

`FOLKLORE_EVENT` 추가 필드:

```text
SOURCE_ID               # Fxx 또는 Axx
SOURCE_TITLE_INTERNAL   # 내부 원형명
SOURCE_TYPE             # tale / legend / shamanic_epic / classic
SOURCE_REGION_GRADE     # A+ / A / B / C / D
SOURCE_REGION_NOTE
ADAPTATION_MODE         # DIRECT / VARIANT / ECHO
SOURCE_VERIFIED         # true 필수
```

`MAIN_FRAME` 추가 필드:

```text
SOURCE_ID               # MAIN_FRAME_* 형태
MAIN_FRAME_ORIGIN_NOTE  # 창작 메인 프레임 설명
FOLKLORE_ECHO_IDS[]     # 선택적 연상/학습 재사용. 원작 출처라는 뜻이 아님
```

규칙:

- `FOLKLORE_EVENT`에서 `SOURCE_VERIFIED=false`면 빌드에 포함하지 않는다.
- `MAIN_FRAME`에 `Fxx/Axx`를 위장해 붙이지 않는다.
- `AMBIENT`에 사건 수를 부풀리기 위한 가짜 출처를 붙이지 않는다.
