## v2.3 정합성 패치

### 1. 일반 레벨 체계 제거

- 기존 숫자 레벨 기반 해금 조건을 모두 삭제한다.
- 경험치/레벨 게이지를 만들지 않는다.
- 전투 숙련은 주요 사건 완료로 해금한다.

| 숙련 | 해금 조건 |
|---|---|
| 받아밀기 | `CASE_NAMWON_COMPLETE` |
| 빠른 투척 | `CASE_HANYANG_BOOKSHOP_COMPLETE` |
| 회피베기 | `CASE_GANGNEUNG_COMPLETE` |
| 빠른 사격 | `CASE_GYEONGJU_COMPLETE` |
| 큰 짐승 흘리기 | `CASE_PYEONGYANG_COMPLETE && SKILL_BEAST_TRACE` |
| 보조도구 전환 | `CASE_HAMHUNG_COMPLETE` |

Vertical Slice에서는 현재 구현 결정대로 **남원 완료 후 받아밀기, 한양 책방 완료 후 빠른 투척**만 먼저 해금한다.

### 2. PROP ID 중복 수정

- `PRP_OFF_006` 책더미/책장: 유지
- 박규상 객주 표식 세트: `PRP_OFF_006` → `PRP_OFF_008`

### 3. PROP 절 번호 수정

- 기존 중복 `## 10. v2.2 연결부 보강 자산 영향`
- → `## 14. v2.3 연결부 보강 자산 영향`

### 4. R0104

천안삼거리의 `朴` 표식은 그대로 유지한다. 첫 노정 완주 전 빠른 이동이 열리지 않으므로 첫 플레이에서 자연스럽게 노출된다.

### 5. 변경하지 않는 것

- 월드/노정 구조
- F01~F48/A01~A22 설화 배치
- 박규상 복선 위치
- 이겸 조사 원칙 6개
- 메인 ACT 순서
- 기존 캐릭터/아이템/대형 프롭 범위
