# 이야기 시계 규칙 v1 — 메인 날짜 · 세상 시각 · 계절 연출

- 대상: 메인 「천하제일 신선 소동」 3일~7일(승인된 통합 시간표 [`master_timeline_v1.md`](master_timeline_v1.md) v1.1)과 자유 탐험·독립 설화가 함께 도는 시간
- 성격: **설계 규칙(제안)**이다. 코드·데이터는 바꾸지 않았다. 2026-10-18.
- 사용자 결정(3차): ② 이야기 날짜는 **큰 메인 사건이 넘어갈 때만** 흐른다. 자유 탐험·독립 설화는 따로 돈다. 낮·밤 연출이 메인 사건의 때와 어긋나지 않게 한다. ③ 계절은 **늦여름~이른 가을**로 정한다. 계절 체계를 새로 만들지 않는다.

## 1. 지금 코드에 있는 것(확인한 것)

| 무엇 | 어디 | 동작 |
|---|---|---|
| 세상 시각 | `scripts/main.gd` `hour`(0~24 실수), `_apply_time()` | **저절로 흐르지 않는다.** `time_flow`는 기본 `false`다. 시험용 키(`time_step`, 6시간 건너뛰기)만 있다 |
| 사건이 시각을 정함 | `scripts/story/story_director.gd` `set_hour(h)` | `main.hour`를 바꾸고 그 사건 상태 `S.time`에도 적는다. 춘향(`namwon_chunhyang_*`)·제주·황주가 박자마다 부른다. 황주만 조사 중 `TIME_RATE`(1시간 = 2.5분)로 천천히 흐르게 한다 |
| 사건을 열 때 시각 | `story_director._apply_world()` | 처음(phase start)이면 `case.start_hour`(메인 서장 9.5), 아니면 저장된 `S.time` |
| 사건을 바꿀 때 | `story_director.switch_case()` → `_keep_hour` | 같은 공간에서 사건만 바꾸면(오누이 ↔ 메인 등) **세상 시각을 그대로 잇는다.** 저장된 그 사건의 옛 시각으로 되돌리지 않는다. `fresh`일 때만 예외 |
| 한 공간 한 사건 | `scripts/story/case_registry.gd` | 공간마다 한 번에 한 사건. 메인이 `rest_flag`(쉬는 자리) 깃발에 서 있으면 스스로 서는 독립 사건이 먼저 고른다 |
| 주막에서 쉬기 | `scripts/story/save_keeper.gd` `rest()` | 주막 안 [F]: 기록만 정리 / 한 시진(+2시간) / 해 질 녘까지(18시) / 하룻밤(다음 날 7시). 짧은 암전 → `set_hour` → 저장 |
| 빠른 이동(역마 창) | `scripts/region/fast_travel.gd` | 거리 ÷ 말 속도만큼 **시각을 앞으로 돌린다**(0.3~60시간). 2시간 넘으면 날씨를 다시 굴릴 수 있다 |
| 권역 넘어가기 | `scripts/region/travel.gd` | 다음 공간으로 `{hour, weather}`를 넘긴다 — 시각과 날씨가 이어진다 |
| 날씨 | `scripts/region/weather.gd` | 권역 기후대 확률로 고른다. 남원·운봉 권역은 `south`(맑음·흐림·비·안개, **눈 없음**). 이야기 쪽 API: `force(kind, duration, fade, values)` · `release()` · `force_time(hour, …)` · `release_time()` · `snapshot/restore` |
| 날짜·계절 | — | **날짜 수를 세는 변수가 없다. 계절 체계도 없다.** 논밭(`scripts/region/farm.gd`)은 `season = -1`이 기본이고, 이때 논마다 저장된 상태(`P[k*STRIDE+5]`)를 그대로 쓴다. `--farmseason=` 시험 인자만 계절별 그림을 고른다 |

**정리.** 시각은 **사건이 정하고**, 사람이 쉬거나 멀리 갈 때만 앞으로 간다. 날짜를 세는 곳이 없다. 그러므로 '이야기 날짜'는 새 변수를 두지 않고 **메인 진행 깃발에서 읽어 내는 값**으로 두면 지금 구조에 맞는다.

## 2. 두 시계

| 시계 | 무엇 | 누가 움직이나 | 화면에 보이나 |
|---|---|---|---|
| **이야기 날짜** | 메인 3일~7일(시간표 v1.1) | **메인 장·큰 사건이 넘어갈 때만**(§3 표). 저장하지 않고 메인 깃발에서 읽는다 | **숫자로는 보이지 않는다**(DEC: 실종 일수는 숫자로 쓰지 않음). 볕·날씨·인물의 말로만 |
| **세상 시각** | `main.hour` | 사건의 박자(`set_hour`) · 주막 쉬기 · 빠른 이동 · 권역 넘어가기 | 하늘·빛·등불·기록 창의 시진 |

- 자유 탐험과 독립 설화는 **세상 시각만** 쓴다. 이야기 날짜를 움직이지 않는다.
- 7일은 이야기 안의 구조 시점일 뿐이다. **어떤 시계도 사망·실패 타이머가 아니다**(사용자 결정 1, v5.12 E).

## 4. 넘어가는 규칙

### R1. 메인 장(또는 박자)에 들어갈 때

| 경우 | 세상 시각 | 연출 |
|---|---|---|
| 지금 시각이 그 박자의 시각보다 **이르다**(같은 날 안에서) | 박자 시각으로 **앞으로** 맞춘다 | 0.25초 dip(구현 프롤로그의 dip과 같은 문법). 자막 없음 |
| 지금 시각이 그 박자 시각보다 **늦다** 또는 밤·낮이 다르다 | 박자 시각으로 맞춘다(다음 날로 넘긴 것으로 본다 — 이야기 날짜는 메인 깃발이 정하므로 문제없다) | 0.6초 암전(주막 쉬기와 같은 길이) + 볕이 바뀐 첫 컷. 자막 없음 |
| 이미 같다 | 그대로 | 없음 |

- 이 규칙은 `_keep_hour`(사건만 바꿀 때 시각을 잇는 동작)를 **고치지 않고**, 메인 사건이 박자를 열 때 한 번 `set_hour`를 부르는 것으로 맞춘다(구현 때 확인).

### R2. 메인 장을 떠나거나 장 사이에 있을 때(자유 탐험)

- 메인 장이 끝나면 메인은 **쉬는 자리**(`rest_flag`)에 선다. 그동안 세상 시각은 플레이어 것이다: 그대로 멈춰 있고, 주막 쉬기·빠른 이동으로만 간다(지금 동작).
- 이야기 날짜는 그대로다. 다음 메인 박자에 들어갈 때 R1이 시각을 맞춘다.
- **장 안에서**(예: 2장 밤판 도중) 플레이어가 장 구역 밖으로 멀리 나가면: 그 장은 멈춘다(지금처럼 사건 트리거는 그 자리에서만 돈다). 세상 시각도 그 장의 시각(밤)에 머문다. 돌아오면 이어서 한다. 장 도중에는 독립 설화가 새로 서지 않게 한다(R5).

### R3. 잠과 쉼

| 경우 | 규칙 |
|---|---|
| 주막 쉬기(지금 있는 [F]) | 언제든 쓸 수 있다. **세상 시각만** 간다. 이야기 날짜는 그대로다 |
| 메인 장 **도중** 주막 쉬기 | 막는다 — 그 장의 박자 시각과 어긋나기 때문. 주막 안내는 '기록만 정리하고 일어선다'만 열고, 나머지는 '지금은 쉴 때가 아니다'로 흐리게(지금 `disabled`·`hint` 꼴 재사용) |
| 메인 장 **사이**의 이야기 속 잠(4일 오전 · 5일 밤) | 화면 밖이다. 다음 박자의 R1 암전이 그 잠이다. 새 잠 장면을 만들지 않는다 |

### R4. 권역 사이 이동

| 경우 | 규칙 |
|---|---|
| 걷기·말(같은 권역) | 시각은 가지 않는다(지금). 메인 박자에 닿으면 R1 |
| 빠른 이동(역마 창) | 지금대로 거리만큼 시각이 간다. 이야기 날짜는 가지 않는다. 도착지가 메인 박자 자리면 R1이 다시 맞춘다 |
| 노정·권역 넘어가기 | 지금대로 시각·날씨가 이어진다. 메인 3일~7일 무대는 모두 남원·운봉 권역(`JL_NAMWON_UNBONG`) 안이다 — 메인 필수 이동에 권역 넘어가기는 없다 |

### R5. 메인 도중에 오누이·춘향을 할 때

| 경우 | 규칙 | 지금 코드와 |
|---|---|---|
| 메인 장 **사이**(쉬는 자리)에 오누이·춘향 시작 | 허용. 그 설화가 제 박자로 시각을 정한다(춘향은 8.4·18.1·21.0 등) | `switch_case` + `case_registry` 쉬는 자리 규칙 그대로 |
| 메인 장 **도중**에 설화 들머리를 밟음 | 설화를 시작하지 않는다. 들머리 인물은 '바빠 보이는구려, 나중에 오시오' 한 줄(새 줄)로 미룬다 | 메인 장 도중에는 `rest_flag`가 서지 않으므로 `case_registry`가 독립 설화를 고르지 않는다 — 들머리 행상(오누이 `entry: trigger`)에 조건 하나만 더하면 됨(구현 때 확인) |
| 설화를 하다 메인으로 돌아옴 | `_keep_hour` 때문에 설화의 마지막 시각이 이어진다 → 다음 메인 박자에서 R1이 맞춘다 | 그대로 둠 |
| 설화 안의 긴 시간(춘향 이별 → 어사 귀환 몇 달, DIRECTION v3.0 §6.3) | 설화의 시간은 설화 안에서만 흐른다. 메인 날짜를 움직이지 않는다. **다만 계절이 바뀌어 보이는 설화 장면(춘향 재방문 등)을 메인 도중에 하면 늦여름 연출과 부딪힌다** → 결정 필요(open_decisions N33): 계절이 다른 재방문 편은 메인이 끝난 뒤 열지, 아니면 그대로 둘지 | 정하지 않음 |

### R6. 날씨

- 메인 박자는 §3 표의 날씨만 `force` 한다. 박자가 끝나거나 장을 떠나면 `release` 한다(컷 안개와 같은 방식).
- 기후대가 `south`라 눈은 나오지 않는다. 비는 메인 박자에서 강제하지 않는다(늦여름 소나기는 자유 탐험의 기후대 확률에 맡김).
- 2장 밤은 **달을 밝히지 않는다**(횃불·소리 놀이가 산다). 지금 하늘에 달 표현이 없으면 할 일이 없다.

### R7. 저장과 불러오기

| 경우 | 규칙 |
|---|---|
| 메인 장 도중 저장 → 불러오기 | 그 박자를 다시 열 때 §3 표의 시각으로 맞추고, 박자 안에서 앞으로 간 만큼은 `S.time`을 쓴다(`S.time`이 박자 시각보다 이르면 박자 시각) |
| 장 사이(쉬는 자리) 저장 | 세상 시각은 `S.time` 그대로(지금 동작) |
| 이야기 날짜 | 저장하지 않는다. 불러오면 메인 깃발에서 다시 읽는다 → **옛 저장도 옮김 규칙이 필요 없다** |
| 독립 설화 도중 저장 | 그 설화의 `S.time` 그대로(지금 동작) |

### R8. 어긋남을 막는 검사(구현 때 시험으로)

1. 메인 박자 장면이 시작된 첫 프레임의 `main.hour`가 §3 표와 ±0.3시간 안인가.
2. 메인 장 도중 주막 쉬기가 막히는가.
3. 메인 장 도중 독립 설화 들머리가 서지 않는가.
4. 2장 밤판 동안 낮 하늘이 나오지 않는가(불러오기 포함).
5. 대사·기록에 날짜 숫자가 없는가.

## 5. 계절 연출 지침 — 늦여름~이른 가을

계절 체계를 만들지 않는다. **배경 · 날씨 · 소품 · 소리 · 말**로만 보인다.

| 영역 | 보일 것 | 피할 것 | 지금 자산·코드 |
|---|---|---|---|
| 논 | 이삭이 패어 고개를 숙이기 시작한 벼, 초록에 누런 기운. 아직 베지 않았다 | 벼 벤 그루터기, 물 댄 빈 논, 보리 | 논밭은 저장된 상태를 쓴다(`season=-1`). 메인 무대 둘레 논은 **배치·소품으로** 덮는다(익은 벼 그림은 `farm.gd` 가을 상태 그림이 이미 있음 — 시험 인자 `--farmseason=autumn`로 확인만, 게임 설정으로 쓰지 않음) |
| 마을 | 초가 지붕·멍석에 **이른 고추** 말리기, 박·호박이 지붕에, 수수 이삭, 대추가 붉어지기 시작 | 김장, 곶감, 눈 | 키트 소품. **단 여원재 길(D3~D5 구간)에는 붉은 고추를 두지 않는다** — 그 길에서 붉은색은 광고판만 쓴다(구조 검토 B3-3) |
| 산 | 짙은 초록에 밤송이(풋 → 갈색), 도토리, 머루·다래 | 단풍 절정, 낙엽 수북 | 산열매는 5장·최종장 생존 흔적과 같은 것(시간표 §6) |
| 소리 | 낮: 매미가 **잦아드는** 소리(드문드문). 해거름부터: 귀뚜라미. 밤: 풀벌레 | 한여름 매미 떼, 개구리 합창 | `birds_day`·`stream_small` 등 기존 바탕 소리 + 임시 소리 둘(매미 드문, 귀뚜라미) |
| 날씨·빛 | 낮은 맑고 볕이 따갑다. 아침 안개. **밤은 서늘하다**(인물이 소매를 여미는 몸짓) | 입김, 서리 | 날씨는 `south` 확률 그대로. 메인 박자는 §3 |
| 사람 | 홑옷·삼베, 밤에는 겹옷을 걸침. 들일은 피사리·논두렁 풀베기 | 솜옷 | 인물 그림은 사용자 제작 대기 — 옷은 그 일정에 묶임 |
| 말 | 계절을 직접 말하지 않는다. 한 장에 한 줄 정도, 일과 날씨로 | 날짜·명절 이름(추석 등) | 아래 예 |

**말 예(한 장에 한 줄 이하, 모두 [신규 제안]).**
- 1장 마을 노인: "벼가 고개를 숙이기 시작했으니, 산에 빌 것도 많지."
- 2장 우치(밤): "벌써 밤바람이 차구먼. 매미도 철을 아는 게지."
