# 업무 리스트 — 고을 차이 + 기후대 시스템 (2026-10-03 정리)

목표: 고을마다 **첫 화면에서 알아볼 수 있는** 차이를 만들고, 그 위에 지역별 기후 차이(남부 해·비, 북부 추위·눈)를 얹는다.
범위·정체성 층(L0~L4)·대표 도시 목록: `docs/WORLD_SCOPE_PLAN.md`. 원칙: 고증 → 원칙 → 게임성 순. 고정 카메라(화면 폭 약 35m, 위에서 내려다봄)라 **화면 축척의 큰 신호**부터 다르게 한다.
통과 기준(모든 단계 공통): **눈가림 시험** — 고을 이름을 가린 게임 화면을 섞어 보고 어느 고을인지 맞힐 수 있어야 한다.

## A. 고을 차이 (우선순위 순)
| # | 업무 | 담당 |
|---|---|---|
| A0 | 고을 성격표 스키마(주 지붕·담 재료, 마을 짜임, 어귀 장면, 사람·짐승, 생업, 분위기, 이야기, 기후대) → 계약서 추가 | 총괄 |
| A0.5 | **입지 유형(원형)**: 해양(포구)·강가(나루)·산악(산촌)·평야(들)·고개·읍치(성곽)·사찰 아래·섬(제주) + 특수 유형 **도읍(한양)**. 유형마다 지붕·담·짜임·어귀 장면·사람·식생·분위기·기후대 기본값, 각 고을은 유형 기본값 + 고유값으로 덮어쓰기. 이 권역: 남원=읍치, 운봉·이백=평야(고원 들), 인월=강가+역참, 여원재=고개, 산내=사찰 아래, 반선=산악. 해양은 다음 해안 권역에서 처음 시험 | 총괄 → 전원 |

| A3 | **어귀 장면**: 고을마다 들어서는 순간 보이는 고유 장면 하나(운봉 억새 들판+돌장승, 인월 마방·역 깃발, 반선 물레방아 줄+계곡 다리, 여원재 성황당 돌무더기·오색 천) | 랜드마크 · 마을 키트 · 배치 |
| A4 | **사람·짐승**: 인월 말·보부상, 운봉 소·농부, 산내 스님, 반선 약초꾼 — 프레임 캐릭터 종류 추가와 배회 배치 | 캐릭터(웹 굽기 엔진) · 엔진 |

## B. 기후대 시스템 (지역별 차이 — 시간에 따라 바뀌는 계절 아님)
남부·중부는 해와 비, 북부는 추위와 눈. 기후대는 **위도 + 해발 + 해안 거리**로 정하고(남부라도 고산은 눈), 날씨는 기후대별 **출현 확률**로.

| 기후대 | 지역 | 날씨 | 식생·땅 | 집(지역 가옥형) |
|---|---|---|---|---|
| 남부 | 전라·경상 남부, 남해안 | 해 + 잦은 비, 장마 안개 | 대숲·동백·감나무, 짙은 녹음, 물 댄 논 | 一자형 홑집, 넓은 마루, 낮은 초가 |
| 중부 | 경기·충청·강원 서부·경상 북부 | 맑음·비, 가끔 눈 | 소나무·참나무, 논밭 반반 | ㄱ자·ㄷ자집 |
| 북부 | 평안·황해 북부·함경 | 추위 + 눈, 낮은 해·찬 빛 | 침엽수(전나무·잎갈나무), 눈 덮인 산·지붕, 밭 위주 | 田자형 겹집, 두꺼운 벽, 작은 창, 정주간 |
| 고산 | 지리산·백두대간 고지, 백두산 | 눈·안개·강풍 | 구상나무·고사목, 눈밭 | 거의 없음, 너와·귀틀집 |
| 해안·섬 | 동해안, 제주 | 해무·강풍 | 해송, 현무암 | 제주 돌집·띠지붕 |

| # | 업무 | 담당 |
|---|---|---|
| B1 | 기후대 필드: 권역 데이터에 기후대 지도(위도·해발·해안 거리로 계산), 고을 성격표에 기후대 값 | 지형 데이터 · 총괄(계약서) |
| B2 | 날씨 시스템: 맑음·비·안개·눈·강풍, 기후대별 출현 확률, 날씨 전환(비 입자·눈 입자·안개 농도·바람) | 엔진 |
| B3 | 색·빛 층: 기후대별 하늘·빛·색보정(남부 따뜻·습함, 북부 차갑고 낮은 해) | 엔진 + 공용 재질(총괄) |
| B4 | 눈 층: 지붕·땅·가지 윗면 눈 덮기 셰이더(북부·고산 기본, 고도에 따라 눈선) | 엔진 |
| B5 | 텍스처 층: 기후대별 땅·이엉·물 텍스처(남부 젖은 흙·이끼, 북부 언 땅·얼음 개울) | 총괄 + 자연 |
| B6 | 식생: 기후대별 수종 규칙(남부 대숲·동백, 북부 침엽수), 고도 눈선 위 식생 | 자연 |
| B7 | 지역 가옥형 키트: 남부 一자 홑집, 중부 ㄱ·ㄷ자, 북부 田자 겹집, 귀틀집, 제주 돌집 | 마을 키트 |
| B8 | 기후 소품·배치: 남부 빗물받이·도롱이, 북부 장작더미·고드름·굴뚝 연기·눈 치운 길 | 마을 키트 · 배치 |
| B9 | 북부·고산 겨울 물: 개울이 얼면 얼음 위 걷기 | 엔진 |
| B10 | (나중) NPC 기후대 옷차림(남부 홑옷·도롱이, 북부 솜옷·털모자) | 캐릭터 |

이 권역(남원·운봉·지리산 서부)은 **남부 + 고산(지리산 고지)**: 해·비·안개, 고지에만 잔설. 북부 눈·추위는 북쪽 권역에서 시험.
