# 월드 범위 계획 — 대표 도시 · 위성 마을 · 길목 쉼터 (2026-10-03)

월드 개발계획서 v1.1(`seolhwa/docs/WORLD_DEV_PLAN.md`) §5.2의 "권역 확장"을 **필요한 만큼 만드는 방식**으로 좁힌다.
명세서 거점 88곳을 다 짓지 않는다. 문화권마다 **설화가 몰린 대표 도시** 하나를 완전히 짓고, 둘레에 **특징 하나씩 가진 위성 마을**, 권역 사이 **노정의 길목 쉼터**(이벤트·조우 자리)만 만든다. 나머지 고을은 지도·이정표·소문으로만 존재한다.
근거 목록: `docs/FOLKTALE_CATALOG.md`(설화 163편, 문화권별·장소 유형 색인).
원본 명세서: `seolhwa/docs/WORLD_SPEC_v0.3.md` — §21 "거점 삭제 금지"와 이 문서의 축소 범위가 어긋남(사용자 결정 대기). 새 권역 배치는 명세서 §18·§25~§29 규칙을 따른다.

## 1. 정체성 층 (아래 층이 위 층을 물려받고 고유값만 덮어씀)
| 층 | 단위 | 정하는 것 |
|---|---|---|
| L0 시대 | 조선 전체 | 1870년 양식, 화풍, 공통 규칙(배산임수, 읍치 짜임) |
| L1-기후대 | 남부·중부·북부·고산·해안섬 (위도·해발·해안 거리로 계산) | 날씨 확률, 눈·비, 식생, 하늘빛 |
| L1-문화권 | 호남·영남·기호·관동·해서·관서·관북·탐라 | 가옥형(호남 一자 홑집, 영남 북부 ㅁ자 뜰집, 기호 ㄱ자, 관동 귀틀·너와, 관북 田자 겹집, 탐라 돌집), 지붕·담, 풍습, 말씨 |
| L2 권역 | 수계·분지·교통권 | 권역 색: 특산, 지역 설화, 장시 연결망, 대표 지형, 권역 고유 재료 |
| L3 고을·마을 | 입지 유형(읍치·평야·강가·산악·고개·사찰 아래·해양·섬·도읍) + 고유값 | 마을 짜임, 어귀 장면, 생업, 사람·짐승, 상징 |
| L4 장소 | 건물·경내 | 랜드마크, 사건 장소 |

권역 사이는 L1·L2로 크게, 권역 안 이웃 고을은 L3(입지·생업)로 은근하게 구별한다.
주의: 안동은 영남(남부 문화권, 내륙이라 겨울이 추움)이다 — 기후대와 문화권을 따로 본다.

## 2. 등급
| 등급 | 무엇 | 얼마나 짓나 |
|---|---|---|
| 대표 도시 | 권역 중심, 여러 사건·이야기의 무대(A+/A 설화) | 완전히: 성·관아·장터·골목, 촘촘하게 |
| 위성 마을 | 대표 도시 둘레 2~4곳, 마을마다 특징 하나 | 작고 뚜렷하게 |
| 길목 쉼터 | 노정 위 고개·주막·나루·원·지나가는 성읍 | 몇 채짜리 장면, 이벤트·조우(D등급 설화: 호랑이·도깨비·여우 등) |
| 지도에만 | 나머지 고을 | 짓지 않음 |

고르는 기준: 설화 전승지(A+/A 우선) · 지형 다양성 · 교통 요지 · 문화권마다 하나.

## 5. 2순위(필요해지면 대표 도시급으로)
호남 전주·구례 / 영남 밀양(아랑)·안동 / 기호 개성·공주·부여 / 관동 원주 / 관서 철산(장화홍련 — 밀양 아랑과 짝) / 관북 북청. 대부분 노정에서 '지나가는 성읍'으로 먼저 등장.
