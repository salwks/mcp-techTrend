## 1. 확인한 기존 구현

- **모델링**
  - `kit/village/_common.gd`의 `M`(부분별 Batch·충돌체·조명·앵커·걷기 면)과 `Kit`(`scripts/kit/kit.gd`)를 쓴다.
  - Kit은 버텍스 색 그라데이션 + 붓 아틀라스 + 먹선 헐로 그린다.
  - 재질은 아틀라스 하나(`Kit.material("atlas")`)와 천만 쓴다. 키트마다 재질을 따로 만들지 않는다.
- **기존 건물 키트**
  - `choga.gd`: 3칸 하나에 plan 3종(기본·il·giyeok).
  - `giwa.gd`: 5칸 하나.
  - `house_compound.gd`: 크기 3종(small·medium·large).
  - 칸 수·칸 쓰임·지역·신분이 자료로 바뀌지 않는다.
  - 창호는 한 가지 격자뿐이고, 벽 짜임(인방·중방)·서까래·막새 줄·주춧돌 구분이 없다. 실내는 초가 한 칸뿐이다.
- **걷기·충돌**: `M.walk_floor`(building-floor-roof) — 한 걸음 0.32m. 기단은 계단·댓돌로만 오른다. 충돌체는 상자·원.
- **실내**: `interior { minX…, camera, hide:[roof, front] }`. 들어서면 실내 카메라가 켜지고 지붕·앞벽을 숨긴다.
- **스트리밍·LOD**
  - 정적 물체는 근경 타일(반경 2, 약 512m+)에서 전부 붙고, 중경은 큰 것만 붙는다.
  - 건물별 LOD는 없었다. 집 묶음 `lod=1` 한 덩이만 있었다.
- **키트 캐시**: `kit_cache.gd`. params JSON + 같은 칸의 `_*.gd` + preload를 따라간 스크립트의 내용 해시로 디스크(.scn + .info)에 담는다.

## 2. 명세 형식(spec)

건물 한 채 = 사전(JSON으로 그대로 저장 가능). 전체 칸 설명은 `kit/bldg/_spec.gd` 머리에 있다. 예:

```json
{ "type": "anchae", "region": "central", "cls": "yangban", "seed": 1, "wear": 0.3, "interior": false,
  "base": { "kind": "jangdae", "h": 0.78, "tiers": 2 }, "floor_dh": 0.3, "cho": "dressed", "column": "round", "col": 0.22,
  "wall": "plaster", "wall_h": 2.3, "lattice": "a", "meoreum": true, "paint": "none",
  "roof": { "kind": "giwa", "form": "hipgable", "eave": 1.3, "rise_k": 0.6, "lift": 0.4, "buyeon": false },
  "chimney": { "kind": "stone", "at": "back_right" },
  "wings": [
    { "id": "main", "depth": [2.9], "toet": { "kind": "toet", "d": 0.9 }, "ends": ["hipgable", "corner"], "corner_w": [0, 3.8],
      "bays": [ { "w": 2.7, "fn": "room", "role": "anbang", "front": { "kind": "door2" } }, { "w": 2.8, "fn": "hall" }, … ] },
    { "id": "wing1", "x": 7.6, "z": 1.9, "ry": -1.5708, "depth": [3.8], "ends": ["open", "hipgable"], "joined": true,
      "bays": [ { "w": 2.9, "fn": "kitchen", "front": { "kind": "join" } }, { "w": 2.7, "fn": "store" }, … ] } ],
  "attach": [ { "kind": "firewood", "x": -6.4, "z": -0.2 }, { "kind": "jangdok_s", "x": 4.6, "z": -2.8, "n": 4 } ] }
```

| 칸 | 값 |
|---|---|
| type · region · cls · seed | 프리셋 이름 · south/central/north/jeju/mountain(문화권 코드 JL·GG·HG… 도 받음) · poor/commoner/middle/yangban/official · 변주 씨앗 |
| wear | 0~1: 나무 잿빛 · 이엉 금빛→잿빛 · 용마루 처짐 · 흙벽 빛 |
| base · floor_dh | 기단 흙/막돌/장대석(단 수)·높이, 기단 위 방·마루 높이 |
| cho · column · col | 주춧돌 덤벙/다듬은/원형 · 기둥 각/원 · 굵기 |
| wall · wall_h · lattice · meoreum · paint | 흙벽/회벽/판벽/제주 돌벽 · 벽 높이 · 창살 띠살/용자/아자/빗살/꽃살 · 창 밑 머름 · 단청 없음/가칠/단청 |
| wings[] | 날개(一자 몸채) 여러 개 → 一·ㄱ·ㄷ자, 객사 세 채 등. `bays[]`는 칸마다 너비·쓰임 + 면별 창호를 갖는다. `depth[]`(홑집/겹집) · `toet`(쪽마루/툇마루+퇴기둥) · `ends`(지붕 끝: hip/gable/hipgable/corner/open) · `roof_up` · `floor_up`(누마루) · `butt`(높은 건물 벽에 맞댐) |
| 칸 쓰임 fn | room·hall(대청)·kitchen·store(곳간)·shop·maru·shed·stable·gate(대문간)·jeongju(정주간)·mill·forge·shrine |
| 면 kind | door2·door1·door4(분합)·bunhap_up(들어열개)·window·smallwin·plank·plank2·salchang·wall·open·shop(들창)·gate·board·rail·join |
| roof | kind 초가/기와/너와 · form · eave(처마 내밀기) · rise_k · lift(앙곡) · buyeon(부연) · net(새끼 그물) · rc(이엉 모서리) |
| chimney · attach | 굴뚝 흙/독/돌(연가)/통나무/없음 + 자리 · 곁 것(장작·장독·평상·용수·한데부뚜막·술독·물레바퀴·박·소쿠리·연장) |
| interior · refs | 실내(칸막이·장판·마루·가구) · 참고 그림 열쇠 |

**묶음(compound, `kit/bldg/compound.gd`)**은 건물 명세 여럿 + 담·대문·마당 것이다. `choga_house` · `jungnong` · `yangban`(짜임 3가지) · `jumak_yard` · `gate_demo` · `village_entry`가 있다. 배치 로더에 `layout()`으로 조각을 넘겨 건물마다 따로 짓고 스트리밍한다.

### 지붕(핵심)

- **기와**
  - 높이 = 처마 + rise·(오목 단면) + 앙곡(모서리 치켜들기) − 처짐.
  - 끝 구역의 x 칸을 깊이 칸과 같게 하고, 대각선을 추녀선 방향으로 자른다. 그래서 추녀선이 삼각형 모서리 위에 정확히 온다(톱니 없음).
  - 팔작: 가운데는 맞배 높이, 끝 구역은 min(앞뒤, 옆) 높이. 사이에 생기는 수직 틈을 합각벽(판벽 + 박공 널)으로 막는다.
  - 용마루·내림마루·추녀마루는 같은 높이 함수의 꼭짓점을 따라 놓는다. 그래서 지붕에서 뜨지 않는다(fix-1017 뜬 용마루).
  - 막새는 처마 띠에 0.28m마다, 기와골은 0.33m마다 둔다(rect 반복 UV).
  - 처마 밑은 연등천장 무늬다. 서까래(6각)·부연(각)·추녀(모서리 굵은 각재)를 그린다.
- **ㄱ·ㄷ자 회첨(corner)**
  - 몸채 지붕이 날개 바깥 처마까지 정사각 모퉁이 구역을 덮는다.
  - 구역 안 높이:
    - 뒤·바깥 = min(몸채 비탈, 날개 비탈) → 추녀.
    - 앞·안 = max → 회첨골.
    - 앞·바깥 = 날개 비탈.
    - 뒤·안 = 몸채 비탈.
  - 날개 지붕은 몸채 앞 처마 줄에서 'open'으로 잘린다.
  - 결과: 용마루가 ㄱ으로 이어지고, 골은 한 면으로 만나며, 두 지붕 판이 서로 뚫지 않는다.
  - 기와 날개 깊이는 몸채 지붕 깊이(벽 + 퇴칸)와 같게 둔다. 그래야 모퉁이 구역이 정사각이 되고 골·추녀가 45°가 된다.
- **솟을대문(행랑채)**
  - 행랑 지붕을 대문 칸에서 두 토막(대문 쪽 끝 맞배)으로 끊는다.
  - 대문 칸은 기둥을 1.05m 올리고, 같은 깊이의 맞배를 한 층 위에 따로 얹는다(풍판 포함).
  - 양옆 행랑 지붕은 그 처마 밑으로 들어간다(층진 단면 — 겹친 판 아님).
- **객사**: 익헌 지붕의 정청 쪽 끝은 `butt`(처마를 내밀지 않고 0.08m)이다. 정청 벽에서 0.6m 떨어져 정청 박공 처마 밑에 든다.
- **이엉**
  - 처마가 둥근 모서리 사각인 등고선 고리 9줄이다. 단면은 볼록(s(1.5−0.5s))하고, 곧은 용마루 줄 + 용마름(짚 결 무늬, 끝은 이엉 속으로 묻힘)이 있다.
  - 처마 두께 띠, 서까래(도리 위에서 처마 밑으로 기울게), 새끼 그물(제주 7~9줄)을 그린다.
  - 처마 높이는 벽 위 0.3m다. 도리가 낮은 제주 지붕 밖으로 나오지 않게 정했다.
  - 처마 밑면 안쪽 고리는 **모서리가 날카로운** 사각으로, 벽·기둥 줄 바로 바깥, 벽 위 + 0.08m에 둔다. 둥근 고리는 벽 모서리 안으로 파고들었다(③의 원인 꼴).
  - 둥근 모서리 반지름은 벽 모서리 + 0.32m를 덮는 만큼으로 줄인다(`rc` 자동 제한).

### LOD · 재질 · 캐시

- **LOD**: 한 노드 안에 near(0~55m) · mid(55~160m) · far(160m~)를 두고 `MeshInstance3D.visibility_range`(±2m 여유)로 바꾼다. far는 그림자를 끈다.
  - mid: 기단 + 몸 상자 + 창호 판 + 앞 기둥·창방 + 거친 지붕(3칸 깊이) + 용마루.
  - far: 몸 상자 + 지붕 덩이.
- **재질**: Kit 아틀라스 재질 하나 + 천. 건물마다 재질을 따로 만들지 않는다.
  - 실내가 없는 건물의 near는 한 메시라서, 그리기 호출이 표면 1~2개(+그림자)다.
  - 실내 건물은 부분 노드(기단·몸·앞·지붕·실내·곁 것)가 6개다.
- **키트 캐시**: 키트 경로 `bldg/building`·`bldg/compound`·`bldg/gate`. 같은 칸 `_*.gd`(spec·roof·furn·atlas)와 preload한 village 키트가 해시에 들어간다. 그래서 스크립트를 고치면 다시 짓는다.
- **배치 로더 연결(두 줄)**: `placement_loader.gd`의 `dress_is_building`이 `bldg/`도 건물로 보게 했다(처마 낙숫물 칠). `YARD_COMPOSITES`에 `bldg/compound`를 넣었다(담 안 마당 흙).

### 걷기 · 충돌 · 실내

- **걷기 면**
  - 기단 윗면(기단 높이 > 0.33m면 큰 돌계단, 단 0.24m)이 있다.
  - 바닥이 기단보다 높으면 댓돌(중간 높이)을 둔다.
  - 툇마루·쪽마루, 트인 칸 바닥(대청·마루·가게·헛간), 실내면 방·부엌 바닥, 누각 나무 계단·위층 마루, 대문 문지방(0.18)·디딤돌(0.13)도 걷기 면이다.
- **충돌**
  - 닫힌 칸은 칸 상자 하나다.
  - 트인 칸은 뒷벽 + 끝 옆벽만 둔다.
  - 실내면 앞벽에 문 자리 0.9m만 트이고, 칸막이는 문 자리(가운데 0.9m)만 트인다.
  - 가구·부뚜막·독은 상자·원 충돌체다.
  - 등잔·소반은 칸막이 문길을 막지 않는 구석에 둔다.
- **실내**
  - 방: 장판, 흰 도배(앞벽 안쪽 도배는 '앞' 부분이라 잘라 보기에서 함께 숨는다), 칸막이(방↔방 외여닫이, 방↔대청 쌍문, 부엌↔방 문)가 있다.
  - 대청: 우물마루.
  - 부엌: 흙바닥(마당 높이), 부뚜막 + 솥 + 아궁이, 살강, 물독, 장작.

- **디테일**: 바깥·안 디딤돌(0.13m), 넘어서는 문지방(0.18m — 둘 다 걷기 면), 문간 박석, 널판 문짝 + 띠장, 문고리(바깥), 빗장 걸이(안)·빗장(닫힘), 둔테(기둥 안쪽 위·아래)를 둔다. 문짝은 안(마당)으로 열린다.

  - 행랑채 집은 중문을 대문 줄에서 2.5~4m 비켜 내고 중문 안에 내외담을 둔다.

### 6-3. 겹친 면 결과

결과는 `shots/building_builder/face_check.json`에 있다(§6-3a). 고친 것은 아래와 같다.

- 내림마루가 용마루 밑에서 겹치지 않게 했다.

## 10. 한계(정직한 평가)

- **조선 집으로 읽히는가**
  - 1인칭·마을 카메라에서는 읽힌다. 짜임(인방·중방·문선)·창살·서까래 끝·막새·장대석·댓돌·툇마루가 근거리에서 기존 키트보다 훨씬 '집'답다.
  - 기와 지붕(앙곡·팔작 합각·회첨)과 솟을대문·객사의 층진 지붕이 가장 효과가 크다.
  - 약한 곳:
    - 이엉 지붕이 여전히 넓은 '덩이'로 보인다. 짚 결 무늬가 크고 고르며, 실제 초가의 처마 끝 들쭉날쭉함·묵은 얼룩이 약하다.
    - 남부 초가 시드끼리 실루엣이 비슷하다(칸 수·툇마루·외양간이 바뀌어도 지붕이 화면을 차지한다).
    - 마을 카메라(22°)에서 시전·동헌처럼 긴 기와집은 지붕이 화면 대부분을 덮는다.
- **다양한가**
  - 유형 사이는 확실히 다르다. 시드 사이는 평면·칸·곁 것이 바뀌지만 같은 유형 안에서는 '같은 손'이 보인다.
  - 양반가 짜임 3가지(행랑+중문 / 옆 사랑+물러난 대문 / 튼ㅁ자)는 서로 다르게 읽힌다.
  - 지붕 재료가 기와·이엉·너와 셋뿐이다(굴피·억새·돌너와는 기존 board_roof만).
- 실내 가구가 소품 수준이다(작은 상자). 방 천장(반자)·벽장·다락이 없다.
- 물레바퀴는 옆벽 축이라 남쪽 카메라에서 옆모습으로 보인다(기본 시점에서는 보임).
- **겹친 면**: 실외 부재 이음(창방·도리 끝, 누각 내림마루 가까이)에 10cm²~0.17m²짜리가 몇 남았다(§6-3a). 지붕 밑에 가려지는 자리다.
- **갤러리 촬영 한계**
  - 촬영 터가 붙어 있어서, 이웃 항목의 터 고르기 높이 차로 땅에 구덩이가 생긴 곳이 있다(배치 간격 문제, 실제 마을에는 해당 없음).
  - 나무가 카메라를 가리는 장이 있다(가림 처리 켬).
  - 대화 카메라 그림에 상대 인물이 빠졌다(`--nostory`).
- **아틀라스**: 웹에서 아틀라스를 다시 내보내면 새 12칸이 지워진다. `tools/bldg/make_atlas.gd`로 다시 그린다.
- **키트 캐시 위치**: 시험 도구는 `--kitcache=/tmp/seolhwa_bldg_kit_cache/`로 돌렸다. 앞선 몇 번의 갤러리 실행은 기본 `user://kit_cache/`에 새 항목(bldg/*)을 썼다. 저장 파일은 건드리지 않았다(모래상자 `설화록_test`).

## 11. 다음 단계(배치·마을 틀로 넓히기)

1. **보기 승인 뒤, 남원 한 구역부터**: `placement_namwon.json`의 `village/house_compound` 일부를 `bldg/compound`(choga_house·jungnong)로 바꾼다. 같은 자리·footprint 안에서 시드만 다르게 한다.
   - 기존 키트와 겹치는 담·마당 흙은 그대로 쓴다(`YARD_COMPOSITES` 연결 끝남).
2. **고을 틀(town template)**
   - 고을 성격표(roof·wall 재료)를 `region`·`cls`로 넘긴다.
   - 필지(parcels)마다 집 묶음 유형을 고르는 표(읍성 안 양반가·향리 기와집 비율, 장터 둘레 시전·주막, 어귀 서낭·장승)를 placement 생성기(tools/placement)에 붙인다.
3. **길과 대문 방향**: 묶음의 대문(+z)을 가까운 길 쪽으로 돌리고, 물러난 대문·문간 마당을 골목 폭에 맞춘다.
4. **이야기 연결**: 이야기 인물 집은 `spec` 고정(시드 고정)으로 저장해 바뀌지 않게 한다. 기존 앵커 이름(door·maru·daecheong·kitchen·steps)은 그대로 쓴다.
5. **기존 키트 겹침**(§6 ①)은 공용 키트 담당이 고친다. house_compound large의 사랑채 자리, giwa ㄱ자, daemun 솟을이 대상이다.
6. **보완**: 이엉 처마 끝 흐트러짐·묵은 이엉 얼룩, 겹친 면 남은 짝, 반자·벽장, 지역별 지붕 재료(굴피·억새·돌너와), 물레바퀴 방향.
7. **편집기 안 도구**: 이번에는 하지 않았다. 지금은 `--bldgallery --bgonly=id`로 낱장을 다시 찍는다(약 40초). 다음에 명세 JSON을 고쳐 다시 짓는 편집기 플러그인을 단다.
