## C. 외벽 모서리 이음(중간 우선 요청)

요청: "외벽과 외벽 끝이 서로 붙지 못한다. 모서리를 더하든 맞춰라. 모서리만 다르게 보이게 하지 마라."

### C-1. 찾은 원인
1. **벽 조각이 기둥 속에서 멈춤**(`building.gd _face`): 벽 채움은 칸 양끝에서 기둥 반지름×0.9만큼 물러나 기둥이 모서리를 메우는 구조였다. 기둥은 주춧돌 위(기단 + 0.1~0.18m)에서 시작하므로, **바닥이 낮은 칸(부엌·대문간·헛간, 바닥 0.04m)** 모서리 아래와 **ㄱ·ㄷ 날개 이음**(날개 부엌 벽 0.04m ↔ 몸채 방 벽은 기단 위 0.6m부터)에 기둥도 벽도 없는 틈이 생겼다.
2. **벽 조각마다 무늬·빛이 따로**: 벽 채움 상자가 면마다 무늬를 0~1로 늘여 붙이고(긴 조각·짧은 조각의 흙 무늬 크기가 다름), 빛 그라데이션을 조각 높이마다 따로 매겨 이웃 조각·모서리에서 빛이 끊겼다.
3. **담 모서리**(`compound.gd` + `village/todam`): 두 담 토막이 가운데 줄 교점에서 멈춰 바깥 모서리에 담 두께 절반짜리 네모 홈(0.225m)이 비었다.

## 3. 고을 배치 틀 + 대문 방향

### 3-1. 배치 틀(`kit/bldg/town.gd`, 새)
- **필지 표(TABLE)**: 틀 · 신분(cls) → 묶음 type 무게. 예) 골목·서민 = 초가 0.6 · 중농 0.25 · 기와집 0.15, 골목·중인 = 기와집 0.5 · 중농 0.3 · 초가 0.2, 골목·양반 = 양반가 0.6 · 기와집 0.4, 우물·서민 = 초가 0.75 · 중농 0.25, 주막거리 = 주막 마당 0.5 · 초가 0.35 · 대장간 0.15. region은 그대로 넘겨 지붕·담 재료가 권역을 따른다.
- **틀 다섯**(로컬: 길이 x축, 대문 +z가 길): 
  - 장터 — 길 폭 7m, 북쪽 시전 행랑 줄(가게 칸이 길로 트임), 남쪽 시전 + 주막 마당(장 끝), 길 가장자리 좌판 줄, 모퉁이 우물(김홍도 「장터길」·김준근 장시).
  - 골목 — 폭 3.6m, 양쪽 담 집이 골목으로 대문을 낸다. 읍내 골목의 서민 초가는 싸리울 대신 **이엉 갓 흙담 75% · 돌담 25% + 초가 대문**(묶음 `choga_house`에 `wall` 덮어쓰기 칸 추가). 기와집·양반가는 대문 안 내외담(신윤복 「월하정인」·「야금모행」).
  - 주막거리 — 큰길(6m) 북쪽 주막 마당(길로 트임)·대장간, 남쪽 초가·주막(김홍도 「주막」·신윤복 「주사거배」).
  - 관아 — 남북 축: 홍살문 → 외삼문(솟을삼문) + 기와 갓 둘레 담 → 동헌(남향), 양옆 행랑(「경기감영도 병풍」·읍성도).
  - 우물 블록 — 가운데 우물·평상·장독, 네 집 대문이 우물 쪽. 우물 마당 안쪽 거리는 이웃 집 반폭 + 0.8m(모서리 겹침 없게).
- **대문 방향 규칙 `gate_ry`**: 네 방향 중 대문 앞 1~2.2m 띠가 다른 필지에 막히지 않고, 길(region.json roads)이 가장 가깝고 그쪽을 보는 방향.
- 견본 배치: `tools/bldg/gallery_place.gd --set=town`(읍성 서쪽 풀밭 여섯 자리 — 처음 자리 둘이 개울 r017 위라 길 걷기가 막혀 옮김. 틀마다 보이지 않는 빈터 하나로 한 번에 땅을 고른다 — 필지마다 고르면 골목에 높이 턱이 생겼다).

- **마을 카메라에서 '산을 등진 마을'을 보이려면** 카메라 각을 낮추거나(지금 22°) 화면 위를 지평선 위까지 올려야 한다. 카메라 설정은 바꾸지 말라는 조건이라 하지 않았다. 대안: ① 고을에 들어설 때 잠깐 높은·먼 '고을 소개' 시점(지명 뜰 때)에서 진산이 보이게, ② 권역 높이장 자체에 읍성 뒤 낮은 산(100~200m 앞)을 더함(terrain-data 몫 — 걷기·배치에 영향).
- 다른 권역(한양·경주 등)에도 같은 backdrop.json을 둘지.

## 5. 폐가 옵션(`ruin`) — 따로 빌더를 두지 않고 명세 위에 얹음

레퍼런스: 폐가 레퍼런스 문서(아카이브 872 「공산무인도」 기운 바자울·빈 초정, 689 감로도 무너지는 집, 947/948 순절도, 970 「화개현구장도」 집터 + 이엉·기와 층·외엮기·와송 문헌). 단계 값은 그 문서의 표를 따른 게임용 추정이다.

### 5-1. 명세
```json
"ruin": { "stage": 2, "seed": 7, "collapse_side": "left", "roof_loss": 0.28, "sag": 0.22, "wall_loss": 0.42,
          "doors": "fallen", "paper": 0.9, "lean_deg": 3.5, "overgrowth": 0.7, "debris": 0.5, "salvaged": true, "enterable": "auto" }
```
- 건물: `{ type, region, seed, over: { ruin: {…} } }`(어느 유형·프리셋이든). 묶음: `{ type: "choga_house", …, ruin: {…} }`.
- `stage`만 주면 단계 표(0 막 비운 집 · 1 몇 해 · 2 반쯤 무너짐 · 3 무너짐 · 4 터만 남음, 사이값 허용)로 나머지를 채우고, 칸을 주면 그 칸만 덮어쓴다. `ruin`이 없으면 지금과 똑같이 짓는다(캐시·기존 시트 그대로 — 모서리·겹친 면·지붕 검사 결과가 전과 같음을 다시 확인).

### 5-2. 무엇이 바뀌나(`kit/bldg/_ruin.gd` 새 + building·compound·gate·todam 고리)
| 요소 | 단계별 |
|---|---|
| 지붕 | 처짐(기와 sag·이엉 sag에 더함) · 구멍(1~3: 이엉/기와 판을 뚫고 서까래 막대가 보임) · 꺼진 칸(2부터 무너지는 쪽 끝 칸, 3이면 절반 이상 — 그 칸 위 지붕을 잘라냄. 긴 삼각형은 자르는 선에서 잘게 나눠 너덜한 끝) · 4는 지붕 없음 |
| 이엉·나무 빛 | 단계만큼 검은 잿빛(썩은 이엉) · 나무 잿빛(1.5~) · 처마 끝 늘 들쭉날쭉 · 덧이엉 없음 |
| 벽 | 흙·회벽 칸마다 밑동 패임 / 구멍 — 드러난 자리에 **외엮기(중깃 0.3m + 외 0.12m)** · 3부터는 칸째 없어지고 외엮기만 남기도 함 |
| 창호·문 | 찢긴 창호지(살만 남은 짝 + 종이 조각, 뒤는 어두운 빈 방) · 짝이 기움(경첩 하나) · 열린 채 · 떨어져 앞에 누움 · 없음(떼어 감) |
| 기둥 | 꺼진 칸 기둥은 부러진 토막(0.4~1.6m)이거나 없음 · 창방·도리는 남은 칸 위에만 |
| 기울기 | 몸 전체 전단(기단 위부터, 무너지는 쪽으로 단계 1 ≈ 0.8° · 2 ≈ 3.5° · 3 ≈ 8°) |
| 꺼진 칸 바닥 | 흙·짚(초가)/기와 조각(기와) 더미 + 부러져 누운 기둥 + 막힘 충돌(넘지 못함), 걷기 면 없음 |
| 살림 | salvaged면 방 가구를 떼어 감(빈 방) · 단계 2.25부터 곁 것(장독·박·소쿠리) 없음 · 2.5부터 굴뚝 없음 |
| 풀 | 기단 둘레·꺼진 칸 풀(단계만큼 키 큼 — 마른 풀·들풀, 억새 이삭은 뺌) · 2부터 덤불(원 충돌) |
| 터(단계 4) | 기단 + 흩어진 주춧돌 + 더미 + 풀만. 중경은 낮은 둔덕 상자 하나, 원경은 기단만 |
| 실내 | 0~2.75 들어감(꺼진 칸은 열린 공간), 3부터 실내 없음(`enterable`로 덮어쓰기) |
| 묶음 | 건물마다 단계 ± 변주(곳간·헛간·아래채 +0.5, 안채·사랑채·주막 −0.3) · 흙담은 낮아지고 1.75부터 갓이 빠져 둥근 흙 띠(`todam cap:"none"` 새 선택 칸) · 허물어진 틈(충돌 없음 — 넘나듦) · 싸리울 군데군데 없음 · 대문 짝 기움/떨어짐/없음(`gate ruin`) · 마당 풀·덤불·깨진 독·헌 빗자루(`kit/bldg/ruin_yard.gd`, 앵커 `broom_old`) |

### 5-3. 확인
- 시트: `ruin/ruin_stages.jpg` — 단계 0~4 × 초가(남부)·기와 안채(중부 ㄱ자)·곳간·초가 묶음·읍내 기와집 묶음(마을 카메라 각) + 초가 가까이. `ruin/ruin_walkin.jpg` — 게임 안(남원 서쪽 풀밭 견본 `gallery_place.gd --set=ruin`) 묶음 10채 마을 카메라 + 대문 앞·문 안 1인칭, 초가 단계 1·2·3 방으로 걸어 들어감.
- 걷기·충돌(`--bldgrollout` 견본 `--brset=ruin`):
  - 묶음 10채 모두 대문 밖 → 문지방 → 마당 안 닿음(BRGATE).
  - 옆 담 밖 → 마당 곧장: 단계 0·1·3 막힘, **초가 묶음 단계 2·4는 지나감** — 싸리울이 쓰러져 없거나 틈이 난 자리라 폐가로서 맞는 결과다(검사 기준을 폐가에서는 '지나가도 됨'으로 본다).
  - 초가 방으로: 단계 1·2는 문 앞 → 방 문턱 → 방 안까지 닿고 실내 카메라(지붕·앞벽 숨김)가 켜졌다. 단계 3은 벽에 막힘(실내 없음, 의도).
  - 견본 걷기 경로 중 '마당 안쪽 깊이' 마디(내 경로를 곳간·내외담 쪽으로 잘못 잡음)는 실패로 찍혔다(BRFAIL 17 중 15). 대문·마당·방 판정은 위 BRGATE·방 걷기로 했다.
- 벽–지붕(`roof_check --set=ruin`, 8 유형 × 4 권역 × 단계 1·2·3 = 96): **남은 지붕 밑에서 벽이 뚫고 나온 곳 0**(through 0), 남은 지붕 밑 최소 여유 0.04m. 지붕이 없어진 자리의 벽('outside')은 폐가라 셈하지 않는다. 자른 지붕 끝·구멍에서 창방·도리가 드러나는 칸(24건, 3~98칸)은 의도(서까래·도리 노출)로 본다.
- 겹친 면(`face_check --ruin=1·2·3`, 5 유형 × 2 권역 × 실내 켬/끔): 단계 1 실패 11 · 2 5 · 3 2. 대부분 폐가 없을 때부터 있던 짝(초가 중부 장작–기단 0.129m²·안채 창방 끝 0.04m²)이고, 폐가에서 새로 난 것은 0.01~0.05m²짜리 몇 짝(구멍 낸 벽 조각 끝이 인방 면과 3mm 안에 든 자리 · 곳간 문짝). 처음에는 기운 두 짝이 한 평면에 겹쳐 0.26m²가 났다 — 짝을 문 면에서 12~14cm 앞으로, 짝마다 앞뒤를 달리해 고침.
- 모서리(`corner_check --ruin=0`): 틈 0(단계 0은 모서리 규칙 그대로). 단계 1부터는 일부러 낸 벽 구멍·밑동 패임이라 셈하지 않는다(단계 1: 229광선 — 의도된 구멍).
- 공용·전체 회귀: ROOFTEST PASS 499 · roof_check 빌더 288건 실패 0(옛 키트 4건 전과 같음) · WALLCLEAR 228건 실패 0(최소 0.05m) · 모서리 6(전과 같음) · 겹친 면 22/456(전과 같음).
- 삼각형·짓기 시간(near/mid/far · ms): 초가 남부 단계 0 11.9k/578/180 · 2 11.8k/646/246 · 3 5.6k/397/189 · 4 2.2k/36/24, 기와 안채 0 21.4k · 2 21.2k · 3 15.2k · 4 5.8k. 짓기 16~217ms(자르는 선의 삼각형 나누기 때문에 단계 1~3이 30~70% 느림 — 키트 캐시가 한 번 지은 뒤 담는다).

### 5-4. 약한 곳 · 결정
- 지붕 위 풀·와송은 넣지 않았다(이엉 빛·이끼 빛으로만). 기와골 흙빛 반점·빠진 막새 하나하나도 없다(구멍·꺼짐만).
- 기와 안채 ㄱ자 단계 2~3에서 날개 처마 띠 한 토막이 잘린 칸 너머로 가늘게 남는 자리가 있다(시트 안채 2·3).
- 무너진 벽 조각은 칸 단위로 고른다(벽 전체가 비스듬히 무너진 모양은 없음). 단계 3의 '남은 기둥 8~15° 기욺'은 몸 전체 전단 하나로만 한다.
- 이야기 쓰임(흉가·도깨비 빗자루·여우 집 0↔3 갈아 끼우기)은 앵커(`broom_old`)와 명세 교체만 준비했다. 이야기 쪽 연결은 하지 않았다.
