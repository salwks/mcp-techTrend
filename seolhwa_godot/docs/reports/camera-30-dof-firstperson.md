## 1. 카메라 기본 각 40°

각은 겨냥점에서 카메라까지 선이 땅과 이루는 내려다보는 각(`camera_rig.update`: `off = (0, sin p, cos p)·d`). 시험이 실제 카메라 자리로 잰다(40.00°).

| 권역 기본 `RegionWorld.CAM_DEFAULT` | 40 / 22 | 40 / 22 (그대로) | 권역에서는 이미 40이었다 — 수직으로 보이던 건 도시 구역(45·47)과 틸트시프트 띠 |

- 다섯 구역 모두 40°. **42°로 남긴 구역 없음** — 남쪽(카메라 쪽) 줄 지붕은 가림 점무늬·반투명이 이미 비우고, 한양 두 곳 화면에서 플레이어가 가려지지 않았다. 각이 낮아진 만큼 카메라가 낮아지고 앞이 더 보이므로 거리는 2m씩 당겼다(도성 안·내성·성 안 28→26, 큰길 32→30).
- 원본 `tools/placement/north.py CAM_ZONES`도 같은 값(다시 만들어도 45·47이 돌아오지 않게 — 시험이 본다).
- 그대로 둔 것: 숲길 48/20 · 길 밖 숲 55/17(잎덩이 위로 내려다보는 가림 구역) · 고개 30/22 · 실내(지붕 숨김) 48~60 · 말 20/21/38 · 배 15/15/40 · **대화 TALK 38/13.5/38**(40보다 나은 점이 없었다 — 대화가 조금 더 가까이·낮게 들어가는 느낌이 낫다) · 사건 카메라(`d.camera`, `CameraRig.shot`, 남원 7A 34/17/36, 8A 공식 틀 등) — 저작 값 그대로(override가 구역·기본보다 이긴다 — 시험).
- 가림·잘라 보기: 가림 점무늬 선분(카메라→머리)·반투명 가림은 각과 상관없이 동작(바뀐 것 없음). 실내는 실내 카메라(48~60)를 그대로 쓰므로 영향 없음. 하늘·안개: 40° · fov 30이면 화면 맨 위가 25° 아래를 본다 — 평지에서는 하늘이 들지 않아 지평선 처리는 그대로.

## 2. 깊이 흐림(틸트시프트를 바꿈)

전: 화면 높이 띠(플레이어 높이 ±7%) 밖을 위·아래로 세게 흐렸다(`focus_y·band·top_bias`). 앞 땅·뒤 지붕이 거리와 상관없이 뭉개졌다.
후: **장면 깊이로만** 흐린다(`scripts/post_effect.gd` FINAL 패스).

- 깊이 D(m) = 렌더 투영으로 푼다: `D = B / (d + A)`, A = proj.z.z, B = proj.w.z(거꾸로 Z).
- 초점 F = 카메라→겨냥점(평소 플레이어 가슴 `rig.target`, 연출 겨냥점, 각본 shot의 look, 1인칭은 7m).
- 먼 흐림 `amt = far · x/(1+x)`, x = max(D − F − margin, 0) / (F · scale) — 멀어질수록 `far`에 다가갈 뿐 넘지 않는다(띠·경계 없음).
- 앞가림: D < 0.55F일 때만 `near`까지.
- 값(`region_main.DOF_*`): 걷기 far 0.55 · near 0.3 · scale 1.2 · margin 4m / 배·말 0.3·0.15·2.5·8 / 마방 앞 0.25·0.2·2.0·6 / 1인칭 0.35·0·3.0·3.
  3인칭 화면(깊이 16~35m)에서 맨 위가 0.1~0.15 정도 — **약하게**. 먼 능선만 0.4~0.5.
- 흐림 판은 예전과 같은 1/2 해상도 가우스 하나(비용 같음). 흐린 곳은 먹선도 약해진다(예전과 같은 식).
- **Godot 카메라 DOF를 쓰지 않은 까닭**: 이 후처리가 톤매핑·한지·먹선을 직접 하므로 Godot DOF(톤매핑 단계)는 먹선·한지 결까지 흐린다.
- **Mobile MSAA 깊이**: `access_resolved_depth`는 Mobile에서 "not supported" 경고만 내고 단일 표본 깊이가 비어 있다. 그래서 `render_buffers/depth_msaa`(4× 표본, 표본 읽기 가능)의 첫 표본을 `sampler2DMS`로 읽는 변종 셰이더(`final_ms`)를 따로 둔다. MSAA를 끄면 보통 깊이(`final`).
- 손잡이: `PostEffect.dof`(옛 이름 `tilt`는 같은 값의 별칭 — `--notilt` · P 키 · 남원 `_tilt()` 그대로) · 새 `--nodof` · `set_cine_sharp(true)`면 바로 0(각본 장면 또렷), 끄면 약 2초에 돌아옴 · 설정 '깊이 흐림'(보통/약함/끔 — 새로 더함, 시험·촬영은 늘 보통).
- 시험 보기: 환경 변수 `DOFVIS=1`이면 흐림 비율을 회색 화면으로 그린다.
- 덤으로 본 것: `--nomsaa`면 장면 색 텍스처에 복사 권한이 없어 후처리 전체가 꺼진다(예전부터 — 이번 일과 무관, 손대지 않음).

## 3. 1인칭(0 키)

- **0**(숫자 0 · 키패드 0): 3인칭 ↔ 1인칭. 바란 값 `first_person`, 실제 `fp_active`.
- 눈높이 1.55m, 처음 보는 쪽은 facing(위=북). fov 62(세로), near 0.1(벽 곁에서 안 잘림), far 260m(아래 성능).
- 조작: **W·S(↑↓) 앞뒤 · A·D 옆걸음 · ←→ 돌기 · 마우스 왼/오른 단추 누른 채 끌기로 둘러보기**(위아래 −63°~+46°). 움직임은 카메라 기준, 걸은 쪽으로 facing이 바뀐다(인물들이 플레이어 쪽을 보는 계산 그대로). Q·E·R·M·H·J~L·U는 그대로 — 겹치는 키 없음. ←→만 1인칭에서 옆걸음 대신 돌기.
- 플레이어 그림: 20번 층(`PLAYER_LAYER`)에 두고 1인칭 카메라만 그 층을 뺀다 — 해 그림자는 남는다. 다른 인물 그림은 카메라 쪽을 계속 본다(`update_char`가 카메라 앞 방향으로 세움 — 한양 1인칭 화면 확인).
- 1인칭에서 끄는 것: 가림 점무늬(occ_r·occ_near 0), 가림 반투명, 잘라 보기, **실내 지붕 숨김**(안에서 올려다보면 지붕이 있어야). 3인칭으로 돌아오면 그대로.
- E 대상: 닿는 거리(C02) 안에서 **바라보는 쪽 먼저** — 점수 = 거리 × (1.6 − 0.6·cos). 앞은 거리 그대로, 옆 1.6배, 뒤 2.2배. 우선순위(C01 이야기 대상 → 곁 사람 → 탁본 → 배 → 말)는 그대로.
- **저절로 3인칭**(끝나면 1인칭으로 돌아옴, 바란 값은 그대로): 이야기가 플레이어를 쥘 때(대화·선택지·컷신·전투·기록책·시작 메뉴 — `story.owns_player`) · 고을 사람·마부·깃발 말 걸기 · 연출 카메라(override·focus·shot·glide — 대화 카메라 포함) · 배·말 · 지도 · 역마 창 · 큰 창(HudGate overlay — 문서 등) · 실내 넘나드는 암전 · 불러오기·떠나기. Esc 멈춤 창은 게임이 멈춰 화면이 그대로 남는다(멈춘 그림 위 창).
- 막힌 때 0을 누르면 "지금은 3인칭 — 끝나면 1인칭으로 돌아간다"(HUD 28 = C64 BODY). 켤 때 "1인칭 — W·S 앞뒤 · A·D 옆 · ←→·마우스 끌기 둘러보기 · 0 3인칭".
- 저장: `user://settings.json view`(설정 '시점 (0 키)' 3인칭/1인칭과 같은 값, 기본 3인칭). 시험·촬영(`*test`·`--bench`·`--shot` 등)은 사용자 설정을 읽지도 쓰지도 않는다 — `--view=first`로만.
- 안내: 기록책 '여행 방법'에 '시점' 줄, Esc 멈춤 창 덧글 "0 — 1인칭/3인칭 바꾸기", 설정 '시점 (0 키)' · '깊이 흐림'.

## 8. 사용자가 정할 것

1. **숲 구역 각**: 숲길 48° · 길 밖 숲 55°는 그대로 두었다(잎덩이 가림 구역). 이것도 40~44°로 낮출지.
2. **1인칭 땅 무늬**: 눈높이에서 땅 무늬가 무르게 보인다(텍스처 해상도). 1인칭을 계속 쓸 거면 가까운 땅에 잔무늬(디테일 텍스처)를 더할지.
3. **깊이 흐림 세기**: 지금 아주 약하다(3인칭 화면 맨 위 0.1~0.15). 먼 산만 더 흐리게(far 0.7) 할지 — 설정 '깊이 흐림'(보통/약함/끔)은 더했다.
4. **1인칭 마우스**: 지금은 단추를 누른 채 끌 때만 둘러본다(대화 선택지 클릭과 안 겹치게). 마우스 잡기(커서 숨김) 방식을 원하면 바꿀 수 있다.
