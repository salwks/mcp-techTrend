## 실제로 읽힌 장면과 아직 읽히지 않은 부분

### P94 — 김홍도 주막

처마를 받치는 기둥 아래 조리 용기와 그릇이 모여 있고, 음식을 준비하는 쪽과 작은 상 앞의 손님이 가까이 배치되어 있다. 공간의 기능이 사람의 자세와 도구로 읽힌다. 여기서 도출할 것은 '주막 주변에 소품을 무작위로 흩뿌린다'가 아니라 조리→배식→식사의 관계다. 그림에는 건물 전체 평면이 없으므로 주막 전체가 이 형태라고 단정하지 않는다.

### P802 — 경기감영도

전체 화면에서 중앙의 큰 건축 영역과 주변 취락·산세의 대비가 보인다. 현재 본 해상도로 개별 골목 폭, 담 접합, 필지 경계를 읽을 수는 없다. 고해상도 부분도와 지도 대조 전에는 도시 생성의 치수 근거로 사용하지 않는다.

### H01 — 낙안읍성

사진 1에서 성벽 보행면과 문루, 사진 3에서 길게 이어진 성벽과 양옆의 낮은 지붕군·경작지·먼 산을 확인했다. 기관 설명은 이곳을 평지 읍성으로 구분하며 세 문을 연결한 T자형 도로를 설명한다. 이는 낙안의 사례이지 모든 도시를 T자로 만드는 규칙이 아니다. 특히 같은 자료가 현대 성벽 복원과 옛 구조의 차이를 지적하므로, 현황 사진도 검증 없이 조선 원형으로 취급하지 않는다.

### H02 — 하회·양동

UNESCO 본문은 산림·강·농경지와 주거군의 관계, 종가·주택·정자·교육 공간 등 서로 다른 기능의 구성을 설명한다. 집성촌과 읍성은 크기 차이만 있는 것이 아니다. 다만 개별 필지와 골목 곡률은 아직 사진·배치도로 분석하지 않았다.

## 사용자가 원하는 화면의 구성 요소

- U01: 길 양옆의 건물이 공간을 둘러싸고, 처마 밑 그늘·기단·문턱·목재 틀이 가까운 거리에서 읽힌다.
- U02: 길과 주택 바닥의 높이 차를 기단과 돌이 이어주며 먼 산과 안쪽 건물이 시선을 이끈다. 장식의 고증은 별도 확인 대상이다.
- U03: 바위 사이를 실제로 걸어 올라가는 동선, 수목의 큰 윤곽, 제의 공간의 작은 따뜻한 빛이 장소의 목적을 드러낸다. 푸른 색조와 안개 자체를 고증 규칙으로 만들지 않는다.
