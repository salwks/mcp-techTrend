## 1. 먼저 고정할 목표

사용자 요구: 산은 실제 이동하고 사건을 경험하는 지형이다. 도시는 골목·시장·주거·공공 공간이 구분되고, 건물은 실내외 높이와 출입이 연결되어야 한다. 담은 끊어지거나 길을 부당하게 막지 않아야 한다. 재질은 목재·흙·돌·기와·초가의 차이와 날씨 변화가 읽혀야 한다. 빌더는 여러 도시에서 재사용할 수 있어야 한다.

목표 이미지 U01~03은 화면의 밀도·접합·깊이·생활감에 관한 시각 목표다. 그림 속 건축과 장식 모두가 조선의 사실이라는 뜻은 아니다.

## 3. 자료 카드의 필수 항목

1. 출처와 제작/촬영 시점, 대상 지역·시대, 현황/복원/회화/창작 구분.
2. 실제 본 범위: 전체 그림, 특정 부분도, 평면도, 단면도, 현장 사진, 또는 설명문만.
3. 관찰: 무엇이 어디에 어떻게 붙어 있는가. 이미지에서 안 보이는 것은 추정이라고 적는다.
4. 해석: 그 배치가 동선·소유·작업·지형·방어 등에 어떤 의미를 가질 가능성이 있는가.
5. 설계로 옮길 규칙과 적용 범위, 반례, 아직 모르는 사항.
6. 평면·눈높이·실제 보행으로 확인할 판정 항목.

예: '골목이 구불구불하다'에서 끝내지 않는다. 길 양옆의 경계, 출입구, 기단, 배수, 굴곡 원인을 표시한다. 곡선 계수를 정하는 것은 그 다음이다.

## 4. 원칙을 확정하는 절차

자료 수집 → 실제 그림/사진 판독 → 관계도와 단면 작성 → 유형별 규칙 가설 → 작은 공간 생성 → 시각·보행 검증 → 다른 지형에서 재검증 → 도시 규모 확장.

첫 시험 공간 제안은 생활 골목(문·담·마당·높이 접점), 주막/작업장 거리(행위와 통행), 산중 진입로(지형·물·바위·건물 접점)다. 도시마다 손으로 완성본을 만드는 것이 아니라 동일 빌더 규칙이 다른 지형에서도 작동하는지 검사하는 표본으로 사용한다. 아직 이 시험 구현을 시작하지 않는다.

수치 기준은 도면·축척·게임 보행 시험에서 얻는다. 근거 없이 골목 폭, 필지 밀도, 담장 개방 비율, 기와/초가 비율을 먼저 확정하지 않는다. 조정값을 바꿀 때는 어떤 실패를 해결했고 다른 사례가 악화되지 않았는지 기록한다.

## 5. 통과 판정

- 근거: 해당 유형·지역에 적용할 이유가 있으며 추정은 표시되어 있는가?
- 구조: 길→문→마당→실내가 연결되고 경계에 이유 없는 틈·중복·막힘이 없는가?
- 화면: 사용자 시각 목표와 비교할 때 공간의 둘러싸임, 높이 차, 부재 접점, 행위가 읽히는가?
- 플레이: 걷기·조사·대화에 필요한 공간이 있고 실제 지형을 이용할 수 있는가?
- 재사용: 특정 좌표를 수정하지 않고 다른 입력에서도 규칙이 유지되는가?
- 성능: 목표 기기에서 확인했는가? 아직 미측정이라면 미측정으로 남긴다.

자동 검사 통과, 에이전트의 설계 동의, 보기 좋은 한 장의 캡처 중 어느 하나만으로 완료를 판정하지 않는다.


## 2차 조사 보완

H08~H10 사례를 [경계 설계 제안](boundary-design-proposal.md)에 연결했다. 경계·사람 통행·물 흐름·구조 지지를 별도 관계로 다루며, 출입구와 수구를 구분한다. 경계 한 개를 항상 벽체 한 개로 치환하지 않고 필요하면 두 담 사이 배수 공간도 표현한다. 이는 구현 전 제안이며 자동 검사 또는 실제 플레이 통과 보고가 아니다.
