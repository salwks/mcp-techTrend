# 설화록 자연·인공 환경 통합 제작 사양 — 검토본 v2.0

작성 2026-10-24(v2.0 개정). 범위: 조사·분석·제작 원칙·에디터/빌더 계약. **게임 구현이나 고증 최종 확정본이 아니다.** 현재 게임 코드, 저장, 기존 시나리오, 도시 배치는 변경하지 않았다. V01–V79는 문서상 인수 조건이며 게임에서 통과한 시험이 아니다.

**현재 조사 미완료.** 분야별 확인 수준은 [충족도(12)](12-research-coverage.md), 유형별 제작 체계와 지역·유형별 남은 조사는 [통합 제작 카드(19)](19-integrated-production-system.md)를 기준으로 판단한다.

## 1. 목표와 문서의 권위

사용자가 원하는 것은 도시마다 손으로 다시 맞추는 작업이 아니라, 장소의 이유를 설명할 수 있는 공통 제작 체계다. 남원 한 곳을 눈대중으로 고치는 방식으로 돌아가지 않고, 조선시대 한국의 지형·건축·생활 원리를 먼저 정리한 뒤 지역 프로필로 적용한다. 산은 먼 배경이 아니라 오르고 고개를 넘으며 사건이 일어나는 공간이고, 담은 장식 둘레가 아니라 지형·필지·길·기능·출입·배수가 형태를 정하는 경계다.

생성 의존 관계: **지형·물 → 이동과 생업 → 정착 기능 → 길·필지·마당 → 건물·경계·문·배수 → 표면과 생활 흔적.** 이는 생성 순서이지 역사가 한 방향으로 진행됐다는 주장이 아니다. 제방·논·도로·집터가 물과 지형을 바꾸는 역방향 영향은 변경 지형으로 저장한다.

- **확인 사실:** 출처에서 실제 확인한 범위만 기술한다. 현황·수리 후·복원·유구·회화와 조선 원형을 분리한다.
- **제작 규칙:** 사실과 목표 화면에서 도출한 프로젝트 제안이다. 사료의 직접 진술로 포장하지 않는다.
- **시험값:** 치수·밀도·광택·반응 강도·성능 수치는 측정과 장면 시험 전에는 정본이 아니다.
- **미확인:** 자료가 없거나 판독하지 못한 사항. 필수 입력이 비면 오류를 내거나 가설 표시로 미리보기만 허용한다.

완결성의 기준은 모든 역사적 수치를 아는 것이 아니다. 각 제작 판단에 입력·근거·예외·출력·검증 방법이 있고 모르는 부분을 자동 추정으로 숨기지 않는 것이다. 공통 규칙은 지금 쓰고, 지역별 값은 지역 프로필의 조사 항목으로 분리한다.

## 3. 범위와 제외

포함: 산악·평야·하천·해안, 수목·초본·낙엽, 암반·토양·침식, 길·다리·나루·수로, 대도시·중소도시·마을, 농경·생업·제의 공간, 관아·향교·사찰·암자·성곽, 건축 내외부·가구·도구, 노후·폐허, 재질·기상·조명·충돌·시야·성능. 동물의 서식·축사·계류 공간도 배치 근거에 포함한다.

제외: 건물별 소유자 계보·수리 연혁 수집, 이력 시뮬레이터, 동물 AI·군중 AI·농업 경제·유체 물리 시뮬레이션, 새 렌더러·GI 시스템. 자료의 시기 표시는 적합성 판단용 메타데이터이며, 상세 연대 자료가 없다는 이유로 일반 건물 제작을 막지 않는다.

현재 승인된 3D 지형+2D 인물, 사선 기본 시점과 1인칭 관찰을 고려한다. 참조 이미지의 사진적 질감과 골목 구성은 목표로 분석하되 이미지 속 장식·건축을 모두 조선 고증으로 승인하지 않는다.

## 5. 적용 순서와 완료 게이트

G0 근거: 시대·지역, 전체 배치/보행 시점/접합 상세/사용 장면을 구분해 확보. 없는 자료는 지정한다.
G1 구조: 지형·수계·길·정착 목적·고정 건물 위치를 연결. 용량이 부족하면 면적·요구량·부지 선택을 재검토하며 집을 일괄 축소하지 않는다.
G2 공간: 필지·기능 영역·건물·마당·경계·출입·배수를 연결. 목표 건물 수보다 실제 접근과 생활 기능을 우선한다.
G3 형태: 지붕·재료 층·기단·바위·계단·수목의 실루엣과 접합을 검사한다.
G4 표면: 재질 정체성과 건조/젖음/적설, 노후 상태, 실내외 빛을 비교한다.
G5 배포: 시점·이동·사건·성능·저장 호환을 검증한다.

이번 작업은 G0 근거 정리와 G1~G5의 사양 작성이다. 게이트의 실제 통과를 보고하지 않는다. 후속 구현 전에 기존 settlement v2·건물 빌더·지형·물 구현과 이 사양의 유지/수정/추가/미확인 매핑을 작성하며, 그 감사 전에 전면 재작성 필요 여부를 단정하지 않는다.
