# 인공 환경과 자연 접점 사양

## BLD-01 정착 유형과 규모

대도시·중도시·소도시·마을은 단순 건물 수 프리셋으로 만들지 않는다. 행정 기능, 성곽 유무, 교통 결절, 시장, 농경·어업·역참·제의 등 주요 생업과 지형 제약을 독립 입력으로 둔다. 규모와 성격을 조합한다.

| 유형 | 먼저 확보할 공간 관계 | 자동으로 가정하면 안 되는 것 |
|---|---|---|
| 도성·대규모 행정도시 | 권역·관아/궁역·간선·성문·시장·생활 구획 | 작은 읍성을 단순 확대 |
| 중소 읍치·읍성 | 해당 지역 관아·객사·성문·하천·간선 | 관아 정중앙, 장터 동일 위치 |
| 농촌·집성촌 | 주거군·마당·농경·공동시설·물·친족 관계 자료 | 전 집 둘레에 같은 담 |
| 나루·길목·역참 취락 | 승하선/환승·짐·말·숙식·길 연결 | 수변에 집을 균일 나열 |
| 산중 취락·사찰 주변 | 접근 경사·수원·작은 가용 부지·제의와 생활 | 평지 격자·넓은 일괄 평탄화 |

H01 낙안의 T자 간선은 해당 사례이며 보편 규칙이 아니다. H02 집성촌의 자연·주거 관계도 도성에 복제하지 않는다. 남원 등 실제 주요 건물 위치는 개별 고지도·문헌·지형 대조 전까지 가설로 둔다. 지도 그림의 건물 크기를 실제 면적으로 곧바로 환산하지 않는다.

## BLD-02 길·필지·밀도

간선은 주요 목적지와 문·교량을 연결한다. 생활 골목은 필지 출입과 지형을 따른다. 골목의 굴곡에는 기존 필지, 등고선, 장애물, 배수 또는 이용 관계의 이유 태그가 필요하다. 직선도 정상 결과다. 모든 길을 휘게 만드는 것은 해결이 아니다.

길 단면은 통행 폭, 처마 돌출, 기단, 배수 가장자리, 임시 가판 점유를 포함한다. 통행 폭은 지붕 사이 거리와 다르다. 밀도는 건물 수 외에 가로 접면 비율·건폐 면적·마당 면적·빈터 연속성·길에서 보이는 건물 높이/폭 관계로 평가한다. 목표값은 유형별 실측/참고 장면에서 보정하며 현재 임의 수치를 고증값으로 설정하지 않는다.

필지는 도로 여백의 남은 조각을 무조건 건축 부지로 쓰지 않는다. 출입·배수·최소 기능 공간이 성립해야 한다. 부적합 잔여지는 작은 텃밭·공유지·수로·비건축지 등의 후보로 분류하되 자동 채우기하지 않는다. 정원·마당·일터는 빈 공간 자체가 기능이다.

## BLD-03 경계·담·문

원본은 경계 선분과 양쪽 공간의 관계다. 담은 그중 하나의 표현이다. 경계에는 사유/공공 구분, 시선 차단, 보안, 높이 지지, 배수, 단순 표지 등의 목적을 복수 지정한다. 양쪽 필지에서 별도로 담을 만들어 중복하지 않는다. 실제 이중 담과 사이 배수 공간은 하나의 단면 묶음으로 명시한다.

한 경계는 직선·곡선·꺾임 구간으로 분할 가능하며 곡률은 근거를 가진다. 담 상단 높이 기준은 지표 추종/단계/일정 레벨 중 선택한다. 곡선을 짧은 박스들의 끊어진 줄로 내보내지 않는다. 접합부는 선형 교차에서 단면을 해결하고 같은 재료·줄눈·두께·지붕덮개를 연속시킨다. 모서리 기둥을 추가할 때는 구조적 이유가 있어야 하며 색과 재질이 임의로 달라지면 실패다.

대문·사립문·협문·중문·삼문 등은 유형별 근거와 양쪽 접근 공간을 가진다. 통행 구멍과 수구를 구분한다. 소쇄원 H10의 물이 지나는 담 아래 공간을 사람의 문으로 취급하지 않는다. 문 앞에는 접근·회전·개폐·문턱·기단 연결 검사가 필요하다. 담 끝은 기둥/벽체/지형/명시적 개방부로 끝나야 하며 이유 없는 틈은 오류다. 폐허의 끊어진 담은 파손 이력과 잔해를 가진 의도적 예외다.

## BLD-04 건물과 실내

건물 빌더는 칸 구성, 용도, 구조, 지붕 형식, 기단, 방/마루/부엌, 문·창, 처마, 부속채를 분리한다. 칸을 지역과 건물급에 무관한 고정 미터로 취급하지 않는다. H08 이향정의 분리된 채와 마당 관계는 하나의 유형 사례다.

기둥–보–벽 충전–도리–지붕의 지지 관계를 표현한다. 지붕의 외곽 및 하부 공간은 벽·도리의 실제 외곽과 간섭 검사한다. 초가의 지붕은 원형을 늘여 덮는 것보다 평면과 모서리·처마 두께를 통제할 수 있어야 한다. 기와 지붕은 맞배/팔작/우진각 등의 형식과 합각·회첨 등 접합 근거를 구분하며, 건물끼리 지붕이 우연히 겹친 것을 복잡한 한옥으로 보지 않는다.

보행 바닥, 시각 바닥, 문턱, 계단, 테이블 충돌의 높이를 같은 기준으로 둔다. 낮은 단차는 현재 이동 시스템의 허용 조건에 맞추고, 올라갈 수 없는 높이는 계단·경사 또는 통행 불가로 명시한다. 실내 벽 양면과 종이·목틀·보의 겹침은 형상 소유권을 정해 제거한다. 전 부재를 임의로 밀어내는 방식만으로 z-fighting을 덮지 않는다.

실내는 조리/수면/접객/보관/작업 동선으로 설계한다. 가구는 사용하는 자세와 접근 공간을 가진다. 상을 벽 안으로 넣거나 문을 막는 배치를 금지한다. 실내 그림자·기둥·카메라 가림도 문서의 인수 조건이며 별도 이야기 시스템을 새로 만들지 않는다.

## BLD-05 생업·농경·제의·생활

주막은 조리→배식→식사→정리의 관계로, 대장간은 열원·작업·재료·손님 분리로, 장터는 평시 통행과 장날 점유 변화로 구성한다. P94 주막은 사람과 도구의 가까운 관계를 확인한 사례이며 전체 주막 평면의 증거는 아니다. 말 매는 곳·짐·우물·오수·장작·변소 등 생활 지원 시설은 용도와 시대 근거를 조사하여 선택한다. 모든 집에 모든 소품을 넣지 않는다.

논은 취수·분배·논둑·물꼬·퇴수와 접근을 포함한다. 밭은 토양·경사·작물·작업길, 과수/텃밭은 관리 공간을 가진다. 작물과 농기구의 시대·지역은 별도 근거가 필요하다. 사당·암자·묘역·당산·장승은 접근과 제의 방향, 관리 흔적을 분리하며 사용자 야간 이미지의 깃발·등불을 보편 양식으로 확정하지 않는다.

## BLD-06 폐가·수리

폐가는 동일 건물 빌더의 상태 옵션이다. 별도 임의 건축 종류를 만들지 않는다. 상태는 관리 중/노후/부분 파손/방치/붕괴로 선택한다. 화면 표현에 필요한 원인은 선택적으로 기록하며 구체 연혁·방치 기간을 필수로 요구하지 않는다. 지붕 손실→내부 노출→국소 습기·오염 같은 관계를 표현하되 이 순서나 속도를 모든 건물의 역사적 사실로 단정하지 않는다.

파손은 지지 관계, 노출, 사람이 가져간 부재, 수리 흔적을 선택적으로 반영한다. 무작위 구멍과 검정 얼룩으로 끝내지 않는다. 잔해는 원래 재료·부재와 대응하며 문·통로를 막을 경우 탐험 동선에 반영한다. 사건 건물은 진입과 조사 대상을 보존한다. 실시간 붕괴 물리와 임의 화재 원인은 요구하지 않는다.

상세 원인–결과는 [18 SURF-03·04](18-vegetation-materials-weather-ruins.md)를 따른다. 원인을 고르면(지붕 누수·기단 침하·벽 갈라짐·부재 반출) 손상이 물 진입 지점과 지지 관계를 따라 전파된다.

## BLD-08 성곽

[고증 검토](06-historical-verification.md) H-10~13과 §5를 따른다. 담 프리셋의 높이 변경으로 성곽을 만들지 않는다. 성벽은 기초·외측·속채움·내측 지지·상부·배수의 단면을 가지고, 성문·옹성·치·수구는 지형과 기능 관계를 가진다. 성벽의 평면 곡률과 단면 기울기를 분리한다. 특정 시설은 해당 시대·유형 근거가 있을 때 선택한다. 읍성과 산성 모두 내부 기능·수원·접근을 검사한다.

건축은 H-07~09를 추가 적용한다. 겹처마를 두 지붕 덩어리의 겹침으로 표현하지 않는다. 현대 교재의 칸 치수와 공법을 역사 기본값으로 복사하지 않는다.

## BLD-09 생활 기능에서 평면 도출

[생활·문화 사양](07-living-culture.md) LIV-01~10을 적용한다. 주요 행위 → 필요한 공간과 인접 관계 → 출입·운반·시야 → 채와 경계 → 소품 순으로 설계한다. 소형 민가·큰집·주막·객주·작업장의 기능 차이를 보존한다. 마당의 빈 작업 면을 자동 장식으로 채우지 않는다. 조리/난방 연결과 일상/행사의 공간 공유를 검토하되 새 생활 시뮬레이션은 만들지 않는다.

## BLD-10 공동 시설과 생업의 공간

[공동 생활·생업·장시 사양](08-shared-services-workshops-market.md)을 적용한다. 시설 개수보다 이용 가구·길·작업 면·반입과 수거의 연결을 먼저 정한다. 공유 우물을 가구별 소품으로 복제하거나, 가마와 베틀을 장식처럼 빈자리에 넣지 않는다. 담·문은 이 연결을 보존해야 한다.

## BLD-11 기능 영역과 배치 유형

[목공·관아·향교·사찰 사양](09-workshops-institutional-spaces.md)을 연결한다. 건물 세트 복제보다 기능 영역·경계·접근 관계를 먼저 정한다. 향교의 지형별 경향을 단일 배치 규칙으로 강제하지 않으며 작은 암자를 대사찰의 축소본으로 만들지 않는다.

## BLD-12 민가의 길·담·물 접점

[추가 조사 VIL-01–07](13-village-lanes-walls-water.md)을 연결한다. 지형과 길망·필지 접근을 함께 정하고, 담–문–마당과 수로 횡단을 접점 단위로 검사한다. 택호만 같은 다른 채의 사진·단면은 같은 모델의 근거로 합치지 않는다.

## BLD-13 경계 구현·공법·집의 단면 분리

[담·민가 조립 사양 JOIN-01–06](14-wall-construction-and-house-sections.md)을 적용한다. 필지 경계가 곧 독립된 담이라는 가정을 하지 않는다. 건물 외벽·문간·열린 마당을 구분하고 공유 구간 중복을 막는다. 담 몸체·기초·속 구성·상부 마감, 방 평면·바닥·지붕 지지 영역은 연결하되 동일 윤곽으로 강제하지 않는다. 현대 수리 기준과 사례 치수는 조선 공통 기본값이 아니다.

## BLD-14 소형 주거의 기능·구조·반외부 공간

[HOUSE-01–06](15-small-house-matched-evidence.md)을 적용한다. 방의 기능 면과 구조 칸을 일대일로 강제하지 않으며 마루·아궁이·빈 퇴칸을 각각 조립한다. 작은 주거도 부속채의 경계/지지/작업 기능을 구별한다. 현재 조사 자료의 현대 설비는 조선형 제작에 자동 복제하지 않는다.
