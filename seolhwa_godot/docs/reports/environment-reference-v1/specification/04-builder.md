# 에디터·빌더 데이터 및 작업 계약 — 검토본 v2

2026-10-24 개정. 이 문서는 구현 요구사항이다. 현재 작동하는 기능 목록이 아니다. 완전 자동 고증 도시 생성기를 약속하지 않는다. 자료를 바탕으로 설계자가 통제하고 반복 작업을 자동화하는 편집기를 목표로 한다. 분야별 규칙의 상세는 각 사양 문서에 있고, 여기서는 그 규칙이 공유하는 데이터·순서·편집·보호·검사 계약을 한 곳에 정리한다. 유형별 카드(무엇을 만들고 어떤 입력·순서·검사를 갖는가)는 [통합 제작 체계(19)](19-integrated-production-system.md)에 있다.

## TOOL-02 작업 화면과 조작

필수 보기: 근거 이미지/지도 중첩, 지형 경사·능선/유역·수계, 길 네트워크와 통행 수단별 연결, 필지와 기능 영역, 경계 구현 종류와 문, 건물 단면, 재질/날씨/상태, 이동/가림, 성능 비용. 지도와 눈높이/사선 시점을 연결한다. 검사 오류를 클릭하면 원인 객체와 영향을 받는 객체가 강조된다.

설계자는 출입점 추가, 경계 직선/곡선 편집과 구현 종류 변경, 단면 선택, 마당 크기, 지형 변경 범위, 수계 구간의 종횡단, 칸 간격 배열, 부재 교체, 상태 옵션을 편집할 수 있어야 한다. ‘자연스럽게’ 버튼 하나로 무작위 배치를 다시 만드는 흐름은 피한다.

## TOOL-03 생성 순서와 실패 처리

생성 의존 관계(역사 순서 주장이 아님): **지형·물 → 이동과 생업 → 정착 기능 → 길·필지·마당 → 건물·경계·문·배수 → 표면과 생활 흔적.** 제방·논·도로·집터가 물과 지형을 바꾸는 역방향 영향은 변경 지형으로 저장한다.

1. 근거·지역 입력 검증. 누락한 핵심 시기/지형/출입 요구를 보고한다.
2. 능선망·유역망·수계(종횡단 포함)·이동 가능 영역과 고정 위치를 확정한다.
3. 노선 목적지·고개·통행 수단으로 간선과 산길을 푼다.
4. 정착 프로그램과 후보 부지를 비교한다. 수용량·접근·지형 공사량·근거 충돌을 따로 보여준다.
5. 구획·필지·기능 영역·마당을 구성한다. 서로 영향을 주면 이전 단계로 되돌아가 조정한다.
6. 건물(기둥 기준선→기능 면→바닥/기단→지붕 지지)·경계(양쪽 영역과 이유→구현 종류→단면→접합)·문·배수·높이 연결을 생성한다. 담을 단순 후처리로 맞추지 않는다.
7. 기능 공간과 생활 소품, 식생 관리 상태, 노후·폐가 상태, 재질·날씨 반응을 적용한다.
8. 구조/통행/운반/시각/성능 검사를 수행하고 결과를 내보낸다.

불가능한 배치를 만나면 ‘건물 수 감소’, ‘부지 변경’, ‘길/마당 재설계’의 영향을 제시한다. 임의 축소·지형 삭제·고정 건물 이동으로 조용히 성공 처리하지 않는다. 충돌하는 잠금은 자동 해제하지 않는다. 가설 미리보기는 가능하지만 출시용 내보내기에서 미해결 심각 오류는 차단한다.

## TOOL-04 재생성·협업·사건 보호

지역 전체 seed 하나에 모든 결과를 의존시키지 않는다. 객체의 안정된 ID에서 영역별 변주를 파생하여 소품 하나의 추가가 도시 전체를 바꾸지 않게 한다. 같은 입력·규칙 버전·seed는 같은 논리 결과를 낸다. 엔진 메시 직렬화의 바이트 동일성과 논리 동일성을 구분한다.

잠금은 위치/형태/출입/재질/사건 참조/상태별로 적용한다. 잠근 대문 주변 담을 바꾸면 대문 접근을 재검사한다. 공유 경계는 원본 하나를 참조하므로 한쪽 필지의 재생성이 다른 쪽 담을 복제하거나 지우지 않는다. 변경 전 영향 목록과 차이 미리보기 후 확정·취소한다. 병합 충돌은 객체 수준으로 보고하고 마지막 작성자로 덮지 않는다.

출력은 원본 근거·규칙·편집 오버라이드·생성 형상·검사 보고서를 분리한다. Godot용 배치에는 stable_id, 위치, 충돌, 표면, 입구, 지역 스트리밍 범위를 포함한다. 기존 저장 좌표 이전이 필요하면 별도 승인·격리 시험을 요구하고 현 사용자 저장을 읽고 덮는 도구로 만들지 않는다.

## TOOL-06 시대·구조 근거 전달

[고증 검토](06-historical-verification.md)의 판단 ID를 provenance에 연결한다. 기록 존재를 자동으로 시설 실재로 바꾸지 않는다. 시대 불일치·검색 발췌만으로 들어온 치수·복원 연대 누락·현대 시설 포함은 근거 검사 경고다. 가설은 미리보기 가능하나 고증 승인 상태로 자동 승격하지 않는다. 자료 시기는 적합성 판단용 메타데이터이며 건물별 수리 이력·소유자 계보·변화 시뮬레이터는 요구하지 않는다. 상세 보수 이력이 없어도 정상/노후/부분 파손/방치/붕괴를 선택할 수 있다.
