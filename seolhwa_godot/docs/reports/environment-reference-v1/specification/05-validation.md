## 4. 성능 측정 계약

사용자 M1, 실제 프로젝트 렌더러와 해상도에서 단일 게임 프로세스로 측정한다. 첫 로딩/캐시 생성과 재실행을 분리한다. CPU/GPU 프레임 시간, p50/p95/p99, 메모리, 드로콜, 삼각형, 텍스처 사용량, 스트리밍 정지를 기록한다. 동일 경로 반복과 정지 구도를 함께 쓰고 기기 온도·백그라운드 부하를 기록한다. FPS 평균 하나로 완료를 선언하지 않는다.

목표 FPS/허용 메모리/최악 조건 예산은 아직 사용자 확정값이 아니다. 30/60fps는 비교 프로파일 후보다. 기준 시험 후 효과별 비용을 배분한다. 이전 다중 Godot 실행 중 수치는 통제된 성능 근거로 재사용하지 않는다.
