# 조선 자연·건축·성곽 고증 검토와 제작 규칙 v1

2026-10-24. **일반 환경의 유형과 원리를 검토한 문서다. 특정 고을 복원도나 고증 완료 정본이 아니다.** 게임 코드·배치·사용자 저장은 변경하지 않았다. 사용자 지시에 따라 남원 개별 좌표보다 조선시대 한국의 환경과 건축 체계를 우선한다.

## 1. 무엇을 구별해야 하는가

조선 약 500년을 하나의 외형으로 고정하면 지역성과 변화가 사라진다. 다음 세 층을 분리한다.

1. 지질·능선·유역 등 자연 기반: 현대 지리학으로 형성 원리를 설명할 수 있지만 현대 지형 전체가 조선 그대로라는 뜻은 아니다.
2. 경작·벌목·수리·도로·취락의 역사적 이용: 시기와 지역 자료가 필요하다. 오늘날 숲이나 하천 사진만으로 복원하지 않는다.
3. 건축·성곽과 수리 이력: 창건, 증축, 훼손, 현대 복원 상태를 분리한다. 현존 모습이 게임 시점에 존재했는지 검토한다.

사료는 정책이 논의되었다는 사실과 시설이 실제 완성되었다는 사실을 구별한다. 백과·보존 매뉴얼은 구조를 이해하는 근거지만 모든 조선 건물의 원형 도면은 아니다. 회화와 상업 모델은 공간·시각 참고이며 치수와 연대의 증명이 아니다.

## 3. 자연 환경 유형 — 제작 분류 제안

아래는 제작상의 분류다. 역사 문헌이 전국을 이 표처럼 분류했다는 주장이 아니다. 하나의 지역에서 여러 유형이 이어져야 한다.

| 유형 | 구조적으로 먼저 만들 것 | 재료·식생 판단 | 사람이 만든 환경과 연결 |
|---|---|---|---|
| 능선·안부·산사면 | 분수계, 지능선, 골짜기, 통과 가능한 고개 | 기반암·토심·노출·수분에 따른 구역 | 고갯길·쉼터·산중 사건 부지; 접근 가능성 검사 |
| 낮은 구릉·산록 | 사면과 완경사 접점, 작은 유역 | 산림 이용 이력과 경작 가능 토양 | 집터·밭·묘역 후보; 모든 사면 평탄화 금지 |
| 분지·하천 평야 | 유입·유출, 저지대와 상대적으로 높은 땅 | 침수·배수·퇴적 상태 | 논·취락·둑·길의 상호 영향 |
| 암반 계곡 | 낙차·협착·소·노출 암반 | 물에 닳은 면, 각진 낙석, 운반된 자갈 구별 | 계곡길·다리·취수; 전 구간 포말 금지 |
| 충적 하천 | 곡류·합류·모래톱·범람 가능 공간 | 모래·자갈·실트 혼합; 상류 공급과 연결 | 나루·논·제방; 현대 정비 하도 복제 금지 |
| 해안·하구 | 암석/모래/갯벌 구별과 침수 경계 | 염분·바람·퇴적 조건 | 포구·염업 등의 개별 시대 근거 필요 |
| 화산·석회암 특수 지형 | 해당 지질의 확인 후 선택 | 다른 암종의 균열·색·동굴을 무작위 혼합 금지 | 지역별 추가 고증 전 최종 프리셋 확정 보류 |

산의 높이뿐 아니라 폭, 골짜기 깊이, 능선 연결, 길의 실제 상승량이 경험을 만든다. 국가 평균이나 '산지 몇 %'를 지도 생성 목표값으로 쓰지 않는다. 산을 배경으로만 두지 않고 산속 이동·설화 장소를 수용할 공간을 설계한다.

숲은 수종 하나의 난수 배치가 아니다. 동일 지형도 벌채·채취·보호·경작·회복 상태에 따라 달라질 수 있다. 그러나 이력은 근거 또는 가설로 표시하고 임의로 역사적 사실을 만들지 않는다. 현대 조림지 사진, 1920년대 사진, 조선 회화는 별개 증거로 보관한다.

## 4. 건축·실내의 생성 원칙

**구조 → 공간 → 외피 → 접점 → 생활 흔적** 순서로 검토한다. 지역 양식은 한 건물에서 지붕만 바꿔 얻는 것으로 간주하지 않는다.

- 칸 수와 칸 치수는 별도다. 도면이 없으면 시험값으로 남기고 사용자에게 확정 고증값처럼 노출하지 않는다.
- 골조와 벽 충전재의 소유 면을 구분한다. 모서리는 골조·벽 두께·마감이 만나는 접합이며, 빈틈을 가리는 이색 기둥을 자동 추가하지 않는다.
- 지붕은 벽체와 도리의 외곽, 처마 하부, 빗물 배출, 채 사이 접합을 함께 검토한다. ㄱ자 채의 회첨과 서로 다른 높이의 문간채는 명시적 접합 유형이어야 한다.
- 초가는 지붕 끝 실루엣·초재 두께·묶음·보수 구역을 편집할 수 있어야 한다. 폐가에서는 같은 벽의 내부 구성과 지지 관계가 드러나도록 한다.
- HA01에 등장하는 현대 철망·비닐 결속·공구와 현재 유통 석재는 역사 프리셋에서 자동 배제한다. 재료를 쓸 수 있다는 현대 기술 설명과 조선 사용 증거는 다르다.
- 온돌·부엌·마루·굴뚝은 이후 유형별 도면 고증이 필요하다. 현 문서는 난방 구조의 시대별 상세를 확인했다고 주장하지 않는다.

## 5. 성곽과 담장을 분리하는 사양

**담장은 공간 경계, 성곽은 방어·지형·통행·수리·보급의 복합 구조**로 다룬다. 목적이 중첩될 수 있어도 동일 생성 프리셋으로 처리하지 않는다.

성곽 계획 입력: 시기, 초축/수리 단계, 읍성/산성 등 기능, 방어할 영역, 산세·수계, 출입 목적지, 내부 활동과 수원. 유형 이름만으로 평면을 고정하지 않는다.

성벽 구간 입력: 바깥과 안쪽 방향, 기초, 표면 석재, 속채움, 내측 지형/석축, 벽체 기울기, 상부, 배수, 구간 접합. **평면에서 휘는 것과 단면이 기울거나 굽는 것은 서로 다른 설정**이다.

문과 방어시설: 문 안팎 접근길, 고저차, 문 구조, 필요할 경우 옹성·치·여장 등의 관계를 정의한다. 시설의 존재는 사례 근거를 요구한다. 수구는 물의 경로에 연결하고 통행문과 혼동하지 않는다. 해자는 건식/습식·부분 설치·자연 지형 이용 가능성을 구분하며 획일적 원형 띠로 두지 않는다.

산성은 능선에 선을 그은 뒤 성문을 억지로 연결하지 않는다. 출입과 보급, 내부 수원·가용 부지를 함께 비교한다. 급경사에서 계단·우회가 필요한지 검토하고 수레·말·보행의 가능 여부를 분리한다. 읍성 내부도 성벽 면적을 집으로 채우는 대신 공적 기능·길·거주·여유 공간을 먼저 정한다.

문화유산 자산에는 창건 연대 외에 **표현 중인 모습의 시기**가 필요하다. 후대 복원 건물을 초기 조선 장면에 놓을 때에는 경고를 낸다. 전시용 복원 상태와 당시 생활 소품은 동일 근거로 묶지 않는다.

## 6. 재질·조명에 전달되는 사항

형상·재료·사용 이력을 표면 제작으로 전달한다. '조선풍' 색보정 하나로 고증을 대신하지 않는다.

- 바위/자갈: 암종 미확정 여부, 절리·파손·운반·물 접촉을 전달. 마른 산 암반과 젖은 하상을 같은 광택으로 처리하지 않는다.
- 흙/길: 배수·통행·경작·성토를 전달. 발자국·바퀴 자국은 실제 이동 수단과 이용 구역이 있어야 한다.
- 건물: 목재·흙벽·초재·기와·석재를 재료 ID로 구별. 오염과 파손은 노출·접촉·보수에서 파생한다.
- 젖음/눈: 처마 차폐, 경사, 바람 노출, 배수·고임을 전달. 계절 외양과 특정 역사 시기의 기후 수치 복원은 구분한다.
- 빛: 창호·처마·문 개폐와 광원 위치를 먼저 반영. 등불·장식은 참고 이미지에 있다는 이유만으로 모든 집에 배치하지 않는다.

정확한 거칠기·노멀 강도·적설 두께·조도 수치는 아직 측정하지 않았다. 역사 자료로 셰이더 수치를 확정했다고 보고하지 않는다.

## 7. 남아 있는 고증과 완료 조건

우선순위는 **한국의 환경 유형 → 시기·지역별 차이 → 건축/성곽 단면과 접합 → 생활 공간 → 특정 도시 적용**이다.

1. 자연: 지질도·단면과 현장 사진을 동일 지형에서 묶어 암반/퇴적/식생 관계 검증. 현대 개변 구역 분리.
2. 건축: 여러 지역 민가의 실측 보고서로 평면·가구·기단·부엌/온돌·문·담 사례와 예외 확보. 현대 한옥 교재만으로 완료 금지.
3. 성곽: 읍성·산성·도성의 발굴/수리 보고서와 연혁을 대조. 토성·석성·혼합 축조의 세부 유형, 여장/문루 치수 추가 조사.
4. 생활·재질: 농가·상업·공공 건축의 사용 장면과 실제 재료의 근접 관찰. 실내·폐가·습윤 표면 근거 보강.
5. 특정 도시: 위 체계가 마련된 후 고지도·읍지·실측 위치 대조. 현재 남원 좌표를 확정하지 않는다.

문서 완결과 고증 확정은 다르다. 핵심 형식마다 적용 시기·지역, 배치/단면/접합 근거와 예외가 있고 미확인 치수가 드러나야 사양 승인 후보가 된다. 현재는 그중 확인된 범위와 남은 항목을 분리한 검토본이다.

## 사용자 범위 정정

건물 연혁 자체를 조사 목표로 삼지 않는다. 이 문서의 시기·수리 관련 주의는 참고 모습의 적합성 판단에 필요한 범위로 한정한다. 빌더에 상세 연표나 과거 상태 복원 기능을 요구하지 않는다. 생활·문화와 현재 공간의 관계는 [후속 사양](07-living-culture.md)을 따른다.
