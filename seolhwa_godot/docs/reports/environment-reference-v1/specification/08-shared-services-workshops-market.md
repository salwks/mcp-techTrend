# 공동 생활·생업·장시의 공간 사양 — 검토본 v1.0

2026-10-24. 조사와 설계 제안만 수행했다. 게임 코드·저장·기존 시나리오 변경 없음. 시설의 연혁을 수집하거나 생활 경제 시뮬레이터를 만드는 문서가 아니다.

## 1. 근거의 범위

[생활 출처대장](living_culture_sources.csv)의 LC13–LC19를 추가 검토했다. 박물관 회화는 작품 설명과 메타데이터를 확인했으며, 이번 추가분에서 원화 픽셀의 세부 판독·실측은 완료하지 않았다. 전문 해설과 현대 전승 기술은 유용한 근거이나, 조선 전 기간·전 지역에 동일한 형태가 있었다는 증거로 쓰지 않는다.

표의 ‘제작 제안’은 근거에서 도출한 공간 계약이지 옛 법규의 복원이나 확정된 치수 기준이 아니다. 폭·간격·시설 개수는 검증된 도면과 실제 작업 자세를 확보한 뒤 정한다.

## 3. 배치 전에 결정할 관계

아래는 역사적 정형 배치도가 아니라 **생성 결과가 기능하는지 확인하기 위한 설계 관계**다.

| 공간 | 반드시 확인할 연결 | 확보할 작업 공간 | 피해야 할 자동 배치 |
|---|---|---|---|
| 공동 우물 | 이용 가구에서 공용 길을 통해 접근 | 물 긷기·용기 취급·교행 | 사유 마당을 무단 통과해야 하는 유일한 길; 집마다 동일 우물 |
| 냇가 빨래터 | 길에서 안전하게 내려가는 접근과 실제 수면 가장자리 | 작업 자세·젖은 짐·마른 짐 | 수면 위 공중 작업석; 급경사에 세탁 소품만 배치 |
| 측간 | 이용자 길과 유형에 맞는 수거 길 | 문 여닫기·가림·반출 | 수거 문을 담으로 봉쇄; 부엌·우물과 무관하게 남은 틈에 삽입 |
| 옹기 작업장 | 원료 반입→공정별 자리→출하 | 운반 중인 그릇까지 포함한 통과 폭 | 소성 전후 물건을 무작위 혼합; 가마 투입구 앞 장식 적치 |
| 직조 작업 자리 | 원료 보관과 선택한 공정 연결 | 펼친 실과 작업자의 점유 영역 | 베틀 외곽만 충돌 검사; 출입구를 실·도구로 막음 |
| 장시 | 외부 길·상설 점포·임시 판매 면·통과 길 | 상품 하역·구매자 체류·철수 | 모든 길을 가판으로 채움; 장날에도 공공 시설 접근 불가 |

식수와 오물 처리의 관계는 검토하되, 현대적 위생 이격 거리를 옛 조선의 규정처럼 제시하지 않는다. 근거 없는 고정 거리 대신 수원·지표 흐름·접근·작업 경로의 충돌을 경고한다. 이는 제작상의 검토 장치다. ‘상류 식수, 하류 빨래’라는 단순 배치를 모든 취락의 확정 고증으로 사용하지 않는다.

## 4. 빌더 작업 순서

1. 지역·시기·주요 생업과 공유 시설 이용 범위를 정한다. 실제 자료가 없으면 가설이라고 표시한다.
2. 기존 지형·수계·길·필지에서 작업 가능한 면과 접근 경로를 찾는다.
3. 작업자의 몸, 도구가 움직이는 범위, 운반물의 부피를 포함한 **사용 영역**을 놓는다.
4. 그 영역을 수용하는 건물·차양·기단·담·문을 구성한다. 담은 경계·가림·출입을 해결해야 하며 작업 면을 잘라서는 안 된다.
5. 바닥·배수·적치와 소품을 추가한다. 기능이 성립하지 않는 배치를 소품으로 감추지 않는다.
6. 지형과 건물의 위치를 바꿨을 때 접근·작업 영역이 유지되는지 다시 검사한다.

담의 곡선은 길·필지·지형·작업 공간의 경계에서 유도한다. ‘자연스러워 보이기 위한 무작위 흔들림’은 근거가 아니다. 공유 시설을 둘러싼 여러 필지의 담은 공용 접근을 남긴 상태로 생성해야 한다.

## 5. 상태와 재질로 생활을 읽게 하기

아래는 표현 제안이며 실제 흔적의 범위·강도는 사진·유물로 보정해야 한다.

- 우물·빨래터: 물과 접촉하는 곳의 젖음과 주변 마른 길을 구별한다. 주변 전체를 같은 광택으로 칠하지 않는다.
- 옹기: 선택한 공정에 따라 성형 중·건조 중·완성품을 구별한다. 모든 항아리에 동일한 유약 광택을 쓰지 않는다.
- 가마 주변: 연료 적치·작업 바닥·열과 연기 노출 면을 구분한다. 건물 전체를 검게 칠하는 것으로 작업장 표현을 끝내지 않는다.
- 직조: 섬유 종류와 작업 상태를 구별하고 실의 경로가 도구와 연결되게 한다. 천 무늬만 교체하는 방식은 부족하다.
- 장터: 물건을 내려놓는 면, 반복 통행하는 길, 비어 있어야 하는 출입구를 구분한다. 모든 곳에 균등하게 소품·진흙을 뿌리지 않는다.

## 6. 에디터 입력과 상태 비교

기존 Building / Compound / ActivitySite / Route에 아래 의미를 담는다. 새로운 이력 데이터베이스나 생활 AI를 전제로 하지 않는다.

| 입력 | 용도 |
|---|---|
| 용도와 유형 | 공동 우물·가내 직조·옹기 작업장 등 기능 선택 |
| 이용 주체 또는 연결 대상 | 어느 가구·공공 길·작업장과 연결되는지 표시 |
| 작업 면과 통과 면 | 사람이 머무는 영역과 이동해야 하는 영역을 구분 |
| 운반물·도구 점유 | 사람만 통과하면 충분하다는 잘못된 검사 방지 |
| 출입·수거·반입 접점 | 문과 담에 실제 개구부가 필요한 위치 |
| 선택한 현재 상태 | 평상시·작업 중·장날 등 현재 표현 비교 |
| 근거와 불확실성 | 사실·전승 참고·설계 제안을 구별 |

장터에는 평시 / 준비 / 거래 / 철수의 **비교용 배치 상태**를 제안한다. 임시 가판을 제거했을 때도 길과 장소가 성립하고, 장날 상태에서도 통과가 가능한지 확인하기 위한 것이다. 경제 시스템이나 자동 달력 구현 요구가 아니다. 장날과 고증 수치는 근거 확보 전 미확정으로 남긴다.

## 8. 남은 고증과 후속 작업

이번에 확보한 것은 기능과 관계의 근거다. 지역별 우물·수거 시설의 실측, 공정별 도구·운반물 크기, 실제 장시 배치도는 더 필요하다. 풍속화의 전체 장면 및 세부 이미지 판독도 별도 기록해야 한다.

다음 보강 대상은 목공 작업 공간, 소형 서민 주거의 실내 점유, 관아·향교·사찰의 이용자별 출입과 서비스 동선이다. 자연 환경과 건축·성곽 사양은 계속 함께 적용하며 생활 조사를 이유로 산·수계·암반·식생 범위를 축소하지 않는다.
