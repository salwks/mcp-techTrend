# 목공·관아·향교·사찰 — 사용 관계와 공간 사양 v1.0

2026-10-24. 조사·분석 문서. 게임 구현·실측 검증 미실행. 건물 연혁이나 소유자 이력을 수집하는 것이 아니라, 제작에 필요한 기능·배치·출입 관계를 정리한다.

## 1. 이번에 확인한 자료와 한계

출처 LC20–LC25는 [생활 출처대장](living_culture_sources.csv)에 URL과 확인 범위를 기록했다. 본문 확인과 검색 발췌 확인을 구분했다. 도면 이미지의 픽셀 판독 및 치수 추출은 이번에 수행하지 않았다.

- LC20 「관아」: 지방관아의 업무 공간과 내아의 생활 공간, 서로 다른 동헌 평면 사례를 확인했다. 관아를 하나의 큰 기와집으로 취급할 수 없다.
- LC21 「향교」: 강학·배향·생활 지원 공간과 직렬·병렬 배치 사례를 확인했다.
- LC22 「향교: 입지와 건물배치」: 지형과 배치 유형의 관계, 평지에서도 단일 유형으로 귀결되지 않는 예외를 대조했다. 본문의 현존 사례 비율을 조선 전역 생성 확률로 사용하지 않는다.
- LC23 「목수」: 건축 목공과 소규모 목공의 역할 구분을 확인했다. 작업장 평면을 실측한 자료는 아니다.
- LC24 국가유산진흥원 소목 제작도구 설명: 톱·대패·끌·고정 도구의 기능을 검색 발췌로 확인했다. 직접 본문 열기는 실패했다. 전승 기술 참고이며 조선 작업장 배치의 단독 근거로 삼지 않는다.
- LC25 UNESCO 산사: 일곱 산사의 종교·수행·교육·공동생활 기능과 마당을 중심으로 한 건물 관계를 확인했다. 현존 유산 설명을 모든 조선 사찰·암자의 정형 도면으로 쓰지 않는다.

위 사실 요약과 아래 설계 제안을 구분한다. 특히 출입 허용 인원·시간, 반입문 위치, 정확한 공양·취사 동선은 이번 자료만으로 고증 완료한 사항이 아니다.

객사는 관련 공공 시설로 연결하되 동헌의 일반 접객실과 동일시하지 않는다. 문헌마다 관아의 범위를 다르게 설명할 수 있으므로 데이터에는 건물의 실제 기능을 먼저 기록한다.

## 3. 목공 공간: 도구의 위치보다 작업물의 움직임

다음은 작업 성립을 확인하는 설계 제안이다. 실제 조선 작업장의 보편적 배치 순서로 주장하지 않는다.

재료 놓는 곳 → 치수 확인·가공 자리 → 맞춤·조립 자리 → 완성품 반출을 연결한다. 작업을 한 장소에서 번갈아 하는 경우도 허용한다. 공정마다 별채를 만들 필요는 없다.

- 긴 부재는 작업자뿐 아니라 부재를 돌리고 옮기는 범위까지 확보한다.
- 소목은 제작 중인 창호·가구의 크기와 고정 방법에 따라 작업 영역을 달리한다.
- 완성된 문짝이 작업장 문을 통과하지 못하면 배치 실패다.
- 도구 조작 영역과 손님의 접근 영역이 겹치는지 검사한다. 완전한 분리 통로는 고증 없이 강제하지 않는다.
- 목재 결, 자른 단면, 가공 중 표면, 완성 표면을 구별한다. 톱밥은 활동 상태에 따른 표현 후보이며 모든 목재 바닥을 같은 얼룩으로 덮지 않는다.

대목 작업이 실제 건축 현장에 붙는지, 상설 작업장에서 이루어지는지는 자료와 장면에 맞춰 선택한다. 모든 읍내에 같은 대목 가게를 필수 시설로 넣지 않는다.

## 4. 관아: 공적 접근과 생활을 구별

**자료에서 확인:** 지방관아에는 정무를 보는 공간과 수령 가족의 생활 공간이 함께 있으며, 동헌 평면도 사례별로 다르다(LC20).

**빌더 제안:** 외부 길에서 업무 목적지까지의 접근, 내부 업무 연결, 내아 생활 연결, 물품 반입을 각각 표시한다. 이는 가상의 현대 행정청 동선을 복원하는 것이 아니라 서로 다른 기능이 한 통로에 잘못 합쳐지는지 찾기 위한 검사다.

업무 방문의 유일한 길이 내아 방 안을 가로지르면 실패다. 담은 공사 구분과 출입 조절의 이유를 가져야 하며, 반입 가능한 문이 실제로 있어야 한다. 하지만 모든 부속 청사·형옥·창고를 모든 규모의 관아에 강제로 넣지 않는다. 고을의 격·시기·자료에 따라 구성 항목을 선택하고 누락 근거를 표시한다.

‘동헌’이라는 이름만 보고 객사 동쪽에 고정하는 규칙은 채택하지 않는다. 이름에서 방위를 역산하는 대신 배치 자료를 확인한다.

## 5. 향교: 유형 선택과 지형 검사를 분리

**자료에서 확인:** 교육과 제향 영역이 구분되며, 전후 배치 외에 병렬 배치도 존재한다. 교직사의 생활 지원 기능도 있다(LC21). LC22는 지형에 따른 경향과 예외를 설명한다.

**빌더 제안:** 유형은 근거·지역·시기를 보고 선택하고, 지형은 선택한 유형이 성립하는지 검사한다. ‘평지이면 무조건 전묘후학’처럼 경향을 절대 규칙으로 만들지 않는다.

- 교육 목적지, 제향 목적지, 생활 지원 목적지를 별도 접점으로 지정한다.
- 서로 다른 마당과 문을 구분하되 실제 자료 없이 모든 이용자를 완전히 분리된 길로 보내지 않는다.
- 제향 구역이 닫힌 장면을 설정한다면 교육·생활 공간이 함께 고립되는지 검사한다. 닫힘의 시각·대상은 별도 근거가 필요하다.
- 동일한 지붕·색을 쓰더라도 강학 건물과 배향 건물의 내부 용도·바닥·배치가 구별되어야 한다.
- 전후·좌우는 방위와 관찰 방향을 명시한다. 화면의 왼쪽을 무조건 서쪽으로 저장하지 않는다.

자료에 실린 개별 향교 칸 수와 건물 수는 해당 사례값이다. 모든 향교의 최소·최대 치수로 전환하지 않는다.

## 6. 사찰: 예불 공간과 생활 공간을 함께 설계

**자료에서 확인:** UNESCO의 일곱 산사 설명은 산지 환경, 종교 활동, 수행·교육, 공동생활을 함께 다룬다(LC25).

**빌더 제안:** 산길에서 도달 가능한 진입, 마당·전각의 관계, 거처 접근을 함께 확인한다. 취사·물·연료·저장 기능도 검토 대상으로 두지만, 이번 자료만으로 공양간 위치나 서비스 문의 방위를 확정하지 않는다.

산사 부지를 전부 수평으로 밀지 않는다. 건물을 받는 단과 단 사이의 보행·운반 연결을 먼저 확보한다. 마당이 필요한 공간과 계곡·암반·사면을 유지할 공간을 구별한다. 예불 전각의 정면성을 살린다는 이유로 물길을 막거나 진입 계단을 암벽 속에 묻으면 실패다.

소규모 암자와 대규모 사찰은 요구 기능부터 다르게 정한다. 현재 확인한 대형 산사의 마당 구성을 암자의 필수 조건으로 확대하지 않는다. 현대 관광 동선·관람 시설도 조선 생활 배치와 별도로 취급한다.

## 7. 에디터에서 확인해야 할 공통 정보

새 시스템을 늘리기보다 기존 Compound·ActivitySite·Route에 다음 의미를 연결한다.

1. 기능 영역과 목적지: 업무·생활·교육·제향·작업 등.
2. 연결: 출발점과 도착점, 통과하는 문·계단·마당.
3. 사용 영역: 작업자의 자세, 운반물 크기, 문 개폐와 회전 공간.
4. 경계 이유: 사적 생활, 의례 영역, 작업 면 보호 등. 이유 없는 담은 검토 대상.
5. 근거 상태: 확인 사실 / 전승 참고 / 설계 제안 / 미확인.

이 정보는 배치 검사와 편집을 위한 것이다. 출입 통제 AI·역사적 관제·의례 시뮬레이션을 구현하라는 지시가 아니다.

## 9. 아직 필요한 근거

실측 평면·단면과 출입구 위치, 목공 작업 영상의 자세·운반 범위, 관아의 용무별 이용 방식, 향교의 의례 준비·교직사 연결, 사찰의 취사·급수·연료 동선이 남아 있다. 위 내용을 확인하기 전 정확한 치수나 보편적인 출입 관행을 고증 완료로 표시하지 않는다.

이번 연구는 개별 건물 이력 대신 공간의 사용 이유를 추출했다. 원자료 조사와 설계는 이어가되, 원문을 읽었다는 사실만으로 실측·시각 검증까지 완료한 것으로 보고하지 않는다.

## 그림·도면 대조 결과

제주목 관아 안내도와 탐라순력도 3점, 봉정사 화엄강당·대웅전, 참당암 대웅전 도면, 영산암 공식 자료를 [17 관아·읍성·사찰·암자](17-public-religious-drawings.md)에서 판독했다. 문이 겹으로 이어지는 관아 마당 묶음, 화재 이격이라는 담의 이유, 한 강당 안의 부엌–구들방, 산지 불전의 앞 축대·뒤 배수로, 암자의 프로그램 차이를 PUB-01–09로 정리했다. 공양간·우물·연료 동선과 전체 배치도는 여전히 미확보다.

## 시각 자료 후속 확인

[배치 그림 대조](10-plan-evidence-and-boundaries.md)에서 나주 및 울산·고흥 비교 그림을 직접 확인했다. 이로써 이번 문서의 전체 배치와 내부 조합 구분을 보강했다. 함양 도면은 최초 로딩 실패 후 [공개 원본을 재확보](11-hamyang-recovered-drawings.md)해 판독했다. 단면·높이·운영 동선은 추가 확인이 필요하다.
