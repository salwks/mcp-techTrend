# 배치 그림 대조: 영역·출입·담·지형 — 조사 기록 v1.0

2026-10-24. 문헌 원칙을 실제 공개 그림과 대조하는 조사다. 이번 기록은 세 사례를 포함한 그림 2건을 직접 화면으로 확인한 결과이며, 실측 도면의 치수를 추출하거나 게임을 시험한 결과가 아니다. 관아·사찰을 포함한 모든 유형의 시각 검증이 끝났다는 뜻도 아니다.

## 1. 확인한 원자료

국사편찬위원회 『한국문화사』 39권, 김지민 「향교: 입지와 건물배치」의 확대 그림을 브라우저에서 판독했다.

인쇄된 배치 그림에서 상대적인 위치와 연결은 읽을 수 있다. 다만 축척·측량 기준·치수를 확인하지 못했으므로 픽셀을 미터로 바꾸지 않았다. 그림의 점선 화살표를 모든 시대·모든 이용자의 실제 이동 경로로 확정하지 않는다.

## 2. 사양에 반영할 판단 — 프로젝트 설계 제안

### 2.1 전체 유형과 영역 내부 유형을 각각 선택

향교를 ‘전학후묘’로 정하는 것만으로 명륜당·동재·서재의 조합까지 정해지지 않는다. 전체 배치 유형과 교육 영역 내부 조합을 따로 선택하고, 둘의 조합 근거를 기록하도록 제안한다.

이는 전체를 무작위로 섞으라는 뜻이 아니다. 사례로 확인한 조합을 먼저 보존하고, 새로운 조합은 설계 가설로 표시한다. 지역 이름만으로 같은 평면을 모든 장소에 강제하지 않는다.

### 2.2 담은 둘러친 선이 아니라 서로 다른 영역의 경계

경계를 먼저 임의의 직사각형으로 그린 뒤 건물을 채우는 방식은 위 사례의 부속 영역과 출입을 표현하기 어렵다. 다음 순서를 제안한다.

1. 기능 영역과 유지할 마당을 정한다.
2. 영역 사이에 필요한 연결을 정한다.
3. 경계를 공유하는 구간과 독립된 구간을 나눈다.
4. 필요한 연결이 경계를 통과하는 곳에 문을 둔다.
5. 문에 닿는 보행 면과 단차를 해결한 뒤 담 형상을 만든다.

공유 경계는 하나의 원본 선을 참조하도록 제안한다. 양쪽 영역에서 담을 각각 만들면 겹친 벽·틈·불필요한 이중 담이 생길 수 있기 때문이다. 실제 이중 담은 사례 근거가 있을 때 별개의 구조로 둔다.

### 2.3 시각적 중심축과 실제 보행 연결을 구별

건물 정면을 잇는 중심선은 정렬·위계 표현에 쓰인다. 보행 경로는 문·건물·마당을 통과할 수 있는지를 따져 따로 만든다. 중심선 위에 건물이 있다고 건물을 관통하는 길을 만들지 않는다. 건물을 돌아 연결하는 길도 유효한 해법으로 허용한다.

### 2.4 직선·꺾임·곡선은 경계의 원인에 따라 선택

이번 그림들은 ‘담은 모두 곡선이어야 한다’는 근거가 아니다. 정렬된 영역에는 직선이 성립하고 부속 영역이 붙으면 윤곽이 꺾일 수 있다. 곡선은 별도 지형·길·실측 사례가 뒷받침할 때 사용한다. 직선 담의 문제를 무작위 곡선 추가로 해결하지 않는다.

### 2.5 단차는 별도 단면 근거가 필요

배치 그림에 선이 여러 겹 있다고 이를 모두 계단이나 석축으로 해석하지 않는다. 기단·계단·등고선·담을 구별해야 한다. 높이를 판독하지 못한 사례는 상대 배치 참고로 쓰고, 실측 단면을 확보하기 전에는 역사적 높이값을 확정하지 않는다.

## 3. 빌더 계약으로 옮기는 최소 정보

| 정보 | 필요한 이유 | 누락 시 처리 |
|---|---|---|
| 기능 영역과 보존할 빈 공간 | 건물 수보다 마당과 사용 영역을 유지 | 배치 초안에 미정 표시 |
| 전체 유형·내부 조합 | 한 가지 유형명으로 모든 건물을 고정하지 않음 | 확인 사례 조합만 우선 사용 |

| 출입 연결과 문 위치 | 담으로 사용 동선이 끊기는 문제 방지 | 도달 불가 검사 |
| 중심축과 보행 연결 | 정렬과 통행을 혼동하지 않음 | 건물 관통 경로 거부 |

이 정보는 기존 Compound·Route·경계 데이터에 필요한 의미를 정리한 것이다. 실제 저장 형식이나 생성 코드는 아직 수정하지 않았다.

## 4. 문서상 검토용 인수 조건 — 게임 검증 미실행

- V40: 하나의 전체 유형에서 영역 내부 조합을 바꿔도 마당과 기능 연결이 성립하는가?
- V41: 붙어 있는 두 영역에서 공유 담이 한 번만 생성되고, 의도한 문이 남는가?
- V42: 중심축을 유지하면서도 건물을 관통하지 않는 실제 보행 연결을 표현하는가?
- V43: 근거 없는 곡선·단차·방위가 자동으로 확정되는 것을 막는가?

가설은 허용하되 확인 사실과 같은 표시로 내보내지 않는다. 위 항목은 앞으로 구현 결과를 판정할 조건이며 통과 보고가 아니다.

## 5. 함양향교 자료 접근 결과 — 최초 시도 기록

[국립문화유산연구원 함양향교 자료](https://portal.nrich.go.kr/kor/hyanggyoUsrView.do?idx=104&menuIdx=720)에서 실물 36건·도면 4건의 목록과 설명을 확인했다. 도면 목록에는 배치도·대성전·명륜당·위치도가 있었다. 확대 창을 열었으나 원본은 로딩 상태로 남았고 썸네일도 대체 이미지였다. 따라서 배치도 판독·치수 확인은 미완료로 기록한다.

또한 화면 제목·항목명은 함양향교인데 일부 파일명에는 ‘함안향교’가 섞여 있다. 원본이 표시되면 도면 표제와 건물 구성을 대조해야 한다. 파일명만으로 대상을 확정하지 않는다. 사이트 설명의 구릉지·여러 기단이라는 내용도 이미지에서 직접 확인한 결과와 구분한다.

## 6. 후속 조사 우선순위

1. 공개 가능한 실측 평면·단면으로 기단–계단–문–마당 높이 관계 확인.
2. 관아의 업무·내아·반입 경로를 실제 배치 자료와 대조.
3. 사찰의 예불 영역과 취사·급수·연료 반입 연결을 실제 평면과 대조.
4. 주거 골목·장터·하천변 담의 직선·곡선·돌담 접합을 별도 사례로 확인.

이번 사례는 공공 건축의 영역·경계에 관한 근거다. 도시 전체나 서민 골목을 이 향교 배치로 생성하라는 사양이 아니다. 자연 환경·생활·생업의 다른 사양과 함께 적용한다.
