## 4. 자료 사이 불일치

배치도 범례의 8번은 ‘풍화루’인데 기관 항목 설명과 함양향교 자체 안내에서는 ‘태극루’라고 한다. 도면 표제는 함양향교이며 다른 건물 구성도 대조했지만, 이 명칭 불일치는 남겨 둔다. 임의로 도면 범례를 고치거나 동일 명칭의 다른 향교 자료와 합치지 않는다.
