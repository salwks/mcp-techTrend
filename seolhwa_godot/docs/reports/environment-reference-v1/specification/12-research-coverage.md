# 조사 충족도와 남은 근거 — 2026-10-25 개정

## 현재 판정

**전체 조사 미완료. 통합 사양은 검토본이며 제작 정본으로 확정할 단계가 아니다.** 아래 판정은 파일 수·출처 수로 산출한 진척률이 아니라 확보한 근거의 깊이를 점검한 것이다. 출처 목록의 행 수를 조사 완료율로 쓰지 않는다. 게임 동작·성능·저장 호환 검증은 역사 조사와 별개이며 실행하지 않았다. 기존 자료 색인 984건·962건은 전 이미지 판독 실적이 아니다.

판정 단계: **원칙 작성**(문헌·기관 설명만) → **문헌 중심** → **부분 조사**(원문·원본 그림 일부 직접 대조) → **사례 대응 확보**(같은 대상의 평면·단면·사진 묶음 1건 이상) → 정본 검토 가능(여러 지역·규모 비교와 반례 확보). 정본 검토 가능 단계에 이른 분야는 아직 없다.

## 이번 개정에서 바뀐 판정

- 산·고개·암반·하천: 검색 발췌 중심 → NR01–NR03 원문·원본 사진 대조로 **부분 조사**. 국가지도집(HG02–05)과 M01은 여전히 검색 발췌만이며 원본 확인으로 바꾸지 않았다.
- 관아·사찰: 문헌 중심 → 실제 안내도·기록화·도면 판독으로 **부분 조사**. 단, 관아는 제주 복원 현황과 낙안 복원 안내뿐이며 사찰 전체 배치는 없다.
- 숲: 원칙 작성 → 실록 기사·지정 설명·사진으로 **부분 조사**.
- 재료·폐가: 원칙/사양 방향 → 시방서 층 구조와 보수 사례로 **부분 조사**. 날씨는 비교 사진이 없어 **원칙 작성** 유지.

## 조사 종료 기준

유형별로 아래 연결이 성립해야 제작 사양을 승인 검토에 올린다.

1. 문헌 또는 유물·조사 자료에서 용도와 구성 확인.
2. 배치·평면·단면·눈높이 사진 가운데 필요한 조합 확보.
3. 사람·도구·운반물의 사용 공간 확인.
4. 지역·규모·지형의 변형 및 예외와 대조.
5. 확인 사실에서 생성 규칙으로 넘어가는 추론을 표시.
6. 근거가 있는 치수·단위·범위와 미확정 시험값 구분.
7. 생성 결과를 판정할 형태·접합·통행·재질 조건 정의.

모든 유형에 같은 수의 자료를 억지로 채우지 않는다. 핵심 형상·동선 근거가 비어 있는데 출처 수가 많다는 이유로 완료 처리하지 않는다.

## 차단 조사 현황 — 2026-10-25

[21 §5](21-regional-profiles.md)에 상세. 산림 이용 원문은 실록 국역 2건으로 **부분 해소**, 사찰 서비스 영역은 송광사 현황 사진으로 **부분**(배치도·우물 없음, 공양간은 현대 건물), 폐가는 현대 빈집 판정 기준으로 **부분**(붕괴 사진 없음). 육지 관아 배치도, 골목 단면, 담 기초 단면, 날씨 비교 사진은 **차단 유지**.
