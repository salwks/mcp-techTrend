## 2. 식생 — 관찰 사실

- **보호림과 이용의 공존(NR06):** 1422년 병조는 금산(禁山)의 소나무를 베거나 가지를 치는 일을 막기 어렵다고 보고하고, 가지 채취와 연목 이상 크기 온 그루 벌채를 구분해 처벌하자고 청했다. 금지 구역 안에서도 가지 채취·벌채 압력이 실제로 있었다는 기록이다. 산림 밀도나 전국 분포를 말해주지는 않는다.
- **마을숲의 위치와 목적 서술(NR08):** 금당실 송림은 마을 서북쪽, 산봉우리 아래에서 학교 앞까지 약 800m에 걸친 소나무 숲이다. 지정 설명은 계류가 만나는 삼각주 지형의 여름 범람과 겨울 북서풍을 막기 위해 주민이 조성했다고 하고, 1863·1894년 무렵 큰 나무가 벌채되었다가 이후 보호되었다고 쓴다.
- **사진에서 본 숲의 구조(NR08):** 높이 솟은 굽은 줄기와 높은 수관, 거의 비어 있는 하층(관목층 없음), 겨울에는 마른 풀·맨흙 바닥, 여름에는 낮은 풀밭과 사람이 밟아 생긴 좁은 흙길이 보인다. 조감 사진에서는 숲이 마을·밭과 들 사이에 띠 모양으로 놓인다. 운동장·비닐하우스·지지대 등 현대 요소가 함께 찍혀 있다.
- **현대 조사값(NR07 초록):** 식재목 565그루 중 558그루가 소나무, 흉고직경 30–50cm가 다수, 평균 수령 약 85년, 그루터기 25개. **현대 값이며 조선 시점 값으로 쓰지 않는다.** 다만 ‘단일 수종 우점 + 벌채 흔적’이 함께 기록된다는 점은 숲 상태 표현의 근거가 된다.
- **풍수적 설명(NR09):** 만송정 숲은 강이 만든 모래 퇴적층에 있고, 맞은편 절벽의 기를 완화하려고 소나무를 심었다고 설명된다. 조성 이유의 **문화적 설명**과 실제 방풍·방수 기능은 구별해야 한다.

## 3. 재료의 층 구조와 손상 조사 항목 — 관찰 사실(MT01)

### 3.1 초가지붕

쓰임말과 재료 항목이 지붕을 **층**으로 기술한다: 서까래 위 산자 → 초가알매흙(점성 흙+짚여물) → 군새(물매를 잡는 짚·청솔가지·낡은 이엉) → 이엉(볏짚·억새를 엮은 단)을 겹겹이 → 꼭대기 용마름 → 지붕 전체를 가로·세로·대각으로 묶는 고사새끼, 서까래 밑 연죽에 동아줄로 고정. 처마 끝은 이엉을 이은 뒤 단정하게 자르고(기스락자르기), 추녀 모서리는 둥글게 잇고(방구매기), 합각 양끝에 연기 구멍(까치구멍)을 둔다. 서까래와 이엉 사이는 흙으로 막아 새가 못 들어가게 한다(새굴매기). 조사 항목은 용마름 높이·곡선, 물매, 처마 내밀기, 새끼 간격·굵기, 이엉 겹 수 등이다. 시방서는 초가의 **지역적 특성**을 설계에 반영하라고 명시한다.

### 3.2 기와지붕

개판 또는 산자 → 진새흙 → 물매를 잡는 적심·보토(또는 생석회다짐) → 암키와 밑 알매흙 → 수키와 밑 홍두깨흙 → 처마 수키와 끝 와구토, 지붕면이 만나는 곳에 용마루·내림마루·추녀마루. 수리 시 기와 누수, 개판·산자의 부식 여부와 지붕 하중을 검토해 해체 범위를 정한다.

### 3.3 흙벽

중깃·힘살·가시새에 외(가로·세로 가는 부재)를 엮고, 안쪽 초벽치기·바깥 맞벽치기 → 재벌 → 정벌. 조사 항목: 45° 경사 균열(어긋남), 벌어짐·박락·들뜸·탈락, 판벽의 갈라짐·뒤틀림·부식, 전벽의 동파, **비들이침에 의한 외벽 손상, 결로에 의한 고막이벽 파손**, 내벽의 누수·결로 습기. 표면은 **비스듬히 빛을 비춰(사광조사)** 상태를 본다.

### 3.4 목부·기단

목부는 기울기·처짐·벌어짐, 부재별 부식·충해·변형을 조사한다. 기단은 파손 부위·쌓기법·재질·풍화 정도와 해체 시 단면(뒤채움·쌓기)을 조사한다.

### 3.5 낙안 사진(MT03)

골목 양쪽 돌담은 크기가 다른 막돌을 쌓았고 담 위와 틈에 흙·풀이 있다. 초가는 둥글고 두꺼운 덩어리로 처마 끝이 잘려 있다. 골목 바닥은 낙엽이 쌓인 흙길이며 가장자리가 가운데보다 덜 밟혔다. 동헌은 높은 막돌 기단과 가운데 계단 위에 있다. 내아 안내판은 ㄱ자 7칸×2칸, 대청을 기준으로 수령이 일상적으로 머물며 손님을 맞는 쪽과 안채 쪽이 나뉜다고 쓰고, 1990년 옛 기록을 바탕으로 복원했다고 밝힌다. 모든 사진이 마른 가을 날씨다.

### 3.6 생활 흔적의 위치(MT02 첨부 사진)

한 가옥 사진에서 벽 아래 아궁이 입구 위쪽 흰 벽에만 검은 그을음이 위로 번져 있고, 다른 벽면은 깨끗하다. 기단 주변 마당 흙에는 국부적으로 이끼·습한 얼룩이 있다. 이 사진은 손상 사례 기재 대상과 별개인 가옥 일반 사진이다.

## 4. 손상의 원인과 진행 — MT02 42건 정리

DB에 기재된 현상–원인 쌍을 부위별로 묶었다. 원인 판정은 DB 기재값이며 이번에 검증하지 않았다.

| 부위 | 원인 → 현상 (사례 수·대표 사례) |
|---|---|
| 기와 지붕면 | 지붕 위 풀이 자라 기와 틈이 벌어짐 → 물 유입(무안 나상렬가옥); 동파 → 기와 금·깨짐(진접 여경구가옥); 노후 → 기와 깨짐·이완(여러 건); 회첨 퇴적물·풀 → 기와 깨짐·와구토 탈락(청도 운강고택) |
| 지붕 마루·처마 흙 | 접착 불량·풍화 → 마루 기와·와구토·머거불 탈락; 풍화 → 처마·연등천장 앙토 탈락 |

| 흙벽 | 풍화 → 갈라짐 → 틈으로 빗물 침투 → 벽이 바깥으로 밀림(2건); 풍화 → 내벽 재사벽 탈락 |
| 판벽·인방·창호 | 뒤틀림 → 판재 벌어짐·빠짐, 인방 이탈; **기단 침하 → 판벽 기울어짐·틈**; 돌쩌귀 부식 → 판문 이탈 |
| 기둥 | **화방벽 갈라짐 → 누수 → 부식**; **빗물 침투·고막이벽 풍화 → 기둥 하단 부식**; **초석 침하 → 기둥 하부 부식**; 기둥 하부 부식 → 구조체 기울어짐; 뒤틀림 → 기둥 이완 |
| 마루 | 뒤틀림 → 청판·귀틀 벌어짐·흔들림; 노후 → 부식·변형; 우물마루 일부 유실 |
| 온돌 | 노후 → 구들장 꺼짐, 고래 내려앉음; 풍화 → 이맛돌 균열로 연기 샘, 연도 무너짐 |
| 기단·계단 | 침하 → 기단면 들뜸·갈라짐; 빗물 침투 → 기단면 들뜸; 풍화 → 기단석 빠짐; 충격 → 계단석 깨짐; 침하 → 초석이 바닥에 묻힘 |

**이 42건에서 읽히는 경향(비율·진행 순서는 확정하지 않음):** 원인 기재의 다수가 **물이 들어오는 지점**(깨진 기와·풀 자란 지붕, 갈라진 벽, 고막이·화방벽, 기단면)과 **지지점의 움직임**(기단·초석 침하)에서 시작해 특정 부재(서까래·평고대·기둥 하단·판벽)의 현상과 짝지어진다. 손상 위치가 무작위가 아니라는 근거로 쓰되, §5의 전파 순서는 이를 바탕으로 한 **빌더용 모델(설계 제안)**이다.

## 5. 제작 규칙 — 프로젝트 제안

### SURF-01 재료는 층으로 정의한다

지붕·벽·담·기단은 표면 텍스처 하나가 아니라 §3의 층을 가진 조립품이다. 상태(노후·손상·폐가)는 층을 하나씩 드러낸다: 앙토가 떨어지면 산자·서까래가, 정벌이 떨어지면 재벌과 외엮기가, 이엉이 삭으면 군새·알매흙이 보인다. 현대 신재(시멘트·철물)는 조선형 층 목록에 넣지 않는다. 층 두께·짚 길이 같은 수치는 시방서 기준값으로 표시하고 시험값으로 다룬다.

### SURF-02 형상 단계로 보여야 할 재료 특징

초가의 둥근 덩어리·잘린 처마 끝·모서리 방구매기·용마름·고사새끼 줄·까치구멍, 기와의 막새와 마루 쌓기, 막돌 담의 돌 크기 차이와 틈 흙은 **실루엣·그림자에 영향을 주므로 형상**으로 만든다(MAT-02 큰 형태). 초가 지붕을 하나의 늘인 반구로, 돌담을 돌 무늬 텍스처를 바른 상자로 만들지 않는다. 초가는 지역 차이(재료·결속)를 허용하는 프로필로 둔다(H-09).

### SURF-03 물 진입–손상 그래프

각 건물에 물이 들어올 수 있는 지점(지붕면·회첨·마루, 벽 하단 비들이침 띠, 고막이, 기단면, 초석 둘레)과 그 아래 부재를 연결한 그래프를 둔다. 노후·폐가 상태는 이 그래프를 따라 전파한다. 예: 회첨 퇴적물→기와 깨짐→누수→서까래 끝 부식→처마 처짐. 같은 그래프가 날씨 표현(젖음 띠·얼룩 위치)에도 쓰인다.

### SURF-04 폐가는 원인을 고른 상태 옵션

폐가는 BLD-06처럼 같은 건물 빌더의 상태다. 설계자는 원인 1–2개(지붕 누수, 기단 침하, 벽 갈라짐, 사람이 부재를 가져감 등)와 진행 단계를 고르고, 빌더는 SURF-03 그래프로 결과를 만든다.

- 지붕 누수 → 처마·서까래 처짐 → 일부 붕락 → 실내 바닥 노출·젖음 → 풀.
- 기단·초석 침하 → 기둥 기울어짐 → 판벽·창호 틈·이탈 → 벽 균열.
- 벽 갈라짐 → 빗물 → 벽 밀림·탈락 → 외엮기 노출.
- 온돌: 구들장 꺼짐·연도 무너짐은 바닥 꺼짐과 굴뚝 무너짐으로 이어짐.

잔해는 원래 층의 재료(흙 덩이, 삭은 짚, 기와 조각, 부러진 서까래)와 양이 대응해야 한다. 지붕 풀은 퇴적물이 쌓이는 회첨·골·마루에 먼저 둔다. 진행 속도·방치 연수는 근거가 없으므로 정하지 않는다. 사건 건물은 진입·조사 대상을 보존하고, 막힌 통로는 이동 데이터에 반영한다.

### SURF-05 생활 흔적은 원인 위치에만

그을음은 아궁이·부뚜막 입구 위, 굴뚝 둘레, 실내 화로 위처럼 연기가 나오는 곳에서 위로 번지게 둔다. 마모는 문턱·계단 디딤·골목 가운데에, 이끼·습한 얼룩은 그늘진 기단 주변·낙수선·물 쓰는 자리에 둔다. 집 전체를 고르게 더럽히지 않는다(LIV 사양과 같은 원칙).

### SURF-06 날씨는 노출과 재료로 반응

- 아래 분포·순서는 모두 **설계 가설**이며 바람·기온·지붕 조건에 따라 달라질 수 있다. 비교 사진으로 확인하기 전까지 강도뿐 아니라 패턴도 시험값이다.
- **비:** 처마 밖 지붕면, 벽 하단의 비들이침 띠, 처마 낙수선, 고막이·기단면이 먼저 젖는다. 처마 안쪽 벽 상부와 마루는 바람에 따라서만 젖는다. 흙길은 가장자리·패인 곳에 물이 고이고 가운데 밟힌 면은 다르게 젖는다.
- **눈:** 초가는 둥근 덩어리 위에 두껍게, 기와는 골을 따라, 막돌 담은 윗면과 돌 위에 쌓인다. 처마 밑·사람이 다니는 길 가운데는 얇거나 없다.
- **겨울 장기 상태:** 동파는 즉시 효과가 아니라 노후 상태의 원인 중 하나로만 쓴다.
- 반응 강도·젖음 비율·적설 두께는 **같은 재료의 건조/비/눈 비교 사진 확보 전까지 시험값**이다. 이번 조사에서 그런 비교 사진은 확보하지 못했다.

### SURF-07 숲은 관리 유형으로 만든다

HabitatPatch.management를 다음 중에서 고르고, 유형마다 구조를 다르게 둔다. 수종 목록 + 무작위 산포로 끝내지 않는다.

| 유형 | 근거 | 구조 규칙(제안) |
|---|---|---|
| 자연림·먼 산 숲 | (지역 자료 필요) | 여러 층과 쓰러진 나무 허용, 사면·수분에 따른 차이 |
| 금산·보호림 | NR06, HF02 | 큰 나무 유지, 가지 채취·몰래 벤 그루터기 같은 사람 흔적 허용, 접근길 존재 |
| 마을숲(비보·방풍·수해림) | NR08, NR09 | 금당실형 사례 프로필: 마을 경계·물가·바람 쪽에 **띠 모양**; 굽은 줄기와 높은 수관; 하층이 비어 사람이 지나가고 머묾; 밟힌 오솔길; 계절에 따라 바닥이 마른 풀↔풀밭 |
| 이용림(땔감·채취) | HF01(개간·화전 해설) | 키 작은 나무·맹아·그루터기, 땔감 운반길 |
| 경작지·마당·사당 주변 | LIV | 관리된 면, 경계 수목 |
| 방치지·폐가 둘레 | SURF-04 | 마당·지붕 풀, 관목 침입 |

마을숲의 형태는 사례 프로필로 고르며 모든 마을숲의 필수형이 아니다. 조성 이유는 기능(방풍·수해)과 문화적 설명(풍수)을 따로 기록하고, 게임에서 방재 성능을 계산하지 않는다. 현대 조사의 본수·수령·흉고는 쓰지 않는다.

### SURF-08 표면 입체감은 사광 장면으로 검사

시방서가 벽 상태를 비스듬한 빛으로 보는 것처럼, 재료 검사 장면에 **낮은 각도의 빛**을 포함해 흙벽 요철·막돌 담·이엉 결·기와 골이 평면 텍스처처럼 보이지 않는지 본다. 사진 수준 GI는 요구하지 않는다. 목표는 재질 구분·표면 입체감·날씨 반응·납득할 빛이다.

## 8. 남은 조사

- **날씨 비교:** 같은 초가·기와·흙벽·돌담의 건조/비/눈 사진. 국가유산청 공개 사진 목록에는 날씨 설명이 없어 찾지 못했다. 낙안 81장 중 미확보 61장 확인, 지자체 공식 사진, 국립민속박물관 자료를 다음 후보로 둔다.
- **폐가 실례:** 빈집·폐가의 부재별 붕괴 사진(현재 근거는 보수 사례의 원인 기재).
- **산림:** 조선 후기 산림 이용(송금·봉산·땔감) 연구 원문, 지역별 자연림 구성. 금당실 논문 전문.
- **재료:** 초가 재료(볏짚·억새·새)의 지역 분포 원 자료, 흙벽 단면 실측, 막돌 담 상부 처리 사진 대조.
