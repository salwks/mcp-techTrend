# 통합 제작 체계 — 유형별 제작 카드 — 검토본 v1.0

2026-10-24. 01–18의 조사·규칙을 **하나의 제작 체계**로 묶는다. 각 유형이 무엇을 만들고, 어떤 근거와 입력으로, 어떤 순서와 접합으로 생성되며, 무엇으로 검사하고 무엇을 보호하는지 한 곳에서 읽히게 하는 것이 목적이다. **이 문서는 구현 완료나 고증 완료 정본이 아니다.** 모든 V 항목은 문서상 인수 조건이며 게임에서 실행하지 않았다. 출처·문서 개수는 완료율이 아니다.

검토 기록: 17–19 초안을 외부 모델(Codex, 읽기 전용)에 교차 검토시켰고, 지적 10건(출처 ID 불일치, 도면 관찰과 용도 해석 혼재, 사례 형태의 일반화, 카드의 접합·보호 누락 등)을 반영했다. 반영 내용은 설계 판단이며 새 사실 근거가 아니다.

## 1. 공통 체계

### 1.1 생성 의존 관계

```
지형(능선망·유역망·암체) ─┬─ 물(수계 종횡단·상태)
                          └─ 토양·지표
        │  (역방향: 둑·논·길·집터가 변경 지형으로 기록)
        ▼
이동과 생업(노선 목적·고개·통행 수단, 경작·수리·숲 관리)
        ▼
정착 기능(유형·프로그램·고정 위치)
        ▼
길망·필지·기능 영역·마당
        ▼
건물(기둥 기준선→기능 면→바닥/기단→지붕 지지) · 경계(양쪽 영역·이유→구현 종류→단면→접합) · 문 · 배수
        ▼
표면(재료 층)·생활 흔적·식생 관리 상태·노후/폐가 상태·날씨 반응
        ▼
검사(구조·통행·운반·시각·성능·근거) → 내보내기
```

이는 생성 순서이지 역사 서술이 아니다. 하위 단계가 실패하면 상위로 돌아가 조정하며, 건물 일괄 축소·지형 삭제·고정 건물 이동으로 조용히 성공 처리하지 않는다(TOOL-03).

### 1.3 공통 규칙과 지역 조사의 분리

공통 규칙은 지금 작성할 수 있다. **지역별 값**(암종, 하천 단면, 문 개수·방위, 칸 치수, 초가 재료, 숲 구성)은 지역 프로필에 들어갈 조사 항목이며, 값이 없으면 빌더는 ‘가설’로 미리보기만 허용한다. 모든 수치를 알아야 원칙을 쓸 수 있다는 이유로 공통 규칙을 미루지 않는다.

## 2. 유형별 제작 카드

각 카드의 항목: **만드는 것** / **근거** / **입력** / **순서** / **변형 범위** / **접합** / **사람·물건** / **검사** / **보호** / **모르는 것**. 카드에 적지 않은 항목은 §1.2 공통 규칙과 TOOL-04(보호: 사건 ID·잠근 형상 유지)를 상속한다. 카드의 사례 근거는 해당 지역·자료의 **선택 가능한 프로필**이며 유형 전체의 필수 형태가 아니다.

### C01 산지·고개·산길

- **만드는 것:** 실제로 오르고 넘는 산, 고개를 넘는 노선, 산중 사건 부지.
- **근거:** NR01(기반암별 기복, 12지역 표본), NR03(문경새재 현황), GEO-01–03.
- **입력:** 능선망·안부, 유역, 암체·노출, 노선 양끝 목적지, 통행 수단 프로필(도보/짐말/수레).
- **순서:** 능선·유역 → 안부 선택 → 노선 종단(상승·휴식) → 길 단면(절취면·통행면·지지부·배수) → 물길 횡단 방식 → 사건 부지(산록 완경사·지형 단 우선).
- **변형 범위:** 같은 암종의 암봉·흙 사면·구릉; 갈지자길은 필요할 때만.
- **접합:** 길–사면(지지·절취), 길–물(도섭·징검돌·교량·암거), 부지–길(진입·이탈).
- **사람·물건:** 짐말·수레 통과 여부를 구간별 출력; 계단 구간 표시.
- **검사:** V01, V63, V64.
- **보호:** 사건 부지·고개 위치·노선 ID.
- **모르는 것:** 통행 수단별 경사·폭 허용값(시험값), 옛길 노면·폭, 지역 암종(G01 미대조).

### C02 계곡·하천·나루·다리

- **만드는 것:** 하상·수면·흐름이 일치하는 물길과 물을 건너는 자리.
- **근거:** NR02(직탕폭포 개념 단면·사진), HG01·W01·W02, GEO-05·06.
- **입력:** 수계 그래프, 구간별 종단·횡단·평면, 하상 혼합, 갈수/평수/증수 상태, 횡단 시설 선택.
- **순서:** 유역 → 구간 종단 → 횡단(수중·노출 하상·둑) → 평면(합류·굽이) → 하상 재질 → 흐름·거품 원인 구간 → 횡단 시설 → 상태별 재검사.
- **변형 범위:** 암반 계곡↔충적하천은 다른 규칙 묶음.
- **접합:** 물–둑·담(수구), 물–길(횡단), 물–작업 자리(빨래터).
- **사람·물건:** 상태별 나루·징검돌 접근, 교량 여유고.
- **검사:** V03, V04, V65–V67, V69.
- **보호:** 사건용 나루·다리 위치.
- **모르는 것:** 실제 지역 하천 단면·수위 변동, 충적하천·갯벌 사진.

### C03 암반·절벽·너덜·자갈

- **만드는 것:** 연속 암체 위에 놓인 분리된 돌들.
- **근거:** NR02, NR05(본문), GEO-04.
- **입력:** 암체 영역·암종 후보·절리 방향·노출, 공급원과 쌓임 방향.
- **순서:** 연속 암체 → 절벽·노출면 → 붕락물(공급원→쌓임) → 하상 전석·자갈 → 사람이 쓰는 돌(담·마당).
- **변형 범위:** 암종별 참조 묶음(띠·입자·층·공극).
- **접합:** 밑면–흙·뿌리, 절벽 하단–암설·물.
- **사람·물건:** 바위 사이 길은 통행면을 따로 가짐.
- **검사:** V02, V66.
- **보호:** 사건 바위·동굴 입구.
- **모르는 것:** 암종별 근접 사진, 우음도 상세 사진.

### C04 토양·지표

- **만드는 것:** 원인을 가진 흙·자갈·낙엽·풀의 배분.
- **근거:** NR04, S01, GEO-07.
- **입력:** 모재·토심/입도·배수·현재 이용.
- **순서:** 바탕 재료 → 이용 상태(밟힘·경작·침식) → 경계 블렌딩(원인별 폭).
- **검사:** V05.
- **모르는 것:** 조선 시기 지역 토지 이용.

### C05 숲·마을숲·식생

- **만드는 것:** 관리 유형별 숲.
- **근거:** NR06(금산 기록), NR08(금당실 송림 설명·사진), NR09(만송정 설명), HF01·HF02, SURF-07.
- **입력:** 관리 유형, 근거 프로필(예: 금당실형 띠숲), 수종 후보(미확정은 ‘임시’ 표시), 토양·수분, 마을·물·바람과의 관계.
- **순서:** 유형 결정 → 위치(금당실형 프로필이면 마을 경계·물가·바람 쪽 띠) → 큰 나무 → 하층·초본 → 사람 흔적(오솔길·그루터기·가지 채취) → 계절 상태.
- **변형 범위:** 하층 밀도·수형·흔적이 유형마다 다름.
- **접합:** 숲–길, 숲–마을 경계, 숲–물가.
- **사람·물건:** 마을숲 아래를 지나고 머묾; 이용림의 땔감 운반길.
- **검사:** V19, V77.
- **보호:** 사건용 큰 나무·당산.
- **모르는 것:** 지역 자연림 구성, 조선 후기 산림 이용 연구 원문, 금당실 논문 전문.

### C06 농경지·수리

- **만드는 것:** 논·밭·텃밭과 물의 저장·취수·분배·퇴수.
- **근거:** HR01–03, H-01–03, NAT-07.
- **입력:** 수원, 경사, 경작 유형, 접근길.
- **순서:** 수원(제언·천방·보) → 분배 수로 → 논둑·물꼬 → 퇴수 → 작업길.
- **접합:** 논–길(논둑·퇴수 횡단), 수로–골목(VIL-05).
- **검사:** BLD-07 표, V19.
- **모르는 것:** 지역별 수리 시설 형태·규모 자료.

### C07 정착 유형(읍성 도시·중소 읍치·농촌 마을·나루/길목·산중)

- **만드는 것:** 규모가 아니라 기능·지형·교통으로 구분된 정착.
- **근거:** BLD-01, H01·VR01·VR03, PS02(제주 읍성), PS03(별방진).
- **입력:** 행정 기능, 성곽 유무, 교통 결절, 생업, 지형 제약, 고정 시설 근거.
- **순서:** 성벽·수구 또는 마을 경계 → 간선·빈터 → 고정 공공 시설 → 경작·과원 구획 → 주거 필지.
- **변형 범위:** 문 개수·방위·성곽 윤곽은 자료로 결정; 성안 빈 땅·과원·언덕·물길 포함(PUB-04).
- **접합:** 성벽–물길(수구), 성문–간선, 정착–숲·농경지.
- **사람·물건:** 장날·조련 등 행사 점유는 상태(PUB-05).
- **검사:** V06(기능·동선 차이), V69(수구·물길), V70(빈터 행사 상태). 성안 과원·언덕·빈 땅 보존은 V06의 판정 항목으로 함께 본다.
- **보호:** 관아·성문·사건 위치.
- **모르는 것:** 육지 읍성 기록화·고지도 판독(남원 등은 적용 단계), 도시 밀도 참고 장면.

### C08 길망·필지·골목

- **만드는 것:** 목적지와 지형에서 나온 길, 출입 가능한 필지.
- **근거:** VR01(하회·외암 연구), VR02·VR03, VIL-01–07, BLD-02.
- **입력:** 목적지, 지형, 기존 필지, 배수, 이용 관계.
- **순서:** 간선 → 생활 골목 → 필지 출입 → 문 앞 전환 공간 → 잔여지 분류(텃밭·공유지·수로·비건축).
- **변형 범위:** 직선도 정상; 곡률에는 이유 태그.
- **접합:** 길–필지, 길–수로, 길–담.
- **검사:** V46–V50, V40–V43.
- **모르는 것:** 일반 민가 골목의 실측 종횡단.

### C09 경계·담·문·수구

- **만드는 것:** 양쪽 영역과 이유에서 정해지는 경계와 그 물리 구현.
- **근거:** VR08(시방서 담장공사·입면 3건), VR07, VR12, PS02 페이지의 목관아 해설(1435년 재건 시 화재 이격·담장 서술), JOIN-01–06.
- **입력:** 양쪽 영역, 경계 이유(사유/공공·시선·보안·지지·배수·화재 이격·의례), 구현 종류(독립 담/건물 외벽/문간채/옹벽/열린 경계), 단면(양면 지면·두께·기초·속 구성·상부).
- **순서:** 경계 원본 → 구현 종류 → 단면 → 접합(연속·모서리·T자·건물·대문·수구) → 상부·양끝.
- **변형 범위:** 돌각담·토석담·사괴석담 등 공법별; 모서리는 같은 공법·재료로.
- **접합:** 담–문(개폐 면), 담–옹벽(양쪽 지면), 담–물(수구), 담–건물(외벽이 경계일 때 중복 금지).
- **사람·물건:** 반입문 폭, 수구와 사람 문 분리.
- **검사:** V07, V08, V51–V53, V41.
- **보호:** 잠근 대문과 주변 담 구간.
- **모르는 것:** 개별 담의 기초·두께 실측 단면.

### C10 소형 민가

- **만드는 것:** 기능 면과 구조 칸이 따로 노는 작은 집과 마당·부속채.
- **근거:** VR12(낙안 들마루집 기록화보고서 평면·단면·사진), VR07, HOUSE-01–06.
- **입력:** 필요한 방·조리/난방·저장·작업·가축, 기둥 기준점, 지면 기준.
- **순서:** 기둥 기준선 → 기능 면 → 바닥·기단·마루(끊김 허용) → 아궁이 작업 면 → 지붕 지지 → 부속채(경계 겸용 가능) → 마당 작업 면.
