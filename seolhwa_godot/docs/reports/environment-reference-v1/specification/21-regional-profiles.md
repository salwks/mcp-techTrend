# 지역 프로필 — 게임 8개 권역 초안과 차단 조사 현황 — 검토본 v1.0

2026-10-25. 소유자가 구현 착수를 승인했으므로, 공통 규칙(19)으로 구현을 진행하는 동안 **지역별 값**을 이 문서와 `regions/` 하위 문서로 채운다. 조사·문서만 했다. 게임 코드·`region_data`·저장은 바꾸지 않았다. 권역별 `region.json`은 읽기만 했다.

**지위.** 권역 프로필은 모두 **초안**이다. 근거 등급이 붙지 않은 값, C·U 값은 빌더에서 `proposed` 또는 `unknown`으로 들어가야 한다. 남원 개별 위치는 여기서 정하지 않았다(WP14 보류 유지).

## 1. 작성 방법과 신뢰도

- 8개 권역을 세 갈래로 나눠 병렬 조사했다(제주·남원운봉 / 경주·강릉 / 함흥·황주·평양·한양). 각 조사는 같은 브리프·등급 규칙을 따랐다.
- **등급:** A=원본 사진·도면·고지도 직접 판독, B=공식 기관·전문 백과 본문 확인, C=검색 발췌·요약만, U=미확인.
- **통합자 검토:** 권역 문서의 형식, 근거 ID 연결, 등급 표기, 차단 항목 판정은 확인했다. 개별 B·A 주장은 표본 3건(함흥 1666 한전·수전 결수, 평양 보통문=중성 서문, 남원읍성 형태 서술)만 저장된 원자료와 대조했고 모두 일치했다. 따라서 권역 문서의 모든 문장을 통합자가 원문과 다시 맞춰 본 것은 아니다. 구현에 값을 쓰기 전에 해당 근거 ID의 원자료를 한 번 더 열어 볼 것을 권한다.

## 2. RegionProfile 필드 형식

각 권역 문서 §8의 표는 다음 필드 묶음을 쓴다. 값마다 `등급`과 `status(confirmed/proposed/unknown)`를 붙인다.

|---|---|---|
| 지형·물 | basin/terrain 유형, rock_candidates, river.form·sections·flood_state, lagoon·oreum·gotjawal | C01–C04 |
| 정착 | eupseong.plan·gates·chi·moat·wells·interior, gaeksa, gwana.layout, hyanggyo 유형 | C07, C14, C15, C17 |
| 집 | house.base_type·compound·heating·kitchen_side, bay_front_mm, eave_projection_mm, podium_height_mm, roof 종류·비율 | C10, C11, C18 |
| 경계 | boundary 종류·쌓기·section, gate·entrance(올레 등) | C09 |
| 숲·생업 | forest 관리, farm_mix, economy 공간(포구·장시·목장·어로) | C05, C06, C12 |
| 기후 | 기온·강수·바람·눈(근대 관측이면 표시), 날씨에 대응한 형태 | C18 |

- **NAT-07·SURF-07 보강:** 도성 둘레 산의 송금 위반과 산허리 개간은 하천 토사·준설과 연결된 기록이 있다(FU02). 한양 개천은 "하상에 모래흙이 쌓이는 상태"를 WaterReach 상태로 둘 근거가 생겼다. 수치는 U.
- **보호림 표현:** 금지 구역이어도 헐벗은 곳·베어 둔 나무·벌목 중인 자리를 허용한다(FU01, NR06과 같은 방향).
- **폐가 판정:** 18번 손상 그래프의 상태 판정에 빈집 조사 항목(기울어짐·접합 파손·용마루 처짐 비율·누수·균열 방향)을 검사 항목 이름으로 차용할 수 있다. 수치 기준(2mm·1/4)은 현대 조사 기준이며 게임 시험값이다.
- **사찰 서비스 영역:** 현행 대찰의 공양간 건물은 근현대 신축이 많을 수 있으므로, 현황 사진만으로 조선 공양간 형태를 정하지 않는다. 위치 관계(후원 영역, 요사와 붙음)만 관찰 범위에서 쓴다.
