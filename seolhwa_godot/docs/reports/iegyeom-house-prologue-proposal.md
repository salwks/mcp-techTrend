### 2-5. 추천 — **SA (−3192, 700)** · 다음 SB

SA를 추천하는 까닭:
- 요구한 환경을 실제 데이터로 거의 다 갖췄다. 낮은 솔숲 언덕 자락, 개울(주촌천), 밭과 흙마당, 남원으로 이어진 실제 길(구례 길), 조용함(80m 안 집 0)을 새로 만들지 않아도 된다.
- 고르기·새 길이 가장 적다. 터 높이차 1.4m라 지금 flatten으로 되고, 새 오솔길은 20m다.
- 걷기 2분 14초로 2~3분 안이고, 지금(2분 6초)보다 8초만 길다. 첫 15분을 늘이지 않는다.
- **드러남(A 공간)**: 나루에서 남쪽으로 솔숲 골짜기를 지나 z≈650에서 숲이 열리면 솔숲 언덕 아래 밭 가운데 초가가 보인다(`13_SA_wide_road`). 돌아갈 때도 같다.
- 첫15 '산 아래 주막' 말과 지리가 맞는다(솔숲 산자락 아래 나루 주막).

SB를 다음으로 두는 까닭:
- 더 외지고 아름답다(솔숲 속 언덕 턱).
- 하지만 고르기 2.6m와 오르막 40m가 필요하고, 물이 멀어 샘을 더해야 한다. 걷기가 3분 끝(179초)이다.
- 숲속이라 카메라 앞 나무 가림(반투명 디더)이 많다.

SC는 개울이 가장 가깝지만 길가 띠(폭 20m)라 지나는 사람과 너무 붙는다.

W는 남원 거리(장터길)를 지나는 장점이 있지만, 소나무·언덕이 없고, 3분을 넘고, 오솔길이 막혀 있다.

**흐름 차이(결정 필요)**:
- 남쪽 후보(SA·SB·SC)는 주막이 거처와 읍성 사이(나루)에 있다. 그래서 첫 15분 9번 「남원 거리」가 '나루 너머 남원이 보이는 길'로 바뀐다. 거리 자체를 걸어 지나지 않는다. 장터·성문 거리는 주막 뒤에 남는다.
- 남원 거리를 꼭 지나야 하면 W(고칠 것 많음)뿐이다.

## 3. 프롤로그 가능성

### 3-1. 쓸 수 있는 동작(그림 클립)

| 인물 | 있는 클립(시점 front·side·back) |
|---|---|
| 이겸 `yigyeom`(`frames_story_hamhung.json` + `frames_pose.json`) | idle · walk · **talk** · **sit** · **write**(앉아 쓰기) · burn · **read**(서서 종이를 들고 읽기) · bow · kneel |
| 플레이어 `player`(`frames.json`·`frames_pose.json`·`frames_boat.json`·skills) | idle · idle:a · walk · run · 전투 묶음 · sit · **bow** · **kneel** · throw(1회 0.45초) · quick_throw:a · shove:a |

- 빌더 동작(sit_seat·sit_talk·sit_work·squat·carry 등)은 고을 사람 묶음에만 있다. 이겸·플레이어에는 없다.
- 기억해 둔 사용자 결정(주요 인물은 사용자가 따로 만든다 — 빌더 4단계 대기)에 따라 **새로 굽지 않는다.**

| 필요한 동작 | 쓸 클립 | 빈 것 · 가장 싼 메움 |
|---|---|---|
| 이겸 기록 살핌 | 평상 위 `sit` → `write`(앉아 손이 움직임) | 없음 |
| 제자 젖은 종이 말림 | 멍석 옆 `kneel`(side) | 손으로 펴는 동작은 없다 → `brush_rustle`·`page_turn` 소리 + 멍석 위 종이 장수를 0.8초마다 하나씩 늘리는 소품 바꿔치기 |
| 이겸 기록을 들어 올림 | `sit` → 일어나 `read`(서서 종이를 든다 — 그대로 맞음) | 일어나는 동작 없음 → 클립 바꾸며 평상 앞 0.6m로 자리 옮김(같은 프레임, 거리 14m라 튐이 작다) |
| 제자 고개 듦 | `kneel` → `idle`(이겸 쪽 side) | 고개만 드는 그림은 없다 → 자세 바꿈 + 얼굴 방향 바꿈 |
| 손의 먹을 옷자락으로 닦음 | 이겸 2m `walk` → `bow`(side, 앞으로 숙임) 1.5초, 제자 `idle` 마주봄 | 닦는 손짓 없음 → bow 숙임 + 천 스치는 소리(`flour_rustle` 재사용, 낮게) + 카메라 가깝게(거리 14→9). S1.0 '붓을 건네려다'는 bow 전에 `read` 자세로 0.4초(종이·붓을 든 손)로 대신 |
| 이겸 제 옷을 내려다봄(멈칫) | `idle` front + 0.8초 정적 | 내려다보는 그림 없음 → 말 사이를 비우고, 얼굴을 카메라 쪽(down)으로 돌려 멈춤 |
| 제자 작게 웃음 | `idle:a`(다른 대기) 1회 | 웃음 소리 없음 → **새 임시 소리 `laugh_soft`**(`tools/audio/make_placeholders.py` 방식 — 지금 `laugh_far`는 먼 거리 웃음). 대사·자막 없이 |
| 기록책을 책상에 둠 | 평상 서안 앞으로 `walk` → `bow` 1.0초 | 내려놓는 손짓 없음 → bow 끝에 서안 위 덮인 책 소품(`story/clue ledger`)이 나타남 + `journal_stamp`를 아주 작게 또는 `page_turn` |
| 새·물·바람 | `wind`(있음) | 새소리·개울 소리 없음 → 임시 소리 `birds_day`·`stream_small` 둘(같은 임시 합성 방식). 없으면 바람만 |

마당 소품은 기존 키트로 된다.
- 평상: `village/props pyeongsang`
- 서안(기록책·벼루·먹·붓 포함): `story/clue seoan`
- 장작: `village/firewood`
- 물독: `village/props dok`(또는 `yard_props jars` — 물동이 포함)
- 멍석: `props meongseok`
- 텃밭: `village/teotbat small`
- 사립·토담: `saripmun`·`todam`
- 헛간(딸린 칸): `village/heotgan`
- 샘: `village/well`

**새로 필요한 것은 '말리는 종이' 소품 하나뿐이다**: 멍석 위 흰 종이 1~6장 `story/clue paper_dry`(소품 예산 ≤ 800).

### 3-2. 읽기 시간(실제 대사 속도)

- 게임의 대화 상자는 글자를 45자/초로 찍는다.
- 화면 검토 자동 넘김(`auto_real`)은 `1.0 + 0.06×글자수`초다. 9음절/초로 빨라서 감정 장면에는 짧다.
- 컷 자막의 기존 값: OP00 VO 3.0초(≈7음절/초), P00B 3.2초(≈9음절/초).
- 제안: **컷 자막 머묾 = 0.5초 + 공백 뺀 음절 ÷ 7**(OP00과 같은 빠르기). 대사는 컷 자막(`ui.caption`, 화자 이름 붙임)으로 시간에 따라 흐른다. 대화 상자(E 넘김)는 쓰지 않는다 — Space·Enter가 건너뛰기와 겹치기 때문이다.

배치:
- 집 남향. 마당 B 10×6(L z +3.3…+9.3).
- 평상 L(2.4, 5.8)과 그 위 서안. 이겸은 평상에 앉아 왼쪽(left)을 본다.
- 멍석 L(−1.0, 6.4). 제자(플레이어)는 L(−2.4, 6.6)에서 무릎 꿇고 오른쪽(right)을 본다. 둘 사이 4.8m.

### 3-4. 건너뛰기

- 지금 OP00과 같은 계약이다. `onboard.skippable` + `_sw()`에서 Esc·Space·Enter를 누르면 바로 건너뛴다.
  - 새 게임을 누른 Enter가 넘어오는 것을 막으려고 처음 0.5초는 건너뛰기를 받지 않는다(제안 — 시험으로 확인).
- 건너뛰면 0.08초 암전 → 끝 상태를 한 번에 만든다.
  - 이겸 despawn, 소품 '지금' 상태, 플레이어 `home_start`·실내, `camera(null)`, 자막 지움
  - 0.25초 페이드 뒤 조작
  - 깃발: `PROLOGUE_SEEN`(본 것으로 침 — 다시 돌지 않음)·`PROLOGUE_SKIPPED`·`OP00_DONE`
  - 체크포인트·목표 문구는 끝까지 본 것과 같다
- 건너뛰어도 잃는 단서·안내는 없다. 프롤로그에는 조사·기록 항목이 없기 때문이다.
