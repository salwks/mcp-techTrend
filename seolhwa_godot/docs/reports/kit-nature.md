담당 경로: `kit/nature/**`, `shots/kit/nature/**` (이 보고서 외 다른 파일은 고치지 않음, `class_name`·`godot --import`·커밋 없음)

### 흩뿌리기 `kit/nature/scatter.gd` (계약서 §6 시그니처 그대로)
```gdscript
const Scatter := preload("res://kit/nature/scatter.gd")
Scatter.warm(lod)  # 권장: 시작 때 메인 스레드에서 한 번(모델 메시·Kit 재질 생성, ≈0.3s)
var res := Scatter.scatter(Rect2(tx*256, tz*256, 256, 256), height_at, landuse_at, seed, lod)
# res.nodes: MultiMeshInstance3D(+드문 것을 합친 MeshInstance3D "merged_cN") — 월드 좌표, 씬 트리 접근 없음
# res.colliders: [{type:"circle", x, z, r}] 월드 / res.stats: 시간·개수(디버그용 추가 키)
```
- 4m 격자로 토지이용·높이(8m 간격 표본 + 보간)를 묻고, 길·물 거리(체스판 2-pass), 경사, 해발(=y/0.3+60)로 종류·밀도를 정한다.
  - 0 숲: 나무 0.62/칸(16m²)(급경사 0.32) + 덤불·진달래(900m 위는 철쭉)·숲 바닥 덮개·바위·드문 고사목
  - 1 풀밭: 드문 나무 0.03, 덤불, 풀밭 덮개 / 850m 위는 철쭉 군락 + 억새·원추리 덮개(운봉 바래봉·세걸산 철쭉 고원)
  - 2 논: 칸마다 벼 4×4 포기(1m 간격 → 줄이 칸 넘어 이어짐), 논 가장자리 칸은 네 귀퉁이가 논일 때만
  - 3 밭: 고랑 작물 한두 줄(약 55%·35%), 작물 종류는 잡음으로 밭뙈기별, 고랑 방향은 타일마다
  - 5 물: 기슭 칸에 여울 돌, 산골(해발 250m 위)엔 너럭바위
  - 6 마을 터: 가장자리 칸에만 감나무·활엽수·덤불, 타일마다 최대 한 그루 느티나무(길 가까운 어귀). 집 자리는 비움
  - 7 바위·벼랑: 급경사(tan>0.7)에 벼랑 조각(정면을 내리막으로), 큰 바위·바위·마른 덮개, 바위 소나무(1100m 위 구상나무)·고사목
  - 8 모래톱: 자갈 덮개·여울 돌·물가 갈대, 아주 드문 버드나무
  - 9 대숲: 대나무 무리 0.55/칸
  - 물가 1~2칸(땅): 들판이면 갈대 덮개·버드나무, 산골이면 너럭바위·큰 바위·여울 돌
  - 마을 북쪽 1~3칸 숲·풀밭: 뒤란 대밭
- 수종(해발별, `forest_mix`): <350m 소나무 55·곧은소나무 10·상수리 35 → 350~800m 신갈 비중 증가 → 800~1300m 신갈 중심 + 구상나무 등장 + 고사목 → 1300m 위 구상나무 50·신갈 30·고사목 15·그루터기 5.
- 길(4) 비움: 길 칸·길 옆 칸은 점마다 토지이용을 다시 물어 줄기 3m(덤불·바위 1.4m, 풀 0.7m) 안에 길이 있으면 버림.
- §32 시각 간격: 길이 북쪽(카메라 반대편) 12m 안에 있는 칸에는 큰 나무를 두지 않는다(카메라와 길 사이에서 가리므로). 남쪽에 길이 있는 나무(뒤쪽)는 둔다.
- 묶기: 128m 묶음(타일당 2×2)마다 종류별 MultiMesh 하나. 변형은 **묶음마다 하나**(이웃 묶음은 다른 변형) — 그리기 호출을 종류 수로 묶는다. 묶음 안에서 많은 순 8종은 MultiMesh, 그 밖에 개수 ≤16·꼭짓점 ≤12,000인 드문 것은 정적 메시 하나로 합친다.
- 그림자: 나무·덤불·큰 바위·벼랑만. 작은 바위·진달래·풀·벼·작물은 끔.
- 결정적: 타일 좌표와 seed로 만든 `RandomNumberGenerator`(엔진 PCG32). 같은 입력 두 번 → 버퍼까지 같음(미리보기에서 확인 `deterministic=true`).
- LOD 1: 나무는 LOD1 메시, 풀·작은 돌·작물·자갈·여울 돌 덮개는 뺌.

## 2. 성능 (Apple M1, Godot 4.7.1 Mobile, `scatter_preview.gd` 가짜 함수 — GDScript bilinear 높이·토지이용)
| 항목 | 값 |
|---|---|
| 타일 하나 생성(데운 캐시) | **26~30ms** (들·강·숲 혼합 타일 26.6~29ms, 산 숲 타일 27.5~29.9ms; 한 번 37ms 튐) / LOD1 21~24ms |
| 내역 | 격자 표본 ≈3ms(콜러블 호출) + 거리·보간 ≈3ms + 배치 15~20ms + 묶기 ≈5ms |
| 모델 캐시 데우기(첫 타일 전 한 번) | 230~520ms → `warm()`을 시작할 때 부를 것 |
| 타일당 | MultiMesh 등 40~47노드(4묶음 합), 인스턴스 ≈3,300, 충돌 원 ≈1,500 |
| 화면 안 식생 그리기 호출(게임 카메라 dist 23~30, pitch 35) | 본 패스 **5~23** (네 묶음 모서리가 겹치는 최악 23). 미리보기의 4분할 그림자 패스까지 합치면 17~42 |
| 삼각형 | 혼합 타일 ≈1.1M(LOD0)/0.25M(LOD1) 인스턴스 합. 화면에는 1~2 묶음만 걸림 |

- 측정 방법: `SCATTER …` 줄(시간·결정성·`RENDERING_INFO_TOTAL_DRAW_CALLS_IN_FRAME`을 식생 보임/숨김/그림자 끔으로 비교).
- 실제 지형 엔진의 `height_at`/`landuse_at`가 이보다 느리면(예: 사전 조회 + 보간이 2µs 이상) 그만큼 늘어난다(격자 ≈5,000 + 인스턴스 ≈3,500 호출).

## 4. 고증 근거와 가설
- 지리산 서부 식생대(일반적 서술): 저지대 소나무(적송)·상수리·굴참나무 숲, 해발 700~800m 위 신갈나무 우세, 1,000m 넘는 능선에 구상나무(반야봉·노고단·만복대 일대)와 하얗게 마른 구상나무 고사목, 능선 초지에 억새·원추리, 운봉 바래봉(1,165m)·세걸산 일대의 산철쭉 군락. 수치 경계(350/800/1300m)는 **가설** — 1870년 무렵 실제 분포가 아니라 오늘날 식생대를 옮긴 것.
- **가설**: 조선 후기 마을 가까운 산은 땔감·소나무 금양으로 지금보다 숲이 성기고 소나무 비중이 높았을 것 → 저지대 소나무 비중을 높게 잡음. 민둥산 정도까지는 반영하지 않음.
- **가설**: 남원 일대 마을 뒤 대밭, 마을 어귀 느티나무 정자나무, 집 가까이 감나무 — 남부 지방 마을 경관의 일반적 모습으로 둠.
- 밭 작물 콩·조·보리(1870년 남원 들판 밭작물, 목화·수수 등은 넣지 않음). 계절은 정해지지 않아 진달래·철쭉 꽃을 켜 둠(`bloom` 매개변수로 끌 수 있음).

## 5. 총괄에게 요청할 것
1. **스레드 안전**: `Kit.material()`/`Kit.texture()`가 정적 사전을 잠금 없이 채운다. 작업 스레드에서 `scatter()`를 부르기 전에 메인 스레드에서 `Scatter.warm(0)`·`warm(1)`을 한 번 불러 주기(지형 엔진에도 전달 필요). 가능하면 Kit 쪽에 Mutex 추가.
2. **가림 처리**: MultiMesh 나무는 개별 반투명 처리가 안 된다. 코어의 occluder 방식 대신 셰이더 전역 uniform(플레이어 화면 위치 둘레 디더/투명)으로 처리해 주길 요청. 그 전까지 §32 규칙(길 남쪽 12m 큰 나무 금지)으로 길 위 가림을 줄였다.
3. **`Kit.Batch`에 `mesh_only`/법선 방식 지정**: 지금은 `build()`와 `mesh()`가 각자 메시를 만든다(우리는 `_common.result`로 한 번만 만듦). 또 벼랑처럼 rock 붓결 + 각진 법선을 원할 때 `add()` 뒤 `face_normals()`를 다시 부르는 우회를 썼다 — `add(key, g, outline, faceted)` 옵션이 있으면 깔끔.
4. 지형 엔진(terrain-engine)에: `landuse_at`·`height_at`는 사전 계산 배열 조회로 1µs 안팎이면 30ms 예산이 맞는다. 4m보다 고운 길 폭(2m 이하 산길)은 칸 판정에서 빠질 수 있어 점 검사로만 걸러진다.
5. 그림자: 미리보기 기본(4분할, 120m)에서는 그림자 패스 그리기 호출이 본 패스의 약 2배. 게임의 그림자 거리·분할을 줄이면 화면 안 40 안쪽 유지가 쉽다.

## 6. 남은 일·한계
- 대숲 잎은 세로 깃털 덩이로 단순화(가까이서는 옥수수 이삭처럼 보일 수 있음). 강가 버드나무·느티나무는 드물어 정적 메시로 합쳐진다.
- 타일 경계: 각 타일은 자기 사각형 안에만 놓는다(지터가 밖으로 나가면 버림). 경계 너머 길·물은 3칸(12m) 덧대기로 판정.
- 생성 시간이 예산(30ms) 경계에 있다. 더 줄이려면 덮개 밀도를 낮추거나 격자를 8m로.
