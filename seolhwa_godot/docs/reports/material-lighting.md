# 재질·빛 사실화(material-lighting) — 보고

- 브랜치 `claude/material-lighting`(시작 `origin/claude/youthful-gauss-d0fxzv` 9550854). Godot 4.7.1, **Mobile 렌더러 그대로**, M1 Mac.
- 요청: "재질과 라이팅을 사실적으로" → 중간 조정 셋(① 사진 같은 실시간 GI는 원하지 않음 — Forward+/SDFGI/SSIL 시험 중단, ② 빛은 Mobile에서 할 수 있는 만큼 사실적으로, ③ 텍스처에 볼륨: 법선·높이·오목·시차 매핑, 비·눈이 높이를 따른다).

- 모든 실행은 `--` 뒤 게임 인자 + `--savefile=user://matlight_test.json`(모래상자) + `--kitcache=user://matlight_kit_cache/`. 실제 저장·백업은 건드리지 않았다. 저장 코드는 고치지 않았다(save_guard_e2e 해당 없음).

## 2. 바꾼 것

### 2-1 텍스처: 절차 생성 PBR 18층 (`assets/pbr/`)
- 외부 원본을 내려받지 않았다. GPU 셰이더(`tools/matlight/pbr_bake.gdshader`)로 이음매 없이 굽는다 → `tools/matlight/bake_pbr.gd`(창 필요, 9초, 결정적). 출처·허가: `assets/pbr/manifest.json`(프로젝트 자체 생성, CC0).
- 층: 회벽 · 흙벽(짚 여물·갈라짐·잔돌) · 이엉(짚 올·네 켜 겹침) · 기와(구운 흙 잔결·패임·이끼) · 나무(결·옹이·갈라짐, 비바람 회색) · 마루(널 이음·반들) · 한지(닥 섬유) · 돌(막돌·깊은 줄눈) · 바위 · 박석 · 흙 마당 · 다진 길 · 풀 · 장판 · 껍질 · 잎 · 천 · 눈.
- 층마다 512² 두 장: A = 바탕색 배율 + 높이, B = 거칠기 · 법선(x는 알파) · 오목(AO, 높이에서 굽기). 밉맵 + BC3 → **VRAM 12.0MB**, 디스크 7.3MB.
- 미리보기: `shots/material_lighting/pbr_layers.jpg`(위 3줄 A, 아래 3줄 B).

### 2-2 재질 고르기 — 키트 기하·UV·캐시 키를 건드리지 않음
- 셰이더가 아틀라스 칸(64px 격자)으로 재질 번호를 고른다: 전역 텍스처 `pbr_ids`(16×8). 칸 이름 → 재질 표는 `scripts/render/pbr.gd ATLAS_MAT`, 칸 자리는 `assets/kit/atlas.json`에서 읽는다.
  - 건물 빌더 칸(`b_ddi·b_yong·b_a·b_gyo·b_kkot` 창호 → 한지, `b_maru` 마루, `b_jangpan` 장판, `b_panbyeok·b_dancheong·b_soffit` 나무, `b_yongmareum` 이엉, `b_giwa` 기와)도 표에 있다. 그 갈래 `atlas.json`이 들어오면 그 자리가 이긴다. 합칠 때 고칠 파일 없음(id 표를 찍어 칸 자리 확인함 — 실제 합친 화면은 아직 못 봄).
- 디테일 좌표 = 아틀라스 연속 좌표(64px = 1m, 붓 무늬 반복 규칙과 같음). UV가 한 점인 민 면(white·lamp 칸)은 세계 좌표 주축 투영. 처마 안 위를 본 민 면은 장판으로 본다.
- 접선은 화면 미분으로 만든다(키트에 접선 없음).
- 아틀라스 붓 무늬는 재질마다 남길 만큼만 남긴다(돌·바위 30%, 흙벽 40%, 창살·기와골·널 이음은 그대로). 기와골·창살·널 이음은 아틀라스 밝기를 높이로 읽어 굴곡(법선·오목)을 만든다 — 건물 빌더 칸 무늬에도 저절로 적용된다.
- `kit.gd`·`kit/`·`placement`는 고치지 않았다 → 키트 캐시 그대로 맞음(hits 1197 / misses 24, 전후 같음).

### 2-3 셰이딩 (`shaders/pbr_common.gdshaderinc`, `scripts/materials.gd`, `shaders/region_terrain.gdshader`)
- 직접광: 램버트 + GGX(Smith-Schlick, Schlick 프레넬). 밝기 규칙은 툰과 같아(LIGHT_COLOR/π²) 시간대 표·등불 세기 값을 그대로 쓴다.
- 앰비언트: 하늘 반구 + 수평 안개빛 + **땅에 튄 해빛(벽 그늘 쪽 따뜻한 반사)** + 해 쪽 하늘이 조금 밝음. 오목(AO)을 곱한다. 먹 그늘(후처리 AO)은 그 위에 그대로 곱한다.
- 반사: 하늘 그림판과 같은 하늘색(`sky_top`·`sky_hor`, 날씨가 회색으로 바꾼 값)을 분할합 근사로 — 젖은 기와·물 고임이 실제 하늘을 비춘다.
- 처마 안 하늘빛: 배치 로더가 칠한 처마 부호 거리(`region_world.dress_tex`)를 전역으로 넘겨, 처마 안으로 깊을수록 하늘빛을 줄인다(툇마루 밑 · 방 안이 어둡다). 지붕·나무는 제외.
- 한지·잎·풀은 뒤에서 오는 빛을 비친다(창호지에 볕이 비침).
- 시차 매핑(POM): 화면 품질 높음 · 12m 안 · 흙벽·이엉·기와·돌·바위·껍질 · 10단 + 보간. 높이 = 디테일 높이 + 아틀라스 굴곡(기와골).
- 먹선 껍질은 사실 쪽에서 그리지 않는다(셰이더에서 버림).
- **컴파일 때 고름**: `#define LOOK_PBR`. 실행 중 분기로 두면 큰 셰이더에서 툰 쪽도 약 1.2ms 느려졌다(측정 §4) — `--look=ink`는 예전 셰이더와 같은 비용이다.

### 2-4 비·눈 (기존 날씨 `weather.gd`의 `wet`·`snow`·`snow_line` 그대로 — 쌓이고 마르는 시간도 그대로)
- 비: 재질 다공성대로 짙어지고(흙·흙벽 많이, 기와·돌 적게) 거칠기가 내려간다(기와·돌·박석은 많이 반들). 위를 본 면은 처마 밖만 젖고, 벽은 세로 빗줄기 얼룩(처마 밑 벽은 아래쪽 약하게).
- 물 고임: **높이가 낮은 데부터**(줄눈·바퀴 자국·흙 패인 데), 젖음이 클수록 수위가 오른다. 고인 물은 거울 반사 + 빗방울 동심원(시간 따라). 땅은 길에서 조금 더 고인다.
- 눈: 위를 본 면 · 처마 밖 · **오목한 데부터 찬다**. 이엉·기와·담 갓·장독·마당·길·잎덩이. 처마 밑(툇마루·기단 안쪽)은 비운다. 반짝임 없는 부드러운 눈 재질(거칠기 0.82, 빛 조금 비침), 녹으면 짙은 데부터 드러남.
- 기존 땅 쪽 규칙(밟힌 길·마당은 눈이 덜 덮임, 처마 낙숫물 줄)은 그대로 위에 남는다.

### 2-5 빛 운전 (`scripts/render/look.gd`)
- 해 그림자: 높음 PSSM 4단(분할 0.08/0.22/0.5, 섞음) · 1인칭은 100m. 낮음 2단 60m. 구름이 끼면 그림자가 무르고(blur 1→4.5) 옅어진다.
- 흐린 날(비·눈) 하늘빛 조금 올림(amb_k), 눈 날은 기존 날씨 보정대로 땅빛이 밝다.
- 안개: 해 쪽으로 볕을 머금는 산란(해 질 녘 역광 능선이 붉게 녹음).
- 톤매핑: AgX(Punchy) + 노출. **눈 적응**: 처마 안 깊이(실내)·밤·흐림에 따라 노출 목표를 바꾸고 약 0.6초에 걸쳐 따라간다(측광 없이 상태로 — 비용 0).
- 실내 잘라 보기: 숨긴 지붕·앞벽을 **그림자만 드리우게**(지붕 그림자가 방에 남고 창으로 볕 조각이 든다). 1인칭 규칙(지붕 숨기지 않음)은 그대로.
- 한지 결·종이 비네트·먹선(후처리)은 사실 쪽에서 끔, 옅은 렌즈 비네트만.

### 2-6 하지 않은 것(판단)
- LightmapGI·VoxelGI: 세계가 실행 중 키트로 지어져 미리 구울 수 없다. 반사 프로브: 재질이 Godot 앰비언트를 쓰지 않아(EMISSION 방식) 들어갈 자리가 없고, 하늘 반사 근사로 대신했다.
- Forward+ 시험: 지시대로 하지 않음(이전 visual-pass 측정: Forward+ 효과 켬 1080p p99 21ms).
- 기하 변위(이엉 처마 들쭉날쭉 등): 기하는 건물 빌더 갈래 몫이라 하지 않았다.

## 4. 성능 (M1, 남원 장터 `--warp=-3290,393`, 11시 맑음, 15초, 키트 캐시 따뜻함)

1920×1080 — 바탕(이 갈래 시작점) 실행과 번갈아 쟀고, 그때 다른 Godot이 돌지 않음을 확인:

| 마을 구도(제자리) | 118.9 · 9.1ms (120 상한) | 95.1 · 10.9 | 108.1 · 9.7 |

| | 바탕 | 사실·높음 | 사실·낮음 |
|---|---|---|---|

기능별 비용(1440 마을 구도, 하나씩 끄고 잼, ±1ms 흔들림): 키트 사실 재질 약 1.2ms · 땅 디테일 약 1.4~1.9ms · PSSM 4단(직교 대비) 약 0.8ms · 시차 매핑 마을 구도 0 / 1인칭 가까이 0.4ms · GGX 정반사 측정 흔들림 안 · AgX·노출·지붕 그림자만 0. 실행 중 분기로 두었을 때 툰 쪽도 1.2ms 느려져 컴파일 때 고르게 바꿈(`--look=ink` 77.9fps, 바탕 74.4).
사실감 대비 비용(화면 보고 판단): ① 사실 직접광+하늘 앰비언트+AgX(그늘 대비·땅 튐) — 거의 0ms에 가장 큼, ② 실내 지붕 그림자만 — 0ms, 실내가 실내답게, ③ 키트 디테일·굴곡(흙벽 여물·막돌 줄눈·기와골) — 1.2ms, ④ 비·눈 재질 — 맑은 날 0, ⑤ 땅 디테일 — 1.5ms 내외로 가장 비싸고 3인칭에서는 이득이 작다(낮음에서 한 층·법선 없음), ⑥ POM — 1인칭 가까이만 보임.
- 텍스처 메모리: +12MB(texmem 695 → 708MB, 1080p). 영상 메모리 1215~1239 → 1236~1298MB.
- 셰이더 첫 컴파일: 셰이더가 바뀐 뒤 첫 실행 LOAD 11.4~14.4초, 다음부터 5.6~6.5초(바탕 5.7~6.6초) → 처음 한 번 약 +6~8초.
- **예산**: 1080p는 높음도 60fps 넘고 p99 16ms 안. 1440p 높음은 약 57~60fps · 걷기 p99 23ms로 예산(60fps·p99 16ms)을 넘는다 — 낮음은 안쪽.
