# parcels 보고서 — 논·밭 필지(진짜 논두렁·논물·다랑이·이랑)

담당: terrain-detail. 문제: 논·밭이 landuse.png(4m 칸) 위에 칠한 무늬뿐이라 높이 차도, 논두렁도, 논물도 없고 경계가 흐린 색 띠였다.
해결: **필지 생성기**(Python, 빌드 때)가 논·밭을 진짜 필지 다각형으로 나누고, **필지 엔진**(GDScript, 실행 때)이 근경 타일마다 그 필지로 땅을 새로 짓는다.

## 1. 실행

```bash
python3 tools/region/parcels.py JL_NAMWON_UNBONG          # 권역 하나(남원 약 70s)
python3 tools/region/parcels.py --all --routes            # 8개 권역 + 12개 노정(약 17분)
python3 tools/region/parcels.py JL_NAMWON_UNBONG --png    # + shots/region/parcels/<id>_plan.png 평면도
python3 tools/region/parcels.py JL_NAMWON_UNBONG --box=-3250,-150,-2850,250   # 이미 만든 parcels.bin 부분 평면도
python3 tools/region/farm_find.py region_data/<id>        # 필지 종류별로 가장 빽빽한 자리(스크린샷 자리 고르기)
godot --path . res://scenes/region.tscn -- --farmseason=spring|summer|autumn|winter   # 계절 덮어쓰기
godot … -- --nofarm        # 필지 끄기(예전 칠한 무늬) — 비교·측정용
godot … -- --farmtrace     # 불러오기 중 타일별 짓기 시간
```
빌드 파이프라인에 넣었다: `build.py`(남원·그 밖 권역), `build_region.py`, `north_post.py`, `make_routes.py`가 끝에서 `parcels.run(폴더)`를 부른다. `SEOLHWA_NO_PARCELS=1`이면 건너뛴다. landuse가 바뀌면 필지도 다시 만들어진다.

## 2. 필지 생성기 `tools/region/parcels.py`

1. **구획**: 논(2)·밭(3) 마스크(4m)를 부호 거리장으로 바꿔 가우스로 계단을 둥글린다(2m 격자). 길(반폭 + 1.6m, 논은 + 1m 더 — 도랑 자리), 하천(리본 반폭 + 2.2m)에서 띄우고, 논·밭 사이와 숲·마을 가장자리는 0.6m 띄운다(논밭 사이 1.2m 두렁길).
2. **구역**: 큰 들은 보로노이 구역(논 110m·밭 90m 흔든 격자 씨앗)으로 나눈다. 구역 경계는 1.2m 두렁길(풀). 구역마다 방향과 방식을 정한다.
   - 평지(12m로 고른 땅 경사 논 < 2.2%, 밭 < 4%): 110m 안 가장 가까운 길·하천 방향에 맞춘 거의 직사각형. 논 9~13 × 18~30m, 밭 10~15 × 16~34m(조선 한 마지기 약 20×30m를 조금 줄임).
   - 비탈: 등고선 방향 틀. 기준 등고선의 휨 c(t)를 찾아 모든 줄을 그만큼 휘게 한다 → **휘어진 다랑이**. 논 줄 폭 = 0.45/경사(3.2~12m, 급할수록 좁게), 밭은 1.5/경사(6~13m), 8% 넘는 밭은 **계단밭**(0.9/경사, 4~9m).
3. **자르기**: 칸(사각형 또는 휜 띠) 다각형을 구획 거리장으로 자른다(나갔다 들어오면 조각마다 현으로 닫음). 30m²(밭 40m²) 미만·가는 조각은 버린다(풀밭으로 남음). 이웃 칸은 같은 변을 정확히 나눠 가진다.
4. **바닥 높이**: 평지 논 = 필지 안 땅 중앙값 − 0.30m(둑 윗면 +0.26 → 길·둑보다 0.3~0.55m 아래), 다랑이 = 평균 − 0.18m(깎고 메움, 줄마다 계단), 계단밭 = 평균, 밭 = 땅을 따름.
5. **이웃**: 구역마다 0.25m 래스터로 변마다 바깥 이웃을 찾고 T자 꼭짓점에서 변을 쪼갠다. 변 이웃 번호: 필지 번호 / −1 구획 바깥 / −2 도랑(길과 25° 안으로 나란한 논의 바깥 변).
6. **물꼬**: 논마다 같거나 높은 이웃과 맞닿은 가장 긴 변 가운데.
7. **상태**(climate.png 기후대, 구역 안은 60% 같은 상태로 묶음):
   - 논: 0 물 댄 모 / 1 자라는 벼 / 2 익은 벼 / 3 그루터기. 남부 22/60/18/0%, 중부 10/50/35/5, 북부 0/15/50/35, 고산 0/20/45/35.
   - 밭: 콩·조·보리·배추·고추·묵정(기후대별 비율, 북부·고산은 조·보리 많음).
8. **양식**(style 비트): 1 석축(다랑이 경사 > 4%, 계단밭 > 10%, 제주 비탈 밭), 2 현무암 밭담(제주 모든 밭), 4 계단밭.
9. **출력**(권역·노정 폴더): `parcels.bin`(v2: 'PRCL' + 24바이트 머리 + gzip 본문 — P float32[n,12], V float32[nv,3], 물꼬 I[ni,4], 64m 칸 색인 C int32[nc,4]), `farm.png`(필지·도랑 합집합 부호 거리, 높이맵과 같은 2m 격자, 128 + d·16), `parcels.json`(요약·메타). 형식은 파일 맨 위 설명.

## 3. 필지 엔진 `scripts/region/farm.gd` (+ `shaders/region_farm.gdshader`, `shaders/region_paddy_water.gdshader`)

- **땅 바꾸기**: 지형 셰이더(근경 재질만)가 `farm.png`를 읽어 필지 안 격자점을 6m 내린다 → 보이는 땅은 필지 메시. 필지 밖에 남은 논·밭 칸은 풀밭으로 칠한다(**흐린 필지 무늬 없음**). 중경·원경(768m 너머, 안개 속)은 예전 무늬 그대로.
- **논**: 바닥(진흙, 상태별 색), 논물(바닥 + 0.09m, 반투명 — 위에서 보면 진흙이 비치고 비스듬히 보면 하늘빛, 툰 두 단 반사, 필지마다 물빛 조금씩, 비친 구름), **논두렁**(윗면 0.4m·높이 0.26m, 같은 높이 이웃과는 반쪽씩 0.2m, 풀 포기), 모서리는 두 변 폭에 맞춘 꺾음.
- **다랑이 계단**: 높은 필지가 아래 필지 쪽 변에 둑 + 둑 비탈(흙은 drop×0.35 눕힘, **석축**은 drop×0.12 거의 곧게, 막돌 무늬)을 아래 논 물 밑까지 내린다. 낮은 필지는 그 변에 둑을 두지 않는다.
- **구획 바깥 변**: 둑 윗면에서 바깥 1.6m 땅(−5cm)까지 풀 비탈(테두리) — 셰이더가 내린 땅의 틈을 덮는다. 볼록 모서리는 쐐기로 메움.
- **물꼬**: 같은 높이 변은 둑을 0.56m 끊고(물이 이어짐), 계단 변은 위 논 둑을 끊고 하천 물 재질로 떨어지는 물줄기(위 논에 물이 있을 때만).
- **도랑**: 이웃 −2 변은 둑 → 도랑(폭 0.8m, 바닥 = 논바닥 − 0.32m, 물) → 바깥 둑 → 테두리.
- **벼**: 필지 긴 축 방향 줄(줄 0.8m, 포기 0.7m — 실제 30×15cm를 게임 크기로), 둑에서 0.95m 안쪽. 포기 = 잎 3~7장 다발, 상태 4벌(어린 모·자라는 벼·고개 숙인 이삭·그루터기). MultiMesh 4포기/2포기 조각.
- **밭**: 땅을 따르는 바닥(5m 칸으로 잘라 높이 맞춤) + **이랑·고랑**(1m 간격, 이랑 높이 0.17m, 필지 축 = 비탈이면 등고선 방향) + 이랑 위 작물(kit/nature/crop.gd 두둑 없는 줄, 2.4m) + 밭둑(풀). 계단밭은 평평한 바닥 + 이랑 + 흙 둑/석축.
- **제주**: 밭마다 현무암 밭담(0.8~1.1m, 가운데 점을 흔들어 굽은 담, 둥글게 흔든 막돌 무늬).
- **계절**: 데이터 상태 그대로(기후대별) 또는 `--farmseason`. 가을·겨울은 둑도 마른 풀빛.
- **걷기**: `region_world.ground_at`이 필지 안이면 `farm.height`(논 = 물높이 −3cm, 둑 = 윗면, 비탈 = 보간, 밭 = 땅 + 0.08, 밭담 위), 밖이면 예전 지형(`terrain_at`). `height_at`·배치 로더·NPC·데칼이 모두 따른다.
- **배치와 맞추기**: 배치 로더가 `add_veg_exclusion`을 부를 때 그 사각형에 걸린 필지를 뺀다(그 자리 땅은 내리지 않음). 뺀 다음에 항목 높이를 `ground_at`으로 정하므로 **배치 위치는 그대로, 높이도 그대로**(남원 392개 필지 뺌 — 집·마당 자리). F5 다시 읽기는 `reset_edits` → 다시 뺀다. 배치·마을 파일은 고치지 않았다.
- **식생**: scatter에는 `landuse_scatter`를 넘긴다 — 필지가 덮은 칸은 12(식생 없음), 필지 밖 논·밭 칸은 풀밭(1). 예전 scatter 벼·밭 작물 줄은 필지 칸에서 나오지 않는다. `kit/nature/scatter.gd`는 고치지 않았다.
- **스트리밍**: 근경 타일이 생기면 작업 스레드(동시 2, 불러오기 중 6)가 64m 칸마다 배열을 짓고 메인 스레드가 프레임당 6칸씩 노드로 만든다. 반경 1타일 = 자세히(벼·이랑·작물·풀), 반경 2 = 바닥·둑·물만. 벼·이랑·작물은 150m 너머 그리지 않는다(visibility range). 노드 원점 = 칸 가운데.
- **불러오기**: 불러오기 화면은 플레이어 170m 안에 걸친 타일만 기다린다.

### region_world.gd 변경(작게)
`Farm` preload·`farm` 필드, `load_region`에서 setup, `ground_at` → 필지 + `terrain_at`(예전 ground_at), `_set_tile`/`_drop_tile`/`focus`에서 타일 알림, `update_scatter_lod`에서 update, `scatter_busy_near`·`stats.jobs`에 필지 작업, `shutdown`, `add_veg_exclusion`(필지 빼기), `reset_edits`, `commit_terrain`, `landuse_scatter`. 지형 셰이더에 `farm_tex/farm_meta/farm_size/farm_on`(정점 내리기, 논·밭 칸 → 풀밭). region_main.gd는 건드리지 않았다.

## 6. 고증 근거와 가설
- 논두렁 폭·높이, 물꼬, 다랑이(지리산 산골 축대), 제주 밭담은 일반적인 한국 전통 농촌 경관을 따랐다. 필지 크기는 한 마지기(논 약 200평)를 게임 압축(K≈0.3)에 맞게 조금 줄인 **가설**.
- 상태 비율(기후대별 늦여름 모습)은 게임용 가설. 계절 시스템이 생기면 `farm.season`을 그쪽에 잇는다.
- 권역 landuse에 비탈 논이 거의 없어(남원 논 경사 중앙값 1.9%) 다랑이는 대개 완만한 계단(줄마다 0.3~0.5m)이다. 급한 다랑이·석축은 계단밭에서 주로 나온다.

## 7. 남은 것·요청
1. **(데이터)** 남원 landuse는 밭(4.1km²)이 논(1.7km²)보다 많다. WORLD_SPEC §24(평지·하천가 = 논)보다 밭이 넓어 보이면 landuse.py 비율을 볼 것. 필지는 landuse를 그대로 따른다.
2. **(엔진)** `commit_terrain` → `reset_tiles`(F5 다시 읽기)는 필지 타일도 다시 짓는다 — 그 사이 몇 프레임 근경 필지 자리 땅이 비어 보일 수 있다(F5 때만).
3. 둑 위를 걸을 때 높이는 둑 모양을 따르지만 물 속으로 걸어 들어갈 수 있다(막지 않음). 밭담은 넘어간다(충돌체 없음) — 막아야 하면 담 충돌체를 더한다.
4. 노정(route) 필지: 한강 뱃길 노정에서 불러오기·필지 확인(2,343 필지, 오류 없음, `shots/region/parcels/route_hangang.png`). 다른 노정 화면은 찍어 보지 않았다.
5. 저장소: 필지 데이터 합계 약 58MB(parcels.bin + farm.png, 권역·노정 전부).
