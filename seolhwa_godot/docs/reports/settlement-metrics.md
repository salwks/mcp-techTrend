# 고을·마을 짜임 실측 지표와 생성 규칙(settlement-metrics)

2026-10-22 · 브랜치 `claude/town-organic` · 이 문서가 생성기(`kit/bldg/organic.gd`·`settlement.gd`)의 **목표 분포**이고, 생성 결과는 같은 지표로 재어 통과/실패를 낸다(§5).
방법 바꿈의 까닭: 지금까지는 참고 그림을 눈으로 보고 생성기를 만든 뒤 고쳐 왔다. 이제는 실측 자료를 숫자 규칙으로 먼저 바꾸고, 그 규칙대로 짓는다.

표기: **[직]** 원문에서 읽은 값 · **[초]** 초록만 · **[추]** 원문 값으로 계산·환산 · **[기]** 언론. 1평 = 3.3058㎡, 1칸(길이) ≈ 1.8m(양상호 2011 환산), 영조척 ≈ 0.30~0.31m.

## 2. 자료에서 나온 결론(지금 생성기와 다른 점)

1. **가로 간격이 훨씬 넓다.** 지선 간격 80~120m → 블록 80~120m. 지금 생성기는 36~56m(남원 eup 블록 가운데에 골목까지 넣으면 40m 안팎)로 2배 촘촘하다. 블록 안쪽은 **막다른 골목(≤30m)**과 **뒤 필지(더 큼)**, 그리고 텃밭·논밭이 채운다.
2. **필지는 앞이 좁고 길쭉하며, 길가가 작고 뒤가 크다.** 길가 필지 100~330㎡(앞너비 10~20m가 반), 뒤 필지 330~800㎡. 지금은 블록 띠 깊이 그대로 균일하게 잘라 뒤 필지가 없다.
3. **집은 작다.** 서민 3칸 초가 바닥 ≈ 28㎡(처마 포함 ≈ 50㎡), 칸 2.3~2.6m × 측면 2.76m + 퇴 1.0m. 지금 빌더 서민 초가는 칸 2.75m · 깊이 3.19m · 처마 포함 바닥 ≈ 88㎡로 **실측보다 칸 +12%, 깊이 +16%, 바닥 약 1.7배**. 높이(기둥 2.28~2.49m)는 실측(2.4~2.5m)과 맞다. → 평면 배율은 1.08 안팎이 실측, 높이는 1.22가 실측이다(§6 결정).
4. **건물 덮임은 낮다.** 대지 367㎡에 5.5칸(≈37㎡ 바닥)이면 건폐 약 10%, 처마 포함 지붕 덮임 약 18%. 길가 작은 필지(100~200㎡)에 안채 + 헛간 2채면 지붕 덮임 35~50%. 즉 "35~55%"는 **길가 줄(간선변)에서만** 실측과 맞고, 읍성 전체 평균은 20~30%다. 성 안에도 밭이 넓다(수원·공주).
5. **방향은 남향이 먼저다.** 안채는 대지 뒤 끝에 남향(±45°), 대문은 그 남쪽 일직선. 길이 북쪽에 있으면 대문이 북으로 나지 않고 옆으로 돌아 든다(낙안: 북쪽 대문 없음). 지금 생성기는 늘 길을 향한다.
6. **밀집지에선 건물 벽이 담이다.** 담은 건물이 없는 경계에만, 이웃과 한 줄(맞담). 높이 1.6~2.0m.

## 4. 생성 알고리즘(이 규칙대로 다시 짠다)

1. **간선**: 성문 십자·丁자(대로 5~7m), 성 안 둘레길은 선택(성벽 안 6~10m 띠).
2. **지선**: 간선에서 80~120m 간격으로 뻗고 블록을 80~120m로 나눔(3.4~5m). 블록이 120m를 넘으면 골목 한 줄(2~3m).
3. **블록 = 길로 둘린 면**(다각형). 블록마다:
   a. **길가 띠**: 블록 가장자리를 따라 앞너비를 §3.2 분포(구역별)에서 뽑아 끊김 없이 자르고, 깊이는 앞너비 × (1.3~2.5)로(띠 깊이 상한 25m).
   b. **안쪽**: 길가 띠 뒤 남는 땅이 300㎡ 넘으면 길가 필지 2~5개 간격으로 막다른 골목(≤30m, 1.5~2.5m)을 넣고 그 끝·양옆에 뒤 필지(330~800㎡). 골목이 닿지 않는 땅은 텃밭·밭(뒤 필지 마당에 붙임).
4. **계층 고르기**: 구역·자리(간선변 → 가게·서민, 관아 둘레 → 향리, 성 안 북·동 → 양반, 성 밖 → 서민·장시)와 필지 넓이로 §3.3 짜임 선택.
5. **집 놓기(필지 틀 + 남향)**: 안채 → 뒤 끝·남향(±45°) / 대문 → 안채 앞 일직선, 길에 닿는 변 / 부속 → 측면 담 > 정면 담 / 간선변이면 앞채(가게·행랑) 뒷벽을 길가 선에. 칸 수는 §3.3에서 뽑고, 필지 너비에 맞춰 칸을 줄인다.
6. **담**: 필지 경계 중 건물 벽이 아닌 곳만, 이웃과 한 줄(먼저 지은 쪽), 곧게/굽게 규칙은 그대로(`town-organic.md` §3).
7. **지형**: 필지 터는 앞 길 높이로 고르고(flat_at), 비탈 낮은 변에 축대. 길도 같은 높이장으로 고른다(길가 둔덕 없애기 — 길을 따라 터 고르기 띠).

## 5. 지표 자동 보고(`tools/bldg/settle_metrics.gd`, 만들 것)

생성 결과(배치 파일)에서 §3 지표를 재어 구역별 목표 띠와 견주고, 통과/실패(허용 ±10% 또는 분포 겹침)를 표로 낸다.

| 지표 | 재는 법 | 판정 |
|---|---|---|
| 가로 폭 · 위계별 길이 | 배치 alleys·trunk 폭 | 위계별 범위 안 비율 ≥ 90% |
| 지선 간격 · 블록 크기 | 블록 면(길 다각형) 짧은 변 | 가운데값이 80~120m |
| 필지 넓이 · 앞너비 · 깊이 비 | bldg/lot poly | 구역 분포와 가운데값 ±15%, 사분위 겹침 |
| 블록당 필지 수 | | 범위 안 |
| 필지당 건물 수 · 칸 수 | lot pieces | 계층 표 범위 안 비율 ≥ 80% |
| 안채 방향 | 안채 ry → 남쪽에서 벗어난 각 | ±45° 안 ≥ 80% |
| 지붕 덮임 · 건폐 | 0.5m 격자(처마 포함 / 벽 바닥) | 구역 띠 안 |
| 길가 앞면 막힘 · 건물 벽 비율 | 길 따라 1m마다 앞 1.5m 안 담/벽 | 범위 안 |
| 맞담 두 겹 | 나란한 담 1.3m 안 쌍 | 0 |
| 빈 땅 종류 | 필지 밖 땅: 길·광장·텃밭·밭·나무·관아 | 텃밭·밭이 구역 범위 안 |

생성기 반복은 이 표의 실패를 줄이는 쪽으로만 한다(한 자리 배치를 손보지 않는다).

## 6. 결정이 필요한 것

1. **건물 평면 배율**: 실측(칸 2.3~2.6m, 측면 2.76m + 퇴 1.0m)은 지금 빌더(×1.22)보다 칸 12%·깊이 16% 작다. 높이는 지금이 실측에 맞다. 평면 1.08 · 높이 1.22로 나누면 실측에 맞지만, 예전에 가로·세로 다른 배율이 초가 처마 이음을 깨뜨린 적이 있어 지붕 쪽 손질이 따른다.
2. **덮임 목표**: 실측은 성 안 전체 22~32%, 간선변 줄만 35~50%. 지시한 "읍성 안 주거 ≥35%(40~50)"는 간선변 줄 기준으로 읽을지, 성 안 전체로 둘지(그러면 실측보다 촘촘한 그림 쪽 선택).
3. **성 안 밭**: 실측대로 성 안에 텃밭·밭을 두면(수원·공주) 빈 땅이 보인다. 둘지, 집으로 채울지.
