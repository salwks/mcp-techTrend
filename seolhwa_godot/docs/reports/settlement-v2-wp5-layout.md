# settlement v2 — WP5 Layers 3–5: 구역·길·물길망·블록·공유 변 필지 (settlement-v2-wp5-layout)

2026-10-25 · 브랜치 `claude/settlement-v2` · 감사 문서 20 §5 WP5, 설계 L3-8 3회차(사양 쪽 보완 반영). 게임 런타임 변경 없음.

## 0. 진행 중 반영한 소유자·조정자 결정

1. **조정자(WP4 남은 문제)**: ① 지도 물 폭보다 높이장에 파인 골이 넓으면, 계획에는 **파인 골 단면을 유효 젖은 폭**으로 쓰고 지도 폭은 별도 속성으로 둔다. 불일치는 표시만 한다(막지 않음). 재굽기는 하지 않는다. ② 지도 여울은 **여울 단면**(평수 ≤0.4 m)으로 판정한다. 소·흐름 구간은 설계 깊이 0.8 m를 그대로 둔다.
2. **소유자 정정(2026-10-25)**: 실제 유적이나 연도를 재현하지 않는다. 조선의 생활·건축·배치 *원리*를 재현한다. 빌더는 주어진 땅에 **항상 정착지를 만든다**. 높은 마른 단, 돋운 기단·축대, 군집, 작은 형태로 적응하며, `insufficient_capacity`로 끝내지 않는다. 이야기 잠금은 바뀌지 않는다. 빌더는 하나뿐이다(도시별 특례 없음). 자료의 어긋남은 일관된 내부 규칙으로 처리한다.
3. **Codex 설계 검토(조정자 전달)**: 적응 사다리와 SiteTreatment 기록, 경계 변 분할(개구부 끝점·이유 전환), 영속 경계 id·양쪽 지면 단면, 진단용과 플레이용 내보내기 분리, V14 재정의를 반영했다(아래 §2–§4). 역사 충실도 관문은 WP5에 없다.

### 2.2 형태 지표(L3-8 §5)

- 길 폭 준수는 길이 기준 100 %다. 새 길이 규칙 기본 폭을 쓰므로 정의상 그렇다.
- 필지 앞너비 중앙값은 대부분 목표 ±15 % 안이다. 넓이(뒤뜰 제외)는 도시 주·지선·마을 역할에서 대부분 안에 든다. 표본이 작은 양반·향리 역할은 벗어나거나 판정하지 않았다.
- **지선 간격 중앙값은 목표(96–144 m)를 재지 못했다.** 지선이 대개 L2 회랑 끝에서 나와, 회랑 위 분기 표본이 3개 미만이다.
- 막다른 골목 최장은 37.2 m로 한도 36 m를 넘는다. 부모 중심선까지 이은 길이가 더해졌기 때문이다.
- 지붕 덮임·앞면 닫힘은 L6–7 검사다.

### 2.3 결정성·시험

- 결정성: syn_terrace·syn_stream·syn_estuary·반선을 두 번 구웠고 **95파일 바이트 동일**하다(`determinism-a.json`).
- 마지막 수정(회랑의 잠금 비킴·한 울안 두 집·내보내기 표기) 뒤에 잠금 픽스처·안목·남원 재확인을 백그라운드로 돌렸다. 보고 시점의 결과는 커밋 메시지와 조정자 보고에 적는다.
- pytest는 마지막 전체 실행에서 85 통과, 1 실패였다. 실패한 것은 WP2 식별 시험으로, WP5 id가 L0–2 단계에서 은퇴되던 문제다. 은퇴를 WP5 뒤로 옮긴 뒤 wp2·wp5 시험 17개가 통과했다. 이 상태로 전체를 다시 돌리지는 않았다.

## 3. 열린 문제

- 실제 4곳의 적응 결과는 **작다**(남원 47·불국사 45·안목 10·반선 6가구). 남원은 이야기 앵커·잠긴 물건 304개와 범람 화면 때문에 성곽을 둘 수 없어 무성곽 읍치(소형 관아 형태)가 됐다. 반선은 지리산 골짜기 비탈의 좁은 단 위 산촌이다. 화면 판정은 하지 않았다.
- 적응 단계 값(축대 25°/32°, 소형 0.6, 걷기 160/500 m, 여유고 0.3 m)은 모두 시험값이다. 둑은 만들지 않는다.
- 돋운 기단·축대는 기록과 처리된 지면까지만 있다. 실제 형상(옹벽 단면·계단)은 WP6b/WP8 몫이다.
- 0.05 m짜리 개구부 끝 조각 변이 생긴다. 문 구간 끝점과 회랑 가장자리가 어긋난 자리다.
- 성 밖 장터 변형은 평가만 한다(규칙 `program`).
- 수공업 하위 종류를 모르므로 모든 수공업을 오염 가능으로 본다.
- 곡선 맞춤(최소 반경)은 하지 않았다. 검증한 꺾은선을 유지한다.
