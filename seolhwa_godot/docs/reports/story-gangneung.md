# story-gangneung 보고 — 사건 「고개에 남은 종소리」와 잔영·호신물 체계

개발 우선순위 3번. ACT 2A 강릉 사건(S2001~S2008)을 GW_GANGNEUNG 권역에서 처음부터 끝까지 할 수 있게 만들었다. 결말은 셋이다. 이 사건이 처음 쓰는 잔영·소리·경계·호신물 체계는 다음 사건(경주 세 번째 등불, 제주 감응 매듭, 최종장 강복)이 데이터만 바꿔 쓰도록 따로 떼었다.

## 1. 실행

| 하고 싶은 것 | 명령 |
|---|---|
| 대본 시험(결말별) | `godot --path seolhwa_godot res://scenes/region.tscn -- --region=GW_GANGNEUNG --storytest=gangneung:A` (B, C도 같다). `--headless`도 된다. `--storyshots=shots/story_gangneung`이면 장면마다 찍는다 |
| 직접 하기 | `-- --region=GW_GANGNEUNG` — 저장에 `ACT2_OPEN=true`(한양 S1006)가 있어야 사건이 선다. 없으면 강릉은 소문만 돈다 |
| 저장 상태에서 시작 | 대본 시험은 `story/gangneung/test_post_hanyang.json`(남원 C 끝 + 한양 S1006)을 `user://storytest_progress.json`에 깔고 시작한다(`gangneung_test.gd prepare`). 직접 해 볼 때는 `--savefile=<그 꼴의 파일>` |

조작(더한 것): **Q** 호신물 지니기·풀기(가진 것을 차례로, 끝에서 한 번 더 누르면 푼다). 나머지는 남원과 같다(E 조사·대화, R 사건 기록).

## 3. 사건 진행(§11)

- **S2001** 단오장 도착 컷(약 7초): "강릉. 단오를 앞둔 남대천가." 엿듣는 말 "대관령 방울이 없어졌다지?" / "모시기가 내일 새벽인데…". 무녀 → 사건 기록, 반정으로.
- **S2002** 국사성황사 길(순서 없이): 빈 돌자리(끌린 자국 곁에 발자국 없음), 누운 선돌(옛 새김), 끊긴 금줄(칼 단면, 방울 고리만), 바위의 가는 긁힘, 뒤축 감은 짚신 자국, 빈 제물상. 제관은 "그 앞에 금줄을 치고 방울을 달았지"(방울의 옛 자리 — 증언은 관점만, §27).
- **S2003** 발자국 자리에서 **짐승 흔적 읽기**(남원 SKILL_BEAST_TRACE)로 가른다 → 단서 「두 갈래 흔적」, 규칙 R_THIEF_APART. 스킬이 없으면 짚신 자국을 끝까지 따라가야 한다(꾸러미 → 덕보의 자백으로 같은 규칙). 꾸러미(북어·초·쌀·금줄 토막, 방울은 없음)와 처마 밑 짚신 → 덕보에게 내밀면 방울을 내놓고 자백("그 돌은 내가 안 건드렸소"). 제관에게 넘긴다.
- **S2004** 월심(국사성황사, 의식 동작): "오늘 밤 다시 올라가시오." 부적 건네기 → **호신물 칸 1 열림**(ITEM_TALISMAN_SLOT=1), 호신부를 지닌다. "보인다고 다 따라가진 말고." 끊긴 줄은 다시 치면 된다며 새 금줄(ITM_RIT_005).
- **선택(낮)**: 제관에게 방울을 돌려주면 → **B**. "오늘 밤 방울을 들고 한 번 더 올라가 보겠소" → 반정 주모에게 밤을 기다린다.
- **S2005** 밤 21:30, 반정에서 같은 길을 다시 오른다. 방울 없는 방울 소리가 6~10초마다(방향 자막 "딸랑— 방울 소리. (멀리 왼쪽에서)" + 화면의 먹 고리). 앞서 가는 잔영이 간헐적으로 보였다 사라지며 경계석 쪽으로(끝에 닿으면 처음 자리에서 다시). 숲으로 꾀는 잔영을 따라가면 길을 잃는다.
- **S2006** 경계석 30m 앞: R_SOUND_LEADS, 희미한 형체 → R_FAINT_OUT. 경계 안으로 들어서면 또렷 → R_CLEAR_IN(진하기 0.30 → 0.88). 경계석 자리에서 방울을 가까이 가져가면 소리가 멎는다 → R_BELL_HOME, 잔영이 고개를 돌린다. 호신부 없이 경계 둘레에 오래 있으면 착란(가장자리 먹 번짐)이 차서 반정 툇마루에서 깬다. 호신부는 차오름을 70% 줄인다.
- **S2007** 결말:
  - **A 방울·경계석 복원**: 방울을 옛 자리에 둔 뒤 누운 돌을 세우고 새 금줄에 방울을 단다(빈 돌자리·누운 선돌 단서 + 금줄 필요). 잔영이 한 번 돌아보고 옅어진다.
  - **B 도둑 체포 + 제의 정상 진행**: 낮(또는 밤 반정)에 방울을 제관에게. 새벽 모시기는 제대로 치르지만 경계석은 누운 채.
  - **C 괴이를 공격하며 강제 통과**: "칼을 뽑아 벤다" — 칼은 아무것도 베지 못하고 형체는 흩어졌다 다시 선다. 지나가서 성황사에 닿는다. 이후 밤마다 고개 쪽 방울 소리(권역 어디서나 2.5~4분마다). 덕보를 안 잡았으면 밤사이 사라진다(실패도 진행, §29).
- **S2008** 새벽 국사성황사 모시기 → 제관이 꺼낸 옛 제의 기록 뒷장에 이겸 필체: "사람이 훔친 것과 사람이 아닌 것이 남긴 흔적을 섞지 말 것." `MAIN_MASTER_TRACE`에 `GANGNEUNG`을 덧붙인다(쉼표 목록: `HANYANG,GANGNEUNG`). 결말 카드.
- **변수**: `CASE_GANGNEUNG_OUTCOME` = A | B | C, `CASE_GANGNEUNG_DETAIL` = A | B | C_bell | C_nobell, `ITEM_TALISMAN_SLOT` = 1, `TALISMANS_OWNED`·`TALISMAN_EQUIPPED`(확장 — 사건을 넘어 남는다).
- **지역 변화(§30)**: 단오장에 장꾼·아낙·오색 천이 더 선다(모든 결말). A: 경계석이 제자리에, 새 금줄과 방울. B: 경계석은 누운 채, 밤에 호신부를 지니면 희미한 형체가 남는다. C: 밤마다 방울 소리 + 희미한 형체. 덕보는 잡혔으면 반정에 묶여 있다. 제관·장꾼·아낙 대사가 결말마다 다르다.
- **소문(§24)**: 단오장 `GN_JANG`(결말별로 비틀림), 읍내 `GN_EUP`(경포호의 배·헌화 벼랑), 노정 R03 횡계 `R0301`(결말별)·원주 `R0302`.
- **원칙 대응**: 전투 없음(§1.8, C도 상대가 베이지 않음). 해결 수단은 모두 먼저 보인다(§1.5): 짐승 흔적 읽기(남원), 방울(덕보), 금줄·호신부(월심, 밤 전), 돌자리(낮 조사), 규칙(밤 관찰). 돌을 누가 옮겼는지는 끝까지 밝히지 않는다(§1.4). 원작 제목·장황한 설명 없음, 월심 대사는 시나리오 두 줄 + 한 줄.
- §44 필드: SOURCE_ID A09(대관령 국사성황·산신 전승), ADAPTATION_MODE VARIANT, SOURCE_VERIFIED true.

## 4. 잔영·호신물 체계(재사용) — `scripts/story/spirits.gd`, `spirit_char.gd`

사건 데이터에 다음을 넣으면 된다(자세한 필드는 spirits.gd 머리 주석).

| 키 | 하는 일 |
|---|---|
| `spirits` | 2D 잔영. `night`(밤에만) · `sense`(감지 호신물을 지녀야) · `when`(조건식) · `zone`(플레이어가 그 경계 안이면 `alpha_in` 또렷, 밖이면 `alpha_out` 희미·얼룩) · `motion` float / drift(`path`, `speed`, `loop` true·false·"restart") · `flicker`(보임·안 보임 구간 초) · `watch`(가까우면 고개 돌림) · `range` |
| `sounds` | 소리 신호. 자막(가까이·멀리 따로, `dir`이면 화면 기준 방향) + 화면 효과(`ring` 먹 고리·`shake`) + `audio` 이름. 지금은 음원이 없어 `res://assets/audio/<이름>.ogg|wav`가 생기면 3D로 튼다. 다른 체계로 바꾸려면 `Spirits.audio_hook = Callable(이름, 자리)` |
| `zones` | 경계(자리+반지름). 들어설 때·나설 때 단계 실행(`enter`·`exit`, `when`) |
| `dread` | 공포·착란. 구역 안에서 차오르고(화면 가장자리 먹 번짐) 다 차면 `on_full` 단계. 지닌 호신물의 `protect`만큼 덜 찬다 |
| `talismans` | 호신물 정의 추가(기본: 호신부 ITM_RIT_001 감지+보호 0.7, 다라니 ITM_RIT_003 보호, 감응 매듭 ITM_RIT_004 감지). 공격·방어 수치는 없다 — 전투 코드는 이 체계를 모른다(§6.5) |

- 단계 명령: `{ "spirit": id, "do": "appear|vanish|show|hide|release|anim|place|move|face" }`, `{ "sound": id }`, `{ "talisman": "give|equip|unequip|slots", "id", "n" }`, `{ "dread": 0~1 }`.
- 조건식: `tal('ITM_RIT_001')`(''=아무거나), `zone('id')`, `night()`(19~5시), `spv('id')`(그 잔영이 지금 보이나).
- 호신물 칸: 화면 왼쪽 아래 한지 띠 "호신물 [호신부] Q 지니기·풀기". 칸 수는 `ITEM_TALISMAN_SLOT`(0 → 1, 뒤에 최대 2).
- 잔영 그림(SPIRIT_BASE): 구운 프레임 float(still/float)·drift(slow_walk)·head_turn을 쓰고, 셰이더가 옅은 먹빛(밝은 곳은 한지빛)·얼룩(clarity)·흩어짐(dissolve: appear/disappear)·잔떨림(flicker)을 맡는다. 빛을 받지 않아 밤에 희끄무레하게 보이고, 발치는 비어 있다. 그림자·테두리·가림 실루엣 없음.
- 경주(세 번째 등불)는 `spirits`에 불빛 셋(또는 형체)과 `sounds` 없이 `zones`만, 제주(감응 매듭)는 `talismans`의 ITM_RIT_004와 `sense`, 최종장 강복은 `spirits`(CHR_CRE_004 불탄 변형) + `dread`로 쓰면 된다.

## 5. 이야기 틀에 더한 것(작게)

- `story_director.gd`: `CASES`에 `GW_GANGNEUNG = "gangneung"`, 종류 대체(wolsim→shaman, thief→villager_m, spirit_m→elder), `BANK_FILES`에 `frames_gangneung.json`, 사건마다 `spirits` 하나(만들기·update), 규칙 알림 이름 `case.rule_label`(기본 "범의 버릇").
- `story_runner.gd`: spirit·sound·talisman·dread 명령, tal·zone·night·spv 조건.
- `story_ui.gd`: 기록책 규칙 칸 제목 `rules_title`.
- 같이 쓴 한양 에이전트의 틀(그쪽 커밋): `case.requires`(ACT2_OPEN), `case.start_event`, `case.reset_vars`(clear_saved), 사건별 `<사건>_test.gd`와 `prepare()`. **강릉 사건은 이 틀이 커밋되어야 돈다** — 내 커밋에는 그쪽 덩어리를 넣지 않았다.

## 6. 캐릭터 프레임

- `tools/export_gangneung_frames.js` + `tools/gangneung_bake.html`. `python3 tools/web_export_server.py 8770`(launch.json `seolhwa-web`)을 띄우고 `http://localhost:8770/__tools/gangneung_bake.html`을 열면 약 15초 뒤 "done: wolsim, thief, spirit_m"이 뜨고 `data/frames_gangneung.json`과 PNG 8장이 생긴다(data/는 git 제외라 새 맥에서는 다시 구워야 한다). 웹 코드(seolhwa/src)는 고치지 않았다 — SPECS·동작을 스크립트 안에서 더하고 리그의 pose를 감싼다.
  - **wolsim**(월심, CHR_MAIN_008, 무당 베이스 고유변형): 흰 저고리·남치마·붉은 고름·흰 머릿수건 + 손방울(놋쇠 방울 일곱·오색 천). idle·walk·talk + ritual(방울을 치켜들고 흔드는 도무) + give(부적 건네기, 1회). 3쪽
  - **thief**(덕보, 하인/머슴 → 마을 사람 변형): 칙칙한 저고리·검은 배자·머리띠·지게. idle·walk·run·talk·cower. 3쪽
  - **spirit_m**(잔영, CHR_CRE_004 '일반 잔영' 계열): 흰 두루마기·갓의 옛 차림. float·drift·head_turn. 2쪽
- 파일이 없으면 shaman·villager_m·elder로 대신한다(동작이 없으면 idle).

## 8. 남은 것·알려진 문제

- 소리가 없다(자막·먹 고리로만). 음원은 `assets/audio/bell_far.ogg` 하나만 넣으면 방울 소리가 3D로 난다.
- 국사성황사 모시기(신목 베어 모셔 내리기·행렬)는 자막 한 줄로 줄였다. 행렬 인물·신목 소품은 다음에.
- 경계석 자리 둘레 나무 수관이 낮 시점에서 일부를 가린다. 빈터를 넓히거나 카메라를 당기는 조정이 필요할 수 있다.
- 밤 화면이 전체로 푸르고 어둡다(권역 밤 조명 그대로). 잔영은 빛을 안 받아 잘 보이지만 단서 소품은 밤에 거의 안 보인다(밤에 쓸 소품은 경계석 자리 하나뿐이라 지금은 괜찮다).
- `MAIN_MASTER_TRACE`를 쉼표 목록으로 쌓는다(§11 "+="). 한양·다른 사건도 같은 꼴로 덧붙이면 좋겠다(문자열 비교 `== "HANYANG"`은 깨진다 — 남원 시험은 남원만 돌 때라 괜찮다).
- 공통 변수 `TALISMANS_OWNED`·`TALISMAN_EQUIPPED`는 §7 목록 밖의 구현용 확장이다.
- 고증(참고): 대관령 국사성황 모시기는 음력 4월 보름 무렵 대관령에서 시작해 단오에 강릉으로 내려오는 순서다. 게임에서는 "단오를 앞둔 새벽 모시기" 하나로 줄였다. 옛 경계석·방울을 단 금줄은 게임용 장치(가설)이고, 실제 전승이 그렇다고 주장하지 않는다.
