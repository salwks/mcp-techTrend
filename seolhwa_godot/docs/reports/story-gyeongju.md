# story-gyeongju 보고 — 사건 「세 번째 등불」(ACT 2B 경주)과 사람 적 전투·탁본

개발 우선순위 4번이다. ACT 2B 경주 사건(S3001~S3008)을 GS_GYEONGJU 권역에서 처음부터 끝까지 할 수 있게 만들었다. 함께 만든 것은 다음과 같다.

- 사람 적 전투(밀수꾼·도적·경비 공용) — 함흥·한양 최종장·황주가 같이 쓴다
- 탁본(SKILL_RUBBING) — 어느 공간에서나 닳은 새김·표식을 떠 조사 카드로 본다
- 경주 인물 프레임(밀수꾼 둘, 등롱 든 아낙, 숯쟁이, 여인 형체)

## 1. 실행

| 하고 싶은 것 | 명령 |

| 대본 시험 | `godot --path seolhwa_godot res://scenes/region.tscn -- --region=GS_GYEONGJU --storytest=gyeongju:A` (B도 같다). `--headless`, `--storyshots=<폴더>`, `--novsync` |

| | **B**: 한양만 마친 저장(호신물 없음 — 경주를 강릉보다 먼저). 싸움에서 물러나고(escaped) 우치를 놓친다 |

## 3. 사건 진행(§12)

- **S3001 치술령 소문**: 경주 장 주막. 엿듣는 말 "치술령에 밤마다 불이 셋 뜬다며?" / "숯쟁이 하나가 따라갔다 안 돌아왔대요." 주모에게 물으면 사건 기록이 생기고 마을로 갈 수 있다. 마을에 먼저 닿아도 노인에게서 시작한다.
- **S3002 낮 조사("별것 없음")**: 성황당 앞 굳은 등잔 기름, 등성이 바위틈의 그을린 천(바다 쪽이 트임), 발자국 없는 망부석(닳은 새김 — 읽히지 않음), 가지 더미(별것 없다). 둘 이상 보면 "너럭바위에서 밤을 기다려 볼까" 안내. 노인은 망부석을 "부인이 바다 건너 간 남편을 기다리다 돌이 됐다는 바위"라고만 말한다(A08, 원작 설명 없음).
- **S3003 세 불빛**: 너럭바위에서 밤을 기다리면 약 9초 컷(넓은 시점): "해가 지고…" → 불 하나가 고갯길을 오르고(아낙이 실제로 걸어 오른다) → 등성이에서 하나 → 하나 더. **HUD 번호 없음.** 불은 OmniLight + 빛 판(가까운 빛 0.8m, 번짐 5.5m)으로 그렸고 결로 가른다.
  - 걸음에 맞춰 흔들림(아낙의 손) — 규칙 「흔들리는 불은 사람의 걸음이다」
  - 셋 짧게·하나 길게 가렸다 열림, 먼 바다에서 작은 불이 답함 — 「가렸다 열리는 불은 신호다」
  - 흔들림·발소리 없이 내려와 바위 앞에서 꺼짐 — 「흔들리지 않는 불은 든 사람이 없다」
- **S3004 첫째 불**: 아낙 11m 안 → "등불이 걸음에 맞춰 흔들린다…". 말을 걸면 "숯 구우러 간 우리 집 양반이 사흘째 안 와요. / 불 켜 두면 보고 찾아올까 싶어서." 괴이 없음.
- **S3005 둘째 불**: 등성이 19m 안 → 불이 꺼지고 "쉿" → 짐 진 사내 둘 → **짧은 싸움**(사람 적 둘: 몽둥이·장대). 결과는 셋 다 이어진다(§29).
  - win: 쓰러진 자는 붙잡힘(`caught_a/b`), 체력이 적어 달아난 자는 감포 쪽으로
  - escaped(물러남) / lose(쓰러짐 → 깨어 보니 달아난 뒤): 둘 다 달아남
  - 그 뒤 "숯가마 쪽에서 끙끙대는 소리" → 가지 더미 뒤에 묶인 숯쟁이를 푼다(그는 아내의 등불 쪽으로 걸어 내려간다).
- **S3006 셋째 불**: 망부석 앞 15m 안에서 불이 꺼지는 것을 보면. **호신부를 지녔으면** 흰 옷의 여인 형체(spirit_f)가 1초쯤 바다 쪽을 보고 섰다 사라진다. 공격 없음, 벨 것도 없다. 호신부를 가졌는데 안 지녔으면 "(Q)" 안내. 호신물이 없으면(경주 먼저) "바위 앞엔 아무도 없다."
- **S3007 탁본 조각**: 바위 밑 틈 → 기름종이에 싼 오래된 탁본 조각. 이겸의 두 줄(시나리오 그대로): “남겨진 흔적과 방금 생긴 흔적을 한데 묶지 말 것.” / “오래됐다는 이유로 진짜인 것도, 새것이라는 이유로 거짓인 것도 아니다.” `MAIN_MASTER_TRACE`에 `GYEONGJU`를 덧붙인다(쉼표 목록). 이겸의 기록 조각 `ITM_KEY_004`.
- **S3008 우치**: 대사는 시나리오 세 줄뿐이다(“그 양반 아직도 그런 걸 적어놓고 다녔군.” / “스승을 압니까?” / “나보다 당신이 더 늦었소.”). 곧 **짧은 추격**(chase.gd `s3008`, 약 130m) — 우치는 나무에 매어 둔 밧줄로 비탈을 곧장 내려가고(지름길), 플레이어는 굽은 고갯길로 돈다. 끝에서 신목에 매인 밧줄로 서쪽 비탈 아래로 사라진다. 놓쳐도 이어진다(발자국이 성황당으로).
- **보상**: 신목 밑동에 걸린 보자기 — 솜방망이·먹·한지, "먹이 아직 마르지 않았다. 방금 무언가를 떠 간 것이다." → `ITM_TOOL_007` 탁본 도구, `SKILL_RUBBING = true`.
- **결말**: 아낙을 만나고, 숯쟁이를 구하고, 탁본 도구를 얻으면(순서 자유) 새벽 마을 장면 → 결말 카드. 사건 완료(phase done)에서 `CASE_GYEONGJU_COMPLETE`가 서고 skills.gd가 **빠른 사격(SKILL_SNAP_SHOT)**을 연다(데이터만 — 동작은 나중).
- **변수**: `CASE_GYEONGJU_OUTCOME` = A(밀수꾼을 하나라도 붙잡음) | B(모두 달아남), `CASE_GYEONGJU_DETAIL` = A | A_figure | B | B_figure, `MAIN_WOOCHI_KNOWN = true`.
- **지역 변화(§30)**: 모든 결말 — 망부석 앞 공양상, 숯쟁이 부부가 마을 마당에. A — 붙잡힌 밀수꾼이 마당에 묶여 있고 어귀에 횃대. B — 밤마다 감포 쪽 먼 데서 신호가 깜빡인다. 셋째 불은 결말과 상관없이 밤마다 아직 뜬다(§1.4 원인 미확정). 주모·주막 손님·노인·아낙 대사가 결말마다 다르다.
- **소문(§24)**: 경주 장 `GJ_JANG`(결말별), 읍내 `GJ_EUP`(왕릉의 말 탄 사람·옛 절터 종소리), R02 노정 `R0201` 문경새재·`R0203` 제비원(결말별), `R0202` 상주(풀).
- **원칙 대응**: 한 현상·세 원인(§1.4), 불빛을 번호 없이 결로 가름, 해결 수단은 모두 먼저 보인다(§1.5 — 등성이·숯가마·바위 밑은 낮에 본 자리). 싸움은 사람과만, 괴이와는 싸우지 않는다(§1.8). 컷신은 S3003 약 9초가 가장 길다(§28). §44 필드: SOURCE_ID **A08**(망부석·치술령 전승, 지역 고정), ADAPTATION_MODE ECHO, SOURCE_VERIFIED true. F09와 섞지 않았다.
- **확인/들음/추정(온보딩 UX 보강서 P1-7)**: 단서는 `kind`(fact 기본 | heard + `by` 발언자), 규칙은 「흔들리는 불」「가렸다 열리는 불」은 fact(눈으로 확인), 「흔들리지 않는 불」은 guess. 증언(주모·노인·아낙·숯쟁이·우치)은 사실로 올리지 않는다. 결말 카드·기록책에 숫자 세기는 쓰지 않는다. 기록책 UI·지도는 고치지 않았다 — 데이터만(`map_places`: 경주 장 주막 처음부터, 치술령 아래 마을·성황당은 들음, 망부석은 가 봐야 / `journal.unknowns`·`places`).
- **여행 기록의 "이겸의 흔적" 표**는 온보딩 쪽 데이터다. 경주 줄(◆확인 — 망부석 아래 탁본 조각)은 그쪽에서 `MAIN_MASTER_TRACE`의 `GYEONGJU`로 더하면 된다.

## 4. 사람 적 전투 API — `scripts/combat/chuman.gd` (공용, 이 에이전트 소유)

싸움터 데이터에 `humans`를 넣으면 그 판은 사람 적 판이 된다(호랑이 판은 그대로).

```gdscript
"arenas": {
	"spur": { "at": "spur", "radius": 10.0, "camera": { "pitch": 46.0, "distance": 20.0, "fov": 30.0 },
		"foe_name": "밀수꾼", "intro": "사내 둘이 …!", "flee_to": "flee_east",
		"humans": [
			{ "id": "sm_a", "kind": "smuggler", "name": "밀수꾼", "weapon": "club", "hp": 60.0, "flee_at": 0.2, "offset": [3.0, 2.0] },
			{ "id": "sm_b", "kind": "smuggler_b", "name": "장대 든 밀수꾼", "weapon": "pole", "hp": 50.0, "flee_at": 0.35, "offset": [-2.5, 3.5] },
		] },
}
```

- 실행: 사건 GDScript `var res: String = await d.combat("spur", { "allow_flee": true })` 또는 이야기 명령 `{ "combat": "spur", "store": "fight" }`
- 결과: `win`(모두 쓰러지거나 달아남) | `escaped`(플레이어가 싸움터 밖으로 물러남, allow_flee) | `lose`
- 누가 어떻게 됐나: `d.combat_view.human_report()` → `[{ id, name, kind, out: "down" | "fled" | "fleeing" | "", pos, hp, state }]`
- 사람 하나의 spec: `id`, `kind`(프레임 종류), `name`, `weapon`(club 내리치기 · pole 찌르기 · both), `hp`(기본 60), `flee_at`(체력 비율, 0이면 끝까지), `at`(자리 이름·[x,z]) 또는 `offset`(싸움터 가운데 기준), `dmg`·`wind`(배율)
- 행동: 거리를 두고 맴돌다(ready) → 공격 차례를 얻으면(**한 번에 한 명**) 다가가 → 예고(땅에 부채꼴/줄 + 치켜듦, 앞 60%만 플레이어를 따라 돔) → 내리치기/찌르기 → 거둠. 맞으면 움찔(포이즈), 모아 베기에 비틀, 체력이 `flee_at` 아래면 등을 돌려 `flee_to` 쪽으로 달아난다(쫓아가 쓰러뜨릴 수 있다). 체력 0은 **쓰러짐(fall — 죽이지 않는다)**.
- 플레이어 쪽: 받아밀기(SKILL_GUARD_SHOVE)가 사람 적에게도 통한다(`take_hit(…, src)`). 조준·막기 방향·화살은 가장 곧은/가까운 상대를 고른다(`cbattle.aim_foe`·`nearest_foe`).
- 수치: `scripts/combat/ctuning.gd` `T.human`(hp·walk·run·hold 거리·swing/thrust 예고·판정·피해·포이즈·flee 값). 판정 순간 비율 swing 0.62 · thrust 0.55.
- 틀 변경(작게): `cbattle` — `mode`(tiger|human), `foes`, `claim/release`(공격 차례), `on_foe_out`. `cplayer` — 호랑이 대신 `aim_foe/nearest_foe`, `take_hit`의 `src`. `combat_view` — 적 그림 여럿(`foe_chs`), HUD는 남은 적 체력 합("밀수꾼 둘"), 카메라는 플레이어와 맞선 적 사이. 호랑이 판은 바뀐 데 없다(남원 회귀 PASS).
- 시험 봇: `gyeongju_test.gd combat_bot()`가 사람 판을 다룬다(예고에 구르기·막기, 달아나는 자도 쫓음). 다른 사건 시험도 이 함수를 본떠 쓰면 된다.

### 프레임(HUM_COMBAT_LIGHT)

- 공용 모듈 `tools/hum_combat_light.js`: `installHCL(kind, { weapon })` — 웹 리그 pose를 감싸 ready·swing·thrust·hit·fall·flee를 더하고, 사람 공통 전투 부위(환도·활·떡)를 빼고 무기(몽둥이 또는 장대 — 싸울 때 손을 따라 돌고, 장대는 걸을 때 지팡이처럼)를 손에 단다. `hclSpec`(내리치기·찌르기 맞는 순간 초당 24장, 달아남 한 주기 8장). 묶임(tied)·앉기 때는 무기를 숨긴다. 웹 코드(seolhwa/src)는 고치지 않았다.

## 5. 탁본 — `scripts/story/rubbing.gd`, `story/rubbings_data.gd`

- `SKILL_RUBBING`이 참이면 어느 공간(권역·노정)에서나 선다. 사건 조사 대상이 더 가까우면 그쪽이 먼저다. 안내 "탁본을 뜬다 · <이름>" → E → 쪼그려 먹을 두드리고 조사 카드.
- 대상: 손으로 둔 자리(경주 망부석·계림 비각·나정 비각, 남원 황산대첩비, 강릉 국사성황사 길 누운 선돌) + **배치 키트 자동**(장승 天下大將軍/地下女將軍, 돌장승, 비각, 성황당 돌무더기). 탁본은 정답을 주지 않는다 — 읽히는 만큼만, 닳은 획은 못 읽는다고 적는다(이겸의 원칙).
- 다른 사건이 결과를 바꾸려면 사건 데이터에 `"rubbings": [{ id, at, radius, label, title, text, when }]`(같은 id면 사건 것이 이긴다). 처음 뜬 것은 저장 `progress.rubbings`에 남는다.
- 강릉을 경주보다 나중에 하면 누운 선돌을 떠 볼 수 있다(城隍… 境/界) — 강릉 풀이를 바꾸지 않는 덧정보다.

## 8. 첫 조우 범(S0005) 보강 — 조정자 요청

온보딩의 구르기 안내가 범의 첫 "몸 낮춤"에 뜨는데, 범은 플레이어가 3m보다 멀 때만 몸을 낮춰 바로 붙은 플레이어는 안내를 못 봤다. **첫 조우 모드(`firstEncounter`)에서만** 범이 먼저 약 5m로 물러났다가 몸 낮춤 → 멈춤 → 돌진을 한 번 보인 뒤에야 앞발을 쓴다(`ctiger.gd` prowl의 `first_pounce` 갈래, 맞받아치기·반응 뒤 앞발도 그 전에는 막음). 물러설 자리가 없으면 3초 뒤 그 자리에서 몸을 낮춘다. 보통 싸움은 바뀌지 않았다. `namwon:C` 시험: 첫 조우에서 "몸을 낮춘다"가 앞발보다 먼저(PASS).

## 9. 남은 것·알려진 문제

- 소리가 없다(불이 꺼질 때 "쉿", 몽둥이 소리 — 자막·흔들림).
- 너럭바위 넓은 시점에서 밤 안개 때문에 먼 불은 작은 점으로 보인다(빛 판을 키웠다). 화면으로 더 맞출 여지가 있다.
- 망부석 둘레 숲 수관이 낮 시점에서 바위 일부를 가린다.
- 밤 동안 시간은 새벽 3시 36분에서 멈춘다(세 불을 다 가릴 때까지). 사건 뒤에는 정상으로 흐른다.
- 빠른 사격(SKILL_SNAP_SHOT)은 해금 변수만 — 활 축약 동작은 다음.
- 밀수꾼 짐(감포 객주 창고 표)은 꾸러미 소품뿐이다. 박규상 표식은 경주에 넣지 않았다(v2.2·v2.3 패치 노트에 경주 표식 지시 없음 — 황주 S4008이 재등장 자리).
- 장승·돌장승 탁본 글은 공용 문구다(지역마다 다르게 하려면 rubbings_data PLACES에 자리를 더한다).
