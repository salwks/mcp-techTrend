# terrain-data 보고서 — JL_NAMWON_UNBONG (남원·운봉·지리산 서부)

상태: **초안(에이전트 생성, 역사지리 검수 전)**. 계약서 §5 형식을 그대로 따랐고 형식 변경 요청은 없다.
다시 만들기: `python3 tools/region/fetch_dem.py && python3 tools/region/osm_fetch.py && python3 tools/region/build.py && python3 tools/region/qa.py && python3 tools/region/render.py` (캐시가 있으면 build는 약 25초 걸린다).

region.json에는 §5 필드 외에 **필드를 더했다**(형식을 바꾸지 않음): 각 항목의 `lat/lon`, `source`, `confidence`, `notes`. 랜드마크에는 `size_m`(필요한 실물 크기)와 `y`, 하천에는 `parent`·`catchment_km2`를 넣었다. 최상위에는 `projection`, `landuse` 메타, `modern_fixes`(지운 현대 흔적 목록), `hydro`, `build.warnings`를 두었다.

### terrain-engine이 알아 둘 것
- 하천 `points`의 세 번째 값은 **수면 y**이고, 상류→하류로 단조 감소한다. 하상은 수면보다 깊이(실제) B 2.5m · C 1.4m · D 0.6m만큼 낮게 파 두었다(게임 y로는 ×0.3). 모든 하천은 반폭 2.6m(게임) 이상으로 판다. 그래서 `width_m`=2.5인 D급 개울도 땅에는 약 5m 폭의 물길이 나 있다. 물 메시는 `max(width_m, 5.2)`로 그리는 편이 안전하다.
- 둑은 수면에서 0.8m(실제) 위부터 기울기 0.8로 오른다. 하천에서 실제 60m 밖으로 가면 원래 땅과 이어진다. 하천을 따라 4m마다 재 보면 양안이 수면보다 높은 비율이 97.4%다.
- 도로 폭은 실물 기준이다(대로 5m, 지선 3.5m, 마을길 3~4m, 산길 1.5m). 도로 횡단면은 높이맵에서 이미 평평하게 골라 두었다(하천 위는 건드리지 않음).
- 랜드마크와 자동 마을 자리는 바닥을 고르게 해 두었다. 남원읍성은 반경 85m를 고르게 했다.
- spawn = (−3227.8, 366.7). 남문(완월루) 남쪽 25m, 길 위다.

## 2. 수정한 현대 흔적 (명세 §33 금지 8)
1. **저수지·댐 호수 14곳 제거**(OSM 다각형 중 1.5ha 이상). 수면 평탄면과 둑을 마스크로 덮고, 둘레 산사면에서 조화 보간한 뒤 가운데를 V자로 낮췄다(실제 깊이 3~14m). 이어서 하천 단계가 물길을 다시 판다. 지운 곳은 덕산저수지 18.5ha(운봉 남쪽), 고기댐 7.6ha(원천천 상류), 마곡제 7.4ha, 옥계저수지 6.9ha, 무명 5.5ha(고남산 아래), 동마제 5.3ha, 공안저수지 5.1ha, 장안제 3.8ha, 행정제 3.5ha, 무명 2.6ha, 효기제 2.4ha, 매요저수지 2.1ha, 임성제 2.0ha, 집넘어저수지 1.9ha. 곳마다 복원 전후 고도를 `region.json.modern_fixes.reservoirs_removed`에 남겼다. 호수 영역의 최저 고도는 모두 원래 수면보다 5~40m 낮아져 골짜기가 되살아났다.
2. **남긴 것**: 광한루원 '연지'(조선 정원 못)와 1.5ha 미만 방죽·소류지 95곳(`reservoirs_kept`). 조선 후기 제언일 수 있고 DEM에 흔적이 거의 없다. 물로 표시하지 않았다.
3. **선형 현대 시설의 성토·절토 띠 314개 OSM way 덮음**(조화 보간, 터널 구간 제외): 광주대구고속도로(88고속도로), 순천완주고속도로, 전라선과 폐선, 국도(산업로·서부로·춘향로, 24번 국도 황산로 — 여원재 절토 포함).
4. **직강화 하천 사행 복원(가설)**: 평탄(실제 경사<0.6%)하고 곧은(굴곡도<1.04) 구간에 사인 사행을 더했다. 요천 1.9km, 람천 0.6km(운봉 고원), 광치천 0.28km, 원천천 0.24km, 백암천 0.12km(모두 게임 m). 진폭과 파장은 하천 폭에 비례한다. 1870년의 실제 물굽이는 고지도로 검수해야 한다.
5. SRTM 계열 DEM의 반점 잡음은 가우스 σ=2m(게임)로 줄였다. 남원 시가지 건물과 숲 지붕 높이 편향은 따로 지우지 않았다(남은 문제 참고).

**가설 목록(검수 필요)**
1. 통영별로 경유 순서: 전주→남원→여원재→운봉→인월→함양(신경준 『도로고』 체계, 지식 기반, 원문을 대조하지 못함). 길의 세부 경로는 A* 결과다.
2. 인월→실상사→산내→반선 길, 남원→광한루→요천→구례 방면 길, 남원 북문→전주 방면 길, 읍성 안 십자로, 남문 밖 장터길, 운봉 읍내길, 반선→뱀사골 산길: 모두 지형상 그럴 수밖에 없는 길이라는 가설이다.
3. 도강 방식: 요천 동쪽 = 섶다리(겨울~봄)/여울. 요천 광한루 앞 = 나루. 람천 운봉 = 징검다리. 해탈교 = 섶다리. 자동 도강점은 B급(요천 외) 섶다리, C급 징검다리, D급 여울(대로는 돌다리)로 기본값을 매겼다.
4. 남원읍성의 정확한 네 변 위치(한 변 620m 정방형 가정)와 동헌·향교·장터 위치.
5. 직강 구간 사행 복원의 모양.
6. 자동 마을 후보 14곳(`auto_village_*`)과 이름 없는 고개 14곳(`무명 고개`): 입지 규칙과 도로 단면에서 만든 것으로, 사료가 없다.
7. 여원재 성황당과 아랫주막.
8. 대동여지도·용성지 등 원자료와 대조하지 못했다(계획서 §1.3). 모든 항목이 사람 검수 대기다.

## 4. 수계와 분수계
- 흐름 계산은 8m 격자 D8로 했다. 고증 제어선(OSM 하천선)을 DEM에 새겨(요천·람천·만수천·임천 25m, 그 밖의 이름 하천 12m 실제 깊이) 계산 결과가 고증을 따르게 했다(계획서 §4).
- 결과: B 2(요천·람천), C 10(만수천, 광치천, 주촌천, 원천천, 백암천과 그 지류, 람천 지류 3), D 80. 등급을 가른 집수면적(실제)은 B ≥80km², C ≥8km², D ≥1.2km²다. 단 요천은 B, 람천과 만수천은 C를 하한으로 강제했다.
- 람천: 운봉 남쪽(덕산·주촌) → 운봉 → 황산 앞 → 인월 → 실상사 앞(만수천 합류) → 권역 밖 임천·낙동강. 만수천: 달궁·뱀사골 물 → 반선 → 산내 → 람천.
- **분수계**: 여원재 둘레 200m 안에 섬진·낙동 두 유역이 모두 있다. 운봉 관아는 낙동강 유역, 남원은 섬진강 유역이다(QA Q2). 운봉고원 남쪽 고기리 쪽은 원천천을 따라 서쪽 요천(섬진강)으로 빠진다. 이것은 실제 지형 그대로다.

  - **재현성 확인**: 남원을 `SEOLHWA_OUT`(임시 폴더)로 다시 빌드했다. height·landuse·climate·region.json·map.png·map.json의 md5가 모두 같다. qa.json은 내용이 같고, 폴더 크기 표시만 다르다. `region_data/JL_NAMWON_UNBONG/`은 건드리지 않았다.
- 바뀐 공용 모듈은 모두 남원 기본값을 그대로 지킨다.
  - `common`(설정 로드), `hydro`(설정 known·sea 출구·`taper`), `modern_fix`(남길 이름 설정), `landuse`(`area_target`·`avoid`·자동 후보 경계), `profiles`(권역별 고산 하한·해안 거리), `qa`(남원 전용 검사는 남원에만), `render`·`render_map`.
- 새 파일
  - `build_region.py`: 바다(해발 0.5m 이하 + 가장자리와 이어짐, 바닥 −1.5…−20m)·석호를 다룬다. 성곽 직사각 성벽과 성문 통로(QW), 용천수 취락, 오름 강조, 범람지 피하기도 여기서 한다.

### 남은 문제·요청
1. 좌표는 OSM(제주는 Overpass 이름 조회)과 통설로 정했다. 경주·강릉의 Nominatim·Overpass 조회는 요청 제한으로 거의 실패했다. 그래서 경주 동경관·부윤 관아·성곽 크기, 강릉 관아·향교·구산역·반정, 김녕사굴 입구, 송당 본향당은 **추정 또는 가설**이다. 사람 검수가 필요하다.
2. 해안 매립지(제주 탑동·제주항, 감포항, 강릉 안목)는 DEM에서 지우지 못했다. 방파제는 15m 격자라 거의 보이지 않는다.
3. 경포호 윤곽은 지금 모습이다. 1870년에는 호수가 더 넓었다(가설).
4. 엔진 요청
   - 바다를 `sea.y` 평면으로 그려 달라.
   - 경포호를 `lakes`(y·outline)로 그려 달라.
   - 하천 물 폭은 `widths`(점별)를 쓰면 상류가 좁아진다.
   - kit-landmark에 새 kit 이름(`landmark/gyeongju_eupseong`·`jeju_eupseong`·`gwandeokjeong` 등)이 필요하다. 목록은 region.json의 `landmarks.kit`에 있다.
