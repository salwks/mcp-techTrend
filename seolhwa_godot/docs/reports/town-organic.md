## 1. 참고에서 뽑은 규칙(요약 — 자세히는 두 문서)

- **길**: 큰길(성문 축·십자로·둘레길) → 굽고 갈라지는 갈래길 → 고샅(막다른 길도). 문 앞·장터·갈림목은 넓어져 마당.
- **필지·담**: 필지는 길에 붙어 **빈틈 없이** 이어지고(맞담), 앞 너비·깊이·옆선이 제각각. 집마다 담이 필지 가장자리를 따른다. 읍내 기와집·관아 담은 곧고 각지며, 마을 흙담·돌담·싸리울은 모서리가 둥글고 조금씩 굽는다(ACON 47649 평면·2204 초가마을 · 낙안읍성 해설 '터 놓은 대문'·'맞담').
- **집**: 한 필지에 2~4채(안채 + 헛간채·아래채·가게채 — 낙안읍성 필지 135~620㎡, 가운데 470㎡). 큰길가는 가게채가 길로 트인다.
- **구역**: 관아·객사(북 가운데) → 향리·기와집(관아 둘레) → 시전(큰길) → 서민(남·성 밖) → 밭·숲(바깥). 삼단일묘(사직 서·여단 북·성황 진산 쪽)·향교(동)·장시(남문 밖).
- **크기**: 인물이 든 3D 그림이 없어 문·기단·창 비례로 어림 — 지붕이 크고 처마가 깊으며 기단이 무릎~허리.

## 3. 고을 짜임 생성기(`kit/bldg/organic.gd`)

1. **길**: 큰길(region 길·구역 설정의 새 큰길 — 성 안 둘레길 등)은 고정. 갈래길은 큰길에서 36~56m마다 비스듬히 나가 매끈하게 굽고(땅 기울기가 있으면 등고선 쪽으로 최대 35%), 다른 길에 닿으면 T자로 잇는다. 나란한 길은 40~44m 안에 두지 않는다(마당집 두 줄이 등을 맞댈 깊이). 고샅은 24~40m마다, 막다른 길 허용.
2. **블록 필지(맞담)**: 땅 1m 칸마다 가장 가까운 길(·쪽)을 정하고(보로노이 띠), 길마다 양쪽 띠를 **끊김 없이** 앞 너비(17~23m, 종류별 배율)로 자른다. 옆선은 길 법선(이웃과 같은 선), 뒤는 띠 끝(다른 길 띠와 만나는 곳 − 0.5m 뒷길). 앞 변은 길을 따라 여러 마디로 꺾인다. 안 드는 끝은 옆 필지에 붙이거나 밭으로 — 블록에 빈터를 남기지 않는다.
3. **마당집**(`_fill_court`): 뒤에 몸채(좁으면 박공을 길로 돌림) → 옆에 곁채(마당을 봄, 안 되면 몸채 옆 ㄱ자) → 앞에 앞채(가게채는 길로 트이게, 그 밖은 등을 길로) → 가운데 마당 → 대문은 앞 담의 앞채·곁채를 비킨 자리(담이 꺾이는 모서리는 피함). 양반가·주막 등은 기존 묶음(compound)을 필지 틀에 맞춰 넣는다.
4. **담 길**(`_wall_runs` + 키트 `bldg/wall`): 한 줄 = 대문·건물에 끊기지 않고 이어진 담 한 덩이(마디마다 miter, 기와·이엉 갓이 굽은 줄을 따름). 까닭을 `params.why`에 적는다.

| 까닭 | 꼴 |
|---|---|
| 계획된 기와 갓 담(읍내 기와집·양반가)·평지 | 곧은 줄 · 각진 모서리 |
| 곧은 길 앞 / 곧은 필지 경계 | 곧은 줄 |
| 굽은 길 가장자리 | 앞 담이 길 마디를 따라 꺾임 |
| 비탈(옆·뒤 담이 등고선 방향) | 등고선을 따라 안쪽으로 굽음(담 위는 터 고른 단 위라 수평 — 계단식) |
| 마을 막돌담·싸리울 | 손으로 쌓아 0.1~0.25m씩 굽음 |
| 흙담·돌담·싸리울 모서리 | 둥글게(반지름 ≤1.3m) |
| 마당 나무 곁 | 나무 둘레 1.7m를 비켜 감 |

   평면도 `tools/bldg/town_map.gd`는 담을 까닭으로 칠한다(굽음 파랑·곧음 밤색). 화면 `walls_reasons.jpg`.
5. **꾸밈·지형**: 문 앞 정자나무·갈림목 우물·평상(길 띠를 비킨 자리), 마당 나무, 장독대, 읍내 빈 땅은 채마밭·텃밭(풀숲 대신), 성 밖 빈 땅은 소나무·참나무·짚가리. 비탈 필지는 바깥 낮은 변(앞 변 빼고)에 **막돌 축대**(`village/stone_terrace`, 낙차 0.45m 넘으면).
6. **결정성**: 씨앗이 같으면 같은 결과(시험: 같은 씨앗 두 번 → 같은 파일). 옛 배치는 이 파일 머리 `supersede`로 빠지고 원본(namwon.py 생성물)은 안 고친다 — 되돌리기는 파일을 지우거나 `--revert`.

## 4. 도시·마을 빌더(`kit/bldg/settlement.gd`)

`S.build(cfg, height, rivers)` — cfg `{ tier: metro|city|town|village, kind(마을: banchon|minchon|sanchon|yeokchon), walled(소도시), c, ry(로컬 +z = 남문·안산), seed, region, size, prefix }` → `{ items, alleys, majors, districts, urban, log }`. 규칙 표와 근거는 `settlement-rules.md` §1~§6.

- 대도시: 300m 읍성·4문 옹성, 감영(가운데 북)·객사(서)·부영(동)·향청·영리청·사창·원옥·홍살문·하마비·박석 마당, 남문길·동서길 시전(큰길가 65% 가게채), 북서 중인·북동 양반·남쪽 시전·성 밖 장시(좌판 세 줄·주막)·서민, 삼단일묘·향교·비보 숲.
- 중도시: 200m 읍성, 객사(남문 축 북쪽 가운데)·관아(동)·향청·작청(관아 앞 길 건너)·사창(서북)·원옥(관아 동남), 성 안 북(관아·향리)·남(시전·서민)·성 밖 남(장시·서민).
- 소도시: 130m 읍성 또는 무성읍치, 현 관아 일곽·객사·사창·5일장 좌판.
- 마을: 반촌(종가 뒤 높은 곳·서당·정자·위 양반/아래 민가), 민촌, 산촌(너와·비탈 축대), 역촌(역사·마방·원 — 큰길가). 어귀 장승·솟대·당산나무 마당·마을숲(수구막이)·서낭당·우물.
- 견본: `tools/bldg/settlement_place.gd` → `shots/town_organic/_place_<이름>/`(시험 배치 — 세계 배치 안 바꿈). 성곽 등급은 남원 남쪽 구릉(물길 없는 360×400m, 높이 12~27m — 남원 분지 평지는 어디나 개울·강이 지나 성벽이 물을 건넌다), 민촌·역촌은 서쪽 개울가 평지, 반촌·산촌은 기울기 17% 비탈.
- 지형: 생성 때 `height.png`를 읽어 길이 등고선을 따르고 비탈 필지에 축대·등고선 담을 낸다. 필지는 터 고르기(flatten)로 앉는다. 산 지형 작업(claude/mountain-terrain)이 높이장을 바꾸면 생성기만 다시 돌리면 된다(배치 y는 null — 땅을 따름). 산 지형 작업 트리는 건드리지 않았다.
